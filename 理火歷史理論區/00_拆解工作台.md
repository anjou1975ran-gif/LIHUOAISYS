# 理火歷史理論拆解工作台

法位：HISTORICAL_RESEARCH_WORKBENCH / NOT_CANONICAL / NOT_RUNTIME / NOT_RATIFIED

本檔專門拆解早期理火總體系、歷史理論、舊系統、SAC、雷達版本、生成動力學會議與尚未進入現行 OS 的概念分支。它是研究工作台，不是新 OS，也不替歷史理論補發成立證書。

## 拆解原則

1. 先讀原件，再命名；不以現行術語改寫早期原意。
2. 原文直接寫出的內容、後來的推論、跨版本比較必須分欄。
3. 不因未進 OS 就判定無價值；也不因版本較新就判定較正確。
4. 不把後來概念回鑄成早期原文已經包含的內容。
5. 不因名稱相同就判定同一理論；比對定義、問題對象、機制、邊界與責任位置。
6. 歷史材料不自動成為現行方法、模組或 Runtime。

## 歷史法位

UNREVIEWED、SOURCE_VERIFIED、STRUCTURE_EXTRACTED、LINEAGE_MAPPED、SURVIVED、ABSORBED、BRIDGE、DORMANT、SUPERSEDED、REJECTED、DUPLICATE、NEEDS_REVIEW。

## 譜系關係邊

INSPIRED、FORMALIZED_AS、SPLIT_INTO、ABSORBED_BY、CORRECTED_BY、REJECTED_BY、RETAINED_AS、REACTIVATED_BY、SUPERSEDES、DUPLICATES。

每條關係都必須附來源證據；證據不足時標記為待驗假說。譜系採 Graph，不強迫形成單一路徑樹。

## 工作順序

~~~text
來源清冊 → 原件核對 → 概念拆解 → 版本比較 → 譜系關係 → 現行對照 → 證據缺口 → 法位判定
~~~

先拆，不先復活；先比對，不先合併；先保留證據，不先宣告完成。
