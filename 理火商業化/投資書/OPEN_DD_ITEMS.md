# 投资人尽调待验证问题 / Investor Due Diligence

V0.1 · LIHUOOS V1.4.2 · 2026-11-19

## 技术尽调问题 / Technical Due Diligence


尽调应索取可重跑材料、失败样本和现场回执。以下项目在 V0.1 均待取得验证结果。

Diligence should ask for replayable packages, failed cases and observed receipts. Each item below remains open in V0.1.

### DD-01 模型迁移 / Model migration

用相同任务与配置在不同模型上比较，记录质量、重写量、拒放与回滚。

Compare fixed workloads and profiles across models. Track quality, reauthoring, non-release and rollback.

### DD-02 成本 / Lifecycle cost

索取同质量门槛的成本台账、延迟、人工复核及修复数据。

Request quality-matched ledgers for cost, latency, review and remediation.

### DD-03 对应性 / Mechanistic correspondence

预注册可证伪的 PATH 假说，在获授权模型上观测并做对照介入。

Preregister falsifiable PATH hypotheses and run controlled interventions on an authorized model.

### DD-04 独立执行 / Independent runtime

用同一配置演示正常执行、越权拦截、缺凭据 HOLD 和故障恢复。

Demonstrate success, unauthorized-action blocking, missing-receipt HOLD and recovery on one profile.

### DD-05 知识产权与量子 / IP and quantum

核查来源权属、适用许可、可保护范围、先前技术和接口可行性。

Check rights, licenses, protectable scope, prior art and interface feasibility.
