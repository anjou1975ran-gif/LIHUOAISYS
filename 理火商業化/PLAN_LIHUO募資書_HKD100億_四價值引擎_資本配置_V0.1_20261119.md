# 2｜WHY NOW

募資書必須先回答「為什麼是現在」，而不是先講理論史。

核心假說：

1. Foundation model 能力快速上升，但模型供應逐漸多元化。
2. 企業真正難題開始從「模型能不能回答」移向「結果何時有資格使用」。
3. Prompt、Agent workflow、filter、custom code 形成大量重複工程。
4. 模型越能生成，越需要 generation control / qualification / responsibility。
5. 分析能力可能商品化，但具有 provenance 的一手資料與實體採集網路不會自動商品化。
6. 下一代模型若仍用現有訓練邏輯，可能持續面對 qualification theater、reward gaming、over-refusal 等問題。
7. 量子／混合計算若未來進入實用階段，未決關係態的治理可能形成新的 Runtime 問題。

最短投資句：

> **Model capability is becoming abundant. Qualified generation, proprietary real-world data, and portable governance may become the scarce layers.**
