# 0｜一句話定位

> **不是再做一個分析 App，而是先取得市場上最稀缺的東西：來源乾淨、時間新鮮、方法可追溯、可持續取得的一手情報。**

分析能力會快速商品化。

真正可能形成長期資產的，是：

~~~text
SOURCE NETWORK
↓
CLEAN DATA / PROVENANCE
↓
LIHUO QUALIFICATION
↓
INTELLIGENCE PRODUCTS
↓
DECISION PRODUCTS
~~~

本子公司不是監控公司，也不是資料掮客。

它的核心資產候選是：

> **一個能合法、持續、可追溯地取得真實世界訊號的實體與數位採集網路。**

# 1｜「乾淨」的定義

乾淨不等於「資料內容一定正確」。

乾淨至少表示：

- 來源已知；
- 收集時間已知；
- 收集方法已知；
- 同意／授權／許可狀態可核對；
- 去重與污染狀態可標記；
- 原始資料與加工後資料可分離；
- 修改歷史可追蹤；
- 新鮮度可量測；
- 樣本範圍可描述；
- 不把合成資料冒充真實觀察；
- 不把模型推估冒充現場資料。

最短式：

~~~text
OBSERVATION
!=
SIMULATION

SOURCE
!=
INFERENCE

CLEAN
!=
TRUE

CLEAN
=
TRACEABLE + LEGALLY ACQUIRED + METHOD-KNOWN + CONTAMINATION-LABELED
~~~

# 2｜為什麼值得另立子公司

這條業務與 LIHUO Runtime 有強關聯，但資本與風險結構不同。

Runtime 主要是：

- 軟體；
- 語義資產；
- 模型適配；
- 驗證；
- 企業部署。

乾淨情報則可能需要：

- 實體終端；
- 場地；
- 物流；
- 維護；
- 獎勵或補貼；
- 區域營運；
- 資料授權；
- 隱私與同意管理；
- 現場採集治理。

因此適合另立子公司，以便：

1. 隔離 CAPEX；
2. 隔離資料法規與隱私責任；
3. 單獨核算 Unit Economics；
4. 可接受產業夥伴、地方營運商或策略投資；
5. 可將資料資產授權給 LIHUO Core 與外部客戶；
6. 保留未來獨立融資、JV、分拆或上市的可能性。

# 3｜採集網路候選

本版不鎖死設備形式。

候選包括：

- 免費／補貼式販售或試用品設備；
- QR / Reward interaction terminals；
- 商戶合作終端；
- 活動與場域採樣節點；
- 自願回報／調查介面；
- B2B 現場資料接入；
- 經授權的感測與營運數據；
- 其他合法、可同意、可追溯的一手採集方式。

先前提出的：

> **免費設備／商品 + QR 或 Reward 換取自願資料**

可作為候選 acquisition model。

但：

~~~text
INCENTIVE
!=
CONSENT BY DEFAULT

DEVICE DEPLOYMENT
!=
RIGHT TO COLLECT EVERYTHING
~~~

資料欄位、用途、保留期限與授權範圍必須獨立成立。

# 4｜AI 在資料採集中的角色

AI 不負責宣判「這個人說的是真話」。

AI 可做：

- 完整度檢查；
- 時間／來源一致性檢查；
- 重複與異常模式檢查；
- provenance 分類；
- 方法品質評估；
- 樣本偏差提示；
- 欄位缺口；
- 污染風險；
- 需要人工複核的事件排序。

因此：

~~~text
AI JUDGES DATA QUALITY
!=
AI DECLARES WORLD TRUTH
~~~

# 5｜商業產品

子公司可以形成多層收入，而不是只賣原始資料。

## L1｜Clean Data Feed

按時間、地區、產業或主題交付具 provenance 的資料流。

## L2｜Proprietary Index

將長期一手資料壓成可追蹤的產業、消費、價格、需求、供應或行為指標。

## L3｜Qualified Intelligence

使用 LIHUO 對來源、矛盾、缺口與推論範圍做資格治理後，形成情報產品。

## L4｜Decision Product

針對企業、投資、供應鏈、零售、品牌、地產或其他合法商業場景，提供可操作但保留證據邊界的決策產品。

## L5｜Model-Grade Data Licensing

把合法可授權、來源清楚、污染標記完整的資料集提供訓練、評估或模型驗證。

硬鎖：

~~~text
RAW DATA SALE
!=
ONLY BUSINESS MODEL
~~~

真正較高價值的候選是：

> **獨家來源網路 + 長期序列 + provenance + qualification + decision interface。**

# 7｜為什麼它可能比「分析 AI」更值錢

分析模型的邊際能力可能隨基礎模型競爭快速商品化。

但：

- 獨家來源；
- 歷史序列；
- 實體採集位置；
- 授權關係；
- 高密度覆蓋；
- 可追溯方法；
- 乾淨資料資產；

不會因為下一代模型發布就自動出現在競爭者手上。

所以投資命題不是：

> 我們的 AI 比別人更會分析。

而是：

> **當大家都能分析時，誰先擁有可合法使用、可持續更新、可驗證來源的現實資料。**

# 9｜資本釋放方式

不是一次鋪滿。

建議使用 Stage Gate：

~~~text
G0｜Acquisition Model Validation
→ 收集是否合法、有人願意參與、資料是否有商業價值

G1｜Pilot Network
→ 驗證設備、獎勵、維護、資料品質與隱私流程

G2｜Initial Regional Rollout
→ 驗證密度、資料時效、客戶付費與運營成本

G3｜Multi-Region Scale
→ 只有在前述 economics 成立後擴網

G4｜Data Moat Expansion
→ 長期序列、專有指標、模型資料授權與情報產品
~~~

資本可以預留 40 億港幣，但每一階段實際放款應由採購、合規與商業驗證觸發。

# 10｜必須先打掉的風險

後續會議／投資 DD 必須打：

1. 資料是否真的比公開資料更有價值？
2. 硬體網路是不是不必要的昂貴中介？
3. 有沒有更便宜的 partner network 可以取代自建？
4. 使用者是否願意交換資料？
5. Incentive 會不會污染樣本？
6. 地區偏差是否使情報失真？
7. Privacy / consent 是否足以支持商業授權？
8. 客戶為 raw feed、index 還是 decision product 付費？
9. 資料新鮮度的半衰期多快？
10. 網路規模是否真的形成資料護城河？
11. 模型與 synthetic data 是否能低成本替代部分需求？
12. CAPEX 回收是否優於純軟體業務？

# 11｜邊界

禁止：

- covert surveillance；
- 無合法基礎的個資收集；
- 未經許可出售受限制個資；
- 把 synthetic respondent 冒充市場樣本；
- 把 AI 推論冒充現場觀察；
- 為了資訊優勢破壞同意、合約或法律；
- 把「乾淨」寫成「保證正確」。
