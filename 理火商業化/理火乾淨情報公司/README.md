## 三、第一版三條商業路徑（未排序）
1. **VC-FIELD**｜門店活動、貨架及促銷現場執行證據，按核查場次／店月／專案收費候選。
2. **VC-BUYER**｜企業私有的供應商報價、交期承諾、採購與收貨證據核對，按月／專案收費候選。
3. **VC-P1**｜合法授權的價格與缺貨監測情報，按訂閱／覆蓋收費候選。

另保留 `CONSENT_BASED_DATA_COOPERATIVE` 作 `DORMANT / RIGHTS_UNPROVEN` 方向，不因本版三路比較就消滅。

**沒有已驗證的商業 winner。** 不預設資本上限或下限；只分析邊際成本、總成本、訂價、回款與可回收性。沒有客戶、合法來源、工程或成本驗證時不得稱為已可行。
