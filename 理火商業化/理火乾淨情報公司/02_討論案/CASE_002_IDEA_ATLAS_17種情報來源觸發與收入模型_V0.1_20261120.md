## II｜五種生成機制（不是五個固定部門）
1. **買家帶需求：** A-01 / A-07 / A-10 / A-16。買方要可解決的問題，平台拆成可授權的查核任務。
2. **源頭自己想發：** A-03 / A-11 / A-14。源頭發訊號的利益可能與客戶相衝突，需獨立標註與驗核。
3. **城市微觀察：** A-02 / A-09 / A-12。參與者自願，非偷拍或持續追蹤；質量與採樣框架比下載量重要。
4. **反證、沉默與撤回：** A-05 / A-06 / A-13 / A-15 / A-17。驗證失敗、訊號失效或無異常本身可能有付款價值，但不可把「沒有觀測」變「沒有發生」。
5. **合法情報包與分發：** A-04 / A-08，以及上述已合格來源。高價需要合法授權、買家決策價值或時效；低價打包也不能洗掉低品質與權利限制。

## III｜保留的對立與反例
- **下載量高、收入可能低：** 人人貢獻一筆未核 APP 內容，平台可能因複核成本破產。
- **高級來源仍會說錯：** 來源 track record ≠ 單筆報告 E 級，保密情報更不會因來源高級就可出售。
- **一筆稀有訊號可以高價，但可能只值一個驗證委託：** 沒核實時不能向客戶作已證事實出售。
- **低價來源可合成高價報告，但只在授權重用、樣本有效且買方真正有需求時成立。**
- **傳播不等於金字塔獎酬：** 不靠會員入門費、下線人頭或分層抽佣；任何推薦激勵需逐案合法審查。
- **大資本路線仍有位置：** 若實體採集網能靠正向現金流收回成本，不因它比 APP 貴就先淘汰。

## IV｜下一步最小可區分問題（未授權實際執行）
- 若買方要核對「某促銷是否真的在店面發生」，哪個觸發方式可用最少合法採樣成本取得足夠證據？
- 若由商戶自願推送有貨訊號，買方願為驗真/更正付費，還是商戶願為曝光付費？
- 若來源層級會改變任務機會，如何防刷評、串通與濫用，如何降級/申訴？
- 若訊號本身低價卻大量存在，什麼合規採樣與統計條件才有資格打包？
- 若買家把情報視為每季關鍵決策，能否支持高價驗證而非高價謠言？
