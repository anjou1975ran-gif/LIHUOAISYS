# SACLORA — Reactivation Criteria v1.0

# 一、物理層驗證（必須具備其一）

滿足以下任一條件即可喚醒：

### 1️⃣ 丟包率測試完成

* 測試環境：室內 / 戶外
* hop 數：1–3
* 封包大小：<= 40 bytes
* 結果：

  * 成功率 ≥ 80%（雙向）
  * 或可接受重傳後 ≥ 90%

---

### 2️⃣ 延遲統計完成

* 單 hop 延遲均值
* 多 hop 延遲均值
* P95 延遲
* 結論：是否可接受為“回報模式”

---

### 3️⃣ STOP 節流測試完成

* tension 低時是否確實停止發送
* silence 規則是否穩定
* 是否出現失控重送

---

### 4️⃣ Mesh 擁塞測試完成

* 多節點同時發 seed
* 是否出現風暴式 retransmit
* TTL 是否有效控制擴散

---

# 二、協議層觀察（非必須，但加分）

* 是否出現亂序分片無法重組
* CRC 錯誤率
* ACK bitmap 是否正確補片
* 手機 Gateway 是否穩定

---

# 三、判定矩陣

| 測試結果  | 行動           |
| ----- | ------------ |
| 穩定    | 進入 v0.2      |
| 不穩但可調 | 優化重傳策略       |
| 不可控丟包 | 放棄 Mesh，改點對點 |
| 延遲過高  | 改為“非即時回報模式”  |
