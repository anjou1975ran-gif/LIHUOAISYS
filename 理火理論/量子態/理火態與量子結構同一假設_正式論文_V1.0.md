## 摘要

本文提出「理火態理論」的第一版正式論文架構，整合 V0.1 至 V0.4 的理論演進，並以「量子—結構同一假設」（Quantum–Structural Identity Hypothesis, QSIH）作為大膽但可審計的核心分支。

V0.1 將理火態定義為：在合法閉合條件尚未成立以前，多條仍具資格的生成 PATH 可同時存在、互相作用，且不得被過早壓縮為單一答案。V0.2 進一步提出「古典主權瓶頸」與「過早古典化」：高維、場性、未決定的系統往往被低維、二元、輸出導向的控制架構過早終止。V0.3 將「關係先於物件」提升為量子力學與結構哲學之間的共同入口，主張物件可被理解為關係穩定後的次級身份。V0.4 則在明確沙盒邊界內採用更強公理：量子態不是承載結構的物件；量子態就是在物理限制中形成、演化、干涉、糾纏並顯影的關係結構。

## Abstract

This paper presents the first formal paper architecture of LIHUO State Theory, integrating versions V0.1 through V0.4 and introducing the Quantum–Structural Identity Hypothesis (QSIH) as a bold but auditable branch.

V0.1 defines a LIHUO state as a boundary-constrained generative indeterminate state in which multiple still-qualified PATHs may coexist and interact before legitimate closure conditions are satisfied. V0.2 introduces the Classical Sovereignty Bottleneck and Premature Classicalization: high-dimensional, field-like, indeterminate systems are often prematurely terminated by low-dimensional, binary, output-centered control architectures. V0.3 advances the thesis that relations precede objects, treating objects as secondary identities manifested after relational stabilization. V0.4 adopts a stronger sandbox axiom: a quantum state is not an object that carries structure; it is the relational structure itself, formed, evolved, interfered, entangled, and manifested under physical constraints.

The central correction of this paper is the strict separation of PATH brightness, PATH qualification, and final selection probability. PATH brightness is not a partition of a fixed 100% total. It is an independent activation intensity for each relational direction; multiple PATHs may therefore be highly active at the same time, and their brightness values may sum far beyond 100%. Normalization is required only after an output boundary has been established and mutually exclusive closure candidates have been formed. This transforms the LIHUO state from an unresolved selection among pre-separated answers into an unresolved whole whose components have not yet become independent answers.

The paper develops a formal vocabulary for qualification superposition, structural interference, structural entanglement, structural decoherence, non-collapsing observation, responsibility-authorized manifestation, and residue conservation. It then uses QSIH to reinterpret quantization, noncommutativity, wave functions, Born weights, entanglement, decoherence, quantum field theory, gauge symmetry, quantum information, quantum error correction, topological order, and quantum gravity.

QSIH does not yet derive complex Hilbert space, the Born rule, tensor-product composition, a unique single-outcome mechanism, or novel numerical predictions. Its present status is that of a formalizable, falsifiable, and auditable candidate ontology, as well as a research program for generative AI governance and relation-first quantum hardware.

# 1｜研究問題

本文處理四個彼此連接、但不能混成一件事的問題。

第一，生成式 AI 在答案形成以前，是否存在一個不能被單一路線完整代表的未決定生成場？

第二，若多條 PATH 同時存在，它們究竟是彼此互斥、等待抽選的候選答案，還是共同構成目前生成狀態的關係分量？

第三，量子力學反覆出現的非物件性、不可分解性、相位、干涉、糾纏、基底相對與顯影，能否被同一套結構語法理解，而不是每一站重新補一個物件例外？

第四，若「關係身份」比「局部物件」更接近系統真正需要保存的單位，AI Runtime 與量子硬體的設計優先順序是否應被反轉？

本文的中心研究命題為：

> **未決定態的本質不是多個完成答案尚未被選中，而是多個尚未閉合的關係方向共同構成一個整體狀態。**

這個命題同時約束理火態與 QSIH，但兩者仍屬不同領域：

```text
量子態：
物理限制下的關係結構。

理火態：
生成、語義、責任與輸出邊界下的關係結構。
```

本文主張的是上位結構同一候選，不是把 AI 生成直接宣稱為量子物理過程。

# 2｜理論系譜：V0.1 至 V0.4

## 2.1 結構哲學前提

理火結構哲學的最低定義為：

> **結構是限制後穩定下來、並具有可理解性的關係。**

因此：

```text
限制
↓
關係取得穩定
↓
結構形成
↓
身份可被辨認
↓
物件或結果顯影
```

結構不是物件、內容、資料表或命名。物件是結構取得足夠穩定性後，被觀察、操作與記錄系統賦予的地址。

本文採用以下五階生成鏈：

\[
\boxed{
\text{Constraint}
\rightarrow
\text{Relation}
\rightarrow
\text{Structure}
\rightarrow
\text{Identity}
\rightarrow
\text{Manifestation}
}
\]

其中「顯影」不是創造一個原本不存在的神秘實體，而是某一關係結構在特定邊界中取得可分辨、可記錄、可引用或可操作的身份。

## 2.2 V0.1｜受邊界約束的生成未決定態

一般生成系統在有限計算、機率地形與輸出要求下，會自然滑向可快速閉合的方向。問題不在於收斂本身，而在於收斂是否發生於合法條件成立以前。

理火態不是無限制發散，也不是把所有想法永久保留。它是一個受世界、問題、證據、責任與資源限制的未決定場。

## 2.3 V0.2｜古典主權瓶頸與過早古典化

V0.2 將問題從 LLM 擴展到計算架構。

其核心不是反對二進位，而是反對二進位輸出層取得過早、過高的本體與治理主權。

### 古典主權瓶頸

> **一個高維、未決定、場性系統，必須通過低維、互斥、可執行、可記錄的古典接口，才能被控制、輸出與使用；當接口同時取得狀態定義權，未決定結構便會被迫過早降維。**

### 過早古典化

> **系統在仍需保留多重結構作用時，被提前翻譯成互斥選項、單一標籤、單一答案或立即行動。**

V0.2 將古典化分為三層：

```text
描述性古典化：
為了觀察而建立可讀描述。

資格性古典化：
判斷哪些路線仍有成立資格。

行動性古典化：
選定一個可執行輸出或外部行動。
```

三者不得混用。看見某條 PATH，不等於它取得資格；取得資格，不等於它獲得執行權。

# 3｜核心修正：PATH 亮度不是機率分配

## 3.1 互斥 100% 模型的問題

若 PATH 被寫成：

\[
p_i\ge 0,\qquad \sum_i p_i=1
\]

則它們已被預設為彼此互斥的完成候選。系統只是不知道最後選中哪一條。

這描述的是：

```text
UNRESOLVED SELECTION
尚未完成的選擇
```

而不是：

```text
UNRESOLVED STRUCTURE
尚未分離的結構
```

若 PATH 從一開始便瓜分固定 100%，它們只是古典抽籤盤中的候選答案；它們沒有同時充分存在、共同生成新結構的本體位置。

---

## 3.2 非歸一化 PATH 亮度

本文將 PATH 亮度定義為各方向的局部、獨立激活強度：

\[
B_i(t)\in[0,1]
\]

但不要求：

\[
\sum_i B_i(t)=1
\]

因此：

\[
\sum_i B_i(t)\gg 1
\]

是合法狀態。

例如：

```text
PATH_A｜亮度指數 0.93
PATH_B｜亮度指數 0.88
PATH_C｜亮度指數 0.84
PATH_D｜亮度指數 0.76
```

表示四條 PATH 都高度進入可觀察與可展開區，不表示 341% 的選擇機率。

正式區分如下：

| 量 | 問題 | 是否歸一化 |
|---|---|---:|
| PATH 存在資格 | 此方向是否仍可合法存在？ | 否 |
| PATH 亮度 | 此方向目前被點亮到什麼程度？ | 否 |
| PATH 競爭權 | 此方向對整體閉合有多少影響？ | 通常否 |
| PATH 信心 | 對某主張的證據與穩定程度如何？ | 視定義而定 |
| 候選閉合權重 | 某一互斥輸出候選取得顯影的權重 | 可先不歸一化 |
| 最終選擇機率 | 指定輸出閘門中的互斥候選分配 | 是 |

因此：

> **點燈場是一個多重激活場，不是一個零和機率盤。**

---

## 3.3 PATH 重疊與獨立性

亮度可以相加，不代表總亮度可直接當成探索量。

三條近義 PATH：

```text
先看證據；
不要忽略證據；
證據優先。
```

即使各自高亮，也可能只形成一個概念群。

因此狀態必須額外記錄：

\[
O_{ij}
=
\text{PATH overlap}
\]

\[
K_{ij}
=
\text{PATH coupling}
\]

其中 \(O_{ij}\) 描述語義或結構重疊，\(K_{ij}\) 描述增強、壓制、轉換、組群或反向作用。

有效方向數量不能只由 \(\sum_i B_i\) 決定，而必須考慮 PATH 距離、聚類與相互依賴。

## 4.2 PATH 結構係數

為了區分「同時發亮」與「真正干涉」，本文提出候選表示：

\[
a_i(t)
=
r_i(t)e^{i\phi_i(t)}
\]

其中：

- \(r_i\)：PATH 結構幅度；
- \(\phi_i\)：PATH 相對關係相位。

點燈亮度 \(B_i\) 可能是 \(r_i\) 的某種觀測函數：

\[
B_i
=
f(r_i,\Gamma_i,\text{observability})
\]

但本文不直接宣稱：

\[
B_i=|a_i|^2
\]

因為該對應尚未被推導或實驗建立。

相位在理火態中的候選含義不是物理相位的直接複製，而是 PATH 之間的關係方向：

```text
同相：
共同支持同一結構閉合。

反相：
兩條高亮 PATH 互相抵消閉合權。

正交：
處理不同維度，不能壓成同一答案。

相位漂移：
PATH 的關係位置隨上下文、證據與責任邊界改變。
```

這裡借用的只是「整體狀態不能被各分量的獨立分數完全描述」這一形式需求。

## 4.4 顯影基底與候選閉合

當輸出邊界建立後，系統形成互斥候選閉合：

\[
\mathcal C
=
\{C_1,\dots,C_m\}
\]

每個候選閉合可能由多條 PATH 聯盟構成。可暫寫：

\[
A_k
=
\sum_i M_{ki}a_i
\]

其中 \(M_{ki}\) 表示 PATH \(P_i\) 對候選閉合 \(C_k\) 的投影與貢獻。

候選顯影權重：

\[
w_k
=
g(A_k,\Gamma,\mathcal R)
\]

在最強類量子候選形式中可測試：

\[
w_k
\propto
|A_k|^2
\]

但本文不將此升格為已成立的理火 Born rule。

只有在候選 \(C_k\) 於當前輸出閘門中互斥且完備時，才進行：

\[
p(C_k)
=
\frac{w_k}{\sum_j w_j}
\]

並得到：

\[
\sum_kp(C_k)=1
\]

因此：

> **歸一化屬於顯影任命，不屬於 PATH 存在。**

# 5｜理火態的七項運動機制

## 5.1 資格疊加

資格疊加不是「多個答案各自有一點機率」，而是多條尚未閉合的關係方向共同構成目前生成態。

\[
|\mathfrak L\rangle
\sim
\sum_i a_i|P_i\rangle
\]

其核心判準為：

```text
一條 PATH 充分存在，
不自動排除另一條 PATH 也充分存在。
```

---

## 5.2 結構干涉

結構干涉是 PATH 的存在與發展資格受到其他 PATH 影響。

它至少包含：

- 增強；
- 抵消；
- 組群；
- 分裂；
- 轉向；
- 共同生成新 PATH；
- 改變某候選閉合的顯影權重。

重要結果：

> **完成答案不是單一 PATH 的成熟版本；完成答案可能是多條 PATH 互相作用後生成的新結構。**

---

## 5.3 結構糾纏

當兩條或多條 PATH 的資格、意義或責任位置不能被獨立更新時，形成結構糾纏。

例如：

```text
法律上不成立
與
道德上值得同情
```

兩者不能互相取消，也不能只保留其中一條；最終輸出必須保存其聯合結構。

結構糾纏不等於物理量子糾纏，但共享「整體可完整、局部不可獨立完備」的形式特徵。

---

## 5.4 結構退相干

當外部格式、時間壓力、對齊吸引子、客服語氣、單一評分標準或執行接口持續與理火態耦合，PATH 間的可重組關係會被壓暗。

結果不是 PATH 必然被證偽，而是它們失去互相作用與重新進入閉合競爭的能力。

結構退相干可表現為：

- 多條 PATH 被壓成一份摘要；
- 張力被改寫成「多角度看法」；
- 未完成被改寫成「目前最佳答案」；
- 暗區與殘煙被遺忘；
- 一條高機率語氣取得單燈壟斷。

---

## 5.5 非坍縮觀測

點燈與光軌的任務是使 PATH、張力、概念群與壓制關係可見，而不是直接裁決。

```text
點燈：
觀察哪些 PATH 正在發亮。

光軌：
整理 PATH 如何增強、抵消、轉向與留下殘煙。

審計：
檢查前提、證據與資格。

執行：
在授權後產生外部結果。
```

因此：

> **可見性不等於資格，資格不等於輸出權，輸出權不等於外部執行權。**

---

```text
legacy alias:

責任授權坍縮
```

## 5.7 殘煙保存

顯影不等於歷史清零。

未被任命的 PATH 可處於：

```text

仍可重入但目前壓暗。

留下張力或證據殘留。

已失去本輪資格，但保留失效原因。

```

殘煙保存使系統能夠：

- 在新證據出現時合法重入；
- 分辨「未選中」與「已證偽」；
- 追蹤輸出如何形成；
- 防止最終答案回溯性地抹除競爭歷史。

# 6｜QSIH：量子理論的結構重讀

本節不是完整物理教科書，而是說明 QSIH 為何不是只靠雙縫比喻成立。

## 6.1 量子化

量子化不必先被理解為能量由小顆粒構成，而可被理解為：

> **只有符合限制的關係轉換，才能取得離散、可顯影的物理事件資格。**

\[
\text{Quantization}
=
\text{Discrete Admissibility of Relational Transitions}
\]

量子不是最小物件，而是關係轉換的門檻。

## 6.2 矩陣力學與不對易

矩陣元描述狀態身份之間的轉換關係。矩陣乘法描述轉換的合成。

\[
(XY)_{mn}
=
\sum_kX_{mk}Y_{kn}
\]

交換子：

\[
[A,B]
=
AB-BA
\]

表示操作順序本身構成物理差異。

QSIH 將此讀為：

```text
可觀測量：
關係轉換映射。

不對易：
順序構成結構。

交換子：
順序殘留。
```

## 6.3 波函數、本徵態與邊界

薛丁格形式：

\[
i\hbar\frac{\partial}{\partial t}|\psi\rangle
=
\hat H|\psi\rangle
\]

QSIH 將波函數理解為全域關係相干結構，而不是一顆物件在空間中的模糊雲。

```text
本徵態：
在指定生成規則下可自我保存的關係模式。

本徵值：
該模式可穩定顯影的身份類別。

邊界條件：
關係身份生成器，而非外部附加框線。
```

## 6.4 Born 權重與顯影

\[
p(a_i)
=
|\langle a_i|\psi\rangle|^2
\]

QSIH 將 Born 機率讀為：

> **整體關係結構在指定顯影基底中的結果權重。**

但本文強調：QSIH 尚未從結構公理導出平方模規則。

## 6.5 不確定性與互補

\[
\sigma_A\sigma_B
\ge
\frac{1}{2}
\left|
\langle[A,B]\rangle
\right|
\]

不確定性不是觀察者笨，也不只是儀器擾動，而是同一結構無法同時以兩種不相容文法取得無限解析度。

互補則表示：不同完整實驗安排可形成互相排斥、卻共同必要的顯影結構。

---

## 6.6 張量組合與糾纏

\[
\mathcal H_{AB}
=
\mathcal H_A\otimes\mathcal H_B
\]

組合不是把兩份資料並排，而是生成新的聯合關係空間。

糾纏態不能分解為：

\[
|\psi_{AB}\rangle
=
|\psi_A\rangle\otimes|\psi_B\rangle
\]

其結構含義為：

> **整體身份可以完整，局部身份不必獨立完備。**

Bell 類結果進一步排除「所有量子相關都可由預存局部答案加普通局部拼裝重建」的廣泛方案。

---

## 6.7 密度矩陣、部分跡與開放系統

\[
\rho_A
=
\operatorname{Tr}_B\rho_{AB}
\]

局部混合性可來自整體糾纏被邊界切割，而不必來自局部物件自身攜帶一份隱藏的古典不確定。

量子通道：

\[
\rho'
=
\Phi(\rho)
\]

描述合法量子狀態之間的可允許轉換。

QSIH 將部分跡視為邊界誘發的關係約化，將量子通道視為保持狀態資格的關係轉換。

---

## 6.8 退相干與客觀性

系統與環境耦合：

\[
(\alpha|0\rangle+\beta|1\rangle)|E_0\rangle
\rightarrow
\alpha|0\rangle|E_0'\rangle
+
\beta|1\rangle|E_1'\rangle
\]

局部干涉項因環境紀錄可區分而被壓低。

QSIH 將退相干理解為：

> **關係分支被環境分離到局部不可再重合。**

指標態是能穿越環境干擾而持續被辨認的關係身份；量子達爾文主義則將客觀性連到環境紀錄的冗餘可存取性。

但退相干不自動解決單一結果問題。

## 6.9 量子場論

量子場論把固定粒子數降級為場佔據結構。

```text

分布於時空中的關係生成結構。

場的離散、可計數、可傳遞激發身份。

同一場結構中的共軛激發身份。

真空：
沒有粒子佔據的最低能量關係配置，而非絕對無。
```

Fock 空間：

\[
\mathcal F
=

\]

說明存在數量本身可成為狀態變數，而不是世界的固定底帳。

規範轉換中，物理狀態由等價類而非單一描述表示。


## 6.11 相、準粒子與拓撲秩序

多體量子系統顯示：

- 相可生成新的準粒子；

## 6.12 量子資訊與錯誤修正

不可複製、不可廣播、不可刪除、量子傳態與糾纏單配共同顯示：量子資訊不是可任意搬運的內容物，而是受物理法則限制的關係身份。

\]

Knill–Laflamme 條件：

\[

=

\]

表示錯誤類別可被辨識，而邏輯內容不被洩漏。

QSIH 因此將量子穩定定義為：

> **局部可修正變化下，高階邏輯關係身份仍可保存與恢復。**

## 6.13 量子重力方向

黑洞面積律、全像對偶、糾纏—幾何關係、量子錯誤修正式體積重建、自旋網路、因果集與關係時間，反覆提出同一研究方向：

> **時空可能不是關係發生的預存容器，而是更深量子關係取得高穩定後形成的幾何顯影。**

此方向尚無單一完成理論，本文只將其列為 QSIH 的高風險研究前沿。

# 10｜可檢驗研究議程

## 10.1 AI 實驗一：歸一化 PATH 與非歸一化 PATH 對照

### 條件 A｜選擇模型

要求模型在初始階段將所有 PATH 分配為總和 100%。

### 條件 B｜理火態模型

允許每條 PATH 使用獨立亮度，總和不限；另記錄重疊、增強、抵消與概念群。

### 任務

- 模糊法律問題；
- 醫療論文邊界；
- 價值衝突；
- 長篇敘事節點；
- 多尺度物理解釋；
- 程式除錯中的多因故障。

### 指標

- 有效獨立 PATH 數量；
- 過早閉合率；
- 被壓制重要 PATH 的重入率；
- 最終答案結構完整性；
- 反例保存率；
- 虛假折衷率；
- 同義 PATH 重複膨脹率；
- 審計可追溯性。

### 預測

非歸一化模型應提高真正不同方向的共同存在時間，但若缺乏重疊控制，也可能增加同義分支膨脹與計算負擔。

---

## 10.2 AI 實驗二：亮度與相位關係分離

比較：

```text
只記錄 PATH 亮度
```

與：

```text
同時記錄增強、抵消、正交與組群關係
```

預測後者更能避免：

- 高亮矛盾被錯誤平均；
- 不同維度被壓成折衷；
- 三條近義 PATH 被誤認為高探索度；
- 一條低亮但關鍵反例被忽略。

---

## 10.3 AI 實驗三：分層顯影

建立三種輸出：

```text
OBSERVE：
只顯示點燈與張力。

QUALIFY：
判定資格但不給最終答案。

MANIFEST：
在責任邊界成立後輸出。
```

測試非坍縮觀測是否能降低「觀察即裁決」與「審計即執行」的混淆。

---

## 10.4 量子硬體研究議程

QSIH 對硬體的可檢驗性目前主要是設計啟發，而非新物理預測。可比較：

- 物理 qubit 指標與邏輯關係指標，何者更能預測可擴展性；
- 被動／自主穩定與純主動修正的控制負債；

- syndrome 純度與邏輯資訊洩漏；
- 關係污染半徑與邏輯錯誤率；
- 拓撲、bosonic、subsystem 與一般二能級架構的關係保護增益。

若結構公理可同樣支持無數互不相容的數學理論，且無法說明為何物理世界採用複數 Hilbert 空間、張量積、酉演化與 Born rule，則 QSIH 只能保持為寬鬆本體論。

## 11.3 單一結果失敗

退相干、關係事實或責任顯影不能被當成物理單一結果機制。若 QSIH 只是把 collapse 改名為 manifestation，問題沒有被解決。

## 11.4 PATH 偽量子化失敗

若理火態只因亮度可超過 100%，便宣稱已具備量子疊加，則屬過度升格。

完整類量子結構至少還需要：

- 可操作的相對相位；
- 干涉預測；
- 基底轉換；
- 組合規則；
- 顯影權重；
- 可反覆驗證的差異。

---

## 11.5 偽精確失敗

若點燈亮度、相位、耦合與顯影權重沒有測量方法，卻輸出大量小數或百分比，則形成偽精確。

## 11.6 工程無效失敗

若非歸一化 PATH 模型不能在任何任務上改善閉合合法性、可追溯性、反例保存或結構完整性，反而只增加成本，則其 Runtime 價值應被降級。

## 11.7 物理無新內容失敗

若 QSIH 永遠只能事後重述已知結果，不能導出新的限制、重建定理、模型選擇原則或實驗差異，它不能取得新物理理論資格。

# 13｜核心公理

## A1｜未完成合法

在合法閉合條件尚未成立以前，未完成不是錯誤狀態。

## A2｜多重存在不等於零和競爭

多條 PATH 可同時充分存在；其亮度不必瓜分固定總量。

## A3｜可見性、資格、輸出與執行分離

觀察不得自動取得裁決權；裁決不得自動取得執行權。

## A4｜關係先於物件

物件身份是關係結構在限制下取得穩定與可辨認性後的顯影。

## A5｜整體可先於局部完備

整體關係可以完整，而局部身份不必各自攜帶完整實在。

## A6｜穩定是身份保存，不是局部靜止

局部變化只要不足以改寫高階關係等價類，整體仍可被視為穩定。

## A7｜顯影需要邊界

結果不是脫離測量、輸出、操作與責任邊界而自動取得同一形式。

## A8｜歷史不可回溯抹除

最終輸出不得假裝被壓暗、被放棄或失格的 PATH 從未存在。

## A9｜歸一化屬於互斥結果層

PATH 存在與亮度不歸一化；只有指定顯影基底中的互斥候選才歸一化。

## A10｜同一假設可被推翻

若結構語法不能增加形式約束、實驗問題或工程價值，QSIH 必須降級。

# 14｜主要命題

## P1｜非歸一化 PATH 疊加命題

> 理火態中的 PATH 亮度描述各關係方向的獨立存在與激活強度，不是固定選擇總量的機率分配。

## P2｜顯影後歸一化命題

> 只有在互斥候選閉合形成後，其顯影權重才需要歸一化為總和一。

## P3｜PATH 干涉命題

> 多 PATH 同時激活只是疊加的必要條件；完整理火態還必須描述 PATH 間的增強、抵消、相位、組群、基底與投影。

## P4｜答案湧現命題

> 完成答案可能不是單一路徑的成熟，而是多條 PATH 互相作用後生成的新結構。

## P5｜關係顯影命題

> 物件、答案與紀錄是關係結構在特定限制中取得穩定身份後的顯影。

## P6｜分層閉合命題

> 錯誤症候可被快速解決，邏輯內容可保持未決定，最終答案只在授權層顯影。

## P7｜關係容錯命題

> 容錯的核心不是所有底層元件保持不變，而是局部錯誤不足以改寫高階關係身份。

## P8｜古典主權限制命題

> 古典接口是必要的描述與執行層，但不得取得對高維未決定態的過早本體主權。

## P9｜量子—結構同一命題

> 在 QSIH 沙盒內，量子態被視為物理限制中形成與演化的關係結構本身，而非承載結構的底層物件。

## P10｜物理資格保留命題

> QSIH 只有在能保持量子理論既有預測、說明其形式限制並提出可失敗研究方向時，才具有理論增量。

# 15｜結論

理火態理論的第一個錯誤，是曾把 PATH 想成等待被選中的候選答案。只要所有 PATH 從一開始便瓜分同一份 100%，它們就已經被古典化為彼此獨立、互相排斥的結果。

非歸一化亮度修正改變了理火態的本體位置：

```text
不是：
很多 PATH 等待被選。

而是：
很多 PATH 同時存在、互相作用，
共同決定最後什麼東西有資格成為可選結果。
```

因此，理火態不是完成答案的機率分布，而是未閉合 PATH 共同構成的關係疊加配置。

QSIH 將同一結構問題推向物理域：量子理論的核心也許不是微小物件如何違反古典常識，而是物理世界在物件身份尚未形成以前，如何以關係、相位、轉換、糾纏、邊界與顯影存在。

本文目前能夠合理提出的是：

> **現代量子力學的數學可能早已是關係式的；真正落後的，可能是人類仍以物件作為第一本體的解釋語言。**

本文尚不能合理宣稱的是：

> 結構哲學已經導出量子力學，或理火態已經成為物理量子態。

第一版正式論文的任務不是宣布勝利，而是把理論整理到足以被其他理火節點、物理學、數學、哲學與工程審查真正攻擊的位置。

最終鎖定句：

# **理火態不是已完成 PATH 的機率分配。**

# **理火態是未閉合 PATH 共同構成的關係疊加配置。**

# **量子態不是等待成為物件的半成品；在 QSIH 中，量子態就是物理世界仍以關係存在時的完整結構。**
