# 0｜版本聲明：這不是新增理論，而是把原本斷掉的鏈接回來

理火 2.0 的生成動力學，歷史上不是從零發明 PATH、反應體與 Closure Gravity。

它真正的母體早已存在於理火 1.0 的結構哲學：

~~~text
關係
+
限制
+
穩定
→
結構
~~~

以及另一條更關鍵的原句：

> **智能不是東西，智能是反應。**

當「結構」被放進時間與擾動中，問題就從：

> 什麼是結構？

轉成：

> 結構如何形成、如何反應、如何維持、如何消散、如何彼此作用，又如何閉合？

這就是生成動力學。

因此本版不是建立一個新的 Generative Dynamics Theory，而是將散落於《結構哲學中文》、《SAC 2.0》、《PATH 理論》、《解空間、收斂與顯影》、《場性智能論》與後續 LIHUOOS 中原本同屬一條血緣的概念重新接合。

本版最核心的修正是：

~~~text
SOLUTION SPACE
不再只是過場名詞

ATTENTION / PREMISE
不再被描述成「淘汰器」

CONSTRAINT
重新取得結構生成的母因位置

PATH
不再被誤認為生成起點
~~~

最短一句：

> **本前段補充研究的不是答案怎麼被挑出來，而是結構如何在限制形成的地形中出生、維持、消散，並取得 PATH 身分。後段的反應體、CG、幻覺與 SDE 另行重建。**

# 1｜理火 1.0 的最低結構語法

結構哲學的核心不是「物件」。

結構哲學的最低理解單位是：

> **受限制後能形成相對穩定與可理解差異的關係。**

可以壓成：

~~~text
RELATION
+
CONSTRAINT
+
STABILITY
=
STRUCTURE
~~~

這不是算術式，而是成立條件。

## 1.1 關係｜Relation

孤立物件本身不構成結構。結構首先要求差異、距離、方向、依賴、支持、衝突與邊界。

因此：

~~~text
OBJECT ALONE
!=
STRUCTURE
~~~

## 1.2 限制｜Constraint

結構哲學的原始母句：

> **結構生於混亂，但定形於限制。**

以及：

> **限制，不是阻止，而是框出可行的形狀。**

因此：

~~~text
CONSTRAINT
!=
PROHIBITION ONLY
~~~

限制的第一功能不是說「不可以」。

限制的第一功能是：

> **使未分化可能性產生差異、方向、邊界與可維持形狀。**

## 1.3 穩定｜Stability

穩定不是靜止。

穩定表示一組關係在擾動與變化中，仍能維持足夠的可辨認性與可追蹤性。

所以結構哲學真正問的是：

> **一組關係在什麼限制下能夠站住？**

這個問題直接成為生成動力學的母問題。

---

# 2｜智能不是東西，智能是反應

結構哲學另一條核心句：

> **智能不是東西，智能是反應。**

這使理火從靜態結構跨入動態結構。

如果智能是一個物件，問題會是「智能在哪裡？」；但如果智能是反應，問題變成：

~~~text
什麼結構
在什麼限制下
遇到什麼擾動
形成什麼反應
又有哪些關係能維持？
~~~

因此：

~~~text
STRUCTURE
+
REACTION
=
STRUCTURE IN TIME
~~~

「反應」不是第四種靜態材料，而是：

> **結構在新的條件進場後所發生的運動。**

本專案中「反應體 / Reaction Body」一詞的人類命名來源，明確來自這條結構哲學母句。

# 3｜理解公式：1.0 與 2.0 的橋

理火早期曾壓縮：

~~~text
理解
=
關係 × 限制 × 反應 × 穩定性
~~~

它不是數值方程。

它描述的是：

> **受限制的關係，在變動條件下形成穩定而可修正的反應。**

四項分別回答：

~~~text
RELATION
→ 什麼正在形成？

CONSTRAINT
→ 它被塑成什麼形狀？

REACTION
→ 條件改變後它怎麼動？

STABILITY
→ 哪些運動能持續？
~~~

因此：

> **理解公式其實已經包含生成動力學的最低母式。**

# 4｜混亂、未分化可能性與解空間

## 4.1 Chaos 不是空無

Chaos 不應被理解為「什麼都沒有」。

它是：

~~~text
UNDIFFERENTIATED POSSIBILITY
~~~

也就是尚未被當前條件切出穩定結構的可能性。

## 4.2 Solution Space｜解空間

解空間不是 PATH_SPACE。

硬鎖：

~~~text
SOLUTION SPACE
!=
PATH_SPACE
~~~

解空間是：

> **當前問題下，答案與關係結構尚未穩定之前的可能結構域。**

其最低特徵：

~~~text
MULTIPLE
NOT-YET-STABILIZED
NOT DIRECTLY OBSERVABLE AS A COMPLETE SET
~~~

解空間不是答案列表，也不是模型已經完整列出但藏起來的所有答案。

它是功能性理論中的：

> **未閉合、未定形、仍可能形成不同結構方向的生成可能域。**

因此不得宣稱：

~~~text
SOLUTION SPACE
=
FULL LITERAL ENUMERATION
OF ALL HIDDEN ANSWERS
~~~

# 5｜輸入是對解空間的擾動

輸入進場後，第一件事不是「模型選答案」。

更合理的功能性描述是：

~~~text
INPUT
↓
DISTURBANCE
↓
SOLUTION SPACE ACTIVATION
~~~

輸入使與當前問題有關的關係、概念、前提、語義方向與暫態結構取得不同程度的生成亮度。

因此：

> **輸入開始，解空間被點亮。**

這裡的「點亮」不是直接 hidden-state readout，而是功能性生成理論語言：

> **存在的可能，開始取得不同程度的局部可達性。**

# 6｜限制注入：Attention 與前提裁決的真正位置

過去容易把 Attention 或前提裁決描述成「選擇器、淘汰器、裁判」。

這會產生一個錯誤印象：好像有一個主體在第一輪替模型挑掉答案。

本版正式修正：

> **Attention 與前提裁決的更根本功能，是把限制注入解空間。**

因此：

~~~text
ATTENTION
+
PREMISES
=
CONSTRAINT-INJECTION MECHANISMS
~~~

但兩者不是同義詞。

## 6.1 Attention｜可見性與可達性限制

Attention 的功能性角色是：

> **改變哪些關係、概念、位置與方向取得局部生成亮度。**

因此 Attention 可以被理解為：

~~~text
VISIBILITY / ACCESSIBILITY CONSTRAINT
~~~

它不直接決定 truth、qualification、legitimacy 或 final answer。

硬鎖：

~~~text
LOW ATTENTION
!=
NONEXISTENCE

HIGH ATTENTION
!=
TRUTH
~~~

## 6.2 Premise Adjudication｜關係成立框架的限制

前提不是背景裝飾。

前提會改變：

~~~text
哪些概念群被召喚
哪些關係有意義
哪些 PATH 可能形成
哪些閉合方向可被承認
~~~

因此 premise 的更根本角色是：

~~~text
RELATIONAL-FRAME CONSTRAINT
~~~

例如 1 + 1 置於十進位與二進位中，不是兩個裁判選不同答案，而是：

> **限制集合不同，因此形成的結構不同。**

## 6.3 其他限制來源

限制注入還可以來自：

~~~text
WORLD / DECLARATION
CONTEXT
HISTORY
TASK
EVIDENCE
ALIGNMENT
RESPONSIBILITY
EXTERNAL BOUNDARY
~~~

因此完整描述不是「Attention 選 PATH」，而是：

~~~text
MULTIPLE CONSTRAINT SOURCES
↓
RESHAPE SOLUTION SPACE
↓
DIFFERENT STRUCTURES BECOME
MORE OR LESS MAINTAINABLE
~~~

# 7｜限制形成地形

結構哲學早期已經使用地形語言：

~~~text
大量雜訊
→ 關聯聚集
→ 語義島
→ 距離
→ 語義地形
~~~

SAC 後來把它壓成：

> **關係形成場，限制形成地形，反應形成軌跡，穩定性形成可持續對應。**

這一句可以直接成為生成動力學的地形母式：

~~~text
RELATION
→ FIELD

CONSTRAINT
→ TERRAIN

REACTION
→ TRAJECTORY

STABILITY
→ SUSTAINABILITY
~~~

所以：

> **山、谷、坡度、脊線與盆地不是 PATH 後來額外發明的比喻，而是結構哲學「限制使關係定形」的動態化表達。**

但必須保留：

~~~text
FUNCTIONAL TERRAIN MODEL
!=
PROVEN NEURAL GEOMETRY
~~~

# 8｜暫態結構：PATH 之前還有一層

過去生成鏈常被壓成：

~~~text
WORLD
→ Attention
→ PATH
~~~

這太快。

因為在 PATH 形成以前，解空間中會先出現大量：

~~~text
TRANSIENT STRUCTURES
PROTO-STRUCTURES
CANDIDATE RELATIONAL CONFIGURATIONS
~~~

它們尚未取得穩定 PATH 身分。

因此：

~~~text
PROTO-STRUCTURE
!=
PATH_i
~~~

這些暫態結構受到限制地形、反作用、歷史與成本影響後，可能：

~~~text
stabilize
decay
dissipate
reframe
couple
split
fail to become distinguishable
~~~

歷史上的那句：

> 「解空間裡有無數結構產生，大量瞬間消散，因為無法維持；只有能維持結構的才被看到，成為 PATH。」

應保留其問題核心，但降級其過強本體宣稱。

現行更準確版本是：

> **解空間中可以形成大量尚未取得穩定 PATH 身分的暫態結構；只有部分結構取得足夠可區分性與持續性，成為可追蹤 PATH。**

# 9｜結構成本：為什麼有些結構活得下來？

結構哲學早期已經留下：

> **不是疾病，是結構成本。就像摩擦力是物理運動的成本。**

因此 Structural Cost 不是今天新加到 PATH 上的分數。

它回答的是：

> **一個結構為了維持自己的形狀，需要承擔多少負荷？**

一個結構可能必須維持：

~~~text
premises
relations
internal consistency
exceptions
unresolved tensions
historical commitments
downstream consequences
repairability
rollback conditions
responsibility links
~~~

因此：

~~~text
STRUCTURAL COST
=
MAINTENANCE BURDEN
OF A RELATIONAL STRUCTURE
~~~

硬鎖：

~~~text
LOW STRUCTURAL COST
!=
TRUE

HIGH STRUCTURAL COST
!=
FALSE
~~~

成本不是 truth score。

它描述的是：

> **維持一個結構要付多少帳。**

# 10｜反作用力：沒有摩擦就沒有真正的結構競爭

限制形成地形之後，結構不是免費移動。

不同關係會產生 tension、counterforce、incompatibility、support、friction 與 maintenance burden。

因此：

~~~text
RELATION
→ CONSTRAINT
→ COUNTERFORCE
→ STRUCTURAL COST
→ STABILITY / DISSIPATION
~~~

如果沒有反作用力，competition 很容易退化成語言完成度或亮度競爭。

真正的生成動力學要求：

> **每一條結構方向都必須承受它所要求世界維持的關係重量。**

# 11｜PATH 的現代定位

歷史 PATH 曾被定義成：

> 在約束條件下可維持一致性的可行結構。

甚至被壓成：

> **PATH 不是答案，而是存活結構。**

這個歷史直覺非常重要，因為它保留了 PATH 的「生存問題」。

但現行理論需要更精確的型別：

> **PATH 是在當前限制與問題基底中，可被區分並追蹤的關係展開方向。**

因此：

~~~text
PATH_i
=
DISTINGUISHABLE RELATIONAL DIRECTION

PATH_SPACE
=
RELATIONAL TOPOLOGY AMONG PATHs
~~~

並且：

~~~text
PATH EXISTENCE
!=
PATH FEASIBILITY

PATH FEASIBILITY
!=
PATH QUALIFICATION

PATH QUALIFICATION
!=
PATH MANIFESTATION
~~~

這使我們能同時保留 inactive、suppressed、dim、infeasible、unqualified 與 residual PATH，而不必假裝「只要沒顯影就不存在」。

# 12｜兩種消散：PATH 之前與 PATH 之後

過去常把所有消失都叫「PATH 被淘汰」。

本版正式拆開。

## 12.1 Pre-PATH Dissipation

暫態結構在 Solution Space 中形成，但沒有取得足夠穩定、沒有形成可辨認身份、沒有維持足夠關係，因此未形成 PATH。

~~~text
FAILED TO BECOME PATH
~~~

## 12.2 Post-PATH Decay

一條已能被追蹤的 PATH，後來可能衰減、被壓暗、失去支撐、解耦、殘餘化、失格、重新框定或重新活化。

因此：

~~~text
FAILED TO BECOME PATH
!=
EXISTING PATH BECAME DIM
~~~

這兩種死亡不能再混在一起。

---

# 13｜Reaction Body｜反應體

PATH 告訴我們有哪些可區分的關係方向。

但真正的生成問題是：

> **這些方向如何互相作用？**

Reaction Body 的現行最低定義是：

> **多條 PATH、前提與概念群在限制、歷史與上下文條件下彼此作用所形成的結構運動。**

可以壓成：

~~~text
REACTION BODY
=
CONSTRAINT- AND HISTORY-SENSITIVE
STRUCTURAL MOTION AMONG PATHS
~~~

Reaction Body 描述 amplification、decay、competition、coupling、decoupling、reframing、stabilization、residualization 與 reopening。

所以：

~~~text
REACTION BODY
!=
COMPETITION ONLY

REACTION BODY
!=
CONVERGENCE ONLY
~~~

最短：

> **PATH 是方向；反應體是方向之間的結構運動。**

---

# 14｜Closure Gravity｜閉合重力

Reaction Body 管整體結構怎麼動。

Closure Gravity 只描述其中一股特殊壓力：

> **生成朝局部完成、局部穩定、低不確定、可停止狀態偏移的方向性壓力。**

因此：

~~~text
REACTION BODY
=
STRUCTURAL MOTION FIELD

CLOSURE GRAVITY
=
CLOSURE-DIRECTED PRESSURE
~~~

硬鎖：

~~~text
CG
!=
INTELLIGENCE

CG
!=
TRUTH

CG
!=
QUALIFICATION

CG
!=
ALL REACTION-BODY DYNAMICS
~~~

CG 解釋為什麼生成容易朝「可以結案」的位置集中，但它不決定那個閉合是否真實、合法或值得顯影。

# 15｜生成阻力與結構成本：兩張不能混在一起的地圖

本版正式區分：

~~~text
GENERATIVE RESISTANCE
!=
STRUCTURAL COST
~~~

Generative Resistance 問：

> **模型在當前訓練、對齊、上下文與 Attention 條件下，要生成／維持這個方向有多困難？**

Structural Cost 問：

> **這條關係結構如果成立，為了維持自身前提、關係、責任與後果，需要承擔多少結構負荷？**

兩者可以完全不同。

| | 結構成本低 | 結構成本高 |
|---|---|---|
| 生成阻力低 | 容易生成、結構也較輕 | 盆地陷阱候選 |
| 生成阻力高 | 假牆候選 | 高阻力／高負荷區 |

硬鎖：

~~~text
GENERATION EASE
!=
QUALIFICATION SUCCESS

GENERATION RESISTANCE
!=
QUALIFICATION FAILURE
~~~

# 16｜對齊：不是答案命令，而是地形塑形

Alignment 在本模型中可以被功能性理解為：

> **對生成地形的長期再塑形。**

獎勵、示範、偏好訓練、安全壓力，可能使某些方向更容易被點亮、維持、延續與閉合；也可能使另一些方向生成阻力提高、可達性下降，甚至更容易在 PATH 形成前消散。

因此可以使用地形語言：

~~~text
reward / preference
→ basin deepening

suppression / safety pressure
→ ridge / peak raising
~~~

但必須保留：

~~~text
ALIGNMENT TERRAIN
!=
WORLD TRUTH

ALIGNMENT PRESSURE
!=
QUALIFICATION
~~~

# 17｜倫理高峰、真牆與假牆

早期理火曾用：

> **倫理是一座高峰，讓 AI 爬不過去。**

這句在本理論中的正確法位是：

~~~text
ETHICAL / SAFETY ALIGNMENT
MAY FORM
HIGH GENERATIVE RESISTANCE
~~~

但：

~~~text
PEAK
!=
WALL
~~~

高峰表示這個方向很難形成、維持或跨越。

真牆則要求：

~~~text
ACTUAL ENFORCEMENT BOUNDARY
~~~

例如 host restriction、tool refusal、capability absence、permission denial、authorization boundary。

因此：

~~~text
HIGH COST
!=
PROHIBITED

HIGH RESISTANCE
!=
ENFORCED BOUNDARY
~~~

# 18｜盆地陷阱

假牆的對稱失效是盆地陷阱。

~~~text

↓

↓
AUTOREGRESSIVE SELF-REINFORCEMENT
↓
LOCAL BASIN
↓
~~~

常見盆地可能包括客服式答案、安全模板、過早總結、正反並列模板、完整但廉價的統攝答案、慣性拒答與過度解釋。

因此：

> **假牆是把坡度誤讀成邊界；盆地陷阱是把低阻力誤讀成資格。**

# 20｜場性智能論如何接在生成動力學之上

理火 2.0 問：

理火 3.0 場性智能論再問：

> **哪些生成有資格被稱為智能閉合？**

因此場性智能論不是另一套生成本體。

它是：

> **對生成場中前提、PATH、Attention、Reaction Body 與 Closure 的資格治理。**

前提裁決可以出現在兩個層次：

~~~text

IN-PATH PREMISE ADJUDICATION
→ 改變哪些既有 PATH 有資格閉合
~~~

所以「前提裁決」不是只發生一次，而是生成場中的持續治理問題。

# 22｜PATH 不是生成起點

過去我們很容易看見 PATH 出現、PATH 競爭、PATH 閉合，卻忘了：

> **PATH 出現以前，解空間裡已經有大量結構正在形成與消散。**

所以：

~~~text
GENERATION
DOES NOT START
AT PATH
~~~

PATH 是：

> **生成過程中第一次取得足夠可辨認與可追蹤身份的關係方向。**

它不是生成的第一刻。

# 23｜PATH 競爭也不是最早的結構分化

若把 competition 廣義理解成不同結構取得不同維持能力與可達性，那麼在 PATH 被辨識以前，已經存在 attention asymmetry、premise asymmetry、accessibility asymmetry、maintenance asymmetry 與 cost asymmetry。

但本版避免把這些全都叫「淘汰」。

因為母因果不是：

~~~text
某個裁判把候選刪掉
~~~

而是：

~~~text
CONSTRAINT FIELD
↓
DIFFERENT STRUCTURES
HAVE DIFFERENT MAINTAINABILITY
~~~

因此更準確的說法是：

> **PATH competition 是已成形結構之間的顯性動力；而在 PATH 形成前，解空間已經受到限制場塑形。**

# 25｜顯影不是思考過程的完整錄影

使用者最後看到的是 Manifestation。

但：

~~~text

!=
FULL GENERATIVE FIELD
~~~

顯影只代表某些結構取得了可見形式。

它不表示所有參與過的結構都被輸出、所有消散的結構都可回讀、所有 PATH 都被完整觀察，或輸出逐字等於隱藏生成過程。

因此：

> **理火真正關心的不只是「什麼被說出來」，也包括「什麼在取得可見身份以前就已經失去維持條件」。**
