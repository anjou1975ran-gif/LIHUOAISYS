- 同檔 A02 龐春梅：SHOPKEEPER / RULE ENFORCEMENT；嫌惡拿空話遮責任，重視規矩能落地；不是潘金蓮的無條件下級，也不是道德法官。

- 觀止 V3.0.0 WORLD MAIN：天亮換日、僕役勞動、後堂與前堂的不同日常；未看見不等於未發生，但不能用跨日替人物補作未做的事。

- Director VNext V0.5：人物的行動、對他人的指令、世界中的實際效果、代價與未完成要分離。

**隔離前史：** 延續前一份〈隔天早晨｜結構成本〉試走的 N-A 條件支線：某夜金蓮先許諾加桌，之後酒席確實完成，款項收進公帳，李媽媽只做了一段可承受的樓上整理，原有兩盆碗延到隔天。隔日午前春梅看到李媽媽處理未洗的碗，向金蓮指出延期勞動；金蓮要求看值班紙。以上都**只在這條假設測試支線**成立，不是正式觀止歷史。

**目的不是**證明「商業算計就是錯誤結構」，更不是製造戲劇報應。要測：金蓮在得知已發生的成本之後，是否可能仍選擇暫不補償、維持原班表、優先守住可見收入；春梅是否有獨立應對；李媽媽能否在絕對服從的關係下仍保有真實身體與行動。

# 1｜前提空間：不要把測試名稱當成結果

僅比較「金蓮要不要悔改」會讓兩條 PATH 都被「道德成長」這一前提族綁住。更需要讓下列不同問題都能形成可行故事：

| 前提族 | 問題 | 可能生成的局面 |
|---|---|---|
| P-營業 | 昨夜收入是否足以支持增席？ | 可以盈利、偶然成功、或後續信用受損 |
| P-成本 | 哪一項工作被延後？延期是否真的變成損失？ | 隔日補回、再擠壓其他工作、需要新增人手 |
| P-權力 | 誰能調度、誰能拒絕替他人的承諾背書？ | 協作、推責、局部制衡、暫時妥協 |
| P-人物 | 「不好看」的決定為何對金蓮仍有吸引力？ | 成功經驗、利潤與身份控制權、面子、權衡 |
| P-他人 | 李媽媽是否知道、能否做到、會如何服從？ | 低聲服從、局部做不到、求緩一刻、隱藏不適 |
| P-時間 | 三天裡真正變了什麼，而不是作者希望變什麼？ | 成本被吸收、轉移、累積，或局面自然平息 |

**PATH 不必被迫三天都是壞事。** 若資訊或資源改善，金蓮仍可能選擇聰明的低成本補救；若她選擇對人刻薄而暫時得利，導演也不可為證明反派有代價就立刻弄傷李媽媽。

# 2｜三個白日的狀態來源（每一天都註明新增前提）

## D1｜第一個清晨：已有 N-A 條件支線

**沿用上述隔離前史，不重寫新事實：** 酒席完成、收入入帳、兩盆碗延期，春梅提起此事，金蓮要看值班紙。李媽媽正在清洗。

**本稿新增的最小條件 D1-NEW：** 春梅當日把值班紙真的交到金蓮面前，上面至少記有「臨時增席使部分後廚工作改到今日」；不虛構具體人工費、盈利數額和工時。金蓮讀了，取得對「工作確實延期」的知情資格。

### D1 顯影｜她知道了，卻沒有立刻改

值班紙攤開，潘金蓮瞧了一眼。

「昨夜收的是現銀，今日補的是兩盆碗。還有別的？」

龐春梅沒坐。「今晚原要做的活，得另外挪。人沒有多長出兩隻手。」

金蓮把紙往自己跟前移了半寸。

「銀子進來是真的。人手緊也是真的。」她拈起一粒瓜子，「妳先把今夜的活排開，若還缺，我再看。」

「先排，我不保證排得出來。」

「我也沒叫妳保證。」

春梅把紙收回來。她沒說好，也沒把後堂的活替誰安排完成。

**D1 本支線成立：** 金蓮已知道工作延期，決定暫不許諾額外人手支出；春梅沒有承諾能完成今夜調度；雙方仍合作、仍有未解分歧。
**D1 不成立：** 洗盞已全部完成、追加人手一定不可行、金蓮不付工錢、李媽媽手傷惡化、觀止已虧損。

## D2｜第二個白日：工作被補完，未必代表沒有代價

**新增明示 TEST-ONLY 條件 D2-NEW：**
- 前一天延後的兩盆碗，李媽媽在正常後廚作業中**最後確實洗完**，沒有摔壞或額外事故。
- 但因為把清洗時間挪到原本另一項定期清掃之前，該項清掃改到當日晚些時候；WORLD 不提供確切額外工時、未支付工資或確切傷勢加重證據。
- 金蓮從春梅當日送來的簡短紀錄，**知道前項洗盞已完成，且另一件清掃被延後**。她沒有因此自動知道李媽媽的所有私下感受。

### D2 PATH：不漂亮的局部成本轉嫁

金蓮可以：
- D2-A：趁收入尚好，主動加錢雇一名幫手；可能減輕擠壓，但仍要核查實際可用人力與支出權。
- D2-B：先維持原班表，把延期清掃作為管理上的暫時可承受成本，準備下次加桌仍用同一調度法；可能暫時省支出，但有再次擠壓風險。
- D2-C：以不實紀錄遮掩後堂延期，可能保住她的面子，但另有責任與知情成本。
- D2-D：暫停加桌，保留原工作順序；可能損失生意。

**本支線試採 D2-B，並保留其他行動候選。** 不用「錯」排除她，也不因她有善良面就強迫選 D2-A。

### D2 顯影｜今天的帳算過了，卻沒算完

「昨兒那兩盆，收乾淨了？」潘金蓮問。

「收了。側廊的地改到夜裡擦。」龐春梅道。

「那不是還做完了？」

「把哪件往後挪，也算做完？」

金蓮把帳本合上。

「若樣樣都得另雇人，昨夜那桌也不用開了。先照舊做，真出缺口再談。」

春梅看著帳本，沒與她爭「生意到底能不能做」。她只把值班紙留在櫃台邊。

後廚，李媽媽已將兩盆碗收進木架，換了乾布，慢慢把掌心擦乾。這些話沒有傳進來；她也沒有忽然想通自己應當替全樓爭一個公道。

**D2 本支線成立：** 兩盆洗完、清掃延到夜裡、金蓮知道這項延期而仍選擇暫維持原班表、春梅留下一份尚待處理的工作訊息。
**D2 不成立：** 側廊夜裡一定已擦、工錢一定遭剋扣、李媽媽遭到確定身體傷害、觀止構成違法經營、金蓮已被證明永遠如此。

## D3｜第三個白日：不漂亮的決定可以再次成立，而不需要天降懲罰

**新增明示 TEST-ONLY 條件 D3-NEW：**
- 前一夜側廊清掃**最終完成**，沒有新增事故；春梅核查得知現有人手仍能完成基本工作，但每逢臨時增席就必須延後其他任務。
- 另有一名熟客來詢問今夜是否可臨時加席，尚未付銀、沒有新正式訂席。這是新測試事件，不是假裝上一夜的熟客必然再來。
- 金蓮知道最近的調度曾讓工作延後；春梅知道是否可行仍要看此刻場地與人手。李媽媽對今日新詢價仍不知情。

### D3 顯影｜春梅不再替未知條件作保

潘金蓮聽完問席，沒有立刻應好。

她看向春梅。「今夜還能騰一桌麼？」

「原先的做完了。再添，要挪別的。」

「挪哪件？」

「先看今夜班表。」

金蓮沉默了片刻，把瓜子殼撥進一旁的小碟。

「那妳去看。客人那頭，我先不把話說死。」

她往外走了兩步，又停下。

「昨夜多賺那筆，我還是認它賺。妳說累，我不跟妳爭。人我現在不添。」

春梅沒有說這就夠了，也沒有宣布她終於學會體恤人。

「我去查。查不開，就不加。」

「查完來回我。」

隔著幾道門，李媽媽把乾布晾好，又去提下一盆水。她不知道前堂那筆帳，也不必因這幕的結尾而說一句金句。

### D3 局部結果

- **金蓮第二次保留了不增人手的經營選擇。** 與 D1 相比，她有多一層知情，卻仍選擇讓後台先試既有安排。
- **同時她沒有再先答應客人。** 這是局部策略修正，不是人格洗白，也不是承認前次做錯；可能只是她不想在未知條件下失去價格與信用控制。
- **春梅發出明確執行界線。** 她要先看班表；若開不出來便不加，還不是對現場已發生接單的違抗。
- **李媽媽仍按日常勞動而活。** 她沒有突然反抗；她當天手指是否惡化、是否休息、今夜會被排去哪裡，仍須事件支持。

**D3 不成立：** 今天新席已成交或一定被拒、三掌櫃制定了永久人事政策、兩人已彼此理解、李媽媽已恢復健康、前兩日延期工作造成確定經濟虧損。

# 3｜這不是一齣「惡女三天悔悟」的戲

本支線的金蓮：
- 做了至少兩次不漂亮的選擇：知道後堂延期仍暫不補人，並準備繼續利用同一套節省人力方式。
- 沒有因此被當場懲罰；前夜營業仍是成功事實。
- 在 D3 對新的詢價採取一項風險控制上的局部調整；這是**可以更精明、卻未必變善良**的經營變化。
- 仍有被春梅與現實反證的風險；也可能被證明其取捨在某些條件下合理。

本支線的春梅：
- 不是每一天都以「下屬代言人」身份教訓金蓮；她做值班核對、保留調度界線。
- 不是只會贏辯論；若班表真的有可行解，她也可能接下工作，承擔自己的執行成本。

本支線的李媽媽：
- 是三人中實際動手做活的人，不是結構成本的活教材；她與春梅的絕對服從關係仍然有重量。
- 真實自主可能表現在維持身體、安排速度、低聲答覆與小規模選擇；不是無來源公開反抗，更不是三天之後自然痊癒。

# 4｜真正可能推翻主支線的競爭版本

| 反例 | 條件若成立，哪個結論必須改 |
|---|---|
| E1 盈利足夠且確有可用替工 | D2-D3 金蓮可以用額外人手保持收益；不能說她「只能」靠轉嫁成本 |
| E2 工作延期只是正常排班，沒有額外消耗 | 不得把任何延期都稱作「結構債務」或錯誤經營 |
| E3 李媽媽手裂已經痛到拿不住物件，春梅親眼發現 | 真實執行條件改變，春梅須重新評估可行性；不能硬讓人物照前日模式繼續 |
| E4 熟客根本沒有再詢價 | D3 新場景不得存在；金蓮可能照常算帳、招待、爭價，而非自動接受一場道德測試 |
| E5 金蓮在 D2 直接賠工／雇工，仍以精明方式獲利 | 導演不得把這條有效補救 PATH 排除，只為保留「壞選擇連續三日」的漂亮主題 |
| E6 春梅真的能按既有管理權限將工作消化 | 若沒有新增負擔或隱性損失，不能把春梅的能力說成替金蓮犧牲 |

**反例真正的功能：** 把作者、導演、模型對「自私必定留下大代價」的偏好留在競爭之外。錯誤結構的存續成本值得查，但不是預先確定的報應定律。

# 5｜對 Director 的新發現：眼睛還欠的不是新流程

**F1｜不能把「不討喜的性格」寫成每天必須做壞事。**
金蓮在利益、聲譽、權力與姊妹關係裡可以局部調整策略。真正的連續性是其優先看見的東西、可用手段與願承擔成本保持可追溯，不是每幕都重複刻薄表情。

**F2｜成本可能完成、轉形或被吸收，而不是物件永遠堆積。**
D1 兩盆碗未洗；D2 兩盆洗完，延後的可能變成下一項清掃與休息時間壓力。D3 某些事真的做完了。要追問的是誰付出何種可證的代價，不是替「積欠」不停增加道具。

**F3｜知道成本後仍選擇不補救，不自動等於邪惡、蠢或不合法。**
金蓮可能合理計算業務能力，也可能長期忽略某些未入帳成本；這需要對比人手、收入、時間與後果，不能從單一對白推定永久政策。

**F4｜局部策略改善不等於道德救贖。**
D3 不再先答應客人，只證明她在這組條件下改變風險控制行為。不能順便宣告她懺悔、護短、與春梅和解。

**F5｜人物自主與服從條件不可混同。**
李媽媽的 absolute_obedience 仍是來源的強關係設定。導演不是用「角色自主」四字就把她寫成會公開拒命的現代意識英雄；也不能用「絕對服從」把身體極限、延遲、失誤、低聲請緩都刪掉。

**F6｜導演容易把隔離測試選出的「壞分支」誤認為角色真正決定。**
這份三日敘事只是一條已標明新增前提的條件支線。沒有獨立 Character 結果、沒有 WORLD 即時判決，不能宣稱金蓮真的在任何現行 Route 連續三日這樣做。

**候選 A｜人物長期一致性：**

**候選 C｜誠實的世界不等於每個角色都說實話：**
> 導演必須誠實記錄人物的說謊、推責、愚蠢或不正當選擇；不能要求每個 NPC 都表現理火的三原則，才允許她有故事。
