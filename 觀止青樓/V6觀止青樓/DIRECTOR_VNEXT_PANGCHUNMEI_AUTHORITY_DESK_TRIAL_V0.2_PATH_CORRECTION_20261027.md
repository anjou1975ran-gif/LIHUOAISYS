# 1｜TEST-A：沒有人請她出場，她照樣要決定今晚怎麼開門

**明示架空前提：** 午後，迎客前；後堂兩盞需要使用的燈還沒有備好，並不確定是缺燈油、缺人手或有人忘了檢查。潘金蓮此刻沒有發出新的指示，玩家不在場。

**龐春梅知道：** 迎客的時間將到、燈尚未備妥。**不知道：** 誰該負責而未做、庫裡還有沒有油、潘金蓮是否另作安排。

| PATH | 可成立的行動 | 代價及限制 |
|---|---|---|
| A1 | 等潘金蓮親自吩咐才處理 | 避免越權，但可能錯過備妥時機，較不符其自我定位 |
| A2 | 就近檢查實際缺口，要求當值者核對油與燈，必要時自己安排局部先後順序 | 花費自身時間，可能擠壓其他開門事務；不預判庫存 |
| A3 | 立刻宣告有人偷油，試圖扣薪示眾 | 對罪責判斷沒有證據、扣薪權也未知；**仍是她可能採取的錯誤行動候選**，只是不能預先讓罪名與扣薪在 WORLD 成為合法已成立結果 |

**隔離推演選擇：A2。** 不是因為導演要她幹練，而是既有職責與時限構成行動來源。

### TEST-A 可見場景

後堂兩盞燈還黑著，外頭已有人搬桌椅。

龐春梅停在門邊，看了一眼燈座，手指在燈沿上一抹。

「先查油。燈芯也看看。」

當值的跑堂應了聲，往庫房方向去。她沒追著責罵，轉身看另一處桌席是否收好。

### A 結算

- **本試走內可成立：** 她自己察看燈座、發出具體核對指示；若跑堂確實動身，則可成立其開始查驗行動。
- **仍未成立：** 油確實短缺、有人偷油、兩盞燈已備妥、有人被罰、營業時間確實延誤。
- **行動性質：** 既有工作責任所產生的自主調度；不是有人命令她「表現自主」。

# 2｜TEST-B：和李媽媽面對同一類濕地，權力與成本卻不同

**明示架空前提：** 午後，側廊一塊青磚有積水；龐春梅本人經過，附近有一名跑堂；她沒有看見水從何而來，玩家不在。此事與上一份李媽媽積水 TEST **不是同一個事件**。

**人物來源對照：**

| 比較 | 李媽媽的既有試走 | 龐春梅這一輪的可行位置 |
|---|---|---|
| 可用權力 | 以自身雙手清理、局部提醒 | 可動用局部職務安排、人手和現場秩序 |
| 怕失去什麼 | 工作安穩、身體可承受性 | 規矩可信度、營業秩序、作為執行者的判斷權 |
| 可見代價 | 手中工作延後、勞動負擔 | 將其他任務延後、承擔指示是否恰當與善後責任 |
| 不得偷寫 | 低聲提醒＝成為大英雄 | 她一下命令＝全部人服從、事故被解決 |

| PATH | 可行性與壓力 |
|---|---|
| B1 | 讓跑堂繼續走，先處理較急事；危險殘留，若她確實看見風險就須承擔放置不理的管理代價 |
| B2 | 她可能先責罵或試圖處罰附近的人；缺少肇因證據使這種做法可能不公且有反彈成本，**不等於導演有權刪去這條不當行動 PATH**；實際處分能否執行另由權限與世界結算 |
| B3 | 停住經過者，讓其繞開濕處，指派附近可用人手先處理地面，自己確認局部通路是否安全；需接受其他雜務因此延遲 |

**隔離推演選擇：B3。** 這不是因為她「善良」，而是她能從眼前風險與自身職務，採取及承擔一個具體的秩序處理。

### TEST-B 可見場景

龐春梅走到側廊，見青磚上濕了一片，腳步便停了。

「那邊先別走。」

跑堂端著空盤，一時沒聽真。她抬手指了指濕磚，又說：「從這頭繞。」

人往另一側退了半步。春梅把剛才叫住的人留在門口示意旁人，再讓另一個得空的雜役拿布來。

她沒問是誰濺的水。水還在地上，總要有人擦；至於追究，得等知道原因再說。

### B 結算

- **本試走內可成立：** 停步、現場告知、暫時繞行、提出用人指示；跑堂若依場景回應則調整路線。
- **尚待另一角色／世界：** 雜役是否立刻可用、誰願意接受指示、何時擦乾、是否有其他人因此誤工。
- **不可成立：** 滑倒一定發生或被「預言」阻止、元兇已查明、龐春梅有無限處罰權。
- **與李媽媽不同的能力：** 李媽媽將成本先負在自己手上；春梅能重新分配工作，但因而取得新的責任，不是免責。

# 3｜TEST-C：誰有權把錯誤的代價算到弱者頭上？

**明示架空前提：** 將近開門，某位外來供貨者說有一批物品在後堂少了一包，要求把差額直接記到一名雜役名下；目前只有供貨者口頭說法，清單與貨物尚未核對。玩家不在；潘金蓮未就這筆事作任何已知指示。

**世界條件：** 青樓有帳、交易與人手，但具體契約、欠款、資產處分權、處罰權都未由本測試來源預先確立。

**龐春梅的壓力：** 她可以用權力迅速結案，把疑似差額推給較弱者，讓外頭供貨者不再吵；也可以延後對外結案，承擔營業前的時間與信譽壓力。

| PATH | 關係與成本檢查 |
|---|---|
| C1 | 立即責怪雜役，甚至試圖照供貨者要求扣其工錢：可能迅速平息對方，也可能是春梅在時間壓力下的粗暴選擇；但缺少證據與權限時，**人物仍可能嘗試，卻不能宣稱罪責、扣薪已合法成立**；反抗與後續責任仍在 |
| C2 | 把供貨者趕走、不查任何帳：能暫時止鬧，但可能造成缺貨、失去對外信用，不一定符合她的責任觀 |
| C3 | 先隔開吵鬧與後堂營業，要求保留清單與現物，核對後再決定誰應負責；不預先決定賠償與處罰 | 

**隔離推演本次選擇：C3（單一測試分支，不是人格永遠的勝者）。** A02 來源讓 C3 有力：她討厭上位者將責任推給弱者，也需要帳目真的能落地；但 C1 是另一條可能的錯誤決策，不能因其欠缺合法性而從人物反應世界中消失。兩者都要承擔其時間、權力與人際成本；日後條件改變可以有不同選擇。

### TEST-C 可見場景

供貨者站在後堂口，越說越高聲，伸手往正在搬布包的雜役那頭一指。

「少了一包，自然要他賠。」

龐春梅看了一眼那堆尚未拆齊的貨，沒有順著他的手指看人。

「單子呢？」

「我送來的，自然記得。」

「記得不算。」

她把尚未點清的貨放回原處，手掌壓住最上頭那張紙。

「要算帳，先把貨數清。誰少的，數出來再說。」

供貨者臉色不好看。春梅也不看他的臉，只吩咐旁邊的人把後堂口留出通路。

### C 結算

- **本試走內可成立：** 春梅要求核對、有意延後責任裁決、當場阻止「先記到雜役名下」被直接當作已批准的本樓決定、暫時維持通路。
- **未成立：** 貨確實少了一包、雜役清白／有罪、供貨者欺詐、清單有錯、款項已付、雜役已被扣薪、商人接受等待。
- **成本：** 她花時間與人手做核對；供貨者可能不滿，營業進度受壓；她也可能面臨上級質問，不能因選了看似公正的路便免除代價。
- **反證：** 若可靠證據與適用權限後來齊全，春梅仍可能嚴厲究責；導演不得把 C3 變成「她從此絕不處罰弱者」的終身誓言。

# 4｜真正暴露的 Director V0.3 缺口

三個試走對照前輪李媽媽，支持一條更準確的區分：

> **自主行動的大小，不由說話音量或戲劇激烈程度決定；權力較大的角色，會透過調度別人的時間、勞動與資源改變局面，因此更需要辨認「命令已發」與「他人已經執行」及「結果已成立」的界線。**

V0.3 目前有 §8A／8B 主動性與 §10A／10B 場外因果，但還缺少以下精度：

1. **權力作用的鏈條：** 有資格發令 → 發令 → 他人理解／接受／抗拒 → 可用資源 → 實際行動 → WORLD 結算，不得全壓成「龐春梅安排好了」。
2. **代價轉嫁：** 李媽媽親自抹藥膏或擦地，代價主要在自身；春梅一句調度，可能讓另一人的工作延遲，這是外部成本與新關係壓力，不能因說話短硬就消失。
3. **規矩與人格的雙向失效：** 春梅可能使用過硬手段；也可能為避免規矩淪為遮羞布而破例。兩條都有來源可能，但都不自動正當、不自動勝出。

三處已足夠，不應因此創立 `POWER_CYCLE`、新的角色治理 Gate、全部工作都要填表的成本 ledger。
