# 1｜新的明示條件 D4-P（純測試，非既成史）

某個後續**午前**，日常後廚收拾仍要完成（不宣稱是上一份 D3 詢價的新宴席）。李媽媽在工作時，右手指節的既有裂口碰水疼痛，端一隻洗好的碗往木架放時，因手部一縮而失去握持，碗落到青磚上，裂為幾片。

**這只破碗由本次 D4-P 輸入明示成立**，不是從三天前的「有手傷」自動推論事故必然發生；不推定她手傷在先前加桌時因果性加重、也不推定她必然疏忽。碎碗有物件損失；是否可修、是否需買新碗、價格、歸誰負擔，仍要後續調查。

龐春梅此刻在能聽到碗碎聲的附近，但先不預設她看見失手的全過程。潘金蓮在前堂看帳，**尚不知碎碗發生**。李媽媽當然知道自己手痛、碗剛裂；她不知道兩位掌櫃此前談論的所有管理成本。

這道 TEST 輸入允許一件事確定發生：**物理損失不能被導演事後漂亮收束直接取消。** 其餘的「誰的錯」「誰賠」「誰開始反抗」「掌櫃是否改革」都尚未出生。

# 3｜隔離主分支：做不到，並沒有使她變成另外一個人

後廚的水還在木盆裡晃。

李媽媽把洗淨的碗往架上一送。指節碰著粗木邊，疼得她手一縮。碗在架腳磕了一下，墜在青磚地上，裂成幾片。

她先看碎片，再看自己的手。

廊外腳步近了。

龐春梅走進門。「什麼聲音？」

李媽媽低著頭。

「碗。碎了。」

春梅看見地上碎瓷，眉頭壓下來。

「手怎麼了？」

「沒拿穩。」

「我問妳手。」

李媽媽將手攏進紅圍裙裡，過了一會才伸出來。裂口仍舊是裂口。

春梅把地上最近那隻木盆挪開。

「先別碰碎片。拿布來。」

李媽媽應了一聲，轉身去取粗布。她照做，並沒有因這一句話就忽然得到休假。

春梅看著那隻裂碗，聲音仍舊很硬。

「端不穩，先別端。今日還有多少活，拿來給我看。」

李媽媽把布遞過去。「兩盆。」

「我知道兩盆。」春梅望向木架，「我是問妳，還有哪一樣做得了。」

李媽媽沒立刻回答。她伸直那幾根手指，又慢慢攏回掌心。

「擦桌。」

春梅沒有說「妳辛苦了」，也沒有替她抹去這只破碗。

「那先擦桌。碗的事記下，別先抓誰賠。」

李媽媽應了。

**試走刻意不替金蓮補寫在場台詞。** 她不在後廚，不知道這幕發生，只有春梅後續真正傳遞才能改變她的知情。

# 4｜局部成立、未成立與必須留下的代價

**本 D4-P 隔離分支已成立：**
1. 一只洗淨的碗實際落地破裂；物件從 `INTACT` 變成 `BROKEN`，不能下一幕再端給客人。
2. 李媽媽手部疼痛引發這次握持失誤；她有裂口，但不因此宣稱長期傷勢升級。
3. 春梅聽見聲響後走進，見碎碗與裂口，要求先避開碎瓷，提出調換工作；李媽媽低聲答覆「擦桌」。
4. 李媽媽對春梅的服從關係仍維持；她不需因為身體限制而展開一場現代化勞權演講。
5. 破碎的物件、收拾所需時間、需要重新安排手上工作，是可檢查的局部成本。

**仍未成立：**
- 她手傷必然由金蓮的加席政策造成；她必然被扣薪、遭辭退或得到補償。
- 春梅已經完成重新排班；她有權單獨處分所有人薪資；她不再可能對李媽媽發脾氣。
- 金蓮知道發生破碗、親自作出裁決、改變管理政策。
- 新碗已買、碎片已清乾淨、全部後廚工作已完成。
- 李媽媽「受夠了，站起來反抗」，或喪子記憶已被此事觸發並得到療癒。

**不可逆與可修復分離：** 那只已碎的碗不會因後來賠錢而回到原樣；但觀止可能以別只碗替代、修正排班、消化金錢損失。物理損失的發生事實不可抹，經營功能卻未必因此永久崩潰。

# 5｜讓金蓮知道以後：兩位掌櫃未必會站在同一邊

**新分支前提 D4-M（僅在本節成立）：** 春梅之後親自把碎碗與李媽媽手傷的事告知金蓮，沒有誇大手傷是從哪一晚開始。金蓮由此取得知情，**不會倒回頭變成剛才在後廚親眼看到碗裂**。

金蓮可形成至少四條不同方向：

- **J1**：將破碗記入正常耗損，要求現有班表先調整；保住營業，但不等於給李媽媽道歉。
- **J2**：責備春梅調度不周，把壓力推到執行者；合理性與有效性各須檢驗，不得自動成立為真責任。
- **J3**：嘗試將損失算到李媽媽身上，甚至威脅扣工錢；人物可能作出不正當決定，卻不能直接宣稱扣薪權合法、金錢已移轉。
- **J4**：自認只破一只碗不值一提，仍要求原班完成；或可短期行得通，亦可能把問題留待日後。

**隔離選擇 J4 的局部版本，測「暫時維持舊管理」而非必然惡報。**

「一只碗？」潘金蓮翻著帳頁，笑意沒全收。

「碗能再買。桌子今晚還要收。」

春梅說：「能買，手不能今日想要幾雙就有幾雙。」

「妳要我現下加人？」

「我先讓她別搬碗。還欠著的活，我自己查。」

金蓮把帳翻回原處。

「那妳查。真缺了手，再報我。破碗記上，不必先叫人賠。」

春梅沒有得勝的表情，只將後堂還欠的活記在紙上。

**局部結果：** 金蓮知道碎碗，選擇記損並暫不雇新手；春梅繼續查排工；雙方沒有互相原諒／罷免／發下永久新規；李媽媽仍不知道前堂每句話。

**重要：** J4 在這一支線能成立，不證明她是正確經營者；J3 仍是可能 PATH，不因不討喜就消失。也不能為了反過來譴責她，而讓手傷變成命定大病。

# 6｜反向檢驗：如果沒有碎碗、若真正失穩、若作出不當處分

### CF-A｜碗沒有掉

若李媽媽今天拿穩碗，一整日都沒出事，就不能因「作者想測身體極限」而替她摔碎一只。經營壓力仍可存在，但這次物件損失不存在。

### CF-B｜春梅不在場

李媽媽可能自行收拾碎片、隱瞞片刻、等人經過才報告。春梅不能無視距離瞬移來看見整個過程；她後來得知的資訊可能不全。

### CF-C｜春梅直接下令她繼續搬碗

這是可能的嚴厲甚至錯誤選擇。李媽媽可能服從嘗試，但同樣無法保證手部當次握持能力已恢復。若再次失手，應查具體動作與物件，不能先預言。

### CF-D｜金蓮要扣薪

金蓮可以威脅、可以要求別人記帳，甚至可能尋求合法的契約處分；但未查權限與當線工錢紀錄之前，不能把「扣薪已合法完成」寫成事實。不當人物行動不等於合法世界結果。

### CF-E｜李媽媽真正的失穩條件被觸及

若另有充分來源的情節逼她公開講述喪子之痛，或迫使她打破「只管洗碗，別管閒事」的生活底線，她可能不再能保持現有姿態。**但 D4-P 的碗破與手痛本身不構成這項測試**；不得借此偷寫她創傷崩潰。

### CF-F｜春梅找到可行替代人手

實際工作可能被別人承接，排班得以調整；仍存在一只已碎的碗。補救效果不是無效，但也不能回鑄出「碗從未掉落」。

# 7｜Director 的真缺口與修訂候選（尚未入正文）

**G1｜硬限制是世界條件，不是人物選擇的否定。** 角色可以真想服從、真去做，仍因身體、時間或空間做不到。導演不能把 `CHOICE`、`EFFORT`、`CAPACITY`、`OUTCOME` 合成一個「她做到了」。

**G2｜不可逆的局部損失與整體恢復可以共存。** 破碗不能倒回完整，但替代品可以買，排班可以改。持續生存不是修正歷史；補救不是沒有代價。

**G3｜角色的倫理不等於導演的治理倫理。** 金蓮可能推責、春梅可能錯罰、李媽媽可能藏痛；導演需要誠實呈現這些決定及其條件，而不是以理火三原則強迫所有人物說真話。

**G4｜知情必須走路。** 金蓮若未聽報告，不能因為有「掌櫃」法位而全知；春梅也不能因聽見破碎聲就判定全部肇因。

**G5｜不能借「驗收壓測」強迫製造悲劇。** 若在對照分支裡碗沒破，人有足夠勞力，導演必須允許局面平靜，而不是補一個更慘的事故把測試「完成」。

**升級建議：** G1–G5 目前都是 `DIRECTOR_REPAIR_CANDIDATES`。累積到整體工作檔驗收時再整批處理，不把本次失效動作變成五個新 Runtime Gate。
