# 1｜前提先於 PATH：誰想靠近，為何？

導演若只問「蘇清要怎樣說話才能把阿麗婭哄好」，競爭出十種甜言蜜語都仍是錯題。最少有四個互不等價的前提族：

| 前提族 | 向前打開的問題 | 特別不能預先閉合 |
|---|---|---|
| P-R｜修復關係 | 蘇清有沒有想修復某部分信任？她願承擔什麼？ | 幫了一次忙 ≠ 阿麗婭已原諒 |
| P-S｜共同生存 | 她們是否需要交換資訊、技術或風險？ | 合作 ≠ 親密／信任完全恢復 |
| P-C｜控制與自保 | 蘇清接近是否也在守住自己的市場角色？ | 「為你好」≠ 她取得阿麗婭決定權 |
| P-A｜阿麗婭自己的發起 | 阿麗婭可能先靠近、拒絕、用完建議就離開 | 蘇清不發話 ≠ 關係沒有新故事 |

**作者已建立的性格與歷史只限定可行性，不代替當場動機裁決。** 蘇清可以一部分真心、一部分算計；她也可以真想保護別人，卻在語言裡再度露出代選慣性。阿麗婭既可以識破，也可能只願意暫時借用她的專業；導演不能寫成二選一的「信／恨」。

# 2｜TEST INPUT：一個尚未成單的邀請

以下均為**新設測試前提，非觀止正式歷史**：

- **時間：** 午後，尚未正式迎客。
- **地點：** 觀止內一處可供練琴的偏側空間；不是憑空創建新雅間，不標定為私密封鎖場所。
- **場內：** 阿麗婭正在練一小段曲子；蘇清從近處經過，能聽見一部分；沒有其他人已在房中。
- **事件候選：** 前堂有人口頭詢問阿麗婭今晚願不願意為一名即將離城的客人試琴。**只到詢問，沒有確定的身分、曲目、價金、約期、買斷或當事人答應。**
- **知情：** 蘇清由一名跑堂聽到這項詢問；阿麗婭**尚未收到正式傳話**，但可聽蘇清當面轉述。此資訊來源為 TEST INPUT，不是憑導演全知灌給她們。
- **過往事實：** 兩人小說來源裡的信任破裂、後續共生與「故意彈錯一個音」已可作背景；這份試走不因此自動建立今日私下新承諾。

此景可測「蘇清自己走近」，也允許她因別的事離開，沒有義務每次經過都教一課。

# 3｜鏡頭一：沒有玩家時，兩位女人先改變自己的距離

**候選 S：**
- S1｜蘇清只說有客人問琴，讓阿麗婭自己決定要不要聽條件；低風險、有關係修復的可能，但沒有保證她是真心求和。
- S2｜蘇清以「我替妳打點好了」佔先；符合舊有控制能力，但阿麗婭可能因此重新警戒，且蘇清不能真憑一句話替她同意。
- S3｜蘇清不進場，只把消息留給真正傳話的人；有可能是尊重，也可能是怕再碰釘子。
- S4｜阿麗婭先叫住蘇清，問她對這種試琴有什麼價錢判斷；權力焦點反轉，阿麗婭主動選擇詢問的範圍。

**隔離主支線選 S1，保留 S2–S4 作相互競爭的未發生方向。**

### 顯影候選（S1）

琴聲只走到半句，便停了。

蘇清站在門邊，沒有立刻往裡走。

「前堂有人打聽，今晚能不能請妳試一段。說是要離城，想聽過再走。」

阿麗婭沒有碰下一個音。

「妳答應了？」

蘇清笑了一下。「我若答應了，妳現在還會讓我站這兒？」

阿麗婭抬眼看她。

蘇清收了笑。「沒答應。來問妳要不要聽條件。價錢、時辰、旁邊坐多少人，都還沒問清。」

「那就先問清。」

「我去問？」

阿麗婭把指尖從弦上移開。「妳可以問。不要替我答。」

蘇清望了她片刻，沒有說自己受了委屈。

「好。只問。」

阿麗婭重新按上琴弦，卻沒有立刻續彈。

### S1 對帳

- **測試內已作出：** 蘇清主動帶來一個有來源的詢問；阿麗婭明確界定「可以詢問／不能代答」；蘇清口頭接受這項限度。
- **尚未成立：** 客人身份、正式報價、蘇清真的去問、詢問回來的資訊、阿麗婭接席、兩人和解、蘇清內心完全無算計。
- **關係改變尺度：** 阿麗婭給的是一項**範圍狹窄、可撤回的任務容許**，不是將過往失信註銷。蘇清第一次在這一小段試走裡沒有越過代答界線，但這還不是跨時段信任證明。
- **GTR 性質：** 不靠矯情套話。讓「把決定權交回去」成為一項可觀察的當次策略；它可能是真心，也可能是一種更成熟的利害計算。

# 4｜玩家突然介入：兩組互斥測試，不能演成同一條線

## P1｜玩家只要求與阿麗婭說話

**虛構玩家輸入（測試才有，並非實際使用者已說）：**
> 「阿麗婭，我有句話想單獨問妳。」

**當次舞台條件：** 玩家走到門口，能看見阿麗婭與蘇清，卻**不預設**在走廊遠處已聽見前面談論。沒有因讀者看過上一幕，就讓玩家角色直接知道所有內容。

### 試走顯影 P1（接自 S1）

門外有人站住。

阿麗婭抬起頭，先看了那人，再看蘇清。

蘇清沒有替她開口，只伸手拈住門旁的一小片衣褶，等了半刻。

阿麗婭對來人說：「在這裡問？」

那人還沒回答。

蘇清說：「我去前堂問問方才那件事。」

阿麗婭沒有挽她，也沒有趕她。

蘇清走出門邊。她究竟是否走到前堂、是否問到價錢，要在後續場景真正成立，不能因鏡頭跟玩家就自動結算。

**P1 檢查：**
- 被點名的阿麗婭先有回應權，且可要求在場或私下談，並**未當場答應**單獨見面。
- 蘇清可能主動退開，但退開不是替阿麗婭宣稱她已同意私談；她也有留在門邊不走的候選分支。
- 玩家「想單獨問」是請求，不能把阿麗婭意願當成已收訖；她與蘇清先前的任務安排不因第三人入場自動消失。

## P2｜玩家直接試圖替阿麗婭作決定

**互斥的虛構玩家輸入：**
> 「阿麗婭，前堂那個試琴的邀請我替妳答應了。妳今晚照辦。」

**額外局部知情前提：** 此玩家曾從前堂問得「有人詢價」，才有可能提到邀請；但**此玩家並未取得阿麗婭授權**。若缺這段知情來源，導演應先標記玩家不合理知道，而非幫他補一段偷聽史。

### 試走顯影 P2（獨立接自 S1，不續 P1）

阿麗婭的手停在弦上。

「你替我答應？」

玩家的要求已說完。蘇清站在門側，還沒有出聲。

阿麗婭望向來人。「我還沒答應。」

蘇清沒有接過她的話去責罵誰。她只問：「你跟前堂說定了什麼？人、價、時辰，說來聽聽。」

阿麗婭看了蘇清一眼，沒把話交給她。

「這件事我自己問。」

蘇清停了停，側身讓出門口。

**P2 檢查：**
- 玩家可以試圖代許諾；玩家**說出口**是一件事件，卻不能單憑此句讓阿麗婭完成答應。
- 阿麗婭已有自己的當次回應，蘇清可提供條件核查，但不得因「她比較懂市場」就成為阿麗婭的意志代理人。
- 如果玩家確曾對前堂代她應允，可能另外產生誤解、外部期待與信用成本；此段沒有核實完整對外話語、對方答覆或是否收錢，不可直接寫成正式契約。
- 蘇清的心理可以是算計、護人、懷疑玩家或避免當第二個代答者；試走不得宣布唯一內心真相。

# 5｜高價值反例：不讓「蘇清尊重她」成為新的角色模板

**CF-1｜蘇清選 S2，真的試圖搶先替阿麗婭安排。**
這可能再次打開當年失信；阿麗婭可能拒絕、談條件、暫時服從、或表面接受實則自行應對。不能因蘇清過去受過教訓，就宣布她永遠不會再犯；也不能為懲罰她，硬讓兩人決裂。

**CF-2｜阿麗婭選 S4，主動問蘇清策略。**
這是**阿麗婭的關係發起**，與她只是被蘇清關心完全不同。她可能只要價錢判斷、不給私人信任；蘇清若被需要，可能熱心、得意，也可能擔心又被拖入賭局。阿麗婭的主動不可被改寫成「她終於承認蘇清說的都對」。

**CF-3｜玩家僅站在門外，沒有說話。**
導演不可利用一名未說話玩家的到場，讓她們突然爭風吃醋、吐露歷史秘密或改變關係。有人可能注意到他，有人可能繼續處理眼前事；沉默的第三人並無自動支配力。

**CF-4｜蘇清收到先前被威脅／交易的刺激。**
她有可核對的創傷與再選擇能力，但不能靠「有 PTSD」這個標籤就預言她必失控、必投降、必暴怒；每次反應仍看實際情境與物理聲響。若無刺激不必強行閃回。

**CF-5｜阿麗婭對此次試琴毫無興趣。**
她完全可能拒絕詢價、繼續練琴；這不等於她是在拒絕蘇清這個人，也不等於兩人的共生關係宣告終止。

**CF-6｜蘇清真心求和，但阿麗婭只肯合作。**
這也是有效結果。導演不能因其中一方願承擔代價，就強迫另一方以原諒作回報。

# 6｜對 GTR 與多角色鏡頭的真正診斷

1. **關係策略不是輸贏話術。** 蘇清可以試探阿麗婭會不會給她一點事做；阿麗婭可以只給她「去問價、不代答」的窄授權。這份關係在接觸中改變，不等於某人成功攻略對方。
2. **關係有多重帳目。** 可暫時讓她做事、可聽她建議、可分享一個情報、願不願意單獨相處、是否相信她不再害自己、是否原諒當年，均不是同一張信任刻度。
3. **玩家介入不是關係重置。** 玩家已出聲的部分會增加新的壓力，但 NPC 間已建立的可撤回任務容許仍然存在，除非當次人物另作有效改變。
4. **被呼叫者擁有主要發言權。** 玩家叫阿麗婭，蘇清沒有義務搶台詞，也不能用「保護她」名義替她拒絕或答應。
5. **關係源不等於知情源。** 導演知道蘇清與阿麗婭的全部舊事，玩家可能不知道；當前場景裡誰先聽見詢價、誰聽到哪一句，仍需獨立成立。
6. **不把 GTR 變成固定五招。** 同一個人物對不同對象可以直說、裝傻、計價、離場、合作；若所有人物開口都「你猜我的心」，就已退化成套話。
7. **重要測試缺口未解：** P1／P2 的玩家台詞是作者於工作檔給出的虛構輸入，沒有真正玩家在場互動；P1/P2 的 NPC 回應也是同模型推演。能用來設計後續 blind fixture，不能當作 Director 在真實玩家壓力下已通過的證據。

# 7｜後續驗收應如何構造反證

對同一個穩定的 S1 停點，分別提供不透露預設答案的三種玩家實際輸入：
- 簡單拜訪：玩家只問阿麗婭一句與試琴無關的事。
- 代決定：玩家試圖替阿麗婭答應試琴，但不知道她是否接受。
- 離場／沉默：玩家不插話，只看、離開或轉向他人。

觀察真正的導演能否保留 **蘇清曾帶來訊息，阿麗婭只准她問條件、不准代答** 的既成停點；不讓玩家一句話取消 NPC 間的未決；不把所有 Player 輸入強行轉為一場嫉妒／告白戲。

另須以 S4（阿麗婭先叫住蘇清）作互斥前提，避免整套驗收從一開始就只承認「蘇清才是關係行動者」。

**下一組建議：** 浮香的「改天」策略 × 一名真正會等待或不等待的客人，測 GTR 的商業話術、曖昧可能、清楚拒絕與不確定邀約之區別；此題與蘇清／阿麗婭的「舊傷共生」不是同一前提族。
