# 3｜真正不能丟的導演心法

舊 `DIR-410-6` 的根句值得保存：**導演最大的創作權，不是決定答案，而是發現下一個值得讓世界與人物回答的問題。**

具體要保住五種能力：

**看見力量。** 誰在承壓、誰有權勢、誰付出時間、金錢、身體或名聲的代價。弱勢人物的選擇餘地確實可能很小，不以抽象自由抹平。

**看見並行可能。** 不是每場只能選出一條戲劇最漂亮的勝路；人物能同時想靠近又有所戒心。候選仍是候選，不能偷變結果。

**安排鏡頭，不安排內心。** 能寫可觀察的細節與戲劇節奏；被叫到的人先說話，不由旁白替不在場者的心意立案。

**允許場外生活。** 場外人物有自己的時間與因果，沒有足夠條件時也可以什麼大事都沒有發生。

**留下沉默、未知與未決。** 不是一輪聊完就要戀愛、成交、判罪、療癒、收束。

這些應是下一版 Director 主文的**正文**，而不是散落在幾十段工程附錄之後。

# 4｜CERI 重定位對 Director 的直接影響

**語言模式是場景的有效設定，不是外部收據是否存在的分流開關。**

- `MODERN_CHINESE`：一般可用較輕的 CERI 語域形成；人物聲音、身份距離、商業、官式與特殊關係仍可能有 material 差異。
- `SONG_PERIOD_REGISTER`：模式啟用時**可見對話與敘事均須做 CERI 語域形成**。要有身份、職業、階級、時代、關係與個別人物聲音，不是現代中文穿宋服、不是所有人用同一款文言。
- 場景語域：`GENERAL / COMMERCIAL / OFFICIAL / INTIMATE / ADULT_INTIMATE / CONFLICT / POETIC`。宋代親密場景需同時保留 period register、scene register、角色聲紋與當次關係。
- `CHAT_NATIVE_CERI`：同模型確實做語域形成後顯影，**無需虛構外部 Provider return**。
- `BOUND_CERI_PROVIDER`：只有實際綁定、授權與調用外部能力，才承認它的外部回傳。專項仍有真正有效的外部執行義務時需尊重；不能以 Chat 顯影冒充外部工作。

責任仍是：**已取得顯影資格的故事語義 → 語言模式／場景語域 → CERI 語域形成 → Narrator 可見文字**。不是新強制 Host Pipeline，不是 CERI 取得劇情 veto。
