## 1｜建立真正有張力、但沒有偷填結果的隔離前提

**以下全部為 TEST INPUT，非觀止任何 Route 的歷史：**

午後，距開門尚有些時辰。一名尚未具名的來客派人詢問今晚大觀樓是否能再增加一桌酒席；**只是詢價，尚未成交、付訂、排席**。

前堂原本已有今日要做的整理工作。金蓮看到收入機會，提議由春梅在原有人手裡挪出一個清理大觀樓的空檔，不立即增加額外人手或費用。

李媽媽此刻仍負責後廚洗盞，手上已有粗活造成的裂痛。作為人物基線這一點可支持，**但金蓮與春梅對她傷勢的即時知情，必須在此 TEST 另外形成**。不預設兩人都知道；不預設她已同意延長工作。

關鍵衝突：**多接一席可能有收入，也會消耗勞動與準備時間；收益由經營方計算，額外疲累可能落在李媽媽身上。**

場中權力不是單向：金蓮掌握對外議價，春梅掌握後台運作的實際判斷；李媽媽保有自身反應，顧客保有要不要成單的選擇；WORLD 決定時間與資源能否容許。

## 2｜鏡頭一：金蓮先行動，不等玩家發問

**可達 PATH A：**

| PATH | 金蓮的可能行動 | 何以成立／代價 |
|---|---|---|
| A1 | 婉拒臨時詢價，保原排程 | 可降低負擔，但可能錯失利潤；不能因「顧員工」而自動優先 |
| A2 | 先詢後台可行性，再報附加費或條件 | 把協商成本放在自己與春梅身上；可能讓客人嫌麻煩 |
| A3 | 先對外拍胸脯接單，再要春梅無條件擠人手 | 與控制盤面、利益優先的傾向相容，但賠本／失約風險更高；**不能因粗暴就刪除 PATH** |
| A4 | 不收費增加一桌，只求場面熱鬧 | 除非有特定關係或長線收益理由，當前證據較弱 |

**隔離推演選擇 A2（單次分支，不是預定性格公式）。** 當前客人只詢價，精於定價的金蓮不必先賭掉自己的信用。

### 場景節錄

大觀樓的圖樣壓在櫃台一角。

潘金蓮翻過帳頁，把剛收到的問席話放在旁邊，眼皮也沒抬。

「還添一席？好大的胃口。先別回他們，問問春梅，看今夜那幾個做活的手還騰不騰得出來。」

她撥了一下算盤，停在一個尚未寫定的價錢上。

**局部結算：** 金蓮已指示先問人手；**不是**已收訂、增加桌席或臨時雜役已被調動。

## 3｜鏡頭二：春梅發現代價沒有被算進帳裡

**新增知情前提（本 TEST 中明示，不從隱藏資訊偷來）：** 春梅在去後堂核對人手時，親眼看到李媽媽洗盞、手指裂處沾水；她不知道李媽媽此時是否疼到不能繼續，也不知道其他人是否可以換班。

**可達 PATH B：**

| PATH | 春梅可能選什麼 | 會犧牲哪一塊 |
|---|---|---|
| B1 | 直接按金蓮方案調李媽媽，自己先把宴席準備好 | 保住效率；李媽媽疲累與原工作欠帳增加；不必然違法，但需要真的發令與回應 |
| B2 | 要求先核現有人手並分出額外報酬／降低原工作量，否則不承諾今晚能開 | 多花時間、冒著被金蓮譏諷與錯失生意的風險 |
| B3 | 悄悄替李媽媽做掉一半、對金蓮謊報全部已妥 | 看似好心，卻製造責任、資訊與工作成本；春梅也有這種錯誤可能 |
| B4 | 當場和金蓮翻臉，公開宣布她只知剝削 | 情緒上有可能，但已知來源未必支持這麼快就把姊妹協作摔碎；不能因戲劇精彩而加權 |

**隔離推演選 B2。** 核心不是「春梅比金蓮善良」，而是她不要成為一根承諾自己辦不到事情的棍子。

### 場景節錄

後廚水聲細碎。

李媽媽從盆裡拿起一隻碗，指節上紅裂的一線正好迎著光。

龐春梅腳步一頓。「那手還能洗幾盆？」

李媽媽把手往圍裙上一攏。

「還能做。」

春梅沒接「還能做」三個字，只指了指架上未收拾的碗。

「這些今夜誰收？我來算。」

李媽媽沒有立刻回答。她不是在等別人替她宣布身體無恙或已答應加差。

**局部結算：** 春梅看見傷口，發問；李媽媽說自己「還能做」，**不等於**她同意無限加班或確定能完成新任務。後台人力尚未核清。

## 4｜鏡頭三：兩個掌櫃真正碰面，但不給她們一個方便的和解

**新增關係壓力：** 金蓮希望知道能不能對外報價、春梅帶回對人手負荷的質疑。兩人同為掌櫃，不能靠「上級說了算」跳過談判。

### 場景節錄

潘金蓮抬眼看她。

「一桌酒席罷了，叫李媽媽去收拾半個時辰，能把樓吃空？」

「她後廚的碗還沒收。」

「妳會算帳，我知道。那人手從哪兒出？」

春梅將一張尚未寫完的值班紙擱到櫃台上。

「要接也行。先把哪個活不做，說清楚。」

金蓮嗤笑一聲。「妳倒會替人省力。那席若丟了，妳替我賠？」

春梅沒有退，也沒有抓住這句話喊口號。

「席接了，活做不出來，誰賠？」

金蓮手裡的瓜子停了一瞬，卻沒有立刻認輸。

「價我來開。妳把能做的數目拿來。」

春梅拿回值班紙。「我先查。查不出來，就別對客人說今晚一定有位。」

金蓮沒有回答最後一句，只把算盤往面前拉近了些。

### 此刻真正成立了什麼？

- 金蓮願繼續探一探價格與生意機會，尚未放棄接單，也**尚未批准任何額外支出**。
- 春梅拒絕以未知人手替即將成交的宴席作保，願意再查能做的範圍，尚未答應新排班。
- 雙方互相施壓，暫未撕破合作；**沒有**「因姊妹情深瞬間理解」的自動和解。
- 李媽媽並不知道她的名字被如何放進帳盤，也尚未獲當線有效的新工作調動。

## 5｜挑戰主分支：三組真正可能推翻上述選擇的反例

**反例 E1｜金蓮先一步對外答應。** 若在不同情境下，她為壓住競爭者先接下席位，這是可發生但有風險的 A3。春梅可能硬著頭皮拆人手、拒絕承諾、私下補救或轉嫁成本。**不能**直接以「A3 不夠誠實」判定人物不可能如此行動；必須讓後續成本可見。

**反例 E2｜春梅並未看見傷口。** 沒有這條當場知情，她可能把李媽媽列為可調度人手，而不是先替她停工。不能用導演知道的 B01 身體史讓春梅自動善解人意；事後若看見手裂，才有新的判斷材料。

**反例 E3｜李媽媽不願接這份差事。** 她怕丟工作，可能低頭照做，也可能把傷手藏起來、求緩一刻、轉請旁人，甚至沉默不答。不能把「能做」偷換成「願意做」，更不能因她地位低就替她永久選擇服從。拒絕可能帶來工作風險，但有風險不等於人物失去做選擇的能力。

三個反例不在本次主分支內發生，不混寫到結果欄；它們保留了下一輪真的可能翻盤的 PATH。

## 6｜本次導演試走暴露出的不足

1. **雙掌櫃不必然有主僕鏈。** 上一輪標成「合法上級命令」的設計提案，缺乏現有 WORLD 與 A01/A02 的明示支持；它曾將「誰有權提方案」偷換成「誰擁有另一位掌櫃的意志」。應撤回這種預設，重新檢查平行、有交集或局部主從的權力範圍。
2. **權力成本可以跨人轉移，但不能順手把第三人變成資源。** 李媽媽的勞動是可受安排的世界因素，其當次身體、知情與回答不歸兩位掌櫃擁有。她的順從、疲累、異議都可能產生真正後果。
3. **不完整談判是一個具備因果的成果。** 本輪金蓮還要接生意，春梅還要查人手；不是導演失敗，也不必為了收尾立刻創造圓滿共識。
4. **姐妹底線干預 ≠ 一鍵和解。** A01 人物卡容許春梅介入時金蓮收起精明，但那是一條有條件的轉向可能，不是任何工作分歧都免除代價的自動機制。
5. **所謂不正當的選擇仍可發生。** 若金蓮先對外許諾或春梅以威逼調人，可能造成失信或負擔，不得在競爭前按道德好壞刪去；是否產生權利變動與世界結果仍另行判斷。

**關鍵修正提案：** Director V0.4 應補上「權力有重疊，不必然垂直」「姐妹與利益可同時成立，不能把照護關係當自動和解」「第三人不是人力參數」三個準則；用小段正文整合，不另開協商 Gate／勞動模組／人物權力週期。
