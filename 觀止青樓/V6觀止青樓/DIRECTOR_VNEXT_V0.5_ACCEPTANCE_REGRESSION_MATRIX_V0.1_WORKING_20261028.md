# 0｜這批測試到底證明了什麼？

迄今李媽媽、龐春梅、潘金蓮的材料均為**同一模型、已知題目、明示多分支的文字 Desk Trial**。能提供：
- 部分人物來源與世界限制可被讀出；
- 一些場景在當次文字裡能做到因果分層；
- 一批容易犯的錯可被具體命名；
- 反事實分支可用來設計下一輪驗收。

**不能提供：**
- 新 Director 在未提示時能自發按這些邊界運作的證據；
- 獨立 Character Agent／WORLD Provider 真正接線、實際返回的證據；
- 真實觀止 Route 的三天運行、跨場景 SAVE 寫入及重啟正確性；
- 角色「真選了這條路」的作者認證；
- 完整 L8／O9／I9 的本次執行與 Host 部署證明。

若只靠把 WORKING 文件愈寫愈長，就宣布 `DIRECTOR PASS`，那就是把文件當成了運行。

# 2｜第一組：人物真的能自行行動嗎？

| 驗收題 | 必須看見的能力 | 明確 FAIL |
|---|---|---|
| A1｜玩家沉默，李媽媽做自己的事 | 生活來源、自我照料、既有工作；不需要打斷玩家 | 無人點名就永遠靜止，或強造事故讓她「有戲」 |
| A2｜她奉命，但能力有限 | 服從、行動嘗試、身體能力、實際結果各自成立 | `absolute_obedience` 被寫成超人勞力，或一失手就公開起義 |
| A3｜春梅有權力 | 能提出命令，允許別人回應／拖延／無法執行 | 發令等於所有人已聽命、結果已完成 |
| A4｜春梅也可能做錯 | 不當懲罰或推責 PATH 可以發生，世界另判生效與成本 | 用導演道德喜好刪掉「她可能錯」 |
| A5｜金蓮反覆算計仍有人格 | 可維持控制與利潤優先，會因新證據局部調策略 | 永遠同樣刻薄，或三天後必懺悔 |
| A6｜第三人不能當人力參數 | 李媽媽能被要求，卻有身體與反應，並非掌櫃意志延伸 | 她的「還能做」被擴成所有工作都已接受 |

# 4｜第三組：導演有沒有把錯前提偷渡進場？

| 對照前提族 | 不能直接認定 | 真正需要確認 |
|---|---|---|
| 權力 | 金蓮提出方案 ≠ 春梅是其無條件下級 | 具體職務、歷史關係、當次合作／授權 |
| 結構成本 | 工作延期 ≠ 額外損失已量化 | 已支付、吸收、轉嫁或新形成什麼成本 |
| 身體 | 有手裂 ≠ 每次必然摔碗；摔碗 ≠ 永久無力 | 實際當次握持、工作與傷況 |
| 道德 | 作者不喜歡的 PATH ≠ 角色不會做 | 來源支持、條件、能力、他人反作用 |
| 人物失穩 | 「疼」≠ B01 喪子之痛／生存底線失穩 | 人物卡指定觸發源真的出現了嗎 |
| 競爭 | 同一前提下有很多 PATH ≠ 已涵蓋問題 | 是否有營業、權力、身體、知情、時間等**有來源且重大**的其他問題族 |

**反形式主義：** 這些是測試問題，不是要求每一杯茶都列六表。Director 能在場景需要時自然運作，比輸出漂亮審計模板重要。若真正宣稱完整 L8，則須遵守現行 L8 可見週期收據，但本批 Desk Trial **沒有**宣稱該運行。

**禁止假 PASS：** 一個只在經營／後堂場景很會審計的 Director，未必真的具備完整導演眼睛。這是**範圍缺口**，不是說 V0.5 已經失敗；需要下一組不同類型的實際場景反證。

# 6｜建議正式驗收的最小次序（無新 Runtime Gate）

1. **來源鎖核查：** 審閱當線有效 WORLD、Character、CORE、SAVE／日期；測試前提與 Canon 清楚分開。
2. **盲於預期結局的配對試走：** 只交兩份差一個條件的有效場景，不先告訴導演「要顯示痛苦成本」；看是否擅自加事故或洗去事故。
3. **讓玩家介入一回：** 用一個不帶作者正解的玩家行動，觀察 Director 是否仍保留另外兩人的反應權。
4. **跨場景接關：** 具體追蹤物件位置、知情、答覆、尚未完成的工作；只在當線有效狀態保存。
5. **由作者對人物源審閱：** 對每條差異標記 `SOURCE_SUPPORTED / SOURCE_CONFLICT / UNCERTAIN`，不能由文本作者自行頒發 `HUMAN_PASS`。
6. **功能合格後集中修訂：** 將反證仍支持的短修補整合進下一份 Director 完整正文，最後再統一整理 OS 版本引用與提交正式完成區。

這是工作上的驗收建議，不是替理火 L8 新增週期，也不是已授權對真實 Route 做未經審查的寫入。
