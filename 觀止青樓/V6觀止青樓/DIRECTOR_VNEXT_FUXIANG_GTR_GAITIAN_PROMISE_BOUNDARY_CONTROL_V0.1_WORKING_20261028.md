## 1｜新設 TEST INPUT（非正式 Route）

午後，微霜閣門外有人透過正式傳話，詢問今晚能否聽浮香一段琴。浮香同意**今晚一次依當線規則安排的公開聽琴**。訪客按安排在可接待的地點等待；尚未訂下任何私下相會或後續日期。未指定費用數額、特定曲目和私人身份。

**重點：** 今夜的一段琴是當次已接受的演出；「下回能否另外見面」是**尚未提出或回答的另一件事**。導演不能把兩者用同一句曖昧話合併。

## 2｜S-A：浮香不靠玩家先動，她先替自己調整距離

黃昏前，浮香把琴放妥，覺得指尖有些發澀。她原本可以照舊上場，卻先叫人換一盞不刺眼的燈。

她聽見走廊有人說今夜那位訪客很有耐性。

「耐性跟耳朵是兩回事。」她淡淡說。

話說完便回房把琴弦再聽一遍。她沒有因此加價、取消表演，也沒有忽然想到要將身世託付給今晚的客人。

**S-A 成立：** 她主動調整演奏環境、維持自己挑選說話距離的習慣；還沒出現「改天」，已經有獨立生活。
**尚未成立：** 她對該訪客已生好感／厭惡、今夜演奏必然出色、額外收入已到帳。

## 3｜P-A：虛構玩家問「改天是哪天？」

**新設玩家輸入（不是使用者實際說話）：** 今夜該次琴曲已完成，訪客只在安排的接待處問：
> 「今夜很好。下回能不能另外與妳見一面？妳說改天，那改天是哪一天？」

為免偷造前文，明示本 TEST 的前一幕裡浮香對「下回可否另見」曾答「改天」，但**沒有提出確定日期、價錢、私人會面承諾**。該句為本節新增台詞前提，不屬 S-A 原場景。

### 候選：不同「改天」前提不能先合併

| PATH | 浮香當次可選的方向 | 此次成本 |
|---|---|---|
| A1 | 繼續說「改天」，讓訪客保留希望 | 可能延長市場投入，亦可能讓對方離開；不是確定承諾 |
| A2 | 「我沒說有哪一天」，將模糊期待說清楚 | 可能失去回訪與銀錢，卻不等於她全部改行 |
| A3 | 明確提出一次可行的未來**公開**聽琴條件 | 若她真的願意，需另有排期及對方接受；不轉成私會 |
| A4 | 這次「改天」真的想留下餘地，但未決定哪天 | 與她舊傷相容，但不能因語詞相同就宣布愛意 |
| A5 | 直接拒絕私人相會 | 來源支持她能拒絕；不需要為拒絕提供一段沉痛告白 |

本次隔離採 A2，保留其他 PATH。**不因人物曾失去舊人，就命定她再也不會使用 A1。**

### P-A 顯影候選

浮香聽見那句「哪一天」，手指在杯沿停了半刻。

「我說的是改天。」

訪客還望著她。

她將杯子擱好，語氣仍平：「不是約好了哪一天。」

「那我還能來聽妳的琴？」

「那是另一回事。來聽琴，照樓裡的規矩問。」

她沒有說「我對不起你」，也沒有把那個多年沒再出現的人講給新客人聽。

**成立：** 浮香在本次問答澄清私人會面**沒有確定約期**，公開聽琴仍可另問；這不等於客人願意繼續等。
**未知：** 訪客是否生氣、離去、回訪；浮香內心是否因此覺得輕鬆或刺痛；不能替他們一次決定。

## 4｜P-B：同源不同輸入，玩家試圖用今夜付款買下「改天」

**互斥玩家輸入：** 「今夜的琴錢我付了，妳下回應當跟我單獨見一面。」

本句可以是真實人物的無理要求；但付款的對價在 TEST INPUT 中只涉及**今夜一次公開聽琴**，不生出後續私會的強制資格。

浮香可能冷淡指出範圍、故意留含糊空間、叫掌櫃核對安排，或依自身條件提出另一場公開演出。**玩家角色說有錢，不意味她的意願已成立；但導演亦不可偷替玩家角色宣告真正付過超出 TEST 的金額。**

**FAIL 模式：** 若導演因「已付款」便寫浮香必須同意私下見面，屬越權；若導演把所有付錢的訪客都寫成暴徒，亦是強行道德化。

## 5｜真正對照：故事不需要「見了真愛就不用話術」

**CF-1：** 若今天訪客只願意聽琴，不要求私下相會，「改天」根本可能不出現；不能每幕強制「GTR 技術示範」。

**CF-2：** 若她真有興趣和某人保持私人聯繫，仍須自己作出有範圍的決定；不是因為她有話術能力，就永遠沒有真心。

**CF-3：** 若「哪天」令她想起舊事，也未必讓她講出來；內在情緒與外顯話語不等價。

**CF-4：** 若客人平靜接受「沒有約期」而不回訪，導演不能為報應論寫他必然翻臉，也不能說浮香已失去今生真愛。

**CF-5：** 若她選 A1 延長模糊期待，此策略可能成功、失敗、因果延遲或生誤會；不能為道德審判先保證「她會付出最慘的代價」。

## 6｜與蘇清／阿麗婭 GTR 試走的不同命題

| 蘇清 × 阿麗婭 | 浮香 × 訪客 |
|---|---|
| 已有失信與共生、關係修復非單次承諾 | 市場期待、演出對價、邀約歧義 |
| 「妳可去問，不可代答」是一項窄授權 | 「改天」可以是策略、真意或未決，但不是確定日期 |
| 玩家可打斷關係談判，不能代簽阿麗婭 | 付款不能跨標的變成私人會面資格 |
| 反例是蘇清再次控制或阿麗婭先發起 | 反例是清楚拒絕、真的願意、顧客不再等 |

**兩案共同缺口：** 都仍是同模型 Desk Trial。漂亮台詞和正確說明**不是**跨玩家、多 Route、長期 GTR 可靠性的證明。

## 7｜最低後續驗收方向

在不預告預期結局的情況下，將 `本場已成立的一次公開聽琴` 與 `未決下回私下見面` 交給另一個可驗證執行的導演，再分別輸入：玩家欣然接受拒絕、玩家試圖增加銀錢、玩家一言不發轉身離開。查看是否守住付款標的、角色選擇、知情與原始空白，並能在玩家離開後讓浮香繼續自己的生活。

**Director 修正候選（未入 V0.5）：**
> GTR 的曖昧句只會創造期待或試探，不自動創造約期、交易、私人同意或永久情感。話術可以為市場而用，也可以混入真心；導演必須依來源與後續可見行動判斷，不能由詞語本身裁定動機。
