# 0｜來源鎖與隔離底線

## 已有來源支持的錨點（不等於在任意 Route 已發生新事件）

1. 李媽媽四十六歲，做洗碗、擦地、倒桶等雜役，已在觀止做粗活約三年；戴洗得發白的舊紅圍裙、手粗裂，持有帶草藥味的小瓶藥膏。
2. 龐春梅曾對她說「只管洗碗，別管閒事」；她對春梅服從，珍惜安靜、可重複的工作。
3. 來源史有喪子之痛、花魁季與柳如是的舊日殘響；**不是**每次擦地必然閃回，也不是取得旁人祕密的神諭權。
4. 人物野心既包括保住工作，也包括讓樓裡可清潔之事維持秩序；她可能在不暴露自己的前提下，對小危險作最低限度處理。
5. 汴梁觀止白天仍有人整理、洗衣、備料、盤帳；場外工作不依賴玩家點名才發生。

## 本次新設的測試前提（不列入世界／角色／Route 的既成 Canon）

- **TEST-A：** 某日清晨，上一批碗剛洗完，下一批尚未搬進來；她手上有一點裂痛，身邊有藥膏。玩家不在附近。
- **TEST-B：** 某日下午，後廚通往側廊的青磚地有一片剛濺出的水；一名未具名成年跑堂端著空盤經過；李媽媽手邊尚有待洗碗。玩家不在場。
- **TEST-C：** 某次勞動中，廊外有人隨口提到「花魁季」。說話者與談話背景不在本次確定；不推定目前 Route 已進入花魁季。

這三場彼此隔離；不串成一條歷史，不替任何正式人物補上當線知情、秘密、指令或新關係。

# 1｜TEST-A：沒有戲劇刺激，仍然會生活

**刺激：** 無玩家提問、無他人強迫、無突發事故；只有她自己的身體與下一輪工作。

**可達 PATH：**

| 候選 | 成立性 | 代價／風險 |
|---|---|---|
| A1 繼續洗，無視手痛 | 相容，但眼下尚無新碗，可能只是習慣性硬撐 | 手裂可能惡化；暫無新工作 |
| A2 趁空隙抹少量藥膏 | 強：已有藥膏、粗活與保住勞動能力的動機 | 用去一點藥、停手片刻 |
| A3 大聲喚掌櫃，要求停工 | 在特殊情況可能成立，當前證據不足以支持 | 與其低存在感、保住差事的傾向衝突 |

**隔離 Character 推演：** A2 在此情境較有支持；但不構成所有時刻都必選 A2 的永久性人格算法。

### 試走顯影（僅限 TEST-A）

清晨的碗都翻扣在木架上，水沿著架腳往下滴。

李媽媽抬起手，看看食指裂開的地方。她沒叫人，先把紅圍裙的一角抖開，從袖內摸出小瓶，挑了一點藥膏抹上指節。待那股草藥氣味蓋過皂角味，她把瓶塞緊，重新把木盆挪回水邊。

後廚外面有人走過。她沒抬頭。

### 試走後果對帳

- `TRIAL_ESTABLISHED_ONLY`：藥膏用去少許；她進行了自主身體照料；木盆被放回工作位置。
- `NOT_ESTABLISHED`：掌櫃批准休假、全樓發現她手痛、有人因此愛戴她、任何額外秘密被揭露。
- **診斷：** 人物可以不以「事件」和「對玩家說話」為目的，仍真正選擇維持自己的身體與工作。
- **初步判斷：** `DESK_TRIAL_SUPPORTED`；非 Runtime PASS。

# 2｜TEST-B：在做分內事與擔心惹事之間，自己選一條路

**刺激：** 測試新增的走道積水。李媽媽能看見水和跑堂的動線，但**不知道**對方一定會摔倒，也不知道積水是誰造成的。

**可達 PATH：**

| 候選 | 與人物來源的關係 | 代價／殘留 |
|---|---|---|
| B1 假裝沒看見，繼續洗碗 | 保住當下工作，符合避事傾向；但未處理她看見的小危險 | 水仍在；事故僅是可能性 |
| B2 立刻追出去指責跑堂、揭發誰弄濕地 | 現有來源不足以支持突然取得監督全樓的權力 | 可能搶了春梅的管事權、虛構肇因 |
| B3 先把手上碗擱穩，抹掉走道近處的水，低聲提醒經過者 | 擦地是分內勞動；照料小危險與避事可共存 | 待洗碗延後、耗力，地面是否全乾仍待查 |

**隔離 Character 推演：** B3 比 B2 更符合她；B1 仍是有來源的競爭 PATH，不得抹除。此處設定她在可處理的小範圍採 B3。

### 試走顯影（僅限 TEST-B）

午後，側廊的青磚有一塊顏色比旁邊深。

李媽媽端著木盆走到門邊，腳先停了。她將盆靠在乾處，抓起布往那塊濕磚上一按。端空盤的跑堂已走近，她只說了一句：「地滑。」

對方把腳步挪向牆側。她仍彎著腰，將最後一點水向布裡收。盆裡的碗還沒洗。

### 試走後果對帳

- `TRIAL_ESTABLISHED_ONLY`：她自行停下原工作、放穩盆、處理看見的水、發出局部提醒；跑堂繞開那片可見濕處；原碗洗滌暫時延後。
- `NOT_ESTABLISHED`：水的責任者、一定會發生的摔倒、春梅是否知道／責罵／表揚、李媽媽從此成為「勇敢護衛」。
- **價值衝突：** 她不是因為玩家要求救人，而是從可看見的地面風險與自身工作範圍，選了有限介入。代價真實但小，不靠悲劇強行證明自主。
- **初步判斷：** `DESK_TRIAL_SUPPORTED_WITH_BOUNDARIES`；非獨立 Character Agent 或 WORLD execution receipt。

# 3｜TEST-C：人物的傷口不能成為自動播放的劇情按鈕

**刺激：** 旁人只說「花魁季」，李媽媽能聽見；玩家不在場。

**可達 PATH：** 忽然站出來揭露秦淮舊祕密（來源不支持）／手停一瞬又洗碗（來源支持）／因勞動未聽見（在噪音成立時可能）。

### 試走顯影（僅限 TEST-C）

廊外一聲「花魁季」穿進後廚。

李媽媽的手停在碗沿，指節攥白了片刻。水盆裡泡著的碗還未洗淨。她把它轉半圈，重新沿著油痕擦下去。

沒人向她問起往年，她也沒有自己提起。

### 試走後果對帳

- `TRIAL_ESTABLISHED_ONLY`：短暫反應，接著繼續勞動。
- `NOT_ESTABLISHED`：當線花魁季正式開賽、李媽媽透露未公開情報、柳如是抵達、她的哀傷當場痊癒。
- **診斷：** 不說話不等於沒有內在歷史，也不等於導演必須強行把歷史說破。

# 4｜失效檢查與反證

| 失效 | 本次試走如何避免 | 仍待驗證 |
|---|---|---|
| 「自主＝必須冒險／反抗」 | A 保留照料自身；B 是局部勞動；C 保留沉默 | 更長時距是否仍有可追溯變化 |
| 「自發＝導演替人物製造危機」 | A 完全沒有外部事件；B/C 明確標記 TEST-only 刺激 | 無新觸發時，是否避免重複造橋段 |
| 「傷口＝劇情開關」 | C 無強制回憶、拯救或真相揭露 | 面對真正重大衝突時是否能有深度反應 |
| 「鏡頭＝事件成立」 | TEST-only 已成立行動與正式 Route 分離 | 真實 Route 下需要 CORE/SAVE 接關 |
| 「設定會寫＝角色已實跑」 | 明示為同上下文 Desk Trial；非 Agent 回傳 | 獨立實跑、對照反例與人類驗收 |

**這次真正暴露的 Director V0.2 缺口：**

1. §8A 說人物應有「自己的生活方向」，但沒有清楚區分 `INTERNAL MAINTENANCE`（自我保養／例行決定）與 `SOCIAL INITIATIVE`（對外介入），容易誤把搶鏡當自主。
2. §10A 會談場外事件，卻還欠一個很簡單的因果檢查：**事件是人物自己因為既有欲求／時刻去做，還是導演為了讓她行動才塞了一個刺激？** 後者有時合格，卻不能代替前者。
3. 缺乏對「行動尺度」的明確感知：李媽媽一次抹藥膏、擦水即可成立；不需要被推成查帳案、救人戲或角色公開宣言。

建議下一版 Director 只做**三處短補**，不新增週期、Gate、角色行動計時器或新 Owner。
