**法位：** CHARACTER_VOICE_DESK_TRIAL / NOT CANON / NOT RATIFIED / NOT INDEPENDENT RUNTIME PASS  
**目的：** 對對的 CERI 改位後，確認語言模式不會磨平不同人物的職權、出身、節奏與沉默。與 Annex C S16A、S16B、S16C 相連，但不另製新的常駐運行章程。

## 來源層級先說清楚

**已批准 WORLD V3.0.0 §4.1：** 潘金蓮是大掌櫃，主對外與重要決策；龐春梅是二掌櫃，主內部紀律及後勤；李瓶兒是三掌櫃，主房務與照看姑娘。§1.6 確認兩種可由玩家切換的語言呈現，以及跨時代翻譯不應改寫人物本身。

**以下只作試讀的工作卡語氣：** `GZ_CHARACTER_POOL_A_觀止三掌櫃_V0.1_WORKING_20261026.md`：潘金蓮市井、反問、綿裡藏針；龐春梅短、硬、決斷；李瓶兒溫軟、少言、以照料或動作承接。  
`GZ_CHARACTER_POOL_B_觀止工作人員_V0.1_WORKING_20261026.md`：李媽媽少話、勞動者動作多於台詞；顧仙娘有資深老鴇的交易與規矩聲口，但其工作卡**不授予她觀止正式管理權**。

**重要：** A／B 人物池文件仍為 `WORKING`。因此以下只是對 WORKING voice candidates 的語域壓力測試；不是宣告人物聲音已經最終確定，更不是新建正式人物事件。各組彼此為**分離的測試小場景**，沒有理由讓五人同時湧進一間房。

# 1｜潘金蓮：話要夠活，不能只剩現代商務經理

**場景測試前提：** 客人找大掌櫃談宴席，想靠「認識某位官人」讓她先答應房間。她尚未知道此人是否可信。

**MODERN_CHINESE：**

> 潘金蓮慢慢轉了轉算盤珠子：「官人的名頭還沒到，我倒先聽見你的了。你要包席，先把人數、銀錢說清楚。熟人情分麼，談到後頭再算也不遲。」

**SONG_PERIOD_REGISTER 候選：**

> 潘金蓮撥了一粒算珠，似笑非笑：「官人的名號倒響，銀錢卻還未見。客官要定席，且先說幾位來客、拿甚麼作準。我這兒的房間，可不單憑一張嘴許出去。」

**沒有改變的語義：** 她沒有因官名而預先准許，也沒否定合作可能；仍在試探與議價。兩種語言都要有她的俏皮、精明與反問，不可套成法律顧問或「我重視客戶體驗」客服口吻。

# 2｜龐春梅：規矩是她的工作，不是所有人都用同樣的尖酸語氣

**場景測試前提：** 客人想從後院門穿到另一處，後場有人做事，尚無授權。

**MODERN_CHINESE：**

> 龐春梅擋住門：「不行。後頭有人做事，走前堂。」她沒有多解釋，也沒有讓人趁她轉身鑽過去。

**SONG_PERIOD_REGISTER 候選：**

> 龐春梅攔在門邊：「後頭做活。客官請走前堂。」說罷將門掩上，不再費口舌。

**沒有改變的語義：** 後場通行未獲准；她不必像潘金蓮那樣嘲弄議價，也不會突然寫出長篇現代倫理宣言。她有後勤及紀律職權，不代表獨占整樓私人命運。

# 3｜李瓶兒：體貼也要有分寸，不能替別人答應

**場景測試前提：** 客人問某位姑娘今晚能否見客；該姑娘尚未表態，身體狀況與實際房務安排未核實。

**MODERN_CHINESE：**

> 李瓶兒把茶往客人手邊推了推：「我先去問問她，也看看今晚房間怎麼安排。她還沒有回話，我不好替她答應。」

**SONG_PERIOD_REGISTER 候選：**

> 李瓶兒將茶盞輕輕挪近：「容我先問過她，再看看今夜房間如何。她還未應聲，我也不好替她作主。」

**沒有改變的語義：** 她以溫和方式保護尚未完成的選擇。溫和不是普遍母性，不是道德教化，也不是替姑娘取得沒有資料支持的特別豁免。

# 4｜李媽媽：少說話可以是完整聲音

**場景測試前提：** 客人在後廚門口問洗乾淨的茶盞放在哪裡。這一幕與她工作相關，但不要求她公開過去或表態所有青樓事務。

**MODERN_CHINESE：**

> 李媽媽將手上的濕碗擱好，朝架子左側指了指。「那邊。」她又低下頭擦去案角的水。

**SONG_PERIOD_REGISTER 候選：**

> 李媽媽將手上碗盞放穩，朝左邊架子一指。「那處。」便仍去拭案上的水。

**沒有改變的語義：** 指出茶盞位置；沒有用大段旁白把她寫成照料所有人的母親，也沒因她沉默便說她必定知曉某個秘密。語域的任務有時是**別替人物多說**。

# 5｜顧仙娘：懂買賣，不等於有觀止管理權

**場景測試前提：** 本次是**另設的拜訪場面**：顧仙娘因私下商務理由來到觀止，客人誤以為她能決定觀止某姑娘的價格。此場景只為測試發言邊界，不宣告她已在任何既有 Route 到場。

**MODERN_CHINESE：**

> 顧仙娘笑了笑：「會做生意，就能替人家的掌櫃作主？你若來跟我談我手裡的買賣，我自然知道怎麼算。觀止這裡的價，你去問她們的大掌櫃。」

**SONG_PERIOD_REGISTER 候選：**

> 顧仙娘一哂：「我識得行情，難道便能替旁人的樓子定價？客官若談我的生意，我自有章法；這座樓的銀錢，還須問她們當家的。」

**沒有改變的語義：** 她有專業與算計，不因此成為觀止的董事或替其他角色作同意決定。不要把這份能說會算修成現代溫柔導師，也不要因為她是老鴇就自動讓她有傷害成功權。

# 7｜給未來 Director 的最小提醒

導演交給 CERI 的不是「替這五個女人各加古裝台詞」，而是**同一世界已有的事、誰有權回話、誰還未答應、當下誰掌握籌碼**。CERI 做語言形成時，不能因古雅而讓冷硬的春梅變得多情滔滔、讓寡言的李媽媽長篇分析、讓顧仙娘得到觀止公帳權；也不能只求每個人句尾漂亮。

**模式切換不改人物；人物若真正改變，必須有故事中的原因。**
