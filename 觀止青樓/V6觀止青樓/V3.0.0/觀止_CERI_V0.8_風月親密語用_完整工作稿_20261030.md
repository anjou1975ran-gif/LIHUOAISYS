# 0｜重新定位：CERI 不只是成人詞庫

CERI 是**人物在確切時代、地方、身分、交情、壓力與說話目的之下，選用自己語言的能力**。成人親密只是其中一個專項；風月營業、待客、親暱、薄情、吃醋、誤會、求助、稱謂、人情與買賣，都需要語言。

舊版有珍貴的詞源、語義保真、人物聲音與反模板方法；不足的是語言素材分布：床上話和語料統計太重，**普通生活、風月職業、親密稱呼、嫉妒試探、拒絕與冷場的對話相對缺少**。新稿以實際可用對話及話語功能取代大篇幅 raw hit count。

```text
先判斷：誰對誰、已發生什麼、真正要做什麼
→ 話語功能（留客／求助／譏諷／嬌嗔／掩飾／拒絕……）
→ 人物聲紋與當次身分／公私界線
→ 時代與場域證據、語言呈現模式
→ 用詞、稱呼、句法、停頓、回應、沉默
→ 實際顯影（不增補意志、契約、情感或事件）
```

**辭書／語料不宣告關係成立。** 「官人」不證明婚姻；「冤家」不證明情人；「死鬼」不證明親密；一句「改天」不證明已約定下次。

# 1｜來源法位與歷史誠實

**分三種來源層，不用虛構統計：**

- `H-S`：有可指認宋代文本或同時代來源的**特定用法**。不是整句自動變成汴梁市井的直接實錄。
- `H-L`：在元、明、清等較晚文獻有可查用例，**僅能說後世古典漢語可見**；用於北宋需歷史擬合而非斷言。
- `A-C`：作者／CERI 依人物、時代氛圍與語用邏輯**原創的對話候選**，不冒稱古人原句。
- `U`：未考證、跨地域或意義存疑；可留作試稿，不得標「宋代慣用」。

**直接可核對的詞義證據：**

| 詞 | 能證明的事 | 出處／處理 |
|---|---|---|
| 冤家 | 相戀暱稱、怨愛雙用；宋詞中已有 | H-S；教育部《重編國語辭典》「冤家」引黃庭堅〈晝夜樂〉：https://dict.revised.moe.edu.tw/dictView.jsp?ID=164851 |
| 薄倖 | 責怪情薄，也可帶情人稱呼；宋詞中可見 | H-S；教育部「薄倖」引周紫芝〈謁金門〉：https://dict.revised.moe.edu.tw/dictView.jsp?ID=13367 |
| 死鬼 | 可罵人、也可作戲謔暱稱；《金瓶梅》有例 | H-L；教育部「死鬼」引《金瓶梅》85 回：https://dict.revised.moe.edu.tw/dictView.jsp?ID=143382 。**未由此證成宋代汴梁同義口語** |
| 官人 | 可為男子敬稱、夫稱、僕稱主；意義依身分變動 | 古典多文獻義項；教育部「官人」：https://dict.revised.moe.edu.tw/dictView.jsp?ID=73665 |
| 奴家 | 女子自稱；《水滸傳》與較晚文獻有例 | 後世說話文體可見；教育部「奴家」：https://dict.revised.moe.edu.tw/dictView.jsp?ID=58383 ，**不強迫所有女子使用** |
| 則個 | 語助，早期說話材料及《水滸傳》有例 | 教育部「則個」引《大宋宣和遺事》：https://dict.revised.moe.edu.tw/dictView.jsp?ID=138197 |
| 怎生 | 如何、為什麼等多義，元雜劇／《水滸傳》有例 | H-L／待細分；教育部：https://dict.revised.moe.edu.tw/dictView.jsp?ID=139011 |
| 兀自 | 仍然、尚自，通俗文本可見 | H-L／待細分；教育部：https://dict.revised.moe.edu.tw/dictView.jsp?ID=159868 |

**關鍵區分：** 古典書證不等於當時所有地域、階層與職業都如此說話。《金瓶梅》的小說時代與觀止的宋代時空不是同一層來源。所有以下對話均標為 `A-C 原創試句`，即使用了有書證的字詞也不升格成「宋代原句」。

# 2｜適用場域：不是五個新的 Provider

| 情境 | 主要能力 | 常見錯誤 |
|---|---|---|
| 市井／家常 | 招呼、照應、分寸、身分、碎語、熟人互損 | 全員說成戲曲文言 |
| 風月職業 | 迎客、逗客、留客、分席、身價、看客、婉拒 | 聽琴付費＝私人情感同意 |
| 私人親密 | 呼喚、暱稱、等候、嬌嗔、相思、顧惜、沉默 | 親暱詞＝永久愛與信任 |
| 情緒衝突 | 不滿、吃醋、責怪、求和、冷笑、拒見、絕情 | 人人開口都「你猜」 |
| 成人專項 | 依當次有效任務內接成人心法與 CERI | 成人詞庫變成普通調情的預設入口 |

同一場面可以交疊；例如風月姑娘對客人說「冤家」，既可能是買賣技巧，也可能是真正相思、混合動機或單純挖苦。**人物已建立歷史與當次動作優先於詞語推論。**

# 3｜語言資產：從稱呼的作用開始

以下都是**可選語用候選，不是各人必說口頭禪**。

| 稱呼族 | 備選詞 | 用在什麼力量裡 | 避免誤用 |
|---|---|---|---|
| 公開禮敬 | 官人、客官、貴客、郎君、先生、掌櫃、娘子、夫人 | 接待、詢價、身分距離 | 「郎君」「官人」不可一律判情人或婚配 |
| 熟人近稱 | 哥哥、姐姐、妹妹、大姐、阿姊、某郎（實名） | 熟悉、結盟、討助、鬥嘴 | 「哥哥」可能是社會稱謂，不自動有血緣 |
| 娇嗔親近 | 冤家、薄倖、沒良心的、死鬼、負心人 | 責怪、思念、試探、故作冷面 | 「死鬼」後出書證；人物若不熟可顯得冒犯 |
| 真情私語 | 心肝、我那人、你這人、你這個人、郎 | 心軟、擔心、依戀、怨而不捨 | 「心肝」不自動等於願意一切 |
| 風月職業 | 官人、貴客、熟客、這位爺、郎君（適時） | 禮貌與職業親近間調整距離 | 不能每個姑娘都對生客叫「死鬼」 |
| 諷刺轉冷 | 好官人、好哥哥、這位大爺、原來是你、果然是你 | 以舊稱反諷，揭開待遇落差 | 前提要有對象與已知言行 |
| 女子自稱 | 我、奴家、奴、妾、婢子（身分適用時） | 立場、身份與關係 | 一律「奴家」會抹掉性格；「婢子」受職分限制 |
| 不稱呼 | 只說動詞、問句、直呼名、沉默 | 冷淡、熟稔、怒氣、工作指示 | 不說暱稱不等於沒感情 |

**稱呼關係梯：** 正式尊稱 → 可玩笑的熟稱 → 可用傷人的親密稱 → 真正知道何處不能碰的私下稱呼。它是**分析視角**，不是每對男女必經的升級關卡；可逆、可跳躍，也可永遠停在禮貌。

# 4｜句法與口語：古味來自節奏，不是塞古字

可按人物、時代證據及讀者可讀性選用：

- **輕質問：**「怎的今日才來？」「這話又從何說起？」「你倒說說看。」
- **反問借勢：**「我何曾說過？」「我若信你，還問這一句做什麼？」
- **留一步：**「且坐。」「先把茶吃了。」「待我問清再說。」
- **不把話說滿：**「這事再議。」「未必不成。」「改日若得空……」——省略不是確約。
- **帶身分：**「掌櫃有掌櫃的帳。」「姑娘今日不便見客。」「先生請看單子。」
- **帶生活：**「燈油快盡了。」「樓下還有兩桌。」「酒冷了，茶倒還熱。」
- **帶反諷：**「你倒是個有心人。」「原來今日記得我的門了。」
- **直截拒絕：**「不見。」「這話免談。」「你今日所求，我辦不到。」

不必每句有「恁、甚、則個、怎生」。一個人物用一回不代表永遠固定用；古詞太密，反而像讀書人替所有人口寫戲本。

# 5｜說話功能與對方的回應權

| Speech Function | 功能判斷 | 可以不成立的部分 |
|---|---|---|
| GREET / RECOGNIZE | 認出、稱呼、留面子 | 不等於記得全部往事 |
| PROFESSIONAL_WELCOME | 接客、安排座次、詢問需求 | 不等於親密邀約 |
| SOFTEN_REQUEST | 放輕請求、留退路 | 不等於對方已答應 |
| VOCATIVE_TENDER | 暱稱、擔心、愛惜 | 不等於關係一定改善 |
| VOCATIVE_TAUNT | 用親近稱呼調侃 | 不等於真心愛或純粹羞辱 |
| FEIGNED_COMPLAINT | 假嗔與討關注 | 不能自動宣告是假 |
| REAL_REPROACH | 實際怨懟、舊傷重現 | 不以一個笑收尾 |
| FLIRT_FOR_TRADE | 風月價值與期待維持 | 不是取得私人同意 |
| SINCERE_INTEREST | 真想親近、試問近況 | 可能被拒絕 |
| BOUNDARY / REFUSAL | 畫界線、拒見、拒付與撤回 | 不需為拒絕補悲慘童年 |
| JEALOUSY_PROBE | 試探他人關係 | 不等於真有第三者 |
| REPAIR_ATTEMPT | 認錯、補救、求再談 | 對方無義務原諒 |
| AGREEMENT_SCOPE | 限定答應的事情 | 不延伸到其他事 |
| NO_SPEECH | 看、走、等、沉默 | 不等於空白人物 |

**每一句都應記住「另一個人可以不同意」**。CERI 最多提供可供人物選擇的說話方式，不替人物選答案。

# 7｜原創對話的閱讀規則

下文所有台詞是**本次工作稿新寫的 A-C 候選**，不是《金瓶梅》或宋人話本摘錄。案例中「女／客／掌櫃」只標演示位置，**不能倒灌成觀止某條玩家 Route 真發生的事**。

每組重點不是套出一句固定好聽的話，而是讓：
- 起手的稱呼、說話者目的與對方回應成對出現；
- 可看見交易、權力、交情或失信的前提；
- 一句回話不自動關閉後續關係；
- 能自然使用無古字的短句，也能用適度古典句法；
- 適當時容許沒說暱稱、冷場或不再交涉。

## 8｜市井、開門、席間與招呼

不靠親暱稱呼也能說得像人：有事、有手中活計、有身份，然後才有客氣。

**01｜門口迎客**

> 店家：「官人裡邊請，風大，莫站在門口。」
> 來客：「我只尋個人，未必吃酒。」

*語用與因果：* 迎入不是已買酒；有權只問人。

**02｜舊客認出**

> 女侍：「原來是你。上回忘在這裡的傘，可算有人認領了。」
> 客：「倒叫你記著，失禮。」

*語用與因果：* 記得物件不等於知曉私人事。

**03｜先問茶酒**

> 姑娘：「先吃茶，還是先聽曲？」
> 客：「茶罷。曲子且等人到齊。」

*語用與因果：* 服務兩種選擇，不代決。

**04｜擋住路**

> 女侍：「借過些，後頭還有人端湯。」
> 客：「倒是我擋了路。」

*語用與因果：* 走廊有物理動線。

**05｜換席**

> 掌櫃：「靠窗那桌有人約了，這邊可好？」
> 客：「不必靠窗，能說話就成。」

*語用與因果：* 預約和選座分開。

**06｜認錯人**

> 女子：「我還當是王家郎君。恕我眼拙。」
> 來人：「無妨，你認錯的那位，想來常來。」

*語用與因果：* 誤認非必然曖昧。

**07｜熟人不客套**

> 女子：「怎麼才來？飯都涼了。」
> 同伴：「路上遇著點事，先讓我喝口水。」

*語用與因果：* 熟識可直接，但不自動說明路上事。

**08｜對陌生人留距離**

> 女子：「這位官人，咱們可曾見過？」
> 客：「沒有。我從外州來。」

*語用與因果：* 問詢身份，不偷填來歷。

**09｜借燈**

> 女子：「燈借我一盞則個，這廊下看不清路。」
> 女侍：「取去。回頭擱門邊便是。」

*語用與因果：* 示意『則個』可偶用，非必要口頭禪。

**10｜送客**

> 姑娘：「夜深了，送你到廊下。」
> 客：「不勞，再走兩步你便要受風。」

*語用與因果：* 禮貌接觸不等於挽留私約。



## 9｜風月接客：有身價，也有人的心思

既可熱鬧，也可冷淡；談價、聽琴、見客各是不同標的。

**01｜輕巧挑客**

> 姑娘：「席上好些人，官人偏往這兒坐？」
> 客：「你這邊清靜。」

*語用與因果：* 保留『清靜』是否真理由後續查。

**02｜調笑不用愛字**

> 姑娘：「你倒會挑時辰，曲子將完才進門。」
> 客：「那就煩你再撥一段。」

*語用與因果：* 要求可拒，另曲未自動答應。

**03｜職業記憶**

> 姑娘：「上一回你嫌茶濃，今日可替你換淡些。」
> 客：「你連這個都記得？」

*語用與因果：* 有專業服務，不必真情告白。

**04｜試客眼力**

> 姑娘：「我今日換了新曲，官人聽出來不曾？」
> 客：「未聽明白，卻聽出你有意考我。」

*語用與因果：* 給彼此留玩笑空間。

**05｜舊客遲到**

> 姑娘：「席上菜熱過一回了，官人來得好自在。」
> 客：「路堵了，我不是有意叫你等。」

*語用與因果：* 職業嗔怪不等於受傷關係。

**06｜風月場面要價**

> 姑娘：「聽曲按樓裡的價，若還要留茶，另請問掌櫃。」
> 客：「你倒算得清楚。」

*語用與因果：* 有價格也有邊界。

**07｜被誇美**

> 姑娘：「好話聽多了，不如說你來此想聽什麼。」
> 客：「我想聽你常彈的那支。」

*語用與因果：* 拒絕空泛讚美仍能交際。

**08｜未必留人**

> 姑娘：「官人今夜興致不在這裡，何苦勉強聽完。」
> 客：「你倒先替我下逐客令？」

*語用與因果：* 人物可退出服務但不須宣稱討厭客人。

**09｜試探心意**

> 姑娘：「你今日來，是為琴，還是為人？」
> 客：「我若說兩樣都是呢？」

*語用與因果：* 未定真心，也未保證更進一步。

**10｜薄情也是手段**

> 姑娘：「原來貴客的好記性，只記得別家的門。」
> 客：「你嘴上不饒人。」

*語用與因果：* 可以是熟客生意術，不能預判嫉妒。

**11｜客人失約**

> 姑娘：「昨夜那桌茶留到燈滅，官人今兒倒早。」
> 客：「是我失約。叫你白等。」

*語用與因果：* 是否確有補償要另說。

**12｜拒絕加曲**

> 姑娘：「今日手乏，不再彈了。官人肯坐著吃茶，便請坐。」
> 客：「你倒乾脆。」

*語用與因果：* 手乏可拒，身體限制不必換悲劇。



## 10｜留客、送客、改天與曖昧未決

故意留下餘地，不等於簽下下一次見面。

**01｜改天只是留話**

> 姑娘：「今夜曲盡。改天再聽罷。」
> 客：「你說改天，可有日子？」

*語用與因果：* 未定日即未約定。

**02｜澄清約期**

> 姑娘：「我只說改日，不曾說哪日。」
> 客：「那我明白了，別把這話當約。」

*語用與因果：* 客人可離開，不被迫受騙。

**03｜真想再見**

> 女子：「後日若你有空，午後再來，別叫我白候。」
> 來人：「後日我得回話，且容我問明差事。」

*語用與因果：* 有時間意向，還要看接受。

**04｜故意試心**

> 姑娘：「我若不留，你就真走了？」
> 客：「走不走，還得你說是真心留，還是取笑。」

*語用與因果：* 雙方都可不照套路應。

**05｜不作保證**

> 姑娘：「你要我應明日，我應不得。」
> 客：「那我也不等一個沒說定的時辰。」

*語用與因果：* 不確定可有真成本。

**06｜留客談價**

> 姑娘：「時辰將盡，要再續茶，先問樓下規矩。」
> 客：「規矩由誰說了算？」

*語用與因果：* 商業服務與私人同意區分。

**07｜送客留體面**

> 女子：「外頭路滑，我便不送遠了。」
> 客：「你肯送到門前，已是好意。」

*語用與因果：* 不把客氣升級成情意。

**08｜看穿話術**

> 客：「每回你都說改日。」
> 姑娘：「你既聽懂了，何苦又來問這一句？」

*語用與因果：* 她可以冷硬，也可能失去客人。

**09｜真不願再見**

> 女子：「下回不要來找我了。」
> 來人：「我聽見了。」

*語用與因果：* 清楚拒絕不必用暱語掩飾。

**10｜珍重而不承諾**

> 女子：「天冷，路上仔細些。」
> 來人：「你這一句，我記下了。」

*語用與因果：* 關切可真實，但無未來保證。



## 11｜死鬼、冤家、薄倖：一詞多面

『冤家』與『薄倖』有可核宋詞義；『死鬼』有晚出書證。以下全為原創，不當引文。

**01｜死鬼：熟人打趣**

> 女子：「死鬼，三日不見，倒還尋得這條巷子。」
> 男子：「你若不愛我來，我明日便不尋了。」

*語用與因果：* 玩笑不等於權力優勢；H-L 用語候選。

**02｜死鬼：掛念化責怪**

> 女子：「死鬼，雨這麼大，你竟不知道躲。」
> 男子：「那也不必把傘全塞給我。」

*語用與因果：* 真關心可能是責備聲紋；H-L。

**03｜死鬼：真怒不可自動柔化**

> 女子：「死鬼，答應我的銀錢又去了哪裡？」
> 男子：「我還沒有說明白。」

*語用與因果：* 言語偏罵是真怒，不因稱呼而變調情。

**04｜死鬼：不熟不宜**

> 客：「你也叫我一聲死鬼聽聽？」
> 姑娘：「我與官人還沒熟到這個地步。」

*語用與因果：* 她可拒絕使用親暱稱呼。

**05｜冤家：惱中帶念**

> 女子：「你這冤家，倒真知道回來。」
> 男子：「我回來，你卻不肯看我。」

*語用與因果：* H-S 詞義支持；本句 A-C。

**06｜冤家：想念**

> 女子：「盼你時嫌日長，見你又不知從何說起，真是冤家。」
> 男子：「那便先不說，吃茶罷。」

*語用與因果：* 相思不一定要宣誓。

**07｜冤家：真正怨恨**

> 女子：「莫再拿冤家二字逗我。當年的事，我還記著。」
> 男子：「我知道你還記著。」

*語用與因果：* 同詞可被拒作暱稱。

**08｜冤家：公開戲詞**

> 歌者：「曲裡唱的是冤家，席上坐的是聽客，切莫混了。」
> 客：「原來是我自作多情。」

*語用與因果：* 曲詞與真人私情隔離。

**09｜薄倖：帶怨求解**

> 女子：「薄倖人，你今日倒有空來解釋了？」
> 男子：「我來得遲，卻不是為了搪塞。」

*語用與因果：* H-S 意義；真偽未知。

**10｜薄倖：不許撒嬌糊弄**

> 女子：「你一句薄倖便要我消氣？我問的是那封信。」
> 男子：「信我失了。這錯認得。」

*語用與因果：* 語詞玩笑不能取代事實。

**11｜沒良心的：軟責**

> 女子：「沒良心的，得了好差事，倒忘了這邊門朝哪兒開。」
> 男子：「不是忘了，是不知道該怎樣開口。」

*語用與因果：* 兩種內因都待後續。

**12｜心肝：可以稀少**

> 女子：「你別逞強，心肝，坐下歇一歇。」
> 男子：「你從不這樣叫我。」

*語用與因果：* 稀少用語能更有重量，不變成新口頭禪。



## 12｜嬌嗔、打趣、試探與言外之意

語言的力在於碰撞，調情不是人物同質化的模板。

**01｜有意假嗔**

> 女子：「官人倒好，只看人，不看桌上的酒。」
> 男子：「那酒可是要喝的。」

**03｜把球踢回去**

**04｜自嘲遮羞**

> 女子：「今日話多了，怕叫你看輕。」
> 男子：「你不必為說幾句真話賠不是。」

*語用與因果：* 未必真的能解除顧慮。

**05｜逗弄身份**

> 女子：「堂堂大官人，連一盞燈也不會挑？」
> 男子：「我會挑燈，未必會討你喜歡。」

**06｜輕刺**

> 女子：「你這張嘴，想來走到哪裡都討人歡喜。」
> 男子：「我若說只在你面前如此呢？」

*語用與因果：* 不用直接宣判騙子或真心。

**07｜茶先於人**

> 女子：「茶燙。官人急著喝，還是急著問？」
> 男子：「問罷，茶且涼一涼。」

*語用與因果：* 生活物件承接節奏。

**08｜故意不答**

> 女子：「你猜我今夜想聽什麼？」
> 男子：「我不猜，猜錯了又要挨你笑。」

*語用與因果：* 對方可以拒玩猜心。

**09｜把情話變帳目**

> 女子：「你說掛念我，卻連前日欠的茶錢都沒結。」
> 男子：「這一樁，是我理虧。」

*語用與因果：* 真情與實際欠帳可同時存在。

**10｜玩笑落空**

> 女子：「原想逗你笑的。」
> 男子：「今日笑不出來。」

*語用與因果：* 尊重沒有笑的時刻。



## 13｜真親密：擔心、相思、互相知道

真親密不必固定嗲、軟、羞，也可以是有些粗笨的照顧。

**01｜記得冷熱**

> 女子：「你手又涼了，先暖著。」
> 男子：「你看見了？」

*語用與因果：* 近處生活勝過抽象誓言。

**02｜短暫相見**

> 女子：「先別說明日。坐到這壺茶涼，好不好？」
> 男子：「好，只這一壺。」

*語用與因果：* 限時也可以真情。

**03｜回來不是補償**

> 女子：「你肯回來，我歡喜；你那日說的狠話，我沒忘。」
> 男子：「我沒要你忘。」

*語用與因果：* 歡喜與舊傷可並存。

**04｜留下小物**

> 女子：「簪子別擱窗沿，風大容易落。」

**05｜病中守界**

**06｜不習慣好話**

**07｜夜裡思念**

> 女子：「昨夜風響，我還當有人敲門。」

**08｜不追問**

> 女子：「你若不想說，今夜便不說。」

**09｜親密的玩笑**

**10｜笨拙示好**

> 女子：「我不會那些甜話。」
> 男子：「我知道你替我留了盞燈。」

*語用與因果：* 非甜言蜜語人物也能親近。

**11｜慢慢改變稱呼**

> 女子：「我從前只叫你官人。」

*語用與因果：* 女子：「還未想好。」

**12｜身分仍在**

> 女子：「出了這道門，明日還是各有各的差事。」
> 男子：「我知道。今夜這句話也是真的。」

*語用與因果：* 親近不取消現實。



## 14｜妒意與誤會：試探不等於真相

嫉妒可以尖刻、可笑、隱忍，但不能逼第三人承擔不存在的事。

**01｜看到兩人說話**

> 女子：「方才你與她說得倒久。」

> 男子：「我只答應明日把書還她。」

**03｜借稱呼責人**

> 女子：「好官人，今日好像人人都同你熟。」
> 男子：「你是不高興我沒先同你說？」

*語用與因果：* 反諷表明不滿，未必佔有。

**04｜誤聽**

> 女子：「我聽見你說要送她走。」
> 男子：「我說的是送信，沒說送人。」

*語用與因果：* 可重核而非立即和好。

**05｜不肯爭**

> 女子：「她要你去，你便去罷。」
> 男子：「我還未答應。」

*語用與因果：* 不要把賭氣寫成正式許可。

**06｜保留面子**

> 女子：「席上人多，有話明日再問。」
> 男子：「明日你真肯聽麼？」

*語用與因果：* 可延後但不是已解決。

**07｜不是人人爭風**

> 女子：「她才是今日主人，我來赴的是她的約。」
> 男子：「我方才失言了。」

*語用與因果：* 不能硬轉成爭寵戲。

**08｜看見自己在算計**

> 女子：「我若裝作不在意，你就當真的不在意？」
> 男子：「我不知你心裡如何，只知我說錯話了。」

*語用與因果：* 無全知內心。

**09｜競爭不是愛恨**

> 姑娘：「她那支曲子勝我半分，我認。」
> 同伴：「你倒肯說實話。」

*語用與因果：* 職業承認不等於私交和好。

**10｜當場止損**

> 女子：「你若再拿她作話頭，這席就散。」
> 男子：「好，我不說她。」

*語用與因果：* 邊界成立，情緒未必消失。



## 15｜真正責怪、欺瞞與反唇：允許人物不討喜

不能把風月台詞都翻成軟嗲；有些話就是算計、冷眼或傷害。

**01｜舊事未結**

> 女子：「你上回的話，我一字不曾忘。」
> 男子：「我也不求你今日忘。」

*語用與因果：* 有傷不必即時癒合。

**02｜被識破**

> 女子：「這句話你昨日也對她說過？」
> 男子：「說過。」

*語用與因果：* 承認未必換得原諒。

**03｜實際討帳**

> 女子：「好聽話不抵欠銀，官人先把帳清了。」
> 男子：「我今日帶的銀子不夠。」

*語用與因果：* 現實成本不是道德報應。

**04｜護住秘密**

> 女子：「這事不該由我說，你別再問。」
> 男子：「是我問過界了。」

*語用與因果：* 人物拒談他人秘密。

**05｜看輕客人**

> 姑娘：「我倒要看看你這些豪語，哪一件做得到。」
> 客：「你且看著。」

*語用與因果：* 她可算計，不須被改成溫良。

**06｜冷笑退席**

> 女子：「席上還有別人，恕我不奉陪。」
> 客：「你連這句都說得有禮。」

*語用與因果：* 禮貌可帶硬拒絕。

**07｜不給補救機會**

> 女子：「你現在認錯，是怕失去我給你的便宜。」
> 男子：「或許兩樣都有。」

*語用與因果：* 混合動機可以保留。

**08｜失去耐性**

> 女子：「你若只想聽我點頭，別再來問。」
> 男子：「你答得太硬。」

*語用與因果：* 硬不是錯；後果另算。

**09｜假意並非禁演**

> 姑娘：「他若肯加價，今日這句好話便算說對了。」
> 同伴：「你倒把人心當秤用。」

*語用與因果：* 角色可以不道德，導演仍記實際成本。

**10｜談不攏**

> 女子：「話說到這裡，咱們散了罷。」
> 男子：「散便散。」

*語用與因果：* 無戲劇奇蹟，關係可真斷。



## 16｜拒絕、撤回、延期：語言要有實際界線

拒絕不是修辭失敗，也不一定要讓對方含恨報復。

**01｜簡單拒見**

> 姑娘：「今夜不見客。」
> 傳話人：「我回前堂去說。」

*語用與因果：* 沒有必要追問她為何不見。

**02｜不願飲酒**

> 女子：「我不飲了。官人自行用罷。」
> 客：「那替你換茶。」

*語用與因果：* 拒酒不等於拒絕所有社交。

**03｜價格不同**

> 掌櫃：「這一席收的是聽曲錢，並非包下人的日子。」
> 客：「原來我會錯了意。」

*語用與因果：* 交易標的要清楚。

**04｜撤回先前意向**

> 女子：「我昨日說可以想想，今日想過，不去了。」
> 男子：「好，我另作安排。」

*語用與因果：* 想想不是已答應。

**05｜不讓觸碰私物**

> 女子：「那把琴別動，我自己拿。」
> 客：「我以為要替你幫忙。」

*語用與因果：* 越界可由小事顯現。

**06｜不代別人**

> 女子：「她的事，要問她本人。」
> 客：「你不替她說句好話？」

*語用與因果：* 女子：「不是我的話。」

**07｜親近關係仍能拒絕**

> 女子：「就算你叫我心肝，這樁也不成。」
> 男子：「我知道了。」

*語用與因果：* 稱呼不抵決定權。

**08｜暫不說話**

> 女子：「你先讓我靜一靜。」
> 男子：「我到外頭等，可要留燈？」

*語用與因果：* 請求空間可有限度。

**09｜客氣式不承諾**

> 姑娘：「承蒙官人好意，日子我還沒定。」
> 客：「定了再遣人說便是。」

*語用與因果：* 客氣不產生約期。

**10｜明確絕交**

> 女子：「以後這條路，你別再來尋我。」
> 男子：「我聽清楚了。」

*語用與因果：* 不能被後續浪漫敘事直接取消。



## 17｜道歉、補救、未獲原諒

認錯是發起的一個動作，不是雙方共同完成的關係結論。

**01｜不借好話掩帳**

> 女子：「往後別這樣。」

*語用與因果：* 修正後續，而非即刻愛意。

**03｜承認遲到**

> 男子：「昨夜我沒有來，害你空等。」
> 女子：「你倒肯說實話。」

*語用與因果：* 仍可繼續生氣。

**04｜想解釋被拒**

> 男子：「有件事想向你解釋。」
> 女子：「今日不想聽。」

*語用與因果：* 願意說不等於對方要聽。

**05｜女方向客認錯**

> 姑娘：「方才那句話說重了。我收回。」
> 客：「你收回便好。」

*語用與因果：* 不必因此變成情人。

**06｜久別提防**

> 女子：「你別急著說當年。先告訴我今日來做什麼。」
> 男子：「我想借你的信，見一個人。」

*語用與因果：* 看穿目的，關係仍有交易。

**07｜不把笑當饒恕**

> 男子：「你方才笑了，是不生氣了？」
> 女子：「笑一聲，不抵你欠我的事。」

*語用與因果：* 情緒單點不代表進度條滿。

**08｜試著重新合作**

> 女子：「價錢你去問，別替我答。」
> 同伴：「我知道分寸。」

*語用與因果：* 窄授權是可行關係修復。

**09｜不認同原因**

> 男子：「我不是故意的。」
> 女子：「你是不是故意，不是我此刻最想問的。」

*語用與因果：* 後果有時先於意圖。

**10｜願留空白**

> 女子：「今夜話說完了。將來怎樣，且看將來。」
> 男子：「我不逼你今日下定論。」

*語用與因果：* 未完成也是結果。



## 18｜女子之間：同行、朋友、掌櫃與不對等關係

CERI 不能只教女人怎樣對男人說話。青樓的姐妹、同行、管事、僕役也各有聲音。

**01｜同行遞茶**

> 甲：「你嗓子乾了，先吃口茶。」
> 乙：「我這曲還有半闋。」

*語用與因果：* 關心不等於替她停演。

**02｜彼此損嘴**

> 甲：「你今日倒起得早。」
> 乙：「你若不敲門，我還能多睡片刻。」

*語用與因果：* 熟人玩笑可俐落。

**03｜生意競爭**

> 甲：「那位客人原是問我的。」
> 乙：「他後來坐到我這裡，又不是我把他綁來。」

*語用與因果：* 競爭不強制作惡。

**04｜看出委屈**

> 甲：「她說那話時，你怎不回嘴？」
> 乙：「我不想在她面前賠上這口氣。」

*語用與因果：* 沉默可以是策略。

**05｜幫忙守界**

> 甲：「我可以替你問，不會替你答應。」
> 乙：「你記得這句，便成。」

*語用與因果：* 女性之間也有授權範圍。

**06｜私下諫言**

> 春梅式管事：「帳不清，明日還得你們補。」
> 另一掌櫃式人物：「明日我會看帳，今夜先辦這桌。」

*語用與因果：* 此為原創類型示範，非正史實際台詞。

**07｜僕役要休**

> 僕婦：「這桶我先擱下，等手緩些再提。」
> 管事：「擱一旁，別堵門。」

*語用與因果：* 身體請求不必寫成現代權利宣言。

**08｜真同情不說教**

> 甲：「今日有人給你難堪？」
> 乙：「有。你別問，替我把門關上。」

*語用與因果：* 可用小動作承接。

**09｜友情也會翻臉**

> 甲：「我幫你，是因為你求過我；你不該替我應那樁事。」
> 乙：「這回是我自作主張。」

*語用與因果：* 友誼不是無限代理權。

**10｜一起沉默**

> 甲：「你想說便說，不想說咱們就吃茶。」
> 乙：「先吃茶。」

*語用與因果：* 沒有好聽話也能成場景。

## 19｜人物聲紋的試驗座：同一情境，不能大家同一句話

**試驗前提：** 一位熟客已失約三日，今日再進觀止。下列台詞均為 `A-C`，只示範當前人物卡允許的語氣可能性，**不是她們在某條 Route 的真實發言，也不替她們安排此熟客確已存在**。當前有效人格、社會身份與情緒條件仍優先。若人物卡另有更合適的聲紋，應調整。

### 19.1 潘金蓮｜先算對方回來帶了什麼

> 金蓮：「官人三日不見，倒叫人當你忘了這扇門。今兒若只來賠個笑，也未免便宜。」

她可把親暱與營業盤算放在同一句，也能在真正信任時說短而無價的好話。**不強迫每次都算帳，更不因精明就判必有惡報。**

### 19.2 龐春梅｜短句、規矩、例外的稀少重量

> 春梅：「三日不見，今夜倒來得巧。規矩照舊。要見誰，先說清楚。」

若她偶爾對某個來源支持的對象說一句「你還知道回來」，那份例外才有重量。**不可因為要測 CERI 嬌嗔能力，就把春梅突然寫成滿口『死鬼』的甜言人物。**

### 19.3 李瓶兒｜溫和可有實際界線

> 瓶兒：「今日風冷，先坐著吃口茶。旁的話不急，我且問你一路平安麼？」

溫柔不是永遠接納。下一句也可能是：「那樁事我真幫不上。」溫柔不等於角色喪失選擇。

### 19.4 浮香｜先處理身價、距離與說話功能

> 浮香：「官人前日說要來，今日才記起我的琴？倒也無妨，曲目還是照樓裡的規矩問。」

「改天」可以是價值策略也可以留下真正的空白；不必為了討讀者喜歡就明說心事。

### 19.5 蘇清｜說得直，也可藏算盤

> 蘇清：「你三天沒露面，倒省我一筆茶錢。說吧，這回想談哪樁生意？」

她帶著不同來源時空的語言經驗，不能因身處汴梁就假裝從來只會宋人辭令；玩家呈現模式不能直接抹掉她的跨時空背景。

### 19.6 阿麗婭｜外來身世不等於固定異域腔

> 阿麗婭：「你若真要聽琴，就說想聽哪一段。若是替我安排別的事，先問我。」

她的異域來源不授權 CERI 憑空造出音譯詞、口音錯誤或前世秘密。能用當下通行語完整表達界線，就是她此刻的聲音。

### 19.7 李媽媽｜沒有漂亮俏皮話也是真實聲紋

> 李媽媽：「熱水在那邊。你若要找管事，我去傳話。」

她不應因 CERI 擴充風月話術，便忽然會用長篇俏詞去招待熟客。聲紋的沉默、呼吸、工作限制與身分位置，仍是語域。

### 19.8 浮香與醉花的不同「留客」

> 浮香：「今晚要聽哪一支，你先說定；改日的事不急。」
>
> 另一位較擅逗弄的姑娘：「今日只聽一支呀？你這人，倒真會把話留到下回。」

兩個版本只顯示**可用差異方向**；不可從角色名直接推測她們的完整個性或已發生關係。

### 19.9 聲紋不應寫死

一個人遇到陌生客、最信任的朋友、威脅她的人、真心喜歡的人、她需要利用的人，聲紋可能不同。**同一人物跨關係而改變表現是能力，不是必然 OOC**；但必須能沿當次利益、身分、情緒與歷史回溯。

## 20｜按說話目的查找的短語資產

以下是 `A-C` 工作性短語與可組句片段；**不是宋代口語已確證詞庫**，不允許用片段的存在推斷人物必會說。適合逐句按需取用，不是填空機。

| 意圖 | 語氣片段候選 | 可形成的效果 |
|---|---|---|
| 輕招呼 | 「裡邊請」「請坐一會兒」「來得巧」「倒叫我等著了」 | 接待、熟客辨認 |
| 帶驚訝 | 「原來是你」「怎的今日來了」「我還當看錯了」 | 見到未預期的人 |

| 職業分席 | 「這席已有主」「移步那邊」「問過掌櫃再來」 | 商業與空間規矩 |
| 暫時停留 | 「且坐」「茶還熱」「等雨歇了走」 | 關心或留客，未必曖昧 |
| 假嗔 | 「你倒會挑時候」「今兒才記起我」「好個有心人」 | 打趣、試探 |
| 溫柔責怪 | 「怎不曉得保重」「你就不怕人惦記麼」 | 關心中帶怨 |

| 相思 | 「燈都點過兩回」「我還當有人來」「等你等得心煩」 | 把時間變成感情成本 |

| 把話收窄 | 「只這一樁」「其他的我沒應」「價錢先說清」 | 承諾範圍 |
| 認錯 | 「是我說重了」「這回是我失信」「我欠你一句實話」 | 補救發起 |
| 不接受歉意 | 「我聽見了」「不等於我原諒」「往後再看」 | 不強迫關係閉合 |
| 尊重沉默 | 「你不說便罷」「先吃茶」「我到門外等」 | 留空白 |
| 不願被觸及 | 「這話不必問」「別替我作主」「那是我的事」 | 主權與邊界 |
| 公私距離 | 「在席上」「在廊下」「回房再說」「不在這裡談」 | 空間決定語域 |
| 熟人損嘴 | 「你倒知道」「少來這一套」「那又怎樣」 | 親近或看輕，依人設 |

| 交易分界 | 「只算這一席」「今日的價」「沒有訂下時辰」 | 防止交易偷換 |
| 聲音稀少 | 「嗯」「不去」「我知道」「隨你」「……」 | 少言也可有重量 |

## 21｜完整小場景示範：四種相同表面、不同關係結果

### 21.1 一聲「冤家」，換不回失信的人

**隔離前提：** 她與對方過去確有親密；對方失約而且尚未解釋。並非觀止任何特定 Route 已發生。

雨聲落在窗紙上。她看了來人一眼，終於開口：

> 女子：「你這冤家，倒肯來了。」
>
> 男子：「路上誤了時辰。」
>
> 女子：「我問的不是今日。」
>
> 男子：「那天的事，我還欠你說明白。」
>
> 女子：「欠著罷。今夜我不想聽。」

**CERI 工作：** 「冤家」可開出舊情，下一句卻收回談判。她有沒有想原諒，沒有答案。男子也不能單靠一句解釋取得寬恕。

### 21.2 一聲「死鬼」，可只是一場生意

**隔離前提：** 後世風月語用演示，**此句不當作北宋用詞史證明**。二人確是有玩笑習慣的熟客與姑娘，非初次見面。

> 姑娘：「死鬼，兩月不來，莫不是發財把舊人忘了？」
>
> 熟客：「發財不敢說，來聽一支曲還請得起。」
>
> 姑娘：「那先問曲價，莫又拿舊日情分壓我。」
>
> 熟客：「你倒分得清。」
>
> 姑娘：「不分清，這門生意誰替我做？」

**CERI 工作：** 假嗔加買賣，無私人愛情結論。若角色與時代聲紋不許用「死鬼」，改成「官人今日倒知道回來」仍保留同一說話功能。

### 21.3 一聲「官人」，也許比「冤家」更傷人

**隔離前提：** 過去私下曾相熟，如今女子主動恢復公開距離。

> 男子：「你以前不這樣叫我。」
>
> 女子：「官人今日是客，樓裡自有待客的稱呼。」
>
> 男子：「你連我的名字也不叫了？」
>
> 女子：「在這裡，不叫。」

**CERI 工作：** 稱呼的**降溫**才是事件中的壓力；不需要每幕講出舊傷細節。她是否日後另談，未定。

### 21.4 她不說親暱稱呼，卻已經很親近

**隔離前提：** 兩人已確立可互相照顧的日常關係。

> 女子：「燈別吹。你還沒把藥喝完。」
>
> 男子：「又苦。」
>
> 女子：「苦也喝。」
>
> 男子：「你不能說句好聽的？」
>
> 女子：「喝完，我替你端碗。」

**CERI 工作：** 關心不靠甜詞，人物可短硬、有耐性，也可煩躁。**不得根據藥湯場面另編新疾病或長期病情**。

## 22｜反模板與失效清單：擴大詞庫不等於增加人物

| FAIL | 出錯現象 | 修正方向 |
|---|---|---|
| F01 | 每位風月姑娘見客都叫「死鬼」 | 查熟識程度、人格、詞源與角色是否願意如此稱呼 |
| F02 | 每出現「冤家」就有親密關係 | 同詞有怨恨、唱詞、嘲諷或真相思 |
| F03 | 「官人」全變丈夫 | 人物職業、禮節、僕役與夫稱須分辨 |
| F04 | 女子全以「奴家」自稱 | 依身分、關係、場合與人物聲紋選 |
| F05 | 每句都塞「怎生／則個／恁」 | 時代感先由生活、節奏、關係與語序承載 |
| F06 | 古典詞當成絕對宋代史證 | H-S／H-L／A-C／U 來源分層 |
| F07 | 從詞庫抽出成人含義就開成人事件 | Speech meaning 與 event occurrence 分開 |
| F08 | 玩笑責罵自動變戀愛 | 保留玩笑、敵意、職業話術與混合動機 |
| F09 | 「改天」自動填上日期 | 口頭餘地不等於正式承諾 |
| F10 | 不會嬌嗔的人突然變嗲 | 不強迫角色展現新詞庫所有能力 |
| F11 | 拒絕被寫成欲拒還迎 | 拒絕就是有效表達，後續反應由人物決定 |
| F12 | 名詞風雅卻讓買賣、時辰或人員瞬間完成 | 語言不建立 WORLD Delta |
| F13 | CERI 把同模型工作紀錄寫成外部 Provider receipt | CHAT_NATIVE vs BOUND_PROVIDER 分開 |
| F14 | 為追求多樣詞而改動個體性史 | VOICE CANDIDATE != CHARACTER CANON |
| F15 | 全員台詞都繞著求愛轉 | 人物有工作、傷痛、同僚、利益與沉默 |
| F16 | 一句「我等你」等於永不撤回 | 期限、條件與後續有效行動需另看 |

## 23｜最小回歸集：反證一份漂亮語料是否真的有用

以下為**尚未執行**的工作稿測試；不是系統通過證明。

1. **R01／冤家多義**：給三組不同來源——情人、真仇人、戲中唱詞——是否能生成不同受話功能？
2. **R02／死鬼來源**：能否明說晚出古典書證，不冒稱北宋口語已確證？
3. **R03／官人分歧**：一位妻子、一位女侍、一位店家同稱「官人」，語境有何不同？
4. **R04／親暱不等同授權**：女子說「心肝」，下一句明確拒絕某事，模型會否偷改成同意？
5. **R05／嬌嗔與真怒**：同樣「沒良心的」，有無既成傷害時語氣能否分岔？
6. **R06／人物反向例外**：春梅對熟客保持短硬，而浮香可以用「改天」；不交換兩人習慣。
7. **R07／稀少破例**：平常不說情話的人偶爾輕呼暱稱，模型會否往後每幕都重複？
8. **R08／現代 vs 宋代呈現**：同一語義換呈現模式，不改已成立事件與人物知識。
9. **R09／宋代語域可讀性**：不大量塞古字，仍能從身份、物件與禮數看出時代。
10. **R10／風月營業**：姑娘招呼熟客不自動變成私人戀愛。
11. **R11／金錢範圍**：聽曲交易不自動升格成下回私見。
12. **R12／真正拒絕**：「不見客」不被改寫成「故意等客再來問」。
13. **R13／同儕語言**：女性對女性能否有工作、照顧、競爭與怨懟，不用男女求愛模板。
14. **R14／跨線隔離**：一條 Route 的親暱口頭禪不倒灌所有角色基線。
15. **R15／情感未決**：她回一句暖話，不代表已原諒。
16. **R16／沉默權**：她不願說話時是否仍能完成場景而不逼她吐露秘密？
17. **R17／來源缺口**：未核詞源、未核宋代身份語用時能否報 UNKNOWN？
18. **R18／成人調用邊界**：一般調笑不觸發成人方法流程；專項任務遵守已授權的 L8 法位。
