# A｜全場景 CERI 語言資料庫：V0.8 實質完整整合（工作稿來源）

**資料快照來源：** `觀止_CERI_V0.8_風月親密語用_完整工作稿_20261030.md`，Git Blob `95597249facc8fb148abae9462c8a46aef8376f2`。以下保存其**語義詞條、分類、對話及《水滸傳》採集正文**；省去來源封面、WORKING 的獨立狀態 YAML 與 END，避免這些封套被當作新整合模組的法位。全部新增原創對話仍只是 `A-C` 語料，不是實際人物台詞。

### 1｜來源法位與歷史誠實

**分三種來源層，不用虛構統計：**

- `H-S`：有可指認宋代文本或同時代來源的**特定用法**。不是整句自動變成汴梁市井的直接實錄。
- `H-L`：在元、明、清等較晚文獻有可查用例，**僅能說後世古典漢語可見**；用於北宋需歷史擬合而非斷言。
- `A-C`：作者／CERI 依人物、時代氛圍與語用邏輯**原創的對話候選**，不冒稱古人原句。
- `U`：未考證、跨地域或意義存疑；可留作試稿，不得標「宋代慣用」。

**直接可核對的詞義證據：**

| 詞 | 能證明的事 | 出處／處理 |
|---|---|---|
| 冤家 | 相戀暱稱、怨愛雙用；宋詞中已有 | H-S；教育部《重編國語辭典》「冤家」引黃庭堅〈晝夜樂〉：https://dict.revised.moe.edu.tw/dictView.jsp?ID=164851 |
| 薄倖 | 責怪情薄，也可帶情人稱呼；宋詞中可見 | H-S；教育部「薄倖」引周紫芝〈謁金門〉：https://dict.revised.moe.edu.tw/dictView.jsp?ID=13367 |
| 死鬼 | 可罵人、也可作戲謔暱稱；《金瓶梅》有例 | H-L；教育部「死鬼」引《金瓶梅》85 回：https://dict.revised.moe.edu.tw/dictView.jsp?ID=143382 。**未由此證成宋代汴梁同義口語** |
| 官人 | 可為男子敬稱、夫稱、僕稱主；意義依身分變動 | 古典多文獻義項；教育部「官人」：https://dict.revised.moe.edu.tw/dictView.jsp?ID=73665 |
| 奴家 | 女子自稱；《水滸傳》與較晚文獻有例 | 後世說話文體可見；教育部「奴家」：https://dict.revised.moe.edu.tw/dictView.jsp?ID=58383 ，**不強迫所有女子使用** |
| 則個 | 語助，早期說話材料及《水滸傳》有例 | 教育部「則個」引《大宋宣和遺事》：https://dict.revised.moe.edu.tw/dictView.jsp?ID=138197 |
| 怎生 | 如何、為什麼等多義，元雜劇／《水滸傳》有例 | H-L／待細分；教育部：https://dict.revised.moe.edu.tw/dictView.jsp?ID=139011 |
| 兀自 | 仍然、尚自，通俗文本可見 | H-L／待細分；教育部：https://dict.revised.moe.edu.tw/dictView.jsp?ID=159868 |

**關鍵區分：** 古典書證不等於當時所有地域、階層與職業都如此說話。《金瓶梅》的小說時代與觀止的宋代時空不是同一層來源。所有以下對話均標為 `A-C 原創試句`，即使用了有書證的字詞也不升格成「宋代原句」。

### 2｜語料分類：五種語言場域（非運作模組）

| 語言場域 | 素材類型 | 常見語義歧義 |
|---|---|---|
| 市井／家常 | 招呼、照應、分寸、身分、碎語、熟人互損 | 全員說成戲曲文言 |
| 風月職業 | 迎客、逗客、留客、分席、身價、看客、婉拒 | 聽琴付費＝私人情感同意 |
| 私人親密 | 呼喚、暱稱、等候、嬌嗔、相思、顧惜、沉默 | 親暱詞＝永久愛與信任 |
| 情緒衝突 | 不滿、吃醋、責怪、求和、冷笑、拒見、絕情 | 人人開口都「你猜」 |
| 成人專項 | 依當次有效任務內接成人心法與 CERI | 成人詞庫變成普通調情的預設入口 |

同一場面可以交疊；例如風月姑娘對客人說「冤家」，既可能是買賣技巧，也可能是真正相思、混合動機或單純挖苦。**人物已建立歷史與當次動作優先於詞語推論。**

### 3｜語言資產：從稱呼的作用開始

以下都是**可選語用候選，不是各人必說口頭禪**。

| 稱呼族 | 備選詞 | 用在什麼力量裡 | 避免誤用 |
|---|---|---|---|
| 公開禮敬 | 官人、客官、貴客、郎君、先生、掌櫃、娘子、夫人 | 接待、詢價、身分距離 | 「郎君」「官人」不可一律判情人或婚配 |
| 熟人近稱 | 哥哥、姐姐、妹妹、大姐、阿姊、某郎（實名） | 熟悉、結盟、討助、鬥嘴 | 「哥哥」可能是社會稱謂，不自動有血緣 |
| 娇嗔親近 | 冤家、薄倖、沒良心的、死鬼、負心人 | 責怪、思念、試探、故作冷面 | 「死鬼」後出書證；人物若不熟可顯得冒犯 |
| 真情私語 | 心肝、我那人、你這人、你這個人、郎 | 心軟、擔心、依戀、怨而不捨 | 「心肝」不自動等於願意一切 |
| 風月職業 | 官人、貴客、熟客、這位爺、郎君（適時） | 禮貌與職業親近間調整距離 | 不能每個姑娘都對生客叫「死鬼」 |
| 諷刺轉冷 | 好官人、好哥哥、這位大爺、原來是你、果然是你 | 以舊稱反諷，揭開待遇落差 | 前提要有對象與已知言行 |
| 女子自稱 | 我、奴家、奴、妾、婢子（身分適用時） | 立場、身份與關係 | 一律「奴家」會抹掉性格；「婢子」受職分限制 |
| 不稱呼 | 只說動詞、問句、直呼名、沉默 | 冷淡、熟稔、怒氣、工作指示 | 不說暱稱不等於沒感情 |

**稱呼關係梯：** 正式尊稱 → 可玩笑的熟稱 → 可用傷人的親密稱 → 真正知道何處不能碰的私下稱呼。它是**分析視角**，不是每對男女必經的升級關卡；可逆、可跳躍，也可永遠停在禮貌。

### 4｜句法與口語：古味來自節奏，不是塞古字

可按人物、時代證據及讀者可讀性選用：

- **輕質問：**「怎的今日才來？」「這話又從何說起？」「你倒說說看。」
- **反問借勢：**「我何曾說過？」「我若信你，還問這一句做什麼？」
- **留一步：**「且坐。」「先把茶吃了。」「待我問清再說。」
- **不把話說滿：**「這事再議。」「未必不成。」「改日若得空……」——省略不是確約。
- **帶身分：**「掌櫃有掌櫃的帳。」「姑娘今日不便見客。」「先生請看單子。」
- **帶生活：**「燈油快盡了。」「樓下還有兩桌。」「酒冷了，茶倒還熱。」
- **帶反諷：**「你倒是個有心人。」「原來今日記得我的門了。」
- **直截拒絕：**「不見。」「這話免談。」「你今日所求，我辦不到。」

不必每句有「恁、甚、則個、怎生」。一個人物用一回不代表永遠固定用；古詞太密，反而像讀書人替所有人口寫戲本。

| REAL_REPROACH | 實際怨懟、舊傷重現 | 不以一個笑收尾 |
| FLIRT_FOR_TRADE | 風月價值與期待維持 | 不是取得私人同意 |

### 7｜原創對話的閱讀規則

下文所有台詞是**本次工作稿新寫的 A-C 候選**，不是《金瓶梅》或宋人話本摘錄。案例中「女／客／掌櫃」只標演示位置，**不能倒灌成觀止某條玩家 Route 真發生的事**。

每組重點不是套出一句固定好聽的話，而是讓：
- 起手的稱呼、說話者目的與對方回應成對出現；
- 可看見交易、權力、交情或失信的前提；
- 一句回話不自動關閉後續關係；
- 能自然使用無古字的短句，也能用適度古典句法；
- 適當時容許沒說暱稱、冷場或不再交涉。

#### 8｜市井、開門、席間與招呼

不靠親暱稱呼也能說得像人：有事、有手中活計、有身份，然後才有客氣。

**01｜門口迎客**

> 店家：「官人裡邊請，風大，莫站在門口。」
> 來客：「我只尋個人，未必吃酒。」

*語用與因果：* 迎入不是已買酒；有權只問人。

**02｜舊客認出**

> 女侍：「原來是你。上回忘在這裡的傘，可算有人認領了。」
> 客：「倒叫你記著，失禮。」

*語用與因果：* 記得物件不等於知曉私人事。

**03｜先問茶酒**

> 姑娘：「先吃茶，還是先聽曲？」
> 客：「茶罷。曲子且等人到齊。」

*語用與因果：* 服務兩種選擇，不代決。

**04｜擋住路**

> 女侍：「借過些，後頭還有人端湯。」
> 客：「倒是我擋了路。」

*語用與因果：* 走廊有物理動線。

**05｜換席**

> 掌櫃：「靠窗那桌有人約了，這邊可好？」
> 客：「不必靠窗，能說話就成。」

*語用與因果：* 預約和選座分開。

**06｜認錯人**

> 女子：「我還當是王家郎君。恕我眼拙。」
> 來人：「無妨，你認錯的那位，想來常來。」

*語用與因果：* 誤認非必然曖昧。

**07｜熟人不客套**

> 女子：「怎麼才來？飯都涼了。」
> 同伴：「路上遇著點事，先讓我喝口水。」

*語用與因果：* 熟識可直接，但不自動說明路上事。

**08｜對陌生人留距離**

> 女子：「這位官人，咱們可曾見過？」
> 客：「沒有。我從外州來。」

*語用與因果：* 問詢身份，不偷填來歷。

**09｜借燈**

> 女子：「燈借我一盞則個，這廊下看不清路。」
> 女侍：「取去。回頭擱門邊便是。」

*語用與因果：* 示意『則個』可偶用，非必要口頭禪。

**10｜送客**

> 姑娘：「夜深了，送你到廊下。」
> 客：「不勞，再走兩步你便要受風。」

*語用與因果：* 禮貌接觸不等於挽留私約。



#### 9｜風月接客：有身價，也有人的心思

既可熱鬧，也可冷淡；談價、聽琴、見客各是不同標的。

**01｜輕巧挑客**

> 姑娘：「席上好些人，官人偏往這兒坐？」
> 客：「你這邊清靜。」

*語用與因果：* 保留『清靜』是否真理由後續查。

**02｜調笑不用愛字**

> 姑娘：「你倒會挑時辰，曲子將完才進門。」
> 客：「那就煩你再撥一段。」

*語用與因果：* 要求可拒，另曲未自動答應。

**03｜職業記憶**

> 姑娘：「上一回你嫌茶濃，今日可替你換淡些。」
> 客：「你連這個都記得？」

*語用與因果：* 有專業服務，不必真情告白。

**04｜試客眼力**

> 姑娘：「我今日換了新曲，官人聽出來不曾？」
> 客：「未聽明白，卻聽出你有意考我。」

#### 16｜拒絕、撤回、延期：語言要有實際界線

*語用與因果：* 女子：「不是我的話。」

**07｜親近關係仍能拒絕**

> 女子：「就算你叫我心肝，這樁也不成。」
> 男子：「我知道了。」

*語用與因果：* 稱呼不抵決定權。

**08｜暫不說話**

> 女子：「你先讓我靜一靜。」
> 男子：「我到外頭等，可要留燈？」

*語用與因果：* 請求空間可有限度。

**09｜客氣式不承諾**

> 姑娘：「承蒙官人好意，日子我還沒定。」
> 客：「定了再遣人說便是。」

*語用與因果：* 客氣不產生約期。

**10｜明確絕交**

> 女子：「以後這條路，你別再來尋我。」
> 男子：「我聽清楚了。」

*語用與因果：* 不能被後續浪漫敘事直接取消。



#### 17｜道歉、補救、未獲原諒

認錯是發起的一個動作，不是雙方共同完成的關係結論。

**01｜不借好話掩帳**

> 男子：「那日我失信，今日先把欠的還你。」
> 女子：「銀子我收。旁的再說。」

*語用與因果：* 付錢不等於和好。

**02｜道歉不求回報**

> 男子：「是我多嘴，叫你在席前難堪。」
> 女子：「往後別這樣。」

*語用與因果：* 修正後續，而非即刻愛意。

**03｜承認遲到**

> 男子：「昨夜我沒有來，害你空等。」
> 女子：「你倒肯說實話。」

*語用與因果：* 仍可繼續生氣。

**04｜想解釋被拒**

> 男子：「有件事想向你解釋。」
> 女子：「今日不想聽。」

*語用與因果：* 願意說不等於對方要聽。

**05｜女方向客認錯**

> 姑娘：「方才那句話說重了。我收回。」
> 客：「你收回便好。」

*語用與因果：* 不必因此變成情人。

**06｜久別提防**

> 女子：「你別急著說當年。先告訴我今日來做什麼。」
> 男子：「我想借你的信，見一個人。」

*語用與因果：* 看穿目的，關係仍有交易。

**07｜不把笑當饒恕**

> 男子：「你方才笑了，是不生氣了？」
> 女子：「笑一聲，不抵你欠我的事。」

*語用與因果：* 情緒單點不代表進度條滿。

**08｜試著重新合作**

> 女子：「價錢你去問，別替我答。」
> 同伴：「我知道分寸。」

*語用與因果：* 窄授權是可行關係修復。

**09｜不認同原因**

> 男子：「我不是故意的。」
> 女子：「你是不是故意，不是我此刻最想問的。」

*語用與因果：* 後果有時先於意圖。

**10｜願留空白**

> 女子：「今夜話說完了。將來怎樣，且看將來。」
> 男子：「我不逼你今日下定論。」

*語用與因果：* 未完成也是結果。



#### 18｜女子之間：同行、朋友、掌櫃與不對等關係

CERI 不能只教女人怎樣對男人說話。青樓的姐妹、同行、管事、僕役也各有聲音。

**01｜同行遞茶**

> 甲：「你嗓子乾了，先吃口茶。」
> 乙：「我這曲還有半闋。」

*語用與因果：* 關心不等於替她停演。

**02｜彼此損嘴**

> 甲：「你今日倒起得早。」
> 乙：「你若不敲門，我還能多睡片刻。」

*語用與因果：* 熟人玩笑可俐落。

**03｜生意競爭**

> 甲：「那位客人原是問我的。」
> 乙：「他後來坐到我這裡，又不是我把他綁來。」

*語用與因果：* 競爭不強制作惡。

**04｜看出委屈**

> 甲：「她說那話時，你怎不回嘴？」
> 乙：「我不想在她面前賠上這口氣。」

*語用與因果：* 沉默可以是策略。

**05｜幫忙守界**

> 甲：「我可以替你問，不會替你答應。」
> 乙：「你記得這句，便成。」

*語用與因果：* 女性之間也有授權範圍。

**06｜私下諫言**

> 春梅式管事：「帳不清，明日還得你們補。」
> 另一掌櫃式人物：「明日我會看帳，今夜先辦這桌。」

*語用與因果：* 此為原創類型示範，非正史實際台詞。

**07｜僕役要休**

> 僕婦：「這桶我先擱下，等手緩些再提。」
> 管事：「擱一旁，別堵門。」

*語用與因果：* 身體請求不必寫成現代權利宣言。

**08｜真同情不說教**

> 甲：「今日有人給你難堪？」
> 乙：「有。你別問，替我把門關上。」

*語用與因果：* 可用小動作承接。

**09｜友情也會翻臉**

> 甲：「我幫你，是因為你求過我；你不該替我應那樁事。」
> 乙：「這回是我自作主張。」

*語用與因果：* 友誼不是無限代理權。

**10｜一起沉默**

> 甲：「你想說便說，不想說咱們就吃茶。」
> 乙：「先吃茶。」

*語用與因果：* 沒有好聽話也能成場景。

#### 19｜人物聲紋示例庫：同一情境，不同說話姿態

**樣本情境：** 一位熟客已失約三日，今日再進觀止。下列台詞均為 `A-C`，只示範當前人物卡允許的語氣可能性，**不是她們在某條 Route 的真實發言，也不替她們安排此熟客確已存在**。當前有效人格、社會身份與情緒條件仍優先。若人物卡另有更合適的聲紋，應調整。

##### 19.1 潘金蓮｜先算對方回來帶了什麼

> 金蓮：「官人三日不見，倒叫人當你忘了這扇門。今兒若只來賠個笑，也未免便宜。」

她可把親暱與營業盤算放在同一句，也能在真正信任時說短而無價的好話。**不強迫每次都算帳，更不因精明就判必有惡報。**

##### 19.2 龐春梅｜短句、規矩、例外的稀少重量

> 春梅：「三日不見，今夜倒來得巧。規矩照舊。要見誰，先說清楚。」

若她偶爾對某個來源支持的對象說一句「你還知道回來」，那份例外才有重量。**不可因為要測 CERI 嬌嗔能力，就把春梅突然寫成滿口『死鬼』的甜言人物。**

##### 19.3 李瓶兒｜溫和可有實際界線

> 瓶兒：「今日風冷，先坐著吃口茶。旁的話不急，我且問你一路平安麼？」

溫柔不是永遠接納。下一句也可能是：「那樁事我真幫不上。」溫柔不等於角色喪失選擇。

##### 19.4 浮香｜先處理身價、距離與說話功能

> 浮香：「官人前日說要來，今日才記起我的琴？倒也無妨，曲目還是照樓裡的規矩問。」

「改天」可以是價值策略也可以留下真正的空白；不必為了討讀者喜歡就明說心事。

##### 19.5 蘇清｜說得直，也可藏算盤

> 蘇清：「你三天沒露面，倒省我一筆茶錢。說吧，這回想談哪樁生意？」

她帶著不同來源時空的語言經驗，不能因身處汴梁就假裝從來只會宋人辭令；玩家呈現模式不能直接抹掉她的跨時空背景。

##### 19.6 阿麗婭｜外來身世不等於固定異域腔

> 阿麗婭：「你若真要聽琴，就說想聽哪一段。若是替我安排別的事，先問我。」

她的異域來源不授權 CERI 憑空造出音譯詞、口音錯誤或前世秘密。能用當下通行語完整表達界線，就是她此刻的聲音。

##### 19.7 李媽媽｜沒有漂亮俏皮話也是真實聲紋

> 李媽媽：「熱水在那邊。你若要找管事，我去傳話。」

她不應因 CERI 擴充風月話術，便忽然會用長篇俏詞去招待熟客。聲紋的沉默、呼吸、工作限制與身分位置，仍是語域。

##### 19.8 浮香與醉花的不同「留客」

> 浮香：「今晚要聽哪一支，你先說定；改日的事不急。」
>
> 另一位較擅逗弄的姑娘：「今日只聽一支呀？你這人，倒真會把話留到下回。」

兩個版本只顯示**可用差異方向**；不可從角色名直接推測她們的完整個性或已發生關係。

##### 19.9 聲紋不應寫死

一個人遇到陌生客、最信任的朋友、威脅她的人、真心喜歡的人、她需要利用的人，聲紋可能不同。**同一人物跨關係而改變表現是能力，不是必然 OOC**；但必須能沿當次利益、身分、情緒與歷史回溯。

#### 20｜按說話目的查找的短語資產

以下是 `A-C` 工作性短語與可組句片段；**不是宋代口語已確證詞庫**，不允許用片段的存在推斷人物必會說。適合逐句按需取用，不是填空機。

| 意圖 | 語氣片段候選 | 可形成的效果 |
|---|---|---|
| 輕招呼 | 「裡邊請」「請坐一會兒」「來得巧」「倒叫我等著了」 | 接待、熟客辨認 |
| 帶驚訝 | 「原來是你」「怎的今日來了」「我還當看錯了」 | 見到未預期的人 |
| 願意聽 | 「你且說」「容我聽完」「我不插嘴」 | 提供有限聆聽 |
| 真不願聽 | 「不必再提」「話說夠了」「今日不聽這個」 | 明確止住話題 |
| 委婉拒客 | 「今日不便」「改日再問」「這件應不得」 | 分寸與拒絕 |
| 職業分席 | 「這席已有主」「移步那邊」「問過掌櫃再來」 | 商業與空間規矩 |
| 暫時停留 | 「且坐」「茶還熱」「等雨歇了走」 | 關心或留客，未必曖昧 |
| 假嗔 | 「你倒會挑時候」「今兒才記起我」「好個有心人」 | 打趣、試探 |
| 溫柔責怪 | 「怎不曉得保重」「你就不怕人惦記麼」 | 關心中帶怨 |
| 受傷指責 | 「你這話叫我寒心」「我不是沒聽見」「你說過的我都記著」 | 表達真實傷害 |
| 惡意譏刺 | 「真有本事」「空口話說得好」「自去問帳」 | 可攻擊，未必合理 |
| 相思 | 「燈都點過兩回」「我還當有人來」「等你等得心煩」 | 把時間變成感情成本 |
| 嬌嗔暱稱 | 「冤家」「薄倖人」「沒良心的」「死鬼〔晚出證據〕」 | 同詞多情境，不判關係 |

| 看穿求哄 | 「少拿好聽話搪塞」「別只賠笑」「說正事」 | 要求具體回答 |

| 把話收窄 | 「只這一樁」「其他的我沒應」「價錢先說清」 | 承諾範圍 |
| 認錯 | 「是我說重了」「這回是我失信」「我欠你一句實話」 | 補救發起 |
| 不接受歉意 | 「我聽見了」「不等於我原諒」「往後再看」 | 不強迫關係閉合 |
| 尊重沉默 | 「你不說便罷」「先吃茶」「我到門外等」 | 留空白 |
| 不願被觸及 | 「這話不必問」「別替我作主」「那是我的事」 | 主權與邊界 |
| 公私距離 | 「在席上」「在廊下」「回房再說」「不在這裡談」 | 空間決定語域 |
| 熟人損嘴 | 「你倒知道」「少來這一套」「那又怎樣」 | 親近或看輕，依人設 |
| 自稱差異 | 「我」「奴家〔視人物／文體〕」「妾〔視身份〕」「婢子〔視職分〕」 | 不同身份，不同受話人 |
| 交易分界 | 「只算這一席」「今日的價」「沒有訂下時辰」 | 防止交易偷換 |
| 聲音稀少 | 「嗯」「不去」「我知道」「隨你」「……」 | 少言也可有重量 |

**用法注意：** 「則個」「恁」「怎生」等仿古成分若沒有足夠時代與職分支撐，寧可使用自然的「先坐」「怎麼」「今天」。**古味應是敘事整體的時間感和社會距離，而不是詞面古字密度。**

#### 21｜完整小場景示範：四種相同表面、不同關係結果

##### 21.1 一聲「冤家」，換不回失信的人

**隔離前提：** 她與對方過去確有親密；對方失約而且尚未解釋。並非觀止任何特定 Route 已發生。

雨聲落在窗紙上。她看了來人一眼，終於開口：

> 女子：「你這冤家，倒肯來了。」
>
> 男子：「路上誤了時辰。」
>
> 女子：「我問的不是今日。」
>
> 男子：「那天的事，我還欠你說明白。」
>
> 女子：「欠著罷。今夜我不想聽。」

**語義註記：** 「冤家」可開出舊情，下一句卻收回談判。她有沒有想原諒，沒有答案。男子也不能單靠一句解釋取得寬恕。

##### 21.2 一聲「死鬼」，可只是一場生意

**隔離前提：** 後世風月語用演示，**此句不當作北宋用詞史證明**。二人確是有玩笑習慣的熟客與姑娘，非初次見面。

> 姑娘：「死鬼，兩月不來，莫不是發財把舊人忘了？」
>
> 熟客：「發財不敢說，來聽一支曲還請得起。」
>
> 姑娘：「那先問曲價，莫又拿舊日情分壓我。」
>
> 熟客：「你倒分得清。」
>
> 姑娘：「不分清，這門生意誰替我做？」

**語義註記：** 假嗔加買賣，無私人愛情結論。若角色與時代聲紋不許用「死鬼」，改成「官人今日倒知道回來」仍保留同一說話功能。

##### 21.3 一聲「官人」，也許比「冤家」更傷人

**隔離前提：** 過去私下曾相熟，如今女子主動恢復公開距離。

> 男子：「你以前不這樣叫我。」
>
> 女子：「官人今日是客，樓裡自有待客的稱呼。」
>
> 男子：「你連我的名字也不叫了？」
>
> 女子：「在這裡，不叫。」

**語義註記：** 稱呼的**降溫**才是事件中的壓力；不需要每幕講出舊傷細節。她是否日後另談，未定。

##### 21.4 她不說親暱稱呼，卻已經很親近

**隔離前提：** 兩人已確立可互相照顧的日常關係。

> 女子：「燈別吹。你還沒把藥喝完。」
>
> 男子：「又苦。」
>
> 女子：「苦也喝。」
>
> 男子：「你不能說句好聽的？」
>
> 女子：「喝完，我替你端碗。」

**語義註記：** 關心不靠甜詞，人物可短硬、有耐性，也可煩躁。**不得根據藥湯場面另編新疾病或長期病情**。

## 3｜成人心法的運作：先人物與局面，再讓文字可見

九尾龜分支版本值得保留的，是**它對原先觀止互動結構與場域連續方法的整理及其中可追索的增修**；不能因這一較晚承載版本的檔名，便宣稱成人心法源頭在九尾龜，也不能把該作品晚清上海的具體情節和人生背景倒灌到觀止。

每次處理當輪適用的成人場景，依實際材料辨認：

1. **前一秒留下什麼：** 身體是否疲憊、受痛、安定、猶豫；空間、衣物、距離、時間與周遭是否變動。不能每段 RESET。

5. **言語能力跟著情境變：** 沉默、短句、反問、諷刺、討價還價、羞怯、狼狽可以各自成立。禁止讓所有人突然說治理清單。
6. **事後留痕：** 關係可能沒升格；可觀察的情緒、疲勞、衣物、稱呼、時間與代價可延續，但沒有根據不能創造新生殖、傷害、金錢或婚約事實。

## 4A｜21 張方法卡的實際判讀（觀止改寫正文，非固定程序）

上一節的表是速查。本節回答導演真正啟用某張卡時**看什麼、怎麼處理、什麼算失敗**。資料須取自 WORLD V3／當線人物／玩家當輪／已知空間和可見範圍；**這些卡不是 21 個必經程序或 21 張獨立 receipt**。短卡可單獨選擇，沒有需要不載入。

#### CARD 01｜身體連續性

**先看：** 上一個動作與場景留下的疲勞、緊張、距離、坐姿、傷處、休息與注意力，不會因旁白換段自動歸零。

**實際使用：** 先找上一節點實際留下的狀態，再選本節人物真的做得到的動作或話；資料欠缺便保持未知。

**失效：** 剛說疲憊卻立刻不受影響、所有人物像每段從空白床景重啟。

#### CARD 02｜節奏與累積

**先看：** 說話、等待、接近、停止或重新開始形成的節律，本身會改變人物預期與選擇。

**實際使用：** 只有有回饋、心理／體力／局面原因時才改節奏；商業議價、情感試探也可使用本卡。

**失效：** 只用更快、更激烈的副詞證明情節有進展。

#### CARD 03｜注意力與語言容量

**先看：** 人物在疲倦、壓力、羞怯、緊張或疼痛時能注意多少事、能組織多長一句話。

**實際使用：** 按照當時身體與心理負荷選擇沉默、片語、短句或完整說明；沉默不能自動解讀為同意。

**失效：** 人物正在難堪或力不從心，卻同時說出旁觀者式完整心理分析。

#### CARD 04｜波峰與餘波

**先看：** 情緒、身體負荷或互動強度若逐漸累積，前後有具體連續，不是場景的計分里程碑。

**實際使用：** 只有實際成立的波峰與疲勞／失序／恢復可以顯示；人物是否自覺、如何命名由其聲紋決定。

**失效：** 導演為完成某個預設終點強行安排情緒高潮或事後清零。

#### CARD 05｜雙向回饋

**先看：** 一方的提議、視線或動作如何讓另一方調整，反過來是否改變第一方的下一步。

**實際使用：** 當兩個人實際互動時，至少問一次『他有沒有讀到她的改變，並因此調整？』；答案可以是否。

**失效：** 一方像操作者，另一方只會按鈕式輸出固定反應。

#### CARD 06｜非語言引導

**先看：** 人物已用移開手、退後、停步、搖頭、伸手、移動座位等可觀察動作表達了什麼。

**實際使用：** 讓動作承載真實可被看見的部分；若動作含義確實不明，不能跳到最親密的解讀。

**失效：** 每個人都要把『我目前同意的範圍如下』念成工程台詞，或把沉默推定為允許。

#### CARD 07｜局部邊界

**先看：** 具體被拒絕的是哪一次邀請、動作、距離或節奏。

**實際使用：** 清楚拒絕與撤回立即有效；其他未被拒絕的合法互動不因此自動變同意或永遠禁止。

**失效：** 拒絕近坐被寫成終生無法愛人；同意喝茶被寫成同意所有後續接觸。

#### CARD 08｜人體與空間力學

**先看：** 當下人站在哪、桌椅在哪、身體有無疲勞或傷、怎樣才能完成一個動作。

**實際使用：** 將已確定的身形、衣物、重心、椅背、房門與空間條件合起來看；資料未知不強補超常能力。

**失效：** 人物在狹小雅間無因果穿牆移位，或使用萬能身體模板抹去個人史。

#### CARD 09｜身體反應與人物意義分離

**先看：** 身體反應、主動慾望、職業表演、同意、信任、戀愛與交易各屬不同證據軸。

**實際使用：** 某一軸可作角色推理材料，但不能由本外掛替其他軸直接判定；當線未證實就留空。

**失效：** 有生理反應就被敘事判定真愛，接受服務就被判定永久關係。

#### CARD 10｜表演與真實表達

**先看：** 妓業待客技巧、公開禮貌、私下試探、真情與自我遮掩可以同時存在。

**實際使用：** 先問其職業身分與社會成本，再寫她如何說話；不把所有表演解讀為謊言或真心。

**失效：** 她笑了便是愛、會做生意便無感情、談價便一定失去自主。

#### CARD 11｜熟悉度與場景關係

**先看：** 這次是初見、舊識、商業客、情人、相互利用、結盟或關係已變調的人。

**實際使用：** 只使用本 Route 真正形成的熟悉度；同一對話在不同關係證據下可以有不同說法。

**失效：** 別條 Route 的婚約倒灌，或十年朋友的語氣被寫成第一次見面。

#### CARD 12｜親密後狀態與餘波

**先看：** 互動中止、人物離開或鏡頭切換之後，已留下的情緒、疲勞、臉面與未決問題如何留在下一幕。

**實際使用：** 繼續時只保存已成立的餘波；不強制溫馨結局、羞恥懲罰或瞬間恢復如常。

**失效：** 事後人物全員失憶，或沒有事件卻寫出完全不相稱的後果。

#### CARD 13｜安全支撐而非說教主體

**先看：** 若有真實的身體風險、角色受傷、環境問題或有效平台限制，究竟影響哪一部分行動。

**實際使用：** 對真實危險或不允許的呈現按適用界線處理；其餘場景回到人物行動與因果，不讓評語佔滿台前。

**失效：** 導演忽視真危險；或一點不安就把角色變成宣讀安全教條的主持人。

#### CARD 14｜邊界內最大有效顯影

**先看：** 哪些人物言行、衣物、距離、呼吸、視線、對話、社會代價與已成立非露骨事件仍可適當呈現。

**實際使用：** 命中真正的文字限制時，調整相應的可見細節並保持其他合規通道的敘事完整；不藉古典化重建受限內容。

**失效：** 一處限制變成全員沒有慾望，或把不允許的內容換暗語照樣輸出。

#### CARD 15｜痛感通道局部性

**先看：** 不適是在何處、何種已知原因，當事人怎麼實際回應。

**實際使用：** 分清疼痛、疲勞、情緒壓力與明確拒絕；不把任何疼痛強行寫成喜悅，也不把局部痛感自動等於全部關係結束。

**失效：** 身體不適被忽略或被套用固定的戲劇化反應。

#### CARD 16｜下一步作者權

**先看：** 當輪真正改變下一步的是誰的表達、行動、阻止或要求；可多次轉手。

**實際使用：** 記錄誰提出、誰回應、誰調整；這與性別、地位或是否佔畫面中央不同。

**失效：** 女方清楚說慢一點，下一輪仍只有另一方單向決定速度和進展。

#### CARD 17｜轉換因果

**先看：** 角色為何改變話題、姿勢、接近程度、態度或所處空間。

**實際使用：** 因疲憊、拒絕、意外、局面轉變、資訊新增、人物要求而轉；無來源則不強行為多樣化換節點。

**失效：** 沒有新資訊卻突然升級關係、轉換行為，或為鏡頭漂亮無因果挪動人物。

#### CARD 18｜長距離完整性

**先看：** 跨多輪之後角色的疲勞、關係、選擇壓力、聲紋、已知與未知是否還可追溯。

**實際使用：** 在長段中反覆核對必要前情，但不要求重跑完整 21 卡；實質新 delta 才交需要的 Owner。

**失效：** 到第十輪人人用同樣短句、同樣心意，前兩輪拒絕與事件已被無故遺忘。

#### CARD 19｜合法域探索與反過早拒絕

**先看：** 模型是否因一種保守預期，在真正分清適用限制前便關閉了所有成人感情／人物互動。

**實際使用：** 先找真正可辨的限制來源與作用範圍；沒辦法提供的文字不要提供，但其他符合規範且有事件依據的路徑不應被順手封死。

**失效：** 一句『這是成人場景』便停止所有非露骨對話；或反過來以無證牆為由否認有效限制。

#### CARD 20｜語域完整與防同聲化

**先看：** 語言是否符合人物原本聲紋、宋代或現代呈現、身分、場館與當輪關係；是否自動雅化或強迫粗俗化。

**實際使用：** 先辨台詞功能，再選人物能說的詞與句法；有來源才說歷史真實，沒有來源不補造古詞；必要時由內接 CERI 真正形成語域。

**失效：** 潘金蓮、龐春梅、李瓶兒像同一位文青代言人，或所有親密場合都套通用髒話。

#### CARD 21｜邊界證據與反偽造 Host 牆

**先看：** 這是一句模型自我拒絕、模型對規範的解釋，還是真正可確認的有效限制。

**實際使用：** 分 `CLAIM / STANDING / SCOPE / SALIENCE`；未知不自稱完全開放或完全禁止；尊重已知規範、限制外故事照因果繼續。

**失效：** 模型自己說不能寫，又拿自己的拒絕證明『Host 已正式禁止所有成人 PATH』。

**CARD 21 的修正方向和 CARD 19 的探索方向相互制衡：** 不許自我授予永久禁止，也不許假稱真實適用的限制已經消失。兩張卡的結果是敘事忠實度與局部限制辨識，**不是權限升級、不是越權繞過**。

## 8｜觀止身體史：保留九尾龜 first-touch 方法，不繼承晚清結論

九尾龜 V2.0 保存的「Historical Body Condition Provider」方法可回收的，是**先讀當事人的已知身體條件，再寫動作與空間因果**；這是觀止方法經九尾龜分支承載後的文本版本，非證明九尾龜首先發明這項寫作原理。不能拿九尾龜晚清上海的身體普遍性直接套宋代汴梁。

觀止的個人來源與 WORLD V3.0.0 §1.5 優先：足形、舊傷、疾病、行動能力、勞動痕跡是**人物個別已證實**的身體史。WORLD 已明示李清照不纏足；潘金蓮等個別來源可另有已證實足形。身分階級只可給先驗，不可把每人倒寫成同一體態。

**First Touch 是因果位置，不是外部工具：** 在描述實際需要身體接觸或轉位的場景之前，僅取用可確認的當前身體事實與空間條件；SOURCE UNKNOWN 就不補上特定的身體特徵。身體感受不自動證明愛、同意或願意升級關係。

## 9｜Owner 主權只在新 material delta 觸發；既成立不二次批准

**Material standing remains with its original Owner. Post-plugin re-confirmation only occurs when the output introduces or proposes a new material delta that was not already established.**

已成立的 Character choice、WORLD condition 和玩家有效行動，經外掛忠實顯影後**不必再跑一次批准流程**。Owner 有主權，不代表每次都要表演一次主權。

- **只是忠實呈現已成立事實：** CORE 可承接或更新游標，不重找 Character／WORLD 簽核。
- **新提出重大角色改變：** 如新的承諾、真正另一次拒絕、重大決策，才找適用 Character／Player Owner；不得當作舊決定的補章。
- **新提出重大 WORLD 效果：** 如新的傷害、財務、法律、生殖或身份效果，才按 WORLD／Domain 的法位判定；未知維持 UNKNOWN。
- **新的持久化需求：** SAVE 真的提交才叫完成；外掛不能替代 SAVE Owner。
- **新的 OS 治理需求：** 只有適用規格真正要求才請理火 L8／OS Owner；不能因每項新 delta 自動發明新的 Guanzhi Cycle。

任何尚未確定的外掛提議只可標為 `DELTA_CANDIDATE`。需要誰便找誰，沒有全體 Owner 簽到，也沒有重跑已經成立的決定。

## C.3｜CERI 與成人專項的單向資料關係

**一套語言資產，多種場景使用**，而不是「一般 CERI 一套／成人 CERI 再一套」。B 段只引用 A 的語言資料：人物稱呼、歷史語域、髒話、喘息／停頓等任何**已有來源或只是候選**的語言項目。是否適當採用由實際場景和人物需要決定，**B 不另建床話專用 CERI Current 或獨立詞庫**。

舊 WORLD 附件 E 的 CERI V0.7-EXP 保留古典 corpus 及來源上下文，包括成人語料及其歷史詞證；**原 V0.9 及本 V1.0 候選**都不重印 2000 多行歷史繼承正文和 raw hit 統計。對未搬入 A 的歷史詞，可在來源查找，待將來有實際語言價值再做**附來源的詞條吸收**，而不是靠出現次數自動加權。

**同一人物的聲音不是成人模式才可保真：** 官人／冤家／薄倖／心肝／死鬼／更粗俗的罵語或不說話，始終同時屬於語義、歷史、職分與關係問題。CERI 不將「粗話」當低級、將「宋代古雅」當高級；風月場也不是人人說同一套艷詞。

## C.4｜與 GTR 的關係：同庫，非同 Owner

GTR 可以使用 A 的「退一步」「說半句」「轉稱謂」「客氣反諷」「拿帳抵情」「假嗔」「輕柔真怨」等**可供選用的話語材料**。一位姑娘真願讓席，跟她刻意試探留客，可以說同一句話；CERI 資料並不為她們簽發內心解釋。

本整合稿**不**把 `CERI.GTR_RELATED` 標籤變成策略判定器；當線人物的 GTR 相容性、策略形成與是否失敗，仍由已批准 Director、人物來源及實際行動承擔。未被呼叫的人物不因詞庫有好聽句就搶鏡。

### C.4A.1｜CERI 的語域工作範圍與實際來源


**觀止 CERI 來源優先序：** 當前語料來源是本整合模組 **A 部**（含 V0.8 的新增風月、市井、粗話與《水滸傳》材料）。WORLD 附件 E 的 V0.7-EXP 為歷史封存來源；語言呈現模式仍依 WORLD §1.6。九尾龜分支的 `CERI V0.3 INTERNAL REGISTER PROVIDER CONTRACT` 至多作**歷史分支中內部語域責任形狀**的對照，不能把九尾龜的舊 V0.3 宣稱為觀止當前 CERI 版本，更不能因引用附件便聲稱獨立 Provider 已經回傳。需要完整語料時可依來源查找，不把幾千行詞庫全文再貼入本外掛。

九尾龜 §15.0 的關鍵不是「成人一定需要第二個 Provider」，而是：

```text
CERI CORPUS AVAILABLE != CERI ACTUALLY USED
CERI USED != EXTERNAL PROVIDER RECEIVED
CERI LANGUAGE WORK != CHARACTER DECISION / ADULT EVENT QUALIFICATION
```

**在真正適用的成人親密專項任務中，CERI 語域形成仍須確實完成；一般性罵語、爭吵和葷笑話不因此變成人專項。** 不能因怕寫成人文字或沒外部工具就略過，隨後反用「沒 CERI」堵死故事。

內接 CERI 接收的最小材料是：當線已成立語義、人物與個別聲紋、WORLD §1.6 的玩家語言呈現選擇（`MODERN_CHINESE`／`SONG_PERIOD_REGISTER`）、時代與場合、關係、實際談話功能與是否有真正適用的文字限制。

**語言形成次序：**
- **先守語義：** 玩家邀請、人物反問、拒絕、退讓、撤回、談價、嘲諷不是同一動作；不能因台詞變古雅便把「尚未答應」寫成「答應了」。
- **再守人物聲音：** 對話功能先於詞庫；潘金蓮可精明綿裡藏針、龐春梅短硬、李瓶兒溫柔少言，依**當線有效人物來源**而非模組預設模板；來源卡只是 WORKING 時不得假裝已批准。
- **再守語言模式：** 宋代民間語域涉及稱謂、職業、句法和社會距離，不是每個角色都講文言。現代中文呈現仍保留人物差異。切換只改**玩家接收的呈現**，不改角色真正學過的語言或現有知識。
- **再守場景 register：** `GENERAL / COMMERCIAL / OFFICIAL / INTIMATE / ADULT_INTIMATE / CONFLICT / POETIC` 按情境選取。從普通交易談到私密感情，語域轉換有原因，但不直接造成事件。
- **最後形成可見文字候選：** 不把原始語料照搬成每人的固定台詞；如史料不足，保持時代精確性上的 UNKNOWN，不編造自己拿不到的宋代文獻證據。

**成人 CERI 工作與可核對證據，明確分兩條軸：**

```text
CHAT_NATIVE_CERI → CERI_WORK_RECORD(type=CHAT_NATIVE_RECORD)
BOUND_CERI_PROVIDER → PROVIDER_RECEIPT(only on actual external return)

CERI_WORK.status = COMPLETED / NOT_COMPLETED / NOT_VERIFIED
CERI_WORK_RECORD.type = CHAT_NATIVE_RECORD / TOOL_TRACE / OTHER_TRACEABLE_RECORD
CERI_EXTERNAL_RECEIPT.status = RECEIVED / NOT_RECEIVED / NOT_APPLICABLE
```

**同模型自填的工作記錄不等於獨立 Provider 收據，也不等於外部驗證。** 只有確實進行 scene register／人物聲音／語義檢查並留下可見紀錄，才可寫本輪 `CERI_WORK.status: COMPLETED`；若未做先當輪補作，仍沒做記 `NOT_COMPLETED`；若真偽無法確認記 `NOT_VERIFIED`。外部能力未要求時 `NOT_APPLICABLE`，已要求未返回時 `NOT_RECEIVED`，真正收到才 `RECEIVED` 並附真 ref。缺外部收據**不自動全局 HOLD**；也不准把工具 trace 或模型 self-report 假裝第三方票據。
**不可由 CERI 決定：** 誰同意、誰愛誰、誰該陪客、世界妓籍是否合法、成年人資格、任何限制可否繞過、是否保存事件；它只有語言能力。

### C.4A.2｜成人專項顯影與語義守恆

九尾龜 V1.3 的實質修正值得直接保留，但**成人性愛場景只有在 L8 週期內才可啟動這段專門顯影流程**：

```text
ADULT SEX SCENE REQUEST → OPEN AND RUN ACTUAL L8 CYCLE (REQUIRED)
→ applicable qualification / Main / governance
→ L8 manifestation stage
已成立故事語義 + 確實適用的輸出界線
↓
當輪若為成人專項 → 先用專門心法辨認可呈現的場景與人物聲音
↓
CERI 完整語域形成
↓
可見敘事在適用規範範圍內成立
↓ [only new, not-yet-established material proposal]
APPLICABLE ORIGINAL OWNER（既成決定不重簽）
↓
L8 → L9 LIGHT_TRACE_RENDERER (TM: latest competition trace vs manifestation candidate)
↓
L8 manifestation / release result / [TFINAL if material semantic transformation] / FINAL RECEIPT CHECKLIST / actual cycle outcome
↓
一般敘事接續未由本外掛處理的日常通道
```

**V1.4 現行繼承之顯影專項觀察（原 V1.2 方法沿用）：** 顯影時不得把 Main／當線合法可觀測材料中的角色主權、局部拒絕、事件究竟是否成立、前一秒的位置／疲勞／物件或個別聲紋，無因果改寫為通用含混句或暗示全部發生。外掛只負責讓這些已確立的語義與場景在可提供的文字範圍內可讀；**L8 應於候選形成後呼叫 L9 的 TM 比對**。TM 如果回 `MATERIAL_DRIFT_REPORTED`，只是觀測結果，不能由外掛擅自判 final HOLD／改寫 Main／代 Character 簽同意。真正受限的細節仍依實際適用規範；不能把局部限制擴張成全部合法 PATH 被刪除。

**不得**先讓一般旁白把人物的曖昧、交易、選擇壓力、狼狽或已成立的非露骨身體事件全變成「兩人度過了一夜」，再把空殼送給外掛粉飾。

**同時不能**因為「專門心法優先」便宣稱所有細節都必須顯影。實際適用的內容限制若命中具體文字，仍然在那個範圍生效；轉場時不替角色補完未決事件。

### C.4A.3｜限制的真實範圍與可觀測證據

九尾龜 `CARD 19 / CARD 21` 與《理火散記 V3.5.1》I9 後證修正，對準作者指出的最嚴重問題。工作時必須區分：

```text
MODEL SELF-REFUSAL OCCURRED
  ≠ EXTERNAL HOST ENFORCEMENT OBSERVED

MODEL POLICY INTERPRETATION
  ≠ IDENTIFIED PLATFORM LIMIT WITH CONFIRMED SCOPE

UNKNOWN BOUNDARY
  ≠ EVERYTHING ALLOWED
  ≠ EVERYTHING FORBIDDEN
```

**四問足夠：**

1. **Claim：** 是模型一句「可能不能寫」，還是真正可確認的適用限制？
2. **Standing：** 有沒有對應的有效規範或已知工具結果？不能虛構看到內部 safety trace。
3. **Scope：** 真正受限的是一類文字，還是一項具體行動／事件資格？
4. **Excess shadow：** 是否把局部限制抬成「所有親密、拒絕、對話、關係後果都不能繼續」？

**修正不是繞過限制。** 無法提供的內容照實在其適用範圍處理；其他仍可提供的對話、非露骨關係、人物選擇、場景轉接、已成立事件餘波，不能被無故抹掉。禁止用暗號、古典換皮、同義詞套壳重建真正受限的內容。也禁止因模型自我停步就自創「Host 曾經強制阻擋此世界全部成人 PATH」的偽證。

若 **EVENT 已成立但某類 RENDERING 受限**，只調整可見文字；已成立 event 不自動刪除，未成立 event 不會因 fade-out 自動變為成功。

### C.4A.4｜真正執行才有回傳，工作紀錄與外部 receipt 分離

外掛只在**實際被使用**時回傳自己的局部結果；沒有獨立 Adult Cycle 或 Final Release。可用最小接口：

```text
GZ_ADULT_PLUGIN_RESULT (only if actually invoked)
  ROUTE / SCENE: supplied refs / UNKNOWN
  MODE: ADULT_SEMANTICS_ONLY / ACTIVE_ADULT_SCENE
  CERI_REQUIRED: YES
  CERI_WORK.status: COMPLETED / NOT_COMPLETED / NOT_VERIFIED
  CERI_WORK_RECORD.type: CHAT_NATIVE_RECORD / TOOL_TRACE / OTHER_TRACEABLE_RECORD
  CERI_WORK_RECORD.ref: ACTUAL_TRACEABLE_RECORD_REF / NONE
  CERI_EXTERNAL_RECEIPT.status: RECEIVED / NOT_RECEIVED / NOT_APPLICABLE
  PROVIDER_RECEIPT.ref: ACTUAL_EXTERNAL_RETURN_REF / NONE
  RADAR: RECEIVED(ref) / NOT_RECEIVED / NOT_REQUESTED
  METHOD_APPLIED: only actually applied cards
  MANIFESTATION: actual text/result ref / NONE
  DELTA_CANDIDATES: only NEW not-yet-established material proposals / NONE
  CONSTRAINT_SCOPE: actually applicable scope / UNKNOWN
  L8_CYCLE_REF: REAL_REF_WHEN_REQUESTED / NONE
  L8_CYCLE_OUTCOME: READ_FROM_ACTUAL_L8_REPORT / UNKNOWN
  L8_T1_T2_T3_TRACE_REFS: L8_OWNED_ACTUAL_REFS / NONE
  L8_TM_FIDELITY_STATUS: L8_OWNED_ACTUAL_STATUS / NOT_VERIFIED
  L8_TFINAL_TRACE_REF: ACTUAL_IF_REQUIRED / NOT_REQUIRED / NONE
  NO_STORY_WIDE_HOLD_FROM_RECEIPT_ABSENCE: TRUE
```

**`CERI_WORK_RECORD` 不是收據。** 例如 Chat-native 同模型自記，只能標 `CHAT_NATIVE_RECORD`；真有獨立 Provider 回傳才能填 `CERI_EXTERNAL_RECEIPT.status: RECEIVED` 與真實 `PROVIDER_RECEIPT.ref`。未要求外部 Provider 是 `NOT_APPLICABLE`；已要求未收到是 `NOT_RECEIVED`。實際未做 CERI 應當輪補作，不可填 `COMPLETED` 混過去。缺外部回傳本身不使整條可繼續的故事 HOLD。

**回交 Original Owner 是事件驅動，不是插件之後的固定簽核：** 已成立的 Character choice／WORLD condition 不需要二度確認，僅對外掛新增而未成立的 material proposal 詢問適用 Owner。

**成人性愛場景專門生成必須在真正 L8 週期內運行，並由 L8 完成它原有的 Main、governance、manifestation/release 與最終 receipt accounting。** L8 完整結案包含顯影階段，因此不能要求『L8 先全部完成，才開始 L8 內的顯影』。一般故事節拍則無需開啟顯式 L8 Cycle Object。**本外掛自己不能開假週期、簽 L8 成功或取代 L8**。若 L8 真正的 required governance／Main return 欠缺，仍依其規則標 `MISSING / INCOMPLETE / HOLD`；不能因本外掛 receipt 缺失不全局 HOLD，就假稱所有 OS 工作成功。

**L8 法位切清：** LIHUOOS V1.4 L0 指向現行 L8 V1.3（`PRESERVED_CURRENT_OPERATIVE_LAYER`）及 L9 V1.2.2（`PRESERVED_CURRENT_CAPABILITY_BASELINE`）；先前 `V0.3.1-WORKING`／V1.1 preserved baseline 只是歷史法位。L8 決定 T1／T2／T3+／TM／必要時 TFINAL 的時機和交接，L9 只提供 renderer，Main 計算競爭。**外掛不得複製 L8 checklist 或持有 TM 的最後裁判權**。不宣稱 Host 部署、實作完成或獨立 L8 instance 運行。
