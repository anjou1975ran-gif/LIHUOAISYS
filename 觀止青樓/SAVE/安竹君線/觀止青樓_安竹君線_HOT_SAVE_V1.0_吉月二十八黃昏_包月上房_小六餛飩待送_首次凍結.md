# 1｜新 Route 的開場事件：觀止大堂有空席

玩家選擇起點一「觀止今夜有空席」，形成一條**獨立的新玩家 Route**。世界為汴梁觀止青樓；開場時大堂正在營業，外有酒車送酒，內有客人飲茶聽曲。

觀止大堂櫃台前，兩名客人為同一席位爭論：
- 寶藍綢袍的胖商人主張自己前一日已有訂席，反對別人以更高價搶席。
- 灰衫客人出價爭座，又想請浮香下樓彈琴；他認為浮香先前所說「改天」應使自己可以繼續要求見面。
- 浮香透過使女傳話：**今夜不見那位客人，琴也不為他彈**。潘金蓮吩咐使女轉告她安心，若有人再上樓吵擾便讓護院來找掌櫃。
- 灰衫客人沒有立即離開；後來仍在大堂一帶等候，茶已涼了一些。兩客人的席位、銀錢、與浮香的後續結果均**未決**。
- 「改天」不是確定日期、預約、同意見面或演奏義務；不能從此段直接補成浮香另日答應。

玩家未插手爭席或替浮香作決定，而是直接詢問住宿。跑堂接待，潘金蓮在櫃台洽談房事。

# 3｜安竹君 × 小六：住宿安排、賞錢與餛飩委託

- 一名跑堂／小廝在故事中被潘金蓮稱作「小六」；此人為本 Route 首次出場的**局部人物**，不是因本 HOT 而自動編入 73 人共用人物池。
- 安竹君拿出**兩枚銅錢**交給小六，請他幫忙把行李搬去房間。小六已接過賞錢，將行李帶到後院東廂上房，置於木架旁。
- 安竹君稱他「小六哥」並道謝。小六表示不習慣被尊稱作哥，但欣然回應；這是一次友善互動，尚無長期信賴或私人契約。
- 小六開房，介紹房內布置，試窗閂；玩家實際跟去看房，並表示「可以」。
- 房間在觀止後院二樓東廂盡頭，比大堂安靜；後院當時有為明日仕女夜準備的紅綢、木架與後勤人手。
- 龐春梅當場督促明日準備，並提醒小六若窗閂仍鬆應更換。小六試後認為牢靠。
- 一名未具名年長女使在後院洗木桶時提醒：明日仕女夜後勤繁忙，應預先安排送熱水時辰。

## 3.1｜晚間餛飩熱湯訂單

玩家最後說：「可以 先謝了小六哥了 晚上我會去大堂走走 你幫我去對街叫上一碗餛飩熱湯 晚上送來」。

小六接受委託，說**戌時前後再去買**，免得餛飩涼掉；送回房裡，如安竹君尚未回來，他說會先將碗蓋好放桌上。小六亦表示外食錢等買回再結，**此前兩文是賞錢，不抵餛飩錢**。
