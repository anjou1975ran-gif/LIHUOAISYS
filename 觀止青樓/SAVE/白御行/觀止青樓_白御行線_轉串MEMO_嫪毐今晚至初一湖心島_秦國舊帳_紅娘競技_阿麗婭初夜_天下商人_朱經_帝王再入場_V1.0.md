# 0｜這一段真正要做什麼

不是「把名人全部叫來」。

核心是讓一個很低俗、很觀止的笑話——**紅娘被白御行要求終身宣稱自己吃過最大的男人是白御行**——沿著男人面子、歷史名聲、女人做市、帝王舊帳與跨代資本網一路失控，最後把初一湖心島變成一個多市場同時運轉的夜晚。

建議主題：

1. **雄性名聲可以成為商品。**
2. **女人不是獎品；女人可以反過來當莊家、估價者與最後選擇者。**

4. **商人看的不是名號，而是資本怎麼流動。**
5. **歷史人物不是梗本身；梗把人物叫進來後，人物要依自己的舊債與利益活。**
6. **帝王宴的續篇不是再辦一次帝王宴，而是讓帝王被吸進白御行已經做起來的商務／文藝／風月市場。**

# 1｜時間骨架：不要一晚把所有炸彈都炸完

主事件只需要一個：

- 建立嫪毐本人，而不只是「大雞巴歷史梗」。
- 讓紅娘發現白御行原本拿來整她的終身證詞，居然可以變成可售賣的挑戰權／門票／賭盤。

# 4｜趙姬／朱姬｜真正的大爆點必須由她自己點火

## 進觀止的第一原則

不要寫成：「因為她歷史上是妓女，所以來了就掛牌。」

可用背景是：她有善歌舞／姬的歷史來源，對風月、表演、被男人觀看與被交易不陌生。

但是本 Route 若她要掛牌，必須是**現在的趙姬本人選擇**。

## 最有力的路徑

她先來看：
- 嫪毐怎麼又靠自己的身體名聲吃飯。
- 呂不韋現在怎麼看她。
- 白御行與潘金蓮的青樓到底怎麼運轉。
- 觀止姑娘是否真的有選擇權與定價權。

然後她自己問潘金蓮：

**「初一那場，我若只掛一夜呢？」**

這一刻才把秦國線炸開。

## 「一夜限定」的價值

不是重新入籍、不是永久掛牌，而是：

**初一湖心島・趙姬・僅此一夜。**

稀缺性會讓潘金蓮立刻重新算價。

仍需談：
- 是否只陪宴／歌舞／單獨席／成人一夜
- 競價是否只拿候選資格
- 她保留哪些拒絕權
- 是否可撤牌
- 所得分成

趙姬若掛牌，呂不韋出不出價都很有戲。

但不要預設。

他出價：是曾把她送入另一場政治交易的人，千年後重新報價。

他不出價：趙姬也可能拿這件事刺他。

# 9｜阿麗婭初夜拍賣｜湖心島真正的女人主權測試

- 潘金蓮已準備親自去問，但目前答案 PENDING。

## 最適合阿麗婭的玩法

白御行／潘目前討論的規則正好可能碰到她的核心張力：

1. 男人可以拿銀子出價。
2. 文人可拿詩詞書畫等作品，作品值多少由阿麗婭自己評。
3. 競價只決定誰進最後候選。
4. **最後由阿麗婭自己點男人。**

不是「最高價拍走阿麗婭」，而是「阿麗婭看完最後一桌人，自己選一個」。

她仍可能：
- 接受
- 拒絕
- 要求改規則
- 改日期
- 不願公開
- 只接受某些候選類型

## 忽必烈線

玩家補充舊歷史：帝王宴時阿麗婭與忽必烈關係很好。

這可以成為**忽必烈可能被消息吸回湖心島**的原因，但不能寫成他自動擁有阿麗婭優先權。

真正有戲的是：
- 他若到場，究竟以舊交、皇帝、男人、朋友還是競標者身份出現？
- 阿麗婭看到他，是否把他放入候選？由她決定。

所以初一他可以是**既是地主，又是有自己女人社交麻煩的男人**。

## C. 帝王之間的荒謬位置

嬴政若來封母親的盤；忽必烈可能為阿麗婭來；趙受益卻必須面對：

「這群皇帝現在全在我京師的一座湖島上。」

他未必能命令他們，但他最有理由問潘金蓮／白御行：

**「你們到底還邀了多少人？」**

而白御行很可能真的不知道。

# 12｜楊玉環 × 六條｜不要只當趙受益的兩個女人

兩人都應保留自己的角色線。

## 楊玉環

她已有觀止／白玉池／白御行私人歷史，也與六條存在複雜的看戲／競爭／未完全定案三人方向。

初一可以讓她：
- 作女客／名人，而不是員工或拍賣標的。
- 對趙姬的「太后自己掛一夜」產生自己的看法。
- 看嬴政為了面子砸錢，從另一個帝王女人位置形成對照。
- 跟趙受益維持既有雙線追求張力。

不要自動讓她因楊貴妃身份懂秦國所有舊史細節；誰告訴她什麼要有來源。

## 六條御息所

她同樣是女客，不是觀止掛牌姑娘。

她的日本身份與鄭經非常值得碰，但要注意時間知情：

- 六條是平安時代人物。
- 鄭經比她晚數百年。
- 她不可能天然知道鄭氏、明清鼎革、蒙古侵日等未來史。

因此不要讓她一看到鄭經就說「你祖母是田川氏」之類未有來源的百科台詞。

## 六條 × 鄭經／「朱經」最好玩的地方

鄭經的祖母是日本人這個血緣背景，可以從**鄭經本人說出／被有來源的人介紹**後成立話題。

戲不在「都是日本人所以親切」。

而在：
- 六條是日本古典貴族女性。
- 鄭經是以東亞海貿、戰爭與跨文化家族長大的十七世紀男性。
- 他們所理解的「日本」根本不是同一個日本。

六條可能更在意：
- 他的日本語從哪裡來／會不會說。
- 祖母來自何地、為何嫁入鄭家。
- 幾百年後日本的婚姻、船、港、服飾變成什麼樣。

鄭經則可能第一次面對一個「祖母出生以前幾百年的日本女人」。

這可以是一段非常安靜的跨時代對話，放在湖心島其他鬧劇旁邊反而更有味道。
