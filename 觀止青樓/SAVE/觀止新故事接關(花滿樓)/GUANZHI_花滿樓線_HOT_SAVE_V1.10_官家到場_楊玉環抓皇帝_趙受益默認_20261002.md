# 一｜V1.9 後未存尾段：祝惟實、鬼滿樓與木盒

## 1.1 祝惟實與舊木馬

V1.9 後續已演故事中，祝惟實進入鬼滿樓相關線，對陸蘅所指認的舊木馬提供了新的來源線索：木馬很舊、曾補裂、左前腿較短；祝惟實說其父曾修過，但不是其父所造。陸蘅先前則說木馬屬她郎君的弟弟。

這些是各自來源陳述與物件觀察，不把尚未核實的來源關係升格成唯一真相。

## 1.2 祝惟實交付窄長木盒

祝惟實把父親留下的一只窄長木盒交給花滿樓。已成立的安排是：

- 木盒最終由陸蘅自己決定是否收、碰、開或丟；
- 不得先把木盒帶進鬼滿樓西後院；
- 祝惟實對可能造成的失眠等後果有帶玩笑性質的求償約定。

## 1.3 范姓男人的五兩「子時前不開」交易

其後一名范姓男人以 **五兩**成立一項局部交易：**子時以前不要打開木盒。**

花滿樓收下五兩後，為避免自己提前開盒，把木盒交 **小桃**保管，並分給小桃 **一兩**作保管／防手癢之用。子時後若要形成新的不開盒或其他限制，必須重新談，不把前約永久化。

截至本 HOT，不能把「子時前不開」偷寫成「木盒已在幕後被打開」或「木盒內容已知」。

## 2.1 蘇東坡因肉香自行入場

蘇東坡是本朝活人，因觀止酒菜／紅燒肉香自行走進觀止並留下，不是招魂結果，也不是為了完成導演預設而被強行召入。

- 《蝶戀花・問玉環》

兩闕詞成為大堂對趙飛燕、楊玉環的公開挑釁／邀請材料之一。

## 2.2 「今夜 觀止 玉環飛燕共待官家」

花滿樓親筆寫下：

> **今夜 觀止 玉環飛燕共待官家**

潘金蓮批准張貼／公開使用。

此句的既定語義是邀人同場、看另一朝官家與參與觀止的大堂局，**不是「等官家來睡」或侍寢邀請**，不得因青樓背景回鑄成性約定。

## 2.3 蘇東坡公開講仁宗

蘇東坡與趙受益／宋仁宗具有本朝君臣背景；本段中蘇東坡公開講仁宗的仁厚、容人與識才等特質，以自己受仁宗賞識的立場參與現場起鬨與宣講。這是現場人物行動，不代表所有旁人因此已掌握趙受益的具體身分。
