# F｜人物知情硬鎖

- 疏影／錦棠／一般客人 **不自動知道趙受益是皇帝**。
- 王婆剛入班富蘭線，**不自動知道十一萬拍賣全部內幕**。
- 紅娘可以知道自己經歷與眼前談判，不等於知道潘金蓮全部盤算。
- 應伯爵很會看人脈與錢，但不是情報神諭。
- 西門慶私下向趙受益說了什麼，班富蘭目前不知道完整內容。
- 蘇清不是所有後世資料的精準資料庫。
- 班富蘭知道自己的玩家陳述／所見，不得因導演知道而自動知道 NPC 私下內容。
