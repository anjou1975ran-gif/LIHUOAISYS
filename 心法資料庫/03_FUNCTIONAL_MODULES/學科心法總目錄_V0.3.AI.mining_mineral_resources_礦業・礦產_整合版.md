## Professional Support

工地採掘、資源與污染評估、安全及材料須由場址授權工程和環境專業。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構舊採石場結束作業，新草覆蓋地表，但下游長期監測及責任者資料未交接。

**Baseline**　以照片宣布復育完成。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 場址條件 | 分植被與下游未知 | 若歷史和現測均穩，交專家 | |
| 關閉條件 | 找地面與水責任聯結 | 若有缺口不擴結論 | |
| 事後責任 | 核樣本留存及告警承接 | 若分工未定交主管 | |

**觀察轉向**　由基線轉向核場址條件、許可、復育及事後維護

**證據轉向**　核准場址資料、覆土或水質見證、責任和資源

**因果轉向**　地質及水源的不確定可使復育責任延長

**盲點及邊界**　不決實地安全。

**自審結果**　分地表、勾稽及事後監督。
