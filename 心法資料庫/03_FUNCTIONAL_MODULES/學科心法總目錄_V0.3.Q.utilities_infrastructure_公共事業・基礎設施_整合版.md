## Canonical Demonstration Case／Method Shift Test

**案例**　虛構園區供水椿站已恢復，部分用戶仍以替代服務領取，營運方以站點計作全恢復。

**Baseline**　用設備狀態推全體有水。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 服務範圍 | 核代領和直接供給 | 若覆蓋完整仍查負擔 | |
| 互賴與備援 | 查營運回報來源 | 若有重複資料交主管 | |
| 負擔和復原 | 比受限使用群 | 若等價需驗長期 | |

**觀察轉向**　由基線轉向分設施、服務、支付可及與復原

**證據轉向**　服務分布、事件、復原及實際可及

**因果轉向**　多依賴和末端限制可在設施通過時留空

**盲點及邊界**　現地水質與安全另由主管。

**自審結果**　以端點、阻隔與費用解復原差。

## Negative Control
