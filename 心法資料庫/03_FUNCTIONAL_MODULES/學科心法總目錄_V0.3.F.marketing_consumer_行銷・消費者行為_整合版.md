## Canonical Demonstration Case／Method Shift Test

**案例**　虛構會員頁換成醒目廣告後點擊增，購買也增但取消比例上升，客群及定義未知。

**Baseline**　以點擊增宣告價值上升。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 分群與任務 | 分舊客新客與原任務 | 同群內仍差再查訊息 | |
| 訊息與理解 | 查新廣告是否遮住週期 | 若理解未變則查服務 | |
| 留存及回饋 | 比較同群首週和次月 | 樣本不足則留問 | |

**觀察轉向**　由點擊多改問需要、理解及承接

**證據轉向**　比曝光分母、價格與長期行為

**因果轉向**　新版本可帶轉換也能因誤解增加退訂

**盲點及邊界**　以匿名資料核，法律及個資交專業。

**自審結果**　三個轉向區分分群、預期和留存。
