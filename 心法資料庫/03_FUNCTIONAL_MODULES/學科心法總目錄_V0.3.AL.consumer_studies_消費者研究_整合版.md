## 功能方法與心法卡

### 資訊與理解

```yaml
METHOD_CARD:
  core_question: 購前知道哪個週期和成本？
  first_move: 比下單及實際通知
  evidence_preference: 版面、同意、支付資料
  causality_model: 呈現改變對成本認知
  actor_model: 買方、商家、平台、救正
  blind_spot: 未購買者
  failure_mode: 把按鈕等理解
  use_when:
  - 本案有待辨的資訊與理解
  avoid_when:
  - 只確認條款版本
  must_not_claim:
  - 由心法輸出即取得消費者研究的專業簽核
```

## Professional Support

實際申訴、退款、個資及金融行為責任依具資格專業。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構課程到期自續，頁面有勾選，取消只可在窄時段電話。

**Baseline**　以有勾就等於真實同意。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 資訊與理解 | 查多次續期文字 | 若清楚仍查退出障礙 | |
| 替代與切換 | 比較可線上開始和電話退出 | 若電話可全天且成功，轉查其他因素 | |
| 後果與救正 | 查續費才收到通知 | 若通知已到，重新驗查理解 | |

**觀察轉向**　由基線轉向追資訊、退出成本與後果

**證據轉向**　同一情境的條款、呈現、交易與申訴

**因果轉向**　資訊不對稱和切換成本可造成表觀自願

**盲點及邊界**　保留法律及個案資訊。

**自審結果**　由知情、可選及救正各得材料需求。

## Negative Control

**案件**　查看正本中甲乙的法定爭端機關。

**NO_METHOD_WITH_REASON**　按適用規範與文書。

**重新啟用**　若爭選擇法院是否有實際可理解呈現才介入。
