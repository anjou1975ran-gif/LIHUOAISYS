## Canonical Demonstration Case／Method Shift Test

**案例**　虛構市府使用氣象圖。已取得原始感測資料，看板仍無近時圖層，地面審核者剛更換。

**Baseline**　原始資料收到就判服務可用。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 觀測用途 | 確認原資料採集時點 | 若太舊不算近時服務 | |
| 地面交付 | 查新審核接手 | 若已發布再查顯示 | |
| 生命週期治理 | 查主產品與替代來源 | 若已準備備來源驗使用 | |

**觀察轉向**　由基線轉向分任務目標、地面接手、版本與生命週期治理

**證據轉向**　民用需求、測試、元資料與來源、服務端驗收

**因果轉向**　原觀測可取得但處理或責任缺口使產品不可用

**盲點及邊界**　僅用合成民用觀測資料。

**自審結果**　分觀測、產品、交接和責任。

## Negative Control

**重新啟用**　若文件實際標哪個資料版有爭議再核。
