## 功能方法與心法卡

### 工作實況

```yaml
METHOD_CARD:
  core_question: 誰能排班及限制替代？
  first_move: 確認實際指揮
  evidence_preference: 工單、工時和排班
  causality_model: 控制會移工時負擔
  actor_model: 工作者、工會、雇主
  blind_spot: 未記錄或有差
  failure_mode: 合同名稱當實況
  use_when:
  - 本案有待辨的工作實況
  avoid_when:
  - 只查章程日期
  must_not_claim:
  - 由心法輸出即取得勞動關係的專業簽核
```

## Professional Support

實際勞動資格、仲裁及工作安全由勞務專業與授權代表。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構館員換班規則獲一個代表同意，但鐘點人員沒有參與且實際待命變長。

**Baseline**　以代表簽名等同全體接受。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 工作實況 | 找待命紀錄 | 若可自由拒絕還須查收入依賴 | |
| 代表覆蓋 | 列未參與鐘點組 | 若有同意證據重核範圍 | |
| 協議與申訴 | 查待命計入及回覆 | 若紀錄一致轉查合規 | |

**觀察轉向**　由基線轉向先比契約、實際指揮及集體接入

**證據轉向**　實際任務與工時、代表紀錄、協商及申訴

**因果轉向**　發聲成本及代表覆蓋改變訴求可見性

**盲點及邊界**　實際雇用與協議效力另核。

**自審結果**　分指揮、代表及救濟。
