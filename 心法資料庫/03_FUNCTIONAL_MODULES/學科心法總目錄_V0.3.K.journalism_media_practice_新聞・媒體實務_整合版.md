## Canonical Demonstration Case／Method Shift Test

**案例**　虛構地方網報據網友截圖準備發布場館停業消息，現有文件標為草案，館方尚未回覆。

**Baseline**　把截圖直接稱正式決定。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 來源與主張 | 改為草案未獲證 | 若找到生效公告再更正 | |
| 詢問及傷害 | 查館方是否通知任何服務 | 未回應記待核 | |
| 發布追蹤 | 留更新和原主張 | 若外頁仍錯據，回報編務 | |

**觀察轉向**　由基線轉向先鎖原件、知情權、隱私與責任

**證據轉向**　原件、具名或核實來源及向當事人求回應的紀錄

**因果轉向**　不明來源可形塑報導偏差，負責任的更正可控制擴散

**盲點及邊界**　保密與查核由編務。

**自審結果**　三回應分版本、回覆和責任。

## Negative Control

**案件**　正本是已核版作品，只詢問詩節組織。

**NO_METHOD_WITH_REASON**　選敘事／文學分析。

**重新啟用**　若稿件有人以詩節作現實指控才查原件。
