## Canonical Demonstration Case／Method Shift Test

**案例**　合成圖書館實體可進，但自助預約只有特定介面。有讀者說能進不能借。

**Baseline**　由坡道合格推服務可達。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 實體與活動 | 確認借還流程 | 若可達仍查使用障礙 | |
| 資訊與選項 | 比較可直接使用與需代辦 | 若兩路等效仍查制度 | |
| 制度與問責 | 核程序是否保留當事人解釋 | 若回覆有效重驗參與 | |

**觀察轉向**　由基線轉向分活動、功能、環境和制度障礙

**證據轉向**　本人適用任務、場地觀察、規則及替代方案

**因果轉向**　更改障礙可在個人功能不變時增加參與

**盲點及邊界**　真實權利及驗收需專業。

**自審結果**　實體、資訊與制度三處可各別解釋拒絕。

## Negative Control

**案件**　核圖書館正本開幕日期。

**NO_METHOD_WITH_REASON**　在日期欄讀取。

**重新啟用**　若後問受邀者可否參與才轉可及。
