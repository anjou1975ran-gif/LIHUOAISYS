真實交通調度、安全、工程和法規由有權營運及專業。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構公交每段都準點，部分居民仍常未能到場，兩線轉乘時間極短且需要過街。

**Baseline**　以單段準點推人人可達。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 旅程分解 | 列過街時窗 | 若足夠，查負荷 | |
| 服務品質 | 看特定轉乘段 | 若等候不高，查可及 | |
| 替代與人群 | 分使用輔具者路徑 | 若有等同替代要核實際連接 | |

**觀察轉向**　由基線轉向從起訖及時段重建各運具交接

**證據轉向**　實際起訖、班表、載運與可及觀察

**因果轉向**　班期、轉乘和障礙改真實旅程

**盲點及邊界**　案例不改調度。

**自審結果**　旅程、時窗及營運責任三方對照。

## Negative Control

**案件**　只比較兩份證明的承運人名。

**NO_METHOD_WITH_REASON**　按原件核實。

**重新啟用**　若需追哪一段接手，轉旅程。
