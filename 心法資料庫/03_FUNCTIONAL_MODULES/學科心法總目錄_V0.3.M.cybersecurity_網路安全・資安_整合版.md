## Professional Support

現場事件、數位鑑識、通報與復原均先由授權責任者判定。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成公司誤關有權查資料的團隊，服務告警同時跳出，需理解是否正常變更及如何驗證業務復原。

**Baseline**　只看告警就宣布入侵。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 防禦責任 | 核角色和批准 | 若權限確應在且未變，進異常 | |
| 觀測與保全 | 對改權與告警時序 | 若沒有關聯，保持未知 | |
| 服務復原驗證 | 手續完成後核正當權限 | 若失敗保留異常及責任 | |

**觀察轉向**　由基線轉向先畫資產、權責、保護與復原證據

**證據轉向**　核准資產、角色、服務告警和恢復見證

**因果轉向**　權責或訊號缺漏可延長事件和停機

**盲點及邊界**　僅用授權紀錄做查核。

**自審結果**　三回應檢查配置、事件歸屬和復原。

## Negative Control

**案件**　已驗真的名冊只求讀部門名稱。
