  causality_model: 一種證明不涵蓋全部
  actor_model: 編製者、獨立覆核及使用者
  blind_spot: 漏列表外事項
  failure_mode: 覆蓋混淆

## Professional Support

正式審計、確信和任何簽署由具資格且具獨立性的專業人員。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構應收款數被表列兩次吻合，但兩報表均由同一表格匯出，少數客戶狀態有爭議。

**Baseline**　兩表相同即判應收真實。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 主張分解 | 先從是否存在開始 | 即使均存在也仍可有估值問題 | |
| 獨立證據 | 兩內表合併為一條來源 | 若外部且對應一致，才增加佐證 | |
| 異常和覆核 | 把爭議戶當可辨差異 | 若只一期口徑差，另核覆蓋 | |

**觀察轉向**　由帳面對上轉問主張與來源

**證據轉向**　要求外部或獨立佐證

**因果轉向**　同源資料會維持錯誤一致

**盲點及邊界**　責任人另定實際抽查範圍。

**自審結果**　主張、證據與差異回應使同源一致性不成立。

## Negative Control

**案件**　要核對會議頁上的印刷日。

**NO_METHOD_WITH_REASON**　從正本讀取，沒有確信任務。

**重新啟用**　若需獨立保證一批會議紀錄完整，再開審計證據問題。
