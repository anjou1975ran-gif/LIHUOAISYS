## Canonical Demonstration Case／Method Shift Test

**案例**　虛構活動有保單，兩場同日因風雨延期，組織者稱兩個活動一定各賠。完整條款未取得。

**Baseline**　兩場乘固定保額。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 觸發與期限 | 索取兩場事件時點 | 若保期無疑再看條款 | |
| 聚合與風險池 | 同日兩案合不合應交查 | 若獨立觸發則重分 | |
| 留存與責任 | 先列延期未必覆蓋的費用 | 若找到正式批單改限額則開新版 | |

**觀察轉向**　由有無保險轉向責任及留存

**證據轉向**　以原條款和事件紀錄判材料需要

**因果轉向**　共同事件與邊界會改分配

**盲點及邊界**　未確認適用條款與事實。

**自審結果**　拆觸發、聚合和營運剩餘負擔。

## Negative Control

**案件**　已驗真文件只需讀保單編號。

**NO_METHOD_WITH_REASON**　抄原件，無承保問題。

**重新啟用**　若號碼對應兩份不同期間，再啟。
