## Canonical Demonstration Case／Method Shift Test

**案例**　合成檔案平台改欄位格式，新建資料全通過，歷史資料顯示空白。

**Baseline**　只看新項測試就發布。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 需求與相容 | 查既有欄位別名 | 若資料內容本身缺移檔 | |
| 驗證與版本 | 補歷史資料測試 | 若只有現場配置差先核版 | |
| 發布與回復 | 確認舊案未被破壞 | 若涉及重建需主管審核 | |

**觀察轉向**　由基線轉向鎖需求、相容、配置及負責人

**證據轉向**　追溯需求、程式版本、測試、變更與回復紀錄

**因果轉向**　版本和資料遷移不相容可令同碼在既有流程失敗

**盲點及邊界**　操作由維護者決定。

**自審結果**　三回應分契約、相容和回復。
