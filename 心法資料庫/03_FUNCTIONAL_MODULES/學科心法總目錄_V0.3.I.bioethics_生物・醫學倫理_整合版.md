## Professional Support

真實研究倫理、臨床同意與脆弱情境由倫理審查、臨床、法律及當事人。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成大學擬對自願藝術活動參與者做健康問卷，提供者同時評分。只有同意欄。

**Baseline**　以所有勾選判自願。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 自主和理解 | 查拒絕有無後果 | 若條件不清留審查 | |
| 利益和負擔 | 比較老師與評分分離 | 若無依賴仍查合理保障 | |
| 審查及事後 | 列倫理及資料責任 | 若未核准，不模糊通過 | |

**觀察轉向**　由基線轉向把目的、益害、不確定、替代及同意分列

**證據轉向**　允許的方案與替代、材料、同意及受影響資料

**因果轉向**　知情時點、依賴或誘因可改自願性

**盲點及邊界**　倫理准入需專業審查。

**自審結果**　目的、權力及退出都需查。
