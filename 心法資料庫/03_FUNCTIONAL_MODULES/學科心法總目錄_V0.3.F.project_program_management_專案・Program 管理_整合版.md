## Canonical Demonstration Case／Method Shift Test

**案例**　虛構場館三專案各報九成，仍不能開館。員工培訓待設備驗證，開館時段未分人員。

**Baseline**　取平均即接近開館。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 前置與見證 | 員工培訓尚待驗機 | 若培訓可並行，重排 | |
| 資源與變更 | 查試運與日常共用值班 | 若人員已另編則差在其他接口 | |
| 效益擁有人 | 核開館指標和實際服務 | 若僅交裝置可用，受益保留 | |

**觀察轉向**　由百分比轉向可交付與承接

**證據轉向**　看前置、資源承諾、運行採用

**因果轉向**　共同資源與交接會使全體結果晚於各報告

**盲點及邊界**　資料只是示意，不能代營運批准。

**自審結果**　里程、資源和採用回應揭示聯鎖阻礙。
