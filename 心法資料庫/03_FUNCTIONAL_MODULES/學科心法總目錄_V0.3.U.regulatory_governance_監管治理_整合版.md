## Canonical Demonstration Case／Method Shift Test

**案例**　合成市府擬要求所有展場每週交同格式報告，但小館有低風險、續報成本高。

**Baseline**　以同表即同安全。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 基線與工具 | 先列不同展場的待查風險 | 若無差異再比成本 | |
| 差別影響 | 檢查小館不成比例之處 | 若資源等同，重新估計 | |
| 回顧與查核 | 核真正關心的事故結果 | 若報件多但風險不變，查機制 | |

**觀察轉向**　由基線轉向把風險、工具、成本與監測列清

**證據轉向**　基線、替代工具、實際成本和受影響資料

**因果轉向**　規則改變可遵依性，同一要求可對群體產生不同成本

**盲點及邊界**　由主管具體審議。

**自審結果**　三回應分風險、比例及回饋，不以表單率當效果。
