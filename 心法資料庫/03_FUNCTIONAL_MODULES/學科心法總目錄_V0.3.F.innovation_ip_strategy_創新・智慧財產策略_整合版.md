## Canonical Demonstration Case／Method Shift Test

**案例**　合成博物館與學校準備展示共同做的解說器，其中用校方舊模組和館方照片。

**Baseline**　以新作同名推各可自由授權。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 來源 | 分照片與程式 | 若有公用授權核版本 | |
| 貢獻與控制 | 查兩邊的書面授權 | 若範圍未明交法務 | |
| 使用與時機 | 分實體展示與下載 | 若方式不同另作審查 | |

**觀察轉向**　由基線轉向區分來源、貢獻、公開狀態及業務用途

**證據轉向**　實際成果、過程版本、雙方合同和公開紀錄

**因果轉向**　公開及未釐清分工可影響未來使用和保護

**盲點及邊界**　現行法與各材料需責任人。

**自審結果**　分來源、貢獻及使用允許，著作欄不足。
