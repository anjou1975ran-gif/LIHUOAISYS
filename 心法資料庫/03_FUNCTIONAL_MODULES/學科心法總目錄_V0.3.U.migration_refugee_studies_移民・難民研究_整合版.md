具體移民、難民、兒童安全、保護資料和身份審定由授權機構及獨立專業。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成家庭搬進新地區，帳面有轉介，但家人稱未收到可理解的服務通知。

**Baseline**　以登記完成推服務接續。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 時序與資格 | 分搬遷、遞交、收到 | 若已等效更新核下游 | |
| 可理解的轉介 | 對通知版本和使用方式 | 若理解仍未到，再看等等 | |
| 制度銜接 | 查是否排入新站 | 若未排入交服務與法務 | |

**觀察轉向**　由基線轉向分離身份判斷、流動時間、知情與社會支持

**證據轉向**　依法可用的身份時序、本人意願及實際轉介

**因果轉向**　等候、語言及可用識別資料可阻斷服務

**盲點及邊界**　保留自願參與及資料保護。

**自審結果**　身份、實際通知與支持可接手須分看。
