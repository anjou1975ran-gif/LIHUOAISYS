## Professional Support

具體材料、操作或暴露、事件處置與風險定級須交依法授權生物安全責任者。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構自然史館與公立大學研議交換既有科普庫存，只問移交與用途核准。館方沿用舊館藏門類，雙方未核新責任。

**Baseline**　用館藏分類代安全治理。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 用途與核准 | 分館藏和機構安排 | 若授權明確且同範圍，再查接手 | |
| 監督責任 | 查誰可以變更 | 若權限不明保持待審 | |
| 事件與更新 | 核是否有接手時間 | 若規程不足由責任方處理 | |

**觀察轉向**　由基線轉向先查授權、用途、責任和狀態

**證據轉向**　已批准安全審查、訓練責任及事件紀錄

**因果轉向**　未審變更可使既有安全聲明失去適用性

**盲點及邊界**　只查高層責任與核准，不做任何移轉執行。

**自審結果**　用途、監督和交接各需具名及時序。
