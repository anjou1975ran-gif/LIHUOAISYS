## Canonical Demonstration Case／Method Shift Test

**案例**　虛構產品 Q 更換通報頁，通報數翻倍且疑有同案重說。要讀為風險上升嗎？

**Baseline**　用通報變多認定有因果。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 產品與時間 | 分發生和填表 | 若皆早於改版，重估報告機會 | |
| 訊號及替代 | 先分來自同事件的兩說法 | 若分母長期等再比較 | |
| 臨床與監管接口 | 交各責任人核證據 | 若仍資料不齊維持待查 | |

**觀察轉向**　由基線轉向先定產品、暴露、事件及原始來源

**證據轉向**　合規個案紀錄、產品資料、比較分母及時間

**因果轉向**　報告增加受發現與基線影響，不能由時序直接定因果

**盲點及邊界**　合成無人體實際用藥。

**自審結果**　產品、報告及核對分母三組證據使因果判斷保持未定。
