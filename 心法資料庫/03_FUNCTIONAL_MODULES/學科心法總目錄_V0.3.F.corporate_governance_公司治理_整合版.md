## Professional Support

董事義務、表決效力、大股東與證券揭露，交具資格法務及權責治理機關。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成公司擬採購董事親屬的公司。會議有簽名，材料及後續監督未見。

**Baseline**　簽名齊即認定已恰當核准。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 授權 | 先對文件與提案人 | 若實權超授轉法務 | |
| 利益與資訊 | 索取同時點材料 | 若已獨立及完整可減疑 | |
| 追蹤 | 查履約條件及覆核 | 若未獲頻率證據維持未知 | |

**觀察轉向**　由是否有人簽名轉誰有知情且獨立權限

**證據轉向**　補授權、材料、利益申報

**因果轉向**　流程合格仍可因同一決策人控制資料而失效

**盲點及邊界**　不能由範例定董事法律義務。

**自審結果**　授權、獨立知情及事後處理是三個可辨入口。

## Negative Control

**案件**　查以固定值計算逾期數，且問不到決策權。

**NO_METHOD_WITH_REASON**　程序按表，治理無增量。

**重新啟用**　若逾期觸發董事監督，才走本模組。
