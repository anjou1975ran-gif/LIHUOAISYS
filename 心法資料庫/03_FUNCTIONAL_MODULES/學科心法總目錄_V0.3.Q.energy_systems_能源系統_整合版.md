## Canonical Demonstration Case／Method Shift Test

**案例**　合成公共展館平日可維持基本照明，暑期長時運轉多次限量。主管看額定總和認為不缺。

**Baseline**　由名目容量直接斷供足。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 供需時序 | 核暑期長時使用 | 若未達峰，查看故障 | |
| 可用與依賴 | 區分停用和可利用 | 若均可用而仍失效，轉負載 | |
| 服務恢復 | 比較展示與照明基本需求 | 若終端仍缺，未完整 | |

**觀察轉向**　由基線轉向查需求、配置、時間與可用性

**證據轉向**　時序需求與可用容量、服務恢復測試

**因果轉向**　名目容量不等可調度，依賴和同步需求可影響服務

**盲點及邊界**　限示例，現場需具責任驗證。

**自審結果**　區分長期能量、可用性及服務特殊需求。

## Negative Control
