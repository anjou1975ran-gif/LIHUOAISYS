## Canonical Demonstration Case／Method Shift Test

**案例**　合成公園水塘水位下降，有部分移除供水與乾季。管理報告只比較末日水位。

**Baseline**　認定需求變大。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 水收支 | 同時對停供與需求 | 若用量未變，查補注 | |
| 用途和尺度 | 列公園與下游 | 若兩個水體非連通，不合併 | |
| 治理和復核 | 確認報告持有者與用途 | 若核實不足，保持未判 | |

**觀察轉向**　由基線轉向先列入出、儲存與不同負擔

**證據轉向**　流量、水位、庫容及使用時序

**因果轉向**　同量需求在不同補注、儲存及用途下結果不同

**盲點及邊界**　水治理操作自有權責。

**自審結果**　入出、儲存與用途依據分立。

## Negative Control

**案件**　只問水務報告封面發表人。

**NO_METHOD_WITH_REASON**　讀正本。

**重新啟用**　若系統邊界有爭議，再查。
