## Professional Support

任何納稅義務、稅率、申報、選擇與爭訟由實際法域稅務專業及責任人。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　兩虛構部門同報「服務費」。本月實際由不同地點團隊承接，缺交付和比較。兩筆可直接比價嗎？

**Baseline**　同標題直接比較。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 主體及功能 | 逐筆列提供者 | 若一致再查可比 | |
| 期間與交易鏈 | 核本月是否同時交付 | 若仍受條件留未定 | |
| 比較基準 | 列不可比條件 | 若條件一致才理解異常 | |

**觀察轉向**　由總稅額回交易主體與時點

**證據轉向**　新增交付紀錄、履約與可比資料

**因果轉向**　不同交易功能可能使同一票面無從平比

**盲點及邊界**　案例僅整理材料，管轄與稅務待遇待專業。

**自審結果**　交易事實、時序與可比性均可能讓票面排序失效。

## Negative Control

**案件**　只需把既定淨額原樣抄入草稿。

**NO_METHOD_WITH_REASON**　照原件讀數，不重新判稅。

**重新啟用**　若帳實差才進交易核查。
