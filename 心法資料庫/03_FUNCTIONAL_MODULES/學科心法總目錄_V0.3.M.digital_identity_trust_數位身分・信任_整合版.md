## Canonical Demonstration Case／Method Shift Test

**案例**　虛構會員已登入卻不能續借，館方稱驗證已成功。昨日更換帳號角色。

**Baseline**　認證成功則應全能用。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 憑據主張 | 確認會員登入代表何者 | 若僅證帳號持有，另查權限 | |
| 依賴方授權 | 查昨日角色改變 | 若未變，查同步 | |
| 變更和接手 | 查看各方實際採用時間 | 若同步仍異常改查規格 | |

**觀察轉向**　由基線轉向分查證、認證、資料聲明、授權和恢復

**證據轉向**　受權身份及權限規格、驗證與時序

**因果轉向**　身份正確仍可因權限、時點或狀態不一致而拒收

**盲點及邊界**　以已授權跡證查。

**自審結果**　分身分、操作權及生命週期。
