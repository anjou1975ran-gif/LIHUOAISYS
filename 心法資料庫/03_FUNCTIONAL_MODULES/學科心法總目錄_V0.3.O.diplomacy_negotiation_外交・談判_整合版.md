## Canonical Demonstration Case／Method Shift Test

**案例**　虛構兩城共享水位。甲要保有原始資料控制，乙只想準時得摘要。

**Baseline**　以為協商必定損害其一。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 利益與替代 | 各自保有原件並談摘要時效 | 若乙必需原始只能重擬 | |
| 核驗基準 | 記雙方同日收件 | 若無核驗權，不宣告可驗 | |
| 授權與回顧 | 分試行、續期和異常 | 若無持續核准保留未決 | |

**觀察轉向**　由基線轉向區分立場、利益、可逆安排與履約

**證據轉向**　有授權的紀要、條件、核驗及續期

**因果轉向**　可查驗承諾降低誤判，內部權限仍限制批准

**盲點及邊界**　無外部承諾，只讀材料。

**自審結果**　利益、查驗、核准會給不同提問，二選一基線不成立。

## Negative Control

**案件**　照錄正式名單上的接聽窗口。

**NO_METHOD_WITH_REASON**　直接摘錄。

**重新啟用**　若代表有無核准權不清則查。
