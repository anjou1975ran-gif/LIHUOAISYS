## Professional Support

個案健康、決策能力與長照由具資格專業及當事人決定。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構退休者停止到社區館，健康紀錄無改變但公車早班取消。

**Baseline**　以歲數解釋退離。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 功能與環境 | 早班取消可能影響到達 | 若另有同等替代，查使用者情境 | |
| 生命歷程 | 查退出先於交通嗎 | 若只在停班後發生，角色假說降 | |
| 自主和服務 | 查有適合動線是否願意 | 若偏好改變不把留家當障礙 | |

**觀察轉向**　由基線轉向分年齡、功能、意願與環境支持

**證據轉向**　本人目標、日常活動及環境時序

**因果轉向**　環境或資源變可改變參與，人不必病倒

**盲點及邊界**　臨床未完成，個案仍由責任人。

**自審結果**　生活能力、可達性及角色轉換能被分別檢查。

## Negative Control

**案件**　確認已驗真身份證上出生年月。

**NO_METHOD_WITH_REASON**　照錄資料，無功能判斷。

**重新啟用**　若要解釋活動需求，再開。
