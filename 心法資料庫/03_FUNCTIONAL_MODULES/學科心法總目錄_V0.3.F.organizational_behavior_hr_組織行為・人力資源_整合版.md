## Professional Support

實際考核、監控、處分、歧視與職安，由人資、工會或專業及法務承接。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構部門新班夜間回報變少，但退件增加。資深人員換班，有人說團隊怠工。

**Baseline**　以回報少推沒問題或懶惰。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 要求與資源 | 夜班新手較多且隊伍短 | 若同配置仍不同查流程 | |
| 發聲與回饋 | 比較通報後支援 | 若被查到制度未變仍核範圍 | |
| 學習與考核 | 查交班與工具學習 | 若同期資深也錯，查版本 | |

**觀察轉向**　由怪個人轉看工作系統

**證據轉向**　查負荷、回報及培訓時間

**因果轉向**　表面失誤可因表達成本及工作不清累積

**盲點及邊界**　避免依年齡/身份命名，使用核准資料。

**自審結果**　比較負荷、回報門檻及學習機制。

## Negative Control

**案件**　只抄已核對值班表日期。

**NO_METHOD_WITH_REASON**　直接採原版。

**重新啟用**　若實際到班和表不同，再走。
