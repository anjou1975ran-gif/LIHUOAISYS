## Professional Support

結構、工地安全及實地變更由有資格工程與主管責任者。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成步道現場換了排水配置，核准圖已更新，部分工班用舊版且通過表面查驗。

**Baseline**　以目測通過就交付。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 版本與變更 | 比對工班實作 | 若出入無法確認先停正式判斷 | |
| 隱蔽與質量 | 查看原有驗證見證 | 若缺失交工程評估 | |
| 移交及使用 | 核排水功能與責任 | 若未達標不得採既判 | |

**觀察轉向**　由基線轉向比設計、工序、變更與完工

**證據轉向**　版控圖、變更核可、合格測試及照片或見證

**因果轉向**　書面變更若未到現場會造成錯版及後續不相容

**盲點及邊界**　不作施工指導。

**自審結果**　版、工序、使用驗收三角待核。

## Negative Control

**案件**　只問某塊土地登記權人且證件齊。

**NO_METHOD_WITH_REASON**　核產權。

**重新啟用**　若實適設施越出與地界一致性待查，再引施工證據。
