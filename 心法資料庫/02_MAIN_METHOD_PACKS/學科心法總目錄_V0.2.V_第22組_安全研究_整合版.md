## 主要方法取向與心法卡

### 公共風險與保護

```yaml
METHOD_CARD:
  core_question: 誰實際暴露於何處？
  first_move: 畫危害、時段與暴露群
  evidence_preference: 實際積水及使用頻率
  causality_model: 風險透過接觸分布
  actor_model: 居民與主管機關
  blind_spot: 低紀錄群
  failure_mode: 用全區平均
  use_when:
  - 風險分布不均
  avoid_when:
  - 純法律解釋
  must_not_claim:
  - 定出現場措施
```

### 人的安全

```yaml
METHOD_CARD:
  core_question: 管制會把代價轉給誰？
  first_move: 查看替代服務與照護成本
  evidence_preference: 可及性與居民日常使用路徑
  causality_model: 封閉可減接觸也可隔離服務
  actor_model: 居民和社區組織
  blind_spot: 未表達使用者
  failure_mode: 把通行總數當福祉
  use_when:
  - 居民依賴服務
  avoid_when:
  - 只有設施故障
  must_not_claim:
  - 安全感可等同事故率
```

### 安全化與監督

```yaml
METHOD_CARD:
  core_question: 誰接受以緊急名義擴張權限？
  first_move: 對照原風險、議事、到期與審查
  evidence_preference: 公開授權及監督紀錄
  causality_model: 非常治理可因受眾及制度而持續
  actor_model: 申請權力者及監督者
  blind_spot: 危害工程量未定
  failure_mode: 政治語言等於援法
  use_when:
  - 提出長期非常措施
  avoid_when:
  - 單次具時限維修
  must_not_claim:
  - 風險提供越權依據
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構公共公園低窪入口曾在豪雨後積水。有人據此倡議無期限全園封閉，其他入口和替代路徑的資料未知。

**Baseline**　用一段影像支持永久封閉。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 公共風險與保護 | 先查特定低窪入口，其他區段是否安全待評估 | 若已驗證各區都無替代且同樣暴露，局部假說下降 | |
| 人的安全 | 封全園可能中斷到診所的便利通行 | 若經查有同等替代，該項阻隔降低 | |
| 安全化與監督 | 查看封閉有無期限與更新依據 | 若自動解封且每期須獨立核驗，常態化說法削弱 | |

**觀察轉向**　首問由是否啟動全面管制轉為誰真正有風險與保護目標

**證據轉向**　加入暴露、替代服務、非常措施從何獲批准及何時結束

**因果轉向**　同一政策可降低風險或轉嫁風險，也可能改變授權本身

**盲點與邊界**　只分析公共治理，現地安全由權責機構實勘。

**判定**　三個對照分別需要暴露、替代能力、授權退場資料。單一影像不支持完整機制。
