## 主要方法取向與心法卡

### 地層與歷史

```yaml
METHOD_CARD:
  core_question: 同一段沉陷是否沿舊回填走向？
  first_move: 比對地形歷史和斷面
  evidence_preference: 歷年圖、材料記錄、合格剖面
  causality_model: 不同層體沉積與回填導致異質性
  actor_model: 場址觀測者
  blind_spot: 地下連續性
  failure_mode: 依外觀定層位
  use_when:
  - 地基歷史有差
  avoid_when:
  - 純法權
  must_not_claim:
  - 安全診斷
```

### 水文地質

```yaml
METHOD_CARD:
  core_question: 水位和層壓是否對應？
  first_move: 分地表水、地下水層及時序
  evidence_preference: 水位、區域層位與位移
  causality_model: 水位和壓密過程可有時間差
  actor_model: 不同地層、專業者
  blind_spot: 觀測井不同層
  failure_mode: 用一口井推全區
  use_when:
  - 廣域同步變
  avoid_when:
  - 單純表色
  must_not_claim:
  - 指定抽水安排
```

### 跨尺度地球系統

```yaml
METHOD_CARD:
  core_question: 變化一開始是點還是區域？
  first_move: 核對共同基準與歷史尺度
  evidence_preference: 位移分布、時間、爭點尺度
  causality_model: 區域驅動與局部工況可疊合
  actor_model: 居民、測量、工務
  blind_spot: 短期似長期
  failure_mode: 同季節即同源
  use_when:
  - 尺度混用
  avoid_when:
  - 詢問日期
  must_not_claim:
  - 唯一歸因
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構公園步道一區略見沉陷，又有區域水位報告。該處曾改造且測量基準剛更新。能否一律歸因地下水？

**Baseline**　用區域報告直接確定步道失效原因。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 地層與歷史 | 若只在舊溝槽，考慮局部歷史 | 若範圍超越舊溝，增區域假說 | |
| 水文地質 | 與相鄰站點位移、水位同時序比 | 若多點水位一致且無位移，需查地層屬性 | |
| 跨尺度地球系統 | 比較多站和個別步道點的位移 | 若僅基準更新日跳變，先重測 | |

**觀察轉向**　由哪個工程先發生改問區域變形或局部回填

**證據轉向**　加入歷史地表、深度、水位和相鄰點時序

**因果轉向**　地下壓密、局部材料或觀測基準變動可有相同表象

**盲點與邊界**　取點及工程安排須由權責專業。

**判定**　地層、水文及尺度三個路徑各有可否證證據。保留多機制與資料限制。

## Negative Control
