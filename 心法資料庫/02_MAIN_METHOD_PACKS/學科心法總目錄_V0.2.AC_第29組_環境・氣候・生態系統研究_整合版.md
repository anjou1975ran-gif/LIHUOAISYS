  evidence_preference: 流量、濁度、場地時序

  actor_model: 使用者與調查者

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構河邊施工後雨季濁度增，附近同時新開農地，沒有前期多點資料。誰的因素能解釋？

**Baseline**　以施工時間認定施工是唯一原因。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 系統邊界與壓力 | 先核支流交會前後與豪雨時點 | 若上游已升高，不能只看工地 | |
| 影響監測比較 | 先比較控制溪與工地下游是否同步升 | 若同步且幅度近，施工單因降權 | |
| 累積與恢復 | 追濁度回落後棲息回復證據 | 若均快復原，累積說法須縮小 | |

**觀察轉向**　由是否開工就歸因轉成壓力路徑、反事實和受體

**證據轉向**　換看歷史基線、相關對照、多指標與雨季時序

**因果轉向**　局部濁度可由暴雨或跨地點作用產生，須辨識重複比較與累積

**盲點與邊界**　合成案例，現場取樣和許可交由專業。

**判定**　三框架可分基線、源路與累積效應。單時單點不支持歸因。
