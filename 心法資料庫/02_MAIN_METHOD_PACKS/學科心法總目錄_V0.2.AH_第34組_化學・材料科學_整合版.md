## 主要方法取向與心法卡

### 組成與物質辨識

```yaml
METHOD_CARD:
  core_question: 色差來自材料本身嗎？
  first_move: 先核使用批次和同照明比較
  evidence_preference: 材料清單、物件資料、受權檢測
  causality_model: 不同組成或混料可令期初色不同
  actor_model: 製造與管理者
  blind_spot: 同組成不同微結構
  failure_mode: 以色當配方
  use_when:
  - 材料來源爭議
  avoid_when:
  - 只查藝術來源
  must_not_claim:
  - 肯定化學成分
```

### 加工—結構—性能

```yaml
METHOD_CARD:
  core_question: 哪個界面改變了表面反應？
  first_move: 查加工履歷及不同部位
  evidence_preference: 保存紀錄、合格材料鑑定
  causality_model: 微結構和界面影響反應及外觀
  actor_model: 保育與材料者
  blind_spot: 看不到的底層
  failure_mode: 樣本不核先清潔
  use_when:
  - 界面衰退
  avoid_when:
  - 只有光學視角
  must_not_claim:
  - 處置授權
```

### 反應與老化

```yaml

  use_when:

```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構展覽兩塊同名塗層的彩板一片顏色偏黃。批號可能不同，受光及展示歷史不一。可否認定整批有瑕疵？

**Baseline**　以一塊外觀推整批產品。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 組成與物質辨識 | 比較同批留樣與不同批物件 | 若起初同色且批次同，查曝露 | |
| 加工—結構—性能 | 先比較未外露區域與展示邊沿 | 若差限附著層而底材一致，改查表面 | |
| 反應與老化 | 查色變是否隨展期持續 | 若換光源即一致，老化主因下降 | |

**觀察轉向**　先區分光學觀察、物質成分、界面及老化

**證據轉向**　改找同日標準化外觀、批次與使用環境證據

**因果轉向**　外觀差可由照明、表面狀態或反應時間造成，換材料前先辨機制

**盲點與邊界**　實物處理留給授權鑑定，判斷限制在反證。

**判定**　組成、界面及時間三組證據互補。單一影像只支持表觀差。

## Negative Control

**案情**　核對展品卡已確定的典藏號。

**NO_METHOD_WITH_REASON**　按正本讀號。材料未成爭點。

**重新開啟條件**　若登錄號不同而懷疑是否同物件，可先核 provenance。
