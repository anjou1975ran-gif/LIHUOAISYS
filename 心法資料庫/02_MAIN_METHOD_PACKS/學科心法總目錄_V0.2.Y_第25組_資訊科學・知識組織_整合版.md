## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構文化中心官網搜「停辦」回 0。舊卷以「停展」作詞，已知基準有三份相關卷。加停展可見六筆，其中兩份相關。

**Baseline**　因搜尋回 0 推定從未取消過。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 知識組織 | 活動停辦舊稱停展未被索引 | 若同義查詢仍缺，檢查覆蓋或權限 | |
| 檢索評估 | 加舊詞後找到兩份相關也多出四份無關 | 用三份已知相關中的兩份檢查 2/3 召回，只涵蓋基準 | |
| 來源與版本 | 命中兩份一份草案一份核定 | 若原件不可取得，未有發文佐證不推哪個有效 | |

**觀察轉向**　先檢查需求是否能被既有索引表達

**證據轉向**　用詞彙、原件版本和相關性基準組

**因果轉向**　無命中可能只是詞彙、版控或權限造成，無法直接推不存在

**盲點與邊界**　基準並非全館，測試只在已授權資料。

**判定**　詞彙映射與查詢可降低漏找，命中後仍須核版，零命中推論失效。

## Negative Control

**案情**　已取得及核版的刊物只需讀某頁印刷日期。

**NO_METHOD_WITH_REASON**　直接摘錄該頁，研究檢索沒有增量。

**重新開啟條件**　若同刊不同版次出現矛盾，再走來源與版本。
