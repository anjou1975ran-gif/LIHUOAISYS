## 主要方法取向與心法卡

### 人口帳與組成

```yaml
METHOD_CARD:
  core_question: 人數差來自誰進出？
  first_move: 列期初、出生死亡和遷入遷出
  evidence_preference: 同界線同定義的登記
  causality_model: 存量由流量淨額更新
  actor_model: 戶籍及居民
  blind_spot: 漏未登居民
  failure_mode: 以淨額替兩邊流量
  use_when:
  - 群體變動
  avoid_when:
  - 單人登記
  must_not_claim:
  - 得知每人的流動
```

### 分層率與標準化

```yaml
METHOD_CARD:
  core_question: 增加由結構還是群內率？
  first_move: 以同權重重算並保留實際量
  evidence_preference: 年齡別人口及服務人數
  causality_model: 年齡結構變動可推總率
  actor_model: 居民及服務單位
  blind_spot: 未度量需求
  failure_mode: 把總率判作風險變
  use_when:
  - 群體混合
  avoid_when:
  - 僅固定單群
  must_not_claim:
  - 說明個人原因
```

### 世代成分情境

```yaml
METHOD_CARD:

  actor_model: 人口與政策主體

  - 服務容量規劃
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構城鎮長照件數增多。年齡別使用率尚未知，編戶地圖也剛擴張。有人說居民普遍變不健康。

**Baseline**　把件數直接推健康惡化。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 人口帳與組成 | 查老年淨移入及青年遷出 | 若界線不一致先重算 | |
| 分層率與標準化 | 若各年齡率不變，整體差可由權重 | 若同權重率也升，再查政策或個別成本 | |
| 世代成分情境 | 比較青年流失與新社區長者遷入 | 兩假設排序若相反，保留情境不確定 | |

**觀察轉向**　首問由老年比上升轉成世代、遷移和隸屬

**證據轉向**　新增期初人口、年齡別服務率與實際遷移

**因果轉向**　固定服務率也可因年齡權重上升形成總量變更

**盲點與邊界**　需要健康測量才可述個體風險。人口資料須在安全範圍處理。

**判定**　人口帳、分層率和世代替換各可使同量不同因果。現有資料不能作健康判斷。

## Negative Control

**案情**　只要依已提供資料查一人遺囑上簽署人名字。

**NO_METHOD_WITH_REASON**　讀取核驗文書。人口分布無增量。

**重新開啟條件**　若題目改為代際資產分布與世代，才用人口學。
