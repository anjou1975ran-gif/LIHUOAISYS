## 主要方法取向與心法卡

### 土地使用與移動

```yaml
METHOD_CARD:
  core_question: 新建場域接上居民實際路徑嗎？
  first_move: 比對行走、轉乘和多用途時間
  evidence_preference: 入口、步行動線、服務組合
  causality_model: 建成形式改變出行選擇
  actor_model: 居民、經營者
  blind_spot: 不同能力者
  failure_mode: 用直距推使用
  use_when:
  - 交通與用地同變
  avoid_when:
  - 只有材料驗收
  must_not_claim:
  - 交通改善確定
```

### 住房可負擔與公平

```yaml
METHOD_CARD:
  core_question: 建成利益分布給誰？
  first_move: 追新舊使用者的租負與遷移
  evidence_preference: 租金、入住、退出、住房供應
  causality_model: 環境收益資本化可伴隨搬遷
  actor_model: 屋主、租戶、訪客
  blind_spot: 非正式居住
  failure_mode: 以總戶數當保障
  use_when:
  - 住屋與投資同時變
  avoid_when:
  - 沒有分配問題
  must_not_claim:
  - 立刻判有歧視
```

### 基礎服務同步

```yaml
METHOD_CARD:
  core_question: 分期交付能否承受新活動？
  first_move: 對齊入住、車流和服務開放時點
  evidence_preference: 設施容量、分階驗證
  causality_model: 服務延後使既有社區先超負荷
  actor_model: 公共方與營運者
  blind_spot: 意外移動
  failure_mode: 用終局總量代替過渡
  use_when:
  - 有分期
  avoid_when:
  - 規範已定無接續
  must_not_claim:
  - 能核准安全
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構車站周邊將更新，設計圖標示步行 5 分鐘且供應更多新屋，舊租戶擔憂搬走，站口與公車改道資料不齊。

**Baseline**　以鄰近和戶數就判全面得益。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 土地使用與移動 | 車站鄰近住宅但出口朝外 | 若替代入口開放檢查旅時 | |
| 住房可負擔與公平 | 分列原有租戶和新住戶可負擔性 | 若原租戶保留且支出穩定，迫遷假說下降 | |
| 基礎服務同步 | 核車站開放前公車是否擁擠 | 若可觀察容量充足則不採過載假說 | |

**觀察轉向**　由好看的車站圖改問住房與公共路徑是否真正可用

**證據轉向**　查出入口、可負擔住宅、跨街設施和分期容量

**因果轉向**　空間設計、租負與營運相互作用可使原住群反而失去可達

**盲點與邊界**　須取得真實用地、交通及住戶資料。

**判定**　三回應分出空間使用、分配、公共服務過渡。住戶受益不能由示意圖推出。

## Negative Control
