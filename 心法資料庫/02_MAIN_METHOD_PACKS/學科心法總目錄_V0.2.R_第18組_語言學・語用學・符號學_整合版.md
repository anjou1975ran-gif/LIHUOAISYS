```yaml

  evidence_preference: 原文、同版面欄位、替代語句。
  causality_model: 限定詞改變句子可承擔的內容。
  actor_model: 寫者和讀者。
  blind_spot: 字面之外的默示。

  avoid_when:

```


## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構會員頁大字 0，旁邊小字「本月免繳月費」。下一頁才列一次性開通費。第一頁承諾何事，讀者會如何理解？

**Baseline**　只把免繳等同任何費用都沒有。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 組合語義 | 標語的免除範圍是本月月費。 | 改為本月所有費用免繳，其可承擔內容改變。 | |
| 語用與言語行為 | 若按鈕頁沒透露一次性費用，讀者可能推論本月零實付。 | 加入清楚費用提示後，比對相同受眾是否仍有此解讀。 | |
| 符號與多模態 | 大字 0 與小字「月費」可能讓人把零指向總價。 | 交換總價與月費的視覺優先，若讀法改變，版面假說獲辨識。 | |

**觀察轉向**　從「優惠有沒有說免」移向免除對象、使用語境和符號合讀。

**證據轉向**　由單一詞語改找費用頁、完整版面、替代表述與讀者解讀。

**因果轉向**　文字範圍、語境推論及視覺突顯是不同的解讀機制。

**盲點與邊界**　解讀分布須實際檢查。事後看到收費頁不能回填先前語境。

**判定**　三取向拆出字面承諾、合理語用推論與符號配置。任一推論均有可反查的對照。
