## 主要方法取向與心法卡

### 聚焦與敘述層

```yaml
METHOD_CARD:
  core_question: 誰講，誰看到，誰被蒙在鼓裡？
  first_move: 圈出可得資訊及語態
  evidence_preference: 原文視角、敘述層
  causality_model: 所限資訊形成歸因
  actor_model: 人稱、角色及讀者
  blind_spot: 異讀
  failure_mode: 敘述者等作者
  use_when:
  - 認知落差
  avoid_when:
  - 解釋正本效力
  must_not_claim:
  - 角色想法等同真實意圖
```

### 敘事時間

```yaml
METHOD_CARD:
  core_question: 講述順序如何改可理解因果？
  first_move: 並列故事順序與排版順序
  evidence_preference: 場景及披露時間
  causality_model: 延遲及倒敘生成期待
  actor_model: 編者、讀者與人物
  blind_spot: 單例不外推
  failure_mode: 故事時序當敘事時序
  use_when:
  - 同事件重排
  avoid_when:
  - 一段明文查日期
  must_not_claim:
  - 讀者必有同反應
```

### 文類與重複

```yaml
METHOD_CARD:

  evidence_preference: 全篇回聲和文類
  causality_model: 重影音響預期與終局重讀
  actor_model: 讀者社群、作品
  blind_spot: 翻譯差
  failure_mode: 見關鍵詞即當暗號
  use_when:
  - 需要整體解讀
  avoid_when:
  - 單字字義
  must_not_claim:
  - 掌握唯一作者意圖
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　原創微型案例。A 版先跟旅客看見月台改期，再回述工匠修鐘。B 版先到工匠視角，再寫旅客讀告示。兩版事件相同，關鍵措辭「等」可在全文重複。

**Baseline**　把兩版都歸為旅客錯失時間，認為讀感相同。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 聚焦與敘述層 | 旅客只見門上改期，一版後讀到前因 | 若讓旅客先得全資訊，猜疑降低才支援聚焦說 | |
| 敘事時間 | 先放回想時，改期像準備而非突然 | 重排仍相同則查視角而非時間 | |
| 文類與重複 | 每節重覆賣票者等待，比一次出現更可形成母題 | 若只有編輯版添此詞，雙版解讀須分 | |

**觀察轉向**　由判誰出場改問誰知道什麼、何時揭示

**證據轉向**　證據從摘要轉原位置與重排實驗

**因果轉向**　聚焦與時序更動可改讀者推論，事件列表可以完全一致

**盲點與邊界**　只確定可讀差異。實際讀者的情緒需獨立測量。

**判定**　三回應對聚焦、順序與重複提出可改動的反例，事件摘要不足維持解讀。

## Negative Control
