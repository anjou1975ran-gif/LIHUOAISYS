## Professional Support

實際結構、用電、運輸或設備安全需由具責任工程或物理專業以現地條件及標準核定。 心法可生成待查方向和證據需求。現行專業標準與個案處置另由具責任的專業者確認。

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構展館兩室同耗電，一間午後較熱，窗向、牆材、測點可能不同。是否單憑室溫認定空調失效？

**Baseline**　把同電耗當同冷卻效果並立刻換設備。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 收支與守恆 | 同耗能仍可能有西曬額外輸入 | 拉窗簾後若差減，支持外界輸入假說 | |
| 尺度與瞬態 | 厚牆可使升降溫較慢 | 若同等輸入後峰值時序不異，儲熱假說減弱 | |
| 測量與模型檢驗 | 比較近窗與室內測點 | 若移點後兩房一致，不能歸因設備 | |

**觀察轉向**　從空調好壞轉問哪個輸入和儲熱控制日內差

**證據轉向**　看並排熱流、耗能、日照和不同時間曲線

**因果轉向**　相同耗能可因邊界熱流、時間延遲或空間分布呈現不同室溫

**盲點與邊界**　案例無現場故障診斷。設備和建築現測由專業負責。

**判定**　收支、延遲和測點分別形成可對照的物理假說，終值不足以歸因。
