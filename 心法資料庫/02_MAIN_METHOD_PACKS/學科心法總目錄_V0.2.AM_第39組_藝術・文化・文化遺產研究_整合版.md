```yaml
METHOD_CARD:
  core_question: 現場外觀與空間關係承擔什麼解讀？
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構老磨坊改造提議搬走水輪原物並在新館複製，原址仍具教學和操作傳承。怎麼判保存主張？

**Baseline**　外觀一比一即可視為價值延續。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 形式與場境 | 界定磨坊光、聲、轉軸和觀看距離 | 若複製品外觀相同，仍測空間和動作 | |
| 來源與物質 | 輪子、屋架與後置機件分期核 | 若替代輪件有來源歧異，維持未確 | |
| 活態與價值 | 若搬到館內不能給師徒練習，活態效果不同 | 若參與者有同等空間與願望，搬移風險在該層下降 | |

**觀察轉向**　由只保留外觀改問什麼價值依託哪個場所和人

**證據轉向**　找形式、來源及口述和持續使用

**因果轉向**　照原樣搬移仍可能使工藝與展示脫離脈絡

**盲點與邊界**　區分權利、活動影響和適當的保育者。

**判定**　形式、來源及傳承分層使兩案保留物不同，達成可檢視對照。
