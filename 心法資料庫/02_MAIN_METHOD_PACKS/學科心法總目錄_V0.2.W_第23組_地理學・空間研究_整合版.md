## 主要方法取向與心法卡

### 尺度與區域化

```yaml
METHOD_CARD:
  core_question: 分布會因邊界換法而翻轉嗎？
  first_move: 以兩種單位繪圖
  evidence_preference: 原始位置、兩種聚合結果
  causality_model: 合併可隱藏內部差異
  actor_model: 繪圖者與資料主體
  blind_spot: 細格隱私
  failure_mode: 把行政區當自然群
  use_when:
  - 分析熱點或區均
  avoid_when:
  - 單一地點驗真
  must_not_claim:
  - 區平均是居民處境
```

### 交通可達性

```yaml
METHOD_CARD:
  core_question: 同距居民何時才能真的到達？
  first_move: 測路網時間與營業重疊
  evidence_preference: 入口、障礙、時刻、替代運具
  causality_model: 阻隔與服務時段改變可達
  actor_model: 不同移動能力居民
  blind_spot: 臨時施工
  failure_mode: 以半徑當可用路
  use_when:
  - 服務進入受路徑限制
  avoid_when:
  - 只有服務效力
  must_not_claim:
  - 能提出施工核准
```

### 人地與地方

```yaml
METHOD_CARD:
  core_question: 誰能使用同一位置？
  first_move: 比較群體的活動空間與意義
  evidence_preference: 參與者地圖、移動限制及地點觀察
  causality_model: 相同路網對不同能力者提供不同機會
  actor_model: 居民、地方機構
  blind_spot: 代表性不齊
  failure_mode: 將參與圖當普查
  use_when:
  - 經驗與地圖衝突
  avoid_when:
  - 純地籍定位
  must_not_claim:
  - 地方故事涵蓋每人
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構城市報告全區居民都在診療點 1 公里內，但河西居民說常到不了。橋僅出現在下游，診療點傍晚關閉。

**Baseline**　拿服務半徑對照行政平均。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 尺度與區域化 | 以街廓辨河兩岸 | 若兩種聚合結果一致，尺度效應解釋降權 | |
| 交通可達性 | 河西直距短但須繞橋 | 若步行橋開放後差縮小，支持路網機制 | |
| 人地與地方 | 找傍晚時有照護任務者 | 若時段延長後差仍未縮，查費用與空間障礙 | |

**觀察轉向**　由區平均轉問哪群居民在哪個尺度到不了設施

**證據轉向**　加入分時路網、設施入口和兩種聚合單位

**因果轉向**　行政聚合可造表觀平均，阻礙與時段會改變實際可達

**盲點與邊界**　先用去識別化資料，實際院所需求另由責任者確認。

**判定**　尺度、路網、個人時間三種轉向提供可分辨的證據。不能從圓形覆蓋推定真實到達。

## Negative Control
