## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構公園東側的原生草本較早開花，該側有向陽坡、部分較早栽種且物種比例有變。有人推斷整地植物已遺傳改變。

**Baseline**　由一次花期差斷出演化。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 結構功能 | 向陽的同齡株較早不代表整族遺傳 | 若同地歷年一致但今年全提早，查共時環境 | |
| 發育與個體歷史 | 先區分早植株與新植株 | 若同齡同程卻差，再問組成 | |
| 族群與代際變異 | 若快開種比例升可解釋總體提前 | 同種比率也早，組成單因不足 | |

**觀察轉向**　先分株齡、日照應答與世代組成

**證據轉向**　由一次外觀轉向個體追蹤、歷史物候與族群來源

**因果轉向**　同樣提早開花可由年內發育、局部光照或族群比例造成

**盲點與邊界**　自然觀察示例。物種與環境未被隔離，不能判定演化。

**判定**　三個方法提出不同層級的可比證據，排除了從外觀直接推遺傳。
