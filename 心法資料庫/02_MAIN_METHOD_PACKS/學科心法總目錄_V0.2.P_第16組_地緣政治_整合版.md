## 主要方法取向與心法卡

### 可達性與網絡

```yaml
METHOD_CARD:
  core_question: 居民能真的到哪？
  first_move: 抽象起訖、轉運及時間窗。
  evidence_preference: 時刻、實際旅時、末端服務。
  causality_model: 班次錯開會使短路徑無法當日完成。
  actor_model: 居民、承運者。
  blind_spot: 資格和費用。
  failure_mode: 以距離代替時間。
  use_when:
  - 有多個服務腹地。
  avoid_when:
  - 只有界線語義。
  must_not_claim:
  - 最近即最好。
```

### 節點依賴與替代性

```yaml
METHOD_CARD:
  core_question: 一個轉運點不可用時誰仍能被覆蓋？
  first_move: 畫替代路徑、共同依賴與容量。
  evidence_preference: 行程、容量與轉運可用證據。
  causality_model: 名目兩路可共用同一節點，風險沒有分散。
  actor_model: 轉運場與服務提供者。
  blind_spot: 居民分類與制度授權。
  failure_mode: 計路線數便判有備援。
  use_when:
  - 替代安排爭議。
  avoid_when:
  - 服務完全在單點完成。
  must_not_claim:
  - 觀察即可做安全核准。
```

### 政治地理與邊界

```yaml
METHOD_CARD:
  core_question: 誰的界線造成使用限制？
  first_move: 疊加實體網路、權限與行政服務圈。
  evidence_preference: 許可範圍、行政記錄、居民行動。
  causality_model: 行政邊界和名額改變路徑即使距離不變。
  actor_model: 兩方機構與各自居民。
  blind_spot: 個別工作流程缺陷。
  failure_mode: 以硬體孤立解釋制度封閉。
  use_when:
  - 有管制或服務責任界面。
  avoid_when:
  - 純粹物理阻隔。
  must_not_claim:
  - 地理等於法定主權。
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　兩個虛構島域共用郵運。近島因例行維修停航，圖上有兩條替代線。居民需保有同日送達，接駁和許可未知。

**Baseline**　按直線距離選最近替代島。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 可達性與網絡 | 近島班次抵達時郵車已離開。 | 時刻吻合後若仍無法到達，查資格。 | |
| 節點依賴與替代性 | 查兩線是否都必須在同一中繼接貨。 | 若有獨立通路但無承載容量，用量仍受限。 | |
| 政治地理與邊界 | 分開有船到與可合法轉交郵件。 | 若新許可後原路可承接，地理距離解釋降權。 | |

**觀察轉向**　由地理近遠改問每一戶可經哪條有資格且班期相容的路。

**證據轉向**　增加接駁、替代容量與控制邊界的資料。

**因果轉向**　單一停駛經網路瓶頸與管制擴大，中程投資能改變地理約束。

**盲點與邊界**　只用示意通路。真實適航及承運資格需主管專業驗證。

**判定**　比較到達、共同依賴與規制圖層後，尚不能從距離排序選線。三類資料分別推翻三種快判。

## Negative Control

**案情**　已給足跨境請求與豁免規則，只問適用哪一條法定例外。

**NO_METHOD_WITH_REASON**　走法學核實規則和身份，航路與通達無關。

**重新開啟條件**　若新爭點是誰實際能接觸跨境公共服務，再啟空間觀察。
