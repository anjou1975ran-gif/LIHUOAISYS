## 主要方法取向與心法卡

### 人在環境中

```yaml
METHOD_CARD:
  core_question: 使用者的生活目標和做不到的事相同嗎？
  first_move: 確認本人意願及相鄰障礙
  evidence_preference: 本人選擇、生活任務與環境
  causality_model: 障礙相對功能和支援形成
  actor_model: 當事人、居民網
  blind_spot: 沒被問到的人
  failure_mode: 以疾病概括全部
  use_when:
  - 參與下降
  avoid_when:
  - 純病程鑑別
  must_not_claim:
  - 能替本人決定
```

### 個案協調

```yaml

  core_question: 轉介在哪一站失去承接？

```

## Professional Support

個人安全、法定通報、兒少保護、照護計畫及實際給付資格，交有授權的社工、醫療及法律角色。公開處理僅用去識別資料。 心法可生成待查方向和證據需求。現行專業標準與個案處置另由具責任的專業者確認。

## Canonical Demonstration Case／Method Shift Test

**同題案情**　一虛構長者搬房後停止參加社區日間活動。其給付資格未變，女兒稱不想出門，本人仍願意但未接到接駁。

**Baseline**　以年齡或疾病起判照護需求。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 人在環境中 | 想繼續到社區活動，改住後無無障礙交通 | 若有等價交通仍不到，重問偏好和時段 | |
| 個案協調 | 新站收到一半資料，沒有排入時段 | 若已排入但無法交通，轉查環境 | |
| 社會政策與障礙 | 查同地搬遷者是否一致需要重新候位 | 若只一案有落差，先還原個案 | |

**觀察轉向**　先問本人想維持的生活與環境何處相斥

**證據轉向**　由資格單據改看當事人目標、活動空間及跨機構收件與等待

**因果轉向**　資源及環境缺口造成參與下降，既有臨床狀態可能不變

**盲點與邊界**　保留本人意願、健康與家庭狀態的查驗。

**判定**　三回應分辨交通、交接和政策空窗，留下可核對的觀察和轉介點。

## Negative Control

**案情**　只要從已核對的方案手冊確認一般服務時段。

**重新開啟條件**　若使用者無法於公布時段抵達，再查支持。
