## 主要方法取向與心法卡

### 策略互動與相互疑慮

```yaml
METHOD_CARD:
  core_question: 另一方的反應改變了哪個選項？
  first_move: 比對三方可觀察行為、回應次序及可逆性。
  evidence_preference: 各期回報時點、官方行為與替代自然原因。
  causality_model: 先行公開的風險使各方等待別人。
  actor_model: 可撤回承諾的政府與機構。
  blind_spot: 地方技術中斷。
  failure_mode: 把延遲讀成故意。
  use_when:
  - 需釐清相互等待。
  avoid_when:
  - 只有版面收件差。
  must_not_claim:
  - 能確知他國意圖。
```

### 制度合作

```yaml
METHOD_CARD:
  core_question: 共同查驗是否可減少履約爭議？
  first_move: 分章程、查驗機制、例外與重複互動。
  evidence_preference: 機構報告、原始核對紀錄、例外實例。
  causality_model: 可見性下降使互惠無法從紀錄確認。
  actor_model: 國家、委任專員、監測機構。
  blind_spot: 不平等或無代表群體。
  failure_mode: 用協定存在推履約。
  use_when:
  - 節奏或履約可觀察性出現落差。
  avoid_when:
  - 只界定義務是否存在。
  must_not_claim:
  - 制度必然能持續合作。
```

### 建構取向

```yaml
METHOD_CARD:
  core_question: 對互助者及責任的理解是否改變？
  first_move: 在行動前後比較共同規範及公開、內部用語。
  evidence_preference: 連續陳述、會議文本與相符的行為。
  causality_model: 關係身分改變何種成本及承諾能被接受。
  actor_model: 代表、國內受眾、機構。
  blind_spot: 公關言談與實際行動落差。
  failure_mode: 一段演說證明身份改變。
  use_when:
  - 同物質條件卻不同承諾。
  avoid_when:
  - 有清楚的供應中斷。
  must_not_claim:
  - 語言足以決定實際行為。
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構流域三國約定共享水位。原來互報，最近三方都比截止日慢。已知未變更文字，國際機構僅見整理後資料。何以同步延遲？

**Baseline**　依公報措辭把一方認定為不合作，要求另兩方跟進。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 策略互動與相互疑慮 | 三方依賴對方先提供資料，可能全都等到最後。 | 若回報仍同時延後且各自儀器同日換版，策略解釋降權。 | |
| 制度合作 | 查各站都送出但機構缺乏對照收件的權限。 | 若收件完整且各方可查，轉查國內執行或正當性。 | |
| 建構取向 | 比對「共享責任」是否被重釋成「單方求助」，查時序與通知選擇。 | 若用語變而行動未變，角色解釋暫不採。 | |

**觀察轉向**　由判斷誰不合作轉向承諾可見性、互賴和角色。

**證據轉向**　先查回報時點、同儕查驗及各國對責任的理解。

**因果轉向**　延遲報告可能是互惠失信、制度查驗故障或責任敘事變動，三者可用不同證據排除。

**盲點與邊界**　還要確認技術、季節及國內預算變化。術語只生成可查假說。

**判定**　三個方法分別要求對照行為順序、履約接口、規範與行為。缺少原始資料與訪談前，三個機制保持待查。
