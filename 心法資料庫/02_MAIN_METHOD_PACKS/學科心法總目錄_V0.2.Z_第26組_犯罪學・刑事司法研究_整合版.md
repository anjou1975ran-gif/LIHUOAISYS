## 主要方法取向與心法卡

### 被害與測量

```yaml
METHOD_CARD:
  core_question: 錄案升高對應傷害升高嗎？
  first_move: 並列被害調查及報案
  evidence_preference: 匿名調查、流量、同定義案件
  causality_model: 通報成本影響可見事件
  actor_model: 受害者、受理者
  blind_spot: 調查不能見全部
  failure_mode: 以報案直接當事件
  use_when:
  - 管道變動
  avoid_when:
  - 個案證明
  must_not_claim:
  - 犯罪率已知
```

### 場所與預防

```yaml
METHOD_CARD:
  core_question: 改變發生在哪些時地？
  first_move: 按時段比較使用背景
  evidence_preference: 客流、日曆、各區同類事件
  causality_model: 活動密度及環境改變互動機會
  actor_model: 使用者、場館、治理者
  blind_spot: 異常流動
  failure_mode: 從熱點推人群危險
  use_when:
  - 地點分布待釐清
  avoid_when:
  - 純程序期限
  must_not_claim:
  - 地點足以歸責
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　虛構展館新增報案 App，紀錄件數升高，同時開新展。須判斷被害是否更常見和服務是否更可達。

**Baseline**　以錄案變多判安全變差。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 被害與測量 | 先找使用新管道者和舊管道量 | 被害調查持平且紀錄升，支持通報解釋 | |
| 場所與預防 | 按開展及收展各期比每千人報案 | 若非展覽館也同步升，重查全市口徑 | |
| 刑事司法流程 | 比較報案到轉介的分類規則 | 若分類未變但報案後失聯增加，轉查支持可達 | |

**觀察轉向**　先查案件是新增、被發現或被記下

**證據轉向**　改看被害調查、錄案流程及場域分母

**因果轉向**　通報機會與事件機制可能共變，截點須與未變更區對照

**盲點與邊界**　僅使用去識別化制度資料。個人安全與責任由主管者處理。

**判定**　被害、場所與處理流程給出三種可分辨材料。當前紀錄差不能決定事件差。

## Negative Control

**案情**　依法定規則和已確認送達時點，僅查哪一天期滿。

**NO_METHOD_WITH_REASON**　由法學查適用法及期限。群體基率無關。

**重新開啟條件**　如不同群體常錯過期日且原因未知，再查司法流程。
