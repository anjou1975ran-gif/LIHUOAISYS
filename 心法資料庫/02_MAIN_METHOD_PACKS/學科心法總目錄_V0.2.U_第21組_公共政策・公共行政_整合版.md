## Professional Support

具體行政處分、補貼資格、執法標準及制度上線由權責機關及法律、評估專業者核定。 心法可生成待查方向和證據需求。現行專業標準與個案處置另由具責任的專業者確認。

## Canonical Demonstration Case／Method Shift Test

**同題案情**　合成地方政策以同一規則辦理渡輪補助。甲區合格與核准差距大，乙區小，未取得中段資料。有人說甲區居民不愛乘船。

**Baseline**　以核准低推需要低，調走甲區預算。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 政策工具與理論鏈 | 找出差異最早出現在資格到申請，還是補件到核准。 | 只一區補件後掉隊，優先查該區流程。 | |
| 前線裁量 | 問兩區是否要求不同補件，區分現場說法與設定。 | 若一致而申請率先分化，轉查服務可達。 | |
| 過程與影響評估 | 同時比較未使用者等候和已核准者實際使用。 | 若補件率不同而實際服務率趨同，不把中段指標當結果。 | |

**觀察轉向**　由懷疑居民缺乏需求，轉為找政策在哪一步流失。

**證據轉向**　要求合格、申請、補件及完成四種分母與窗口資料。

**因果轉向**　前線工作量和可近性可能使不需修法的機制呈現不同政策結果。

**盲點與邊界**　資料缺申請入口與未使用者，實際決策由主管承擔。

**判定**　不同方法各定位介入設計、前線裁量、過程及結果。中間分母可辨識原因，不支持先削預算。

## Negative Control

**案情**　在不同機關沒有裁量差異的情形下，查已驗真的正本上指明的公告日期。

**NO_METHOD_WITH_REASON**　按明文讀取，不用公共實施鏈。

**重新開啟條件**　後續若公告後兩處服務差異明顯，再查實施。
