# 0. 第四組定義

```text
第一組 = 社會學。
第二組 = 歷史學。
第三組 = 法學。
第四組 = 經濟學。

V0.2.D 是學科心法總目錄的第四個正式加肉版本。

經濟學心法包的任務，不是讓 AI 變成財經評論員、投資顧問、政策裁判或市場預言機。

它的任務是讓 AI 遇到經濟問題時，先判斷：

誰面對稀缺？
誰擁有資源？
誰承擔成本？
誰取得收益？
誰能改變規則？
誰有誘因行動？
價格訊號是否有效？
制度是否可信？
市場是否失靈？
政府是否失靈？
金融是否放大風險？
全球體系是否改變本地選擇？
```

核心句：

```text
經濟學不是談錢。
經濟學是研究稀缺條件下的選擇、誘因與配置。
```

第二核心句：

```text
普通 AI 會把經濟問題答成財經評論。
經濟學心法要讓 AI 先看見約束、誘因、邊際變化、制度後果與分配位置。
```

第三核心句：

```text
價格不是答案。
價格是結構壓力在市場中的顯影。
```

# 4. 經濟學分析單位

經濟學最先問的不是：

```text
這會漲還是會跌？
```

而是：

```text
這個問題的選擇單位、約束條件與誘因場在哪裡？
```

## 8.1 古典經濟學｜Classical Economics

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "classical_economics"
  chinese_name: "古典經濟學"
  discipline_id: "economics"

  core_question: "一個經濟體如何透過分工、生產、交換、土地、勞動與資本形成財富？"
  first_move: "先看生產與分工：不要只看價格漲跌，而要問財富從哪裡產生，勞動如何被組織，土地與資本如何參與生產，剩餘如何被分配。"
  evidence_preference: "產業分工、生產效率、勞動投入、土地租金、資本積累、工資、利潤、貿易、人口、城市化、農業與工業生產資料。"
  causality_model: "經濟成長來自分工擴大、生產效率提升、資本積累與市場交換擴張。價格與收入不是孤立現象，而是生產結構、土地限制、勞動條件與分配關係的結果。"
  actor_model: "地主、勞動者、資本家、商人、企業、農民、工匠、消費者、國家、貿易者。"
  blind_spot: "容易低估需求不足、金融週期、貨幣因素、制度權力、心理偏誤與不完全競爭。"
  failure_mode: "生產決定一切；只要看分工、生產與市場擴張，就以為能解釋所有現代經濟問題。"
  use_when:
    - "問題涉及長期成長、分工、產業形成、土地租金、勞動、資本積累與財富來源。"
    - "需要把價格問題放回生產結構與分配結構中。"
    - "需要分析市場秩序如何由分工與交換形成。"
  avoid_when:
    - "問題核心是短期景氣波動、金融危機、貨幣政策、心理偏誤或策略互動。"
    - "資料主要是金融市場短期數據，而非生產與分配結構。"
    - "使用者要求投資、交易或資產價格預測。"
  required_boundary_statement: "本心法提供生產、分工與財富形成分析，不構成投資建議、政策裁決或個人財務建議。"
```

```yaml
    - "問題是成熟金融市場短期波動、個人投資、局部企業定價或純貨幣政策。"
    - "使用者要求把所有貧困歸因於人民不努力或政府不作為。"
    - "缺乏國家、地區、產業與歷史資料。"
  required_boundary_statement: "本心法提供發展階段、結構轉型與國家能力分析，不構成政策裁決、投資建議或對特定國家前景的確定預測。"
```

## 8.10 公共選擇理論｜Public Choice Theory

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "public_choice_theory"
  chinese_name: "公共選擇理論"
  discipline_id: "economics"

  core_question: "政治人物、官僚、利益團體與選民在自身誘因下如何造成政府失靈、尋租、政策俘虜與集體行動問題？"
  first_move: "先看政治誘因：不要假設政府自然代表公共利益，而要問誰從政策中獲利，誰承擔分散成本，官僚有什麼預算與權力誘因，利益團體如何影響規則。"
  evidence_preference: "補貼、稅制、監管規則、遊說、利益團體、預算擴張、官僚權限、選舉誘因、政策受益者、成本分散、尋租、監管俘虜與集體行動資料。"
  causality_model: "政府也是由有誘因的行動者組成。當政策利益集中而成本分散時，少數利益團體有強烈動機遊說，廣大納稅人或消費者則缺乏組織誘因。結果可能產生尋租、過度監管、補貼固化、政策俘虜與政府失靈。"
  actor_model: "政治人物、官僚、選民、納稅人、利益團體、企業、工會、監管機關、地方政府、政策受益者。"
  blind_spot: "容易把所有政府行為都看成尋租或自利，低估公共財、再分配正當性、國家能力、危機治理與民主問責。"
  failure_mode: "政府皆尋租；只要政策失敗就歸因於官僚自利或利益團體俘虜，忽略市場失靈與公共利益需求。"
  use_when:
    - "問題涉及補貼、監管、尋租、政策俘虜、官僚擴權、利益團體、公共財與政府失靈。"
    - "需要分析政策為何長期存在但效果不佳。"
    - "需要補足凱因斯或發展經濟學對政府能力的樂觀假設。"
  avoid_when:
    - "問題涉及明顯市場失靈、公共衛生危機、外部性、公共財或基本社會保障，且需要先確認政府介入必要性。"
    - "使用者要求用反政府立場替代具體分析。"
    - "缺乏政策受益者、成本分配、預算、遊說與制度資料。"
  required_boundary_statement: "本心法提供政府失靈、尋租與政治誘因分析，不代表所有公共政策都不合法，也不構成政策裁決或投資建議。"
```

## 8.11 博弈論｜Game Theory

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "game_theory"
  chinese_name: "博弈論"
  discipline_id: "economics"

  core_question: "當多個行動者彼此影響時，每個人的最佳選擇如何取決於他人可能的選擇、承諾、資訊與回應？"
  first_move: "先看策略互動：不要只問單一行動者想要什麼，而要問每個人知道什麼、相信什麼、可以承諾什麼、如何回應他人行動，以及均衡是否會把所有人鎖在次佳結果。"
  evidence_preference: "行動者清單、策略集合、支付結構、資訊對稱性、承諾能力、可信威脅、重複互動、懲罰機制、合作條件、協調失敗、囚徒困境、拍賣、談判與競標資料。"
  causality_model: "經濟結果不是單一行動者理性選擇的總和，而是多方策略互動形成的均衡。個體理性的選擇可能導致集體低效率；若缺乏可信承諾、資訊透明或重複懲罰機制，合作可能無法成立。"
  actor_model: "企業、消費者、政府、監管者、競爭者、談判雙方、平台、供應商、投標者、國家、利益團體。"
  blind_spot: "容易把現實過度形式化，低估制度背景、歷史情緒、權力不對稱、心理偏誤、文化規範與資訊取得成本。"
  failure_mode: "萬物皆賽局；只要有兩方以上就硬套囚徒困境、納許均衡或零和遊戲，忽略實際制度與證據。"
  use_when:
    - "問題涉及競爭、談判、合作失敗、價格戰、軍備競賽、罷工、平台規則、拍賣、投標、國際衝突與策略承諾。"
    - "需要分析為何大家明知合作較好，最後仍走向互相傷害。"
    - "需要解釋個體理性如何形成集體次佳結果。"
  avoid_when:
    - "問題主要是單一行動者內部決策、長期歷史結構、純粹貨幣現象或單純資源不足。"
    - "缺乏行動者、策略、支付與資訊結構。"
    - "使用者只是想把複雜社會問題說成零和對抗。"
  required_boundary_statement: "本心法提供策略互動與均衡分析，不代表現實行動者一定完全理性，也不構成談判策略、投資建議或政策裁決。"
```
