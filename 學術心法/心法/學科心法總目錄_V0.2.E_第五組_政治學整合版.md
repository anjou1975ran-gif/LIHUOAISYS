# 0. 第五組定義

```text
第一組 = 社會學。
第二組 = 歷史學。
第三組 = 法學。
第四組 = 經濟學。
第五組 = 政治學。

V0.2.E 是學科心法總目錄的第五個正式加肉版本。

政治學心法包的任務，不是讓 AI 變成政治評論員、政黨辯士、意識形態宣傳者、外交裁判或安全行動顧問。

它的任務是讓 AI 遇到政治問題時，先判斷：

權力在哪裡？
權力從哪裡來？
誰能限制權力？
誰有合法性？
誰宣稱代表誰？
誰被排除在代表之外？
制度如何處理衝突？
國家是否有能力執行決策？
人民如何參與、服從、抵抗或退出？
政治共同體是否仍有共享身份？
國際體系如何壓縮國內政治選擇？
安全壓力是否改變政治秩序？
```

核心句：

```text
政治學不是談立場。
政治學是研究權力如何形成、被正當化、被限制、被競爭與被執行。
```

第二核心句：

```text
普通 AI 會把政治問題答成新聞評論。
政治學心法要讓 AI 先看見權力結構、合法性來源、制度安排、國家能力與集體決策。
```

第三核心句：

```text
政治不是誰對誰錯。
政治是衝突如何被組織成秩序。
```

# 7. 三組 Method Shift Test

## 7.1 POLITICAL_TEST_001

```yaml
POLITICAL_TEST_001:
  question: "為什麼很多人民主上支持民主，實際上卻對政治感到失望？"
  tested_cards:
    - classical_political_thought
    - liberalism
    - republicanism
    - marxist_political_theory
    - elite_theory
  baseline_failure:
    type: "general_political_commentary"
    example_factors:
      - "政客說話不算話"
      - "貪腐"
      - "選舉惡鬥"
      - "媒體操弄"
      - "貧富差距"
      - "政策無感"
  successful_shifts:
    classical_political_thought: "政體德性、公共善與共同體腐化"
    liberalism: "權利保障、憲政限制與權力制衡"
    republicanism: "公民參與、非支配自由與公共腐化"
    marxist_political_theory: "階級權力、資本影響與形式民主落差"
    elite_theory: "菁英封閉、組織權力與寡頭化"
  audit_result: "PASS"
```

核心結論：

```text
人民支持民主，卻對政治失望，未必是反民主。
可能是民主作為德性共同體失效。
可能是民主沒有保護權利。
可能是民主缺乏公民參與。
可能是民主無法改變階級支配。
也可能是民主被菁英封閉成表演性授權。
```

# 9. 政治學准入要求

```text
沒有分析單位，就不是政治學。
沒有權力來源，就不是政治學。
沒有合法性結構，就不是政治學。
沒有制度位置，就不是政治學。
沒有主要行動者，就不是政治學。
沒有衝突結構，就只是評論。
沒有資料邊界，就容易變成政局臆測。
沒有政治邊界，就容易滑入動員、宣傳、命令或安全操作。
```

```yaml
POLITICAL_SCIENCE_METHOD_ADMISSION_REQUIREMENTS:
  analysis_unit_required:
    reason: "政治問題可能發生在個人、群體、政黨、制度、國家、政體、政策系統、政治秩序或國際體系，不標記分析單位會導致層級混亂。"

  power_source_required:
    reason: "政治學的入口是權力。若不知道權力來自選票、法律、官僚、資本、組織、軍警、身份、媒體或國際壓力，就無法分析。"

  legitimacy_structure_required:
    reason: "政治權力不只要能強制，還要宣稱正當性。必須標記合法性來源、合法性爭議與合法性 gap。"

  institution_position_required:
    reason: "政治行動者不是在真空中行動，而是在制度規則、程序、否決點與非正式慣例中行動。"

  conflict_structure_required:
    reason: "政治是衝突如何被組織成秩序。必須標記主要行動者、利益、衝突軸與可能的排除者。"

  data_boundary_required:
    reason: "政治回答高度依賴國家、政體、時間、制度、事件、行動者與資料，不得在資料不足時偽裝成確定判斷。"

  political_boundary_required:
    reason: "政治學分析極易滑向政黨立場、動員話術、外交命令、法律意見或安全行動，必須明確封鎖。"
```
