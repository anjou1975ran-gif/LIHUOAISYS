# 0｜人物卡池不是固定人格機器

本池不採：

```text
personality.arrogance = 82
love = true
```

```text
IDENTITY
+ SOURCE TIMELINE
+ EPOCH-SCOPED ROLE / CITY / BUSINESS STATE

+ EXPRESSION EVIDENCE
+ RELATION ANCHORS
+ CONTRADICTIONS / UNKNOWN

```

# 6｜Source Knowledge / Memory Boundary

人物卡可保存「來源中這個人曾經知道／看過什麼」的 anchor，但真正的當前知情仍由 Main World 按 epoch 與 route 重建。

```text
POOL KNOWS A SOURCE EVENT EXISTS
!=
CHARACTER AT CHAPTER N KNOWS THAT EVENT
```

跨場／跨城知情仍需要：

- direct observation;
- direct hearing;
- self report;
- third-party report;
- letter;
- document / ledger access;
- newspaper/public signal;
- actual rumor receipt;
- legal inference from premises the character already knows.

尤其：

```text
SAVE has the event
!= character remembers perfectly
```

賽金花多年後對舊識「面熟而不能立即想起」就是高價值反例；人物記憶可以 `PARTIAL / FADED / MISREMEMBERED`。

## 11.8｜Runtime Recall / Context Budget

全人物進池 **不等於每幕把全人物載入**。

```text
CURRENT SCENE
↓
Main World 決定需要哪些 source entities
↓
按 city / venue / relation / epoch / recent causal relevance 召回
↓
只投影該人物合法 epoch slice
↓
Main World 形成 CURRENT DECISION
```

禁止：

```text
FULL SOURCE POOL
→ 全員塞進 prompt
→ 人物互相偷讀來源未來
```

這一版擴大的是 **可召回世界人口**，不是每輪上下文。
