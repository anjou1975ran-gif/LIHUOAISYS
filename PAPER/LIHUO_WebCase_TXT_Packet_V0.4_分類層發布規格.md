# Classification rules

```yaml
GENERAL:
  CASE_TYPE: GENERAL_PAPER_REVIEW
  PRIMARY_DOMAIN_ALLOWED:
    - AI_COMPUTING
    - ENGINEERING_TECHNOLOGY
    - SOCIAL_SCIENCE
    - EDUCATION
    - HUMANITIES
    - NATURAL_SCIENCE
    - BUSINESS_POLICY

MEDICAL:
  CASE_TYPE: MEDICAL_PAPER_REVIEW
  PRIMARY_DOMAIN_ALLOWED:
    - CLINICAL_MEDICINE
    - PHARMACEUTICAL
    - BIOTECHNOLOGY
    - MEDICAL_AI
    - PUBLIC_HEALTH
    - MEDICAL_DEVICE_DIAGNOSTICS

SECONDARY_TAGS:
  min_items: 0
  max_items: 3
  separator: ";"
  empty_representation: "NOT_APPLICABLE"
```

# Parser behavior

- `PRIMARY_DOMAIN` is required.
- `SECONDARY_TAGS` key is required.
- `NOT_APPLICABLE` means no secondary tag.
- More than 3 secondary tags must not be silently truncated.
- CASE_TYPE / PRIMARY_DOMAIN mismatch => DRAFT + warning + PUBLISH_READY false.
- Website must not infer a missing classification.
- Classification changes website navigation only; it does not modify the LIHUO review result.
- V0.3 remains readable as legacy, but V0.4 is the new canonical format.
