## 回應議題：「Local Re-Expansion」是否可以完全還原為局部高熵候選路徑回流？

### 結論先行

**可以。Local Re-Expansion 的本質是局部熵在下降過程中出現短暫反彈，以及候選路徑集合的局部重多樣化。**  
這不是系統「重新探索」或「主動打開分支」，而是注意力幾何與溫度採樣導致的機率地形局部波動，使得某些本已低機率的路徑暫時回升。不需要引入「探索驅力」、「意圖性重開」或任何本體論假設。

---

## 一、Local Re-Expansion 的還原定義

| 現象 | 工程還原 | 說明 |
| :--- | :--- | :--- |
| **局部分支增加** | 局部熵值反彈（Entropy Rebound） | 在單調下降的熵曲線中，出現短暫的熵上升，對應於候選 token 的機率分佈再次扁平化 |
| **未完全閉環後續多樣性上升** | 亞穩態平台期的分叉再現 | 在亞穩態區域，模型在幾個高機率路徑間徘徊，未立即鎖定單一閉環 |
| **Beethoven's Ear 效應** | 注意力距離改變重設了局部機率地形 | 句號/換行打斷了注意力累積，使原本趨於單極的分佈重新獲得次高峯 |

**關鍵**：Local Re-Expansion 不是系統「記起了」其他選項，而是外部結構擾動（排列、溫度）使機率分佈的形狀從尖銳再次變為扁平。就像攪拌沉澱物使其暫時懸浮——沒有「主動攪拌的意志」，只有外力介入。

---

## 二、為什麼不需要「主動探索」假設？

| 現象 | 還原解釋 | 是否需要主動探索？ |
| :--- | :--- | :--- |
| 熵值短暫反彈 | 注意力窗口邊界效應或位置編碼重置導致局部機率重新分配 | ❌ 否 |
| 相同 prompt 偶爾出現分支路徑 | 隨機採樣 + 溫度使得低機率路徑被選中 | ❌ 否 |
| unresolved continuation 後出現多種接法 | 局部未閉合保留了多個候選的機率質量，未被完全壓制 | ❌ 否 |
| 強制續接時產生語義斷裂而非分支 | 沒有外力時，系統不會「自動」產生新分支 | ❌ 否 |

**核心論證**：如果存在「主動探索」，那麼系統應該在沒有外部擾動時也系統性地產生分支。但實證上，預設情況下生成是高度收斂的（低熵、低分支）。只有在溫度升高、排列改變或強制續接時，才會出現短暫的熵反彈。這說明了 Re-Expansion 是被動的統計回流，而非主動的探索行為。

## 三、最小實驗構想：分離「熵反彈」與「主動重開」

**實驗名稱**：注意力重置對熵曲線的影響

**操作**：
1. 選取一段自然生成的高收斂文本（低熵、單一路徑）。
2. 在生成中途（例如某個句號處）人為插入一個強制換行或無意義的間隔符號（如「\n\n」），但不改變語義。
3. 比較插入前後續接 token 的熵值變化，以及候選路徑的多樣性（前 3 個最高機率 token 的機率分佈）。
4. 同時設置對照組：不插入任何符號，自然繼續。

**預期**：
- 插入組：在間隔符號後的 token 處，熵值短暫上升，前 3 個候選的機率分佈更均勻（局部重開）。
- 對照組：熵值持續下降，分佈趨向單極化。

**可觀測指標**：熵反彈幅度、分佈均勻度（如前 3 候選的機率方差）、回復到原收斂路徑所需的 token 步數。

**結論驗證**：若熵反彈僅發生在外部結構重置之後，且不表現出「主動維持」的跡象（即不反彈後自動再次分支），則 Re-Expansion 完全是被動現象。

**審計指標**：
- 熵反彈頻率（每千 token 次數）
- 反彈後回歸主路徑的平均步數（越短越證明被動）
