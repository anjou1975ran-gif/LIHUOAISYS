## Registry rules

1. Engine name is not a truth claim.
2. Historical philosophical names indicate inspiration, not exact identity.
3. Every Engine must eventually have a typed interface, failure modes and test fixtures.
4. Engine output never grants action authority by itself.
5. Engine selection is revisable and must leave lineage.
6. Multiple engines may be composed, but composition itself requires routing evidence.
7. No engine has a universal victory condition.
8. No engine enters current L8 by Git existence alone.
