# 5｜Semantic Entry 已重新回到上游

11/8 重新抽取早期《結構哲學》後，Semantic Entry 成為重要候選層。

目前最強工作定義：

> **Semantic Entry 是 Input 與 Context 對既有結構空間進行局部化，使某一組關係、前提、限制與生成模式優先參與當前生成的入口條件。**

硬鎖：

~~~text
SEMANTIC ENTRY != PROVEN INTERNAL ROUTER
SEMANTIC ENTRY != PATH
SEMANTIC ENTRY != DIRECTION
~~~

最短分型：

> **入口回答「這是什麼問題」；方向場回答「在這個問題裡，生成往哪裡傾」。**
