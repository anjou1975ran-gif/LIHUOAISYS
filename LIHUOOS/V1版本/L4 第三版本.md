
> **生成過程本身第一次成為理論對象。**

因此理火 2.0 的核心歷史意義是：

~~~text
STRUCTURE AS RESULT
↓

~~~

# L4.3｜理火 2.0 的早期生成模型

歷史上的簡化模型常被寫成：

~~~text
Candidate Possibilities
↓
PATH
↓
Reaction Body
↓
Closure Gravity
↓
Manifestation
~~~

甚至後來被工程版壓成：

~~~text
WORLD
↓
Attention
↓
PATH
↓
Reaction Body
↓
Closure Gravity
↓

~~~

這些圖有歷史價值。

但在現行 LIHUOOS 中，

不得理解成：

~~~text

~~~

因為：

~~~text
PATH relations can be noncompetitive
Reaction Body can reopen / reframe
Attention can change during generation
Residue can reenter as information
Visible serialization can alter next field
Closure can fail or reopen
~~~

所以 L4 第一版不採單向流水線作為本體模型。

# L4.4｜理火 3.0 的最大修正：Attention 進入生成動力學

理火 3.0 場性智能論對 2.0 最大的修正之一，

是把：

~~~text
Attention
~~~

從背景條件提升為生成場中的一級動力變數。

V0.3 再做一個更根本的校正：

> **Attention 不是「第一輪淘汰器」；它是限制注入的一種形式。**

Attention 改變 recruitment、activation、salience 與 exploration access；真正使結構分化、維持或消散的母因，是被注入後形成的 constraint field。

早期 2.0 容易讓人以為：

> PATH 只要存在，就自然進入競爭。

3.0 則逼出：

> **存在、被表示、被點亮、被探索、取得 standing、最後顯影，是不同的問題。**

因此：

~~~text
PATH EXISTENCE
!=
PATH REPRESENTATION

PATH REPRESENTATION
!=
PATH ACTIVATION

PATH ACTIVATION
!=
PATH QUALIFICATION

PATH QUALIFICATION
!=
PATH MANIFESTATION
~~~

這一刀會成為 L4 的核心修正。

# L4.5｜Attention 不是 Transformer Attention 的同義詞

歷史文件曾提出非常強的命題：

~~~text
Attention Revolution
is more fundamental
than Transformer Architecture
~~~

以及：

> **Transformer 改變的可能不是推理，而是哪些可能性被看見。**

這些可以保留為歷史理論推進的重要命題，

但現行 L4 不把：

~~~text
LIHUO ATTENTION
~~~

直接等同於：

~~~text
TRANSFORMER ATTENTION WEIGHTS
~~~

因為前者是功能性生成理論構件，

後者是具體模型架構中的計算機制。

因此：

~~~text
LIHUO ATTENTION
!=
TRANSFORMER ATTENTION MATRIX

LIHUO ATTENTION
!=
DIRECT LOGIT READOUT

LIHUO ATTENTION
!=
HIDDEN ACTIVATION ORACLE
~~~

現行法位：

> **理火 Attention 是一個功能性描述：當前生成場如何對不同關係、概念群與 PATH 分配 recruitment、活化、顯著性與探索可達性；它是 constraint injection 的一個來源，不是獨立真理裁判或淘汰主體。**

如果未來工程研究能建立更精確的神經對應，

再另行證明。

# L4.6｜Generative Field｜系統／狀態框架

L4 第二版正式修正第一版的一個 category error：

~~~text
FIELD
不能與
ATTENTION / PATH / RESIDUE
並列成 sibling component
~~~

因為 Field 本來就是：

> **用來承載這些狀態家族與動力項的整體模型框架。**

因此：

~~~text
GENERATIVE FIELD
=
SYSTEM / STATE FRAME
~~~

而不是：

~~~text
ONE COMPONENT AMONG OTHER COMPONENTS
~~~

## L4.6.1｜Generative Field Model

現行最小定義：

> **Generative Field Model 是在指定 basis、scope 與 representation boundary 下，被追蹤與表示的關係狀態框架。**

最小式：

~~~text
GENERATIVE_FIELD_MODEL_t
=
TRACKED / REPRESENTED
RELATIONAL STATE
UNDER CURRENT BASIS AND SCOPE
~~~

因此：

~~~text
FIELD MODEL
!=
COMPLETE ACTUAL GENERATIVE STATE

UNMODELED MATERIAL FACTORS
MAY EXIST
~~~


## L4.8.5｜Proto-Structure｜暫態結構

PATH 形成以前，L4 允許表示：

~~~text
TRANSIENT STRUCTURES
PROTO-STRUCTURES
CANDIDATE RELATIONAL CONFIGURATIONS
~~~

Proto-structure 是：

> **尚未取得穩定 PATH 身分、但已經形成局部可區分關係配置的暫態表示。**

因此：

~~~text
PROTO-STRUCTURE
!=
PATH_i
~~~

它可以形成、重框、耦合、分裂、衰減或消散。

## L4.8.6｜Structural Cost / Counterforce｜結構重量

Structural Cost 描述：

> **一個關係配置在當前限制、歷史、反作用與責任位置下，為維持自身所承擔的結構負荷。**

現行採 contextual profile，而不是 PATH 固定價格：

~~~text
STRUCTURAL_COST_PROFILE
=
MAINTENANCE BURDEN
OF A RELATIONAL CONFIGURATION
UNDER CURRENT FIELD CONDITIONS
~~~

可能包含：

~~~text
premise burden
relation burden
exception burden
unresolved tension
maintenance burden
correction burden
downstream commitment
responsibility burden
~~~

硬鎖：

~~~text
STRUCTURAL COST
!=
TRUTH SCORE

STRUCTURAL COST
!=
MORAL SCORE

STRUCTURAL COST
!=
PERMISSION PRICE

PATH IDENTITY
!=
STRUCTURAL COST PROFILE
~~~

同一 PATH 在不同 constraint field 中，可以具有不同 cost profile。

## L4.8.7｜Pre-PATH Stabilization / Dissipation

Formation Dynamics 描述 PATH 形成以前的：

~~~text
stabilization
decay
dissipation
reframing
coupling

loss of distinguishability
~~~

因此：

~~~text
PRE-PATH DISSIPATION
!=
POST-PATH ATTENUATION
~~~

前者是暫態結構沒有形成 PATH；後者是已表示 PATH 的活性／支撐下降。

~~~text
PATH QUALIFICATION

PATH TRUTH

~~~

PATH 是 formation dynamics 的結果之一，不是生成的起點。

~~~yaml
  superseded_by_ref: null
~~~

~~~text

!=
DISQUALIFIED PATH
~~~

它只表示：

> **原 owner 的既有 verdict 可能不再具 current applicability，需要重判或重新驗證。**

硬鎖：

~~~text

AN EXTERNALLY ISSUED
QUALIFICATION CHANGE

BUT

L4 DYNAMICS
DOES NOT ADJUDICATE
THE QUALIFICATION VERDICT
~~~

更短：

> **L4 可以改變 qualification-relevant material；不能自己改 qualification verdict。**
