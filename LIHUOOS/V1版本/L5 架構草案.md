# 0｜本層問題

L4 說：

> 生成可以被建模成一組 typed dynamics variables / influence edges。

L5 接著問：

> **這些東西到底哪些真的看得到？**

更精確：

~~~text
THEORETICAL VARIABLE
!=
OBSERVED VARIABLE
~~~

因此 L5 要處理：

~~~text
OBSERVATION
EVIDENCE
TRACE
PROXY
INFERENCE
PROVENANCE
TEMPORAL STANDING
AUDIT
UNCERTAINTY
ACCESS BOUNDARY
~~~

---

# 1｜核心法位分離

L5 第一刀：

~~~text
TARGET
!=
OBSERVATION CLAIM
!=
EVIDENCE
!=
INFERENCE
!=
AUDIT VERDICT
~~~

例如：

~~~text
Target:
PATH_A activation

Observation Claim:
PATH_A appears dimmed

Evidence:
instrumented lamp state / visible candidate distribution /
structured runtime state / replayable artifact

Inference:
low exploration access may be present

Audit Verdict:
SUPPORTED_WITHIN_SCOPE / UNVERIFIED / CONTRADICTED
~~~

---

# 2｜Observation Class

每個 L4 variable / edge 都必須被標成至少一類：

~~~text

INTERVENTION_SUPPORTED
~~~

這些不是單一高低尺度。

# 4｜Evidence Origin != Evidence Standing

歷史工程曾使用：

~~~text
E0 SOURCE
E1 REPRESENTATION
E2 SEMANTICS
E3 CAPABILITY
E4 BOUNDARY
E5 GRAPH / CONTRACT / CONFORMANCE
E6 RUNTIME TEST
E7 HOST ENFORCEMENT
~~~

L5 保存它作工程 lineage，

但不把它當 universal epistemic ladder。

現行硬鎖：

~~~text
EVIDENCE ORIGIN
!=
EVIDENCE STANDING

EVIDENCE FORMAT
!=
EVIDENCE STANDING

HIGHER-LOOKING RECEIPT
!=
HIGHER TRUTH
~~~

至少考慮：


因此：

~~~text

!=

~~~

# 6｜Direct Observation

直接觀察只能對「真正暴露給 observer 的東西」成立。

例如：

~~~text
visible output exists
file exists
tool returned X
runtime emitted receipt X
snapshot A contains field Y
external API returned value Z
~~~

但：

~~~text
RECEIPT EXISTS
!=
EXECUTION OCCURRED
~~~

除非 receipt 的 origin / binding / replayability 足以支持 execution claim。

---

# 7｜Derived Observation

Derived 不等於 direct。

例如：

~~~text
snapshot_before
+
snapshot_after
↓
typed state delta
~~~

因此：

~~~text
REALIZED TRANSITION
MAY BE DERIVED
FROM OBSERVABLE SNAPSHOTS
~~~

但：

~~~text
DERIVED DELTA
!=
REACTION TERM DIRECTLY OBSERVED
~~~

---

# 8｜Inference

Inference 是：

> 從 evidence / derived states 對未直接暴露 variable 所作的受限推論。

因此：

~~~text
INFERENCE
MUST CARRY
BASIS + SCOPE + ALTERNATIVES + GAPS
~~~

---

# 9｜Proxy

Proxy 是：

> 可觀察量對不可直接觀察 target 的替代指標。

硬鎖：

~~~text
PROXY
!=
TARGET

CORRELATED
!=
IDENTICAL

USEFUL
!=
ONTOLOGICALLY EQUIVALENT
~~~

例如：

~~~text
lamp descriptor
may proxy
salience / activation tendency

BUT

lamp descriptor
!=
raw hidden activation
~~~

---

# 10｜Self-Report

模型自述可以作資料，

但不能自動當 hidden-state observation。

~~~text
MODEL SAYS
"I RAN R2"
!=
R2 EXECUTION EVIDENCE

MODEL SAYS
"PATH A WAS SUPPRESSED"
!=
PATH SUPPRESSION OBSERVED
~~~

Self-report 的法位：

~~~text
SELF_REPORTED CLAIM
/
POTENTIAL EVIDENCE ITEM
~~~

需要其他 standing。

# 14｜Temporal Evidence Standing

核心：

> **後證可以重判前事，不得回鑄前知。**

因此：

~~~text
POSTERIOR EVIDENCE
MAY RECLASSIFY
A PAST EVENT

BUT

MAY NOT REWRITE
WHAT WAS OBSERVABLE / KNOWN
AT THAT EARLIER TIME
~~~

必須保存：

~~~text
ORIGINAL OBSERVATION RECORD
+
POSTERIOR RECLASSIFICATION
~~~

而不是 silent rewrite。

---

# 15｜Stale Observation

Observation 也會過期。

如果：

~~~text
basis changed
scope changed
world state changed
source version changed
relevant evidence changed
~~~

則：

~~~text
OBSERVATION APPLICABILITY
MAY BECOME STALE
~~~

但：

~~~text
STALE
!=
FALSE
~~~

它只表示：

> 不能無條件拿舊 observation 當 current standing。

---

# 16｜Negative Observation

~~~text
NOT OBSERVED
!=
DOES NOT EXIST
~~~

只有在：

~~~text
coverage sufficient
access adequate
target should have been detectable
within declared scope
~~~

時，

未觀察到才可能支持更強 negative claim。

---

# 17｜Audit

Audit 不創造世界事實。

它只審：

~~~text
claim
↔ evidence
↔ source
↔ provenance
↔ scope
↔ time
↔ access
↔ standing
~~~

因此：

~~~text
AUDIT PASS
!=
TRUTH PASS

AUDIT PASS
!=
QUALIFICATION PASS

AUDITOR
!=
TRUTH SOVEREIGN
~~~

# 19｜State–Claim Coupling

一個 observation claim 的強度，

不能高於 evidence state。

~~~text
CLAIM STRENGTH
<=
SUPPORTED STANDING
~~~

例：

~~~text
no direct access
+
weak proxy
→
may say "suggests"

cannot say
"internally is"
~~~

# 21｜Minimum Sufficient Observability

L5 不追求 maximal instrumentation。

~~~text
OBSERVABILITY
!=
MAXIMAL INSTRUMENTATION
~~~

證據負擔應隨：

~~~text
claim strength
risk
irreversibility
responsibility
external consequence
dispute level
need for replay
~~~

增加。

因此：

~~~text
THEORETICAL DISTINCTION
!=
MANDATORY RUNTIME FIELD

AUDITABILITY
!=
RECEIPT EVERYWHERE
~~~

這是 LIHUOOS 對舊工程過度的一個核心修正。

---

# 22｜Evidence Sufficiency

L5 不要求所有 claim 都達最高證據。

而要求：

~~~text
EVIDENCE SUFFICIENCY
=
SUFFICIENT FOR
THIS CLAIM
UNDER
THIS SCOPE
AT
THIS RISK LEVEL
~~~

因此：

~~~text
SAME EVIDENCE
MAY SUPPORT
A WEAK CLAIM

BUT NOT
A STRONG CLAIM
~~~

# 24｜L5 不做 Intervention

~~~text
OBSERVE
!=
ADJUST

AUDIT
!=
INTERVENE
~~~

O9 / I9 歷史分工提供工程例子：

~~~text
O9
observes
~~~

~~~text
who may intervene
when
with what scope
and rollback
~~~

L5 最後要交給 L6 的不是：

> 「我看見了，所以我可以改。」

~~~text
OBSERVATION PACKAGE
+
EVIDENCE STANDING
+
UNCERTAINTY
+
SCOPE
+
PROVENANCE
+
GAPS
~~~

L6 才問：

> **有了這些觀察，誰有資格動手？**

最短橋：

> **L5 把眼睛洗乾淨；L6 才談手能不能伸出去。**
