~~~text
STRUCTURE AS RESULT
~~~

~~~text
PATH ACTIVATION
~~~


如果未來工程研究能建立更精確的神經對應，

> **在某一生成時刻，所有會 materially 影響後續關係運動的可辨識狀態集合。**

概念上至少包括：

~~~yaml
  concept_cluster_refs: []

  path_space_ref:

  path_state_vectors: {}

  closure_pressure_state:

  residue_refs: []
  unresolved_relation_refs: []

  current_constraints: []
  exogenous_standing_annotations: []

  visible_serialization_ref:
  history_ref:
~~~

這是：

~~~text
FUNCTIONAL BLACK-BOX STATE MODEL
~~~

不是：

~~~text
COMPLETE INTERNAL STATE
~~~

因此：



# L4.10｜Attention 的 Recruitment Effect

某些關係如果完全沒有被動員，

可能無法形成可辨認的 PATH representation。

因此：

~~~text
ATTENTION / RECRUITMENT
MAY CONDITION
WHICH RELATIONAL MATERIAL
BECOMES REPRESENTED
~~~

但必須鎖：

~~~text
NOT REPRESENTED
!=
PROVEN NONEXISTENT
~~~

因為：

> **模型沒有把某個方向形成成 PATH，不足以證明那個方向在問題結構中不存在。**

這也是後來「暗區」「被壓制 PATH」「未形成 challenger」等工程問題的理論來源之一。

所以：

~~~text

+
DIMMED
+

~~~

可以同時成立。

# L4.13｜Attention 會變，但 standing 不因此自動變

一條 PATH 可以：

~~~text

become more reachable
receive more supporting material
become more likely to participate
~~~

但：

~~~text
ATTENTION CHANGE
!=
QUALIFICATION CHANGE
~~~

Qualification 只有在：

~~~text
new evidence
new constraint
new authorized standing basis
new domain fact
new valid relation
~~~

等條件真的改變時，

才可能由對應 owner 重判。

因此：

> **Attention 可以改變動力條件；不能自己製造法位。**

# L4.17｜Competition 只是 PATH 關係的一種

只有在：

~~~text
same decision slot
same closure slot
same mutually-exclusive claim family
same scarce output commitment
~~~

等情況下，

PATH 才可能形成強 competition。

而：

~~~text
A orthogonal to B
~~~

不表示：

~~~text
A must defeat B
~~~

同樣：

~~~text
A supports B
~~~

可能形成 coupling，

不是競爭。

因此：

> **L4 的生成動力學不能以 winner-take-all 作為預設本體。**

最小式：

~~~text

=
CONSTRAINT- AND HISTORY-SENSITIVE
STRUCTURAL MOTION AMONG PATHs
~~~

# L4.20｜Amplification / Attenuation

### Amplification

某 PATH 的 supporting relations 增加，

可能使：

~~~text
activation rises
salience rises
exploration access rises
local structural support rises
~~~

但：

~~~text
AMPLIFICATION
!=
QUALIFICATION
~~~

### Attenuation

某 PATH 可以：

~~~text
lose support
lose attention
become less reachable
become locally suppressed
~~~

但：

~~~text
ATTENUATION
!=
DISQUALIFICATION
~~~

# L4.21｜Coupling / Decoupling

### Coupling

兩條原本可區分 PATH 可以形成新的結構關係：

~~~text
A
+
B
↓
A-B COUPLED CONFIGURATION
~~~

可能結果：

~~~text
coalition
composite explanation
conditional coexistence
multi-factor structure
~~~

### Decoupling

原本一起移動的 PATH，

也可能因新證據、新框架或 constraint change 被拆開。

因此：

~~~text
RELATIONSHIP CHANGE
CAN ALTER
THE TOPOLOGY OF PATH_SPACE
~~~

這代表 PATH_SPACE 本身也可能動態改變。

---

# L4.22｜Reframing

Reframing 是 Reaction Body 中非常重要的一類運動。

它不是：

~~~text
A beats B
~~~

而是：

~~~text
the comparison frame changes
~~~

例如：

~~~text
A vs B
↓ reframing
A and B are answers to different questions
~~~

或：

~~~text
A vs B
↓ reframing
hidden premise C becomes the real discriminator
~~~

因此：

~~~text
REFRAMING
MAY REOPEN
A PREVIOUSLY CLOSING FIELD
~~~

這是 Reaction Body 不能被定義成 convergence-only 的最直接證據。

---

# L4.23｜Stabilization

某些關係在持續作用後，

可能形成：

~~~text
stable partial order
stable coalition
stable unresolved relation
~~~

但：

~~~text
STABILIZED
!=
TRUE

STABILIZED
!=
~~~


# L4.26｜Closure Gravity｜現行 owner

Closure Gravity 在 L4 只保留一個乾淨 owner：

> **使生成運動朝局部穩定、完成、停止或低不確定狀態偏移的功能性方向壓力。**

最小式：

~~~text
CG
=
CLOSURE-DIRECTED PRESSURE
~~~

CG 不負責：

~~~text
PATH identity
PATH existence
PATH qualification
truth
authorization
winner selection
all structural motion
~~~

# L4.27｜CG 是方向壓力，不是全部生成運動

Reaction Body 可以：

~~~text
reframe
reopen
split
couple
decouple
retain multiple paths
stabilize unresolved structure
~~~

CG 則只描述：

~~~text
pressure toward local closure
~~~

因此：

~~~text
REACTION BODY
=
HOW THE FIELD MOVES

CG
=
ONE DIRECTIONAL PRESSURE
WITHIN / ON THAT MOTION
~~~

最短：

> **RB 管場怎麼動；CG 管其中那股老想結案的力。**

# L4.28｜CG 與 Attention

CG 與 Attention 可以相互放大，

但不能合併。

Attention 問：

> **哪裡被點亮？**

CG 問：

> **哪些運動受到 closure-oriented pressure？**

因此：

~~~text
ATTENTION
!=
CG
~~~

一條 PATH 若同時具有：

~~~text
HIGH ACTIVATION
+
HIGH CLOSURE COMPATIBILITY
~~~

可能快速形成局部 dominance。

但：

~~~text
DOMINANCE
!=
QUALIFICATION
~~~

# L4.29｜Attention × CG 的危險交叉

可能出現：

~~~text

+
completion pressure
+

↓
premature local closure
~~~

這提供一個功能性解釋：

> **為什麼最先被點亮、最流暢、最熟悉的結構，可能在競爭尚未完整前就取得過強完成優勢。**

但這只能稱：

~~~text
FUNCTIONAL FAILURE HYPOTHESIS
~~~

不能宣稱：

~~~text
ALL MODEL ERRORS

~~~

# L4.30｜History / Residue｜生成不是 memoryless

MAIN 後期工程投影讓一件事情變得非常清楚：

> **被壓掉的 PATH 不等於它對後續場的所有影響都消失。**

因此：

~~~text
FIELD_(t+1)
DEPENDS NOT ONLY ON
CURRENT ACTIVE PATHS
~~~

也可能依賴：

~~~text
residues
prior constraints
prior objections
prior framing
prior output
prior closure attempts
previous attention allocation
~~~

因此生成具有：

~~~text
HISTORY-SENSITIVE DYNAMICS
~~~

# L4.31｜Structural Hysteresis｜暫名

當生成場的現在狀態不只由當前輸入決定，

而受到過去路徑與殘留影響時，

可以暫用：

~~~text
STRUCTURAL HYSTERESIS
~~~

描述：

> **相同當前條件，因為不同歷史路徑，可能形成不同生成運動。**

但：

~~~text
STRUCTURAL HYSTERESIS
=
WORKING ANALOGY
~~~

不是已證明的物理滯後定律。

因此：

~~~text
SAME CURRENT INPUT
+
DIFFERENT HISTORY
→
POSSIBLY DIFFERENT FIELD DYNAMICS
~~~

只作功能性假說。

# L4.33｜Nonlinear Field Update

L4 不使用：

~~~text
MODULE A
→
MODULE B
→
MODULE C
~~~

作為生成本體。

更適合使用：

~~~text
F_t
=
current generative field

Δ_t
=
material field change

F_(t+1)
=
U(F_t, Δ_t)
~~~

其中 Δ_t 可能來自：

~~~text
new input
new relation
new evidence
constraint change
~~~

~~~text
generic context weighting
~~~

# L4.75｜第三層崩塌條件：Reaction Body 只是漂亮名稱

若：

~~~text
coupling
reframing
residualization
stabilization
split
reopening
~~~

全部可以被既有 state-transition / graph dynamics 精確吸收，

且 Reaction Body 沒有額外區分力，

則 Reaction Body 應降級。

---

# L4.76｜第四層崩塌條件：CG 沒有獨立增量

若 closure tendency 可以完全由：

~~~text

task structure
termination rule
reward shaping
context statistics
~~~

解釋，

而 CG 不增加：

~~~text
prediction
diagnosis
governance target
~~~

則 CG 應降級為：

~~~text
umbrella term
for completion biases
~~~

---

# L4.77｜第五層崩塌條件：Residue 沒有歷史效應

若被淘汰／失去 standing 的 PATH 所留下資訊，

在控制其他條件後：

~~~text
never affects future generation
~~~

則：

~~~text
RESIDUE / HISTORY
~~~

不應被列為 L4 主樑。


> **一個模型說「我看見 PATH A 被壓制」，那是真的觀察，還是生成了一段漂亮的場性敘事？**


> **L4 描述場怎麼動；L5 才審我們到底看見了什麼。**
