# 14｜2.0 → 3.0 修正表

| 2.0 早期理解 | 3.0 / 現行修正 |
|---|---|
| PATH 近似候選可行路徑 | PATH 拆成 PATH_i / PATH_SPACE / PATH_STATE |
| 多 PATH 主要被理解成競爭 | PATH 可正交、合成、依賴、重框 |
| Reaction Body 偏競爭／收斂 | Reaction Body = structural motion |
| CG 像整體收斂機制 | CG = closure-directed pressure only |
| Attention 偏背景條件 | Attention = 一級 activation / salience 變數 |
| 被注意近似存在 | representation / activation / qualification 分離 |
| 生成可畫成順序鏈 | event-driven nonlinear field |
| 候選狀態近似無歷史 | residue / history 產生 path dependence |
| token 像生成基本單位 | token = visible serialization，不是 intelligence ontology |
| closure 近似唯一終點 | closure / reopening / non-closure 都可能成立 |
