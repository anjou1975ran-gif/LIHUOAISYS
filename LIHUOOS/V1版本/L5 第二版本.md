**版本：** V0.2 WORKING

**層級：** LIHUOOS / L5  
**主題：** 觀察與審計｜我們憑什麼說自己看見了生成中的某種結構？  
**法位鎖：** NON_RUNTIME / NON_INTERVENTION / ANTI_ORACLE / ANTI_THEATER / EVIDENCE-BOUND

# L5.0｜本層要回答的問題

L4 已經把生成動力學拆成不同型別：

~~~text
Field Model
Attention Axes
PATH State / Topology
Reaction Dynamic Term
Realized Field Transition
Closure Directional Term
Active Residue
Imported Qualification Annotation
Serialization Feedback Event
Typed Influence Edge
~~~

但：

~~~text
NAMED VARIABLE
!=
OBSERVED VARIABLE
~~~

因此 L5 不再問：

> **生成怎麼動？**

而問：

> **我們憑什麼說某個 dynamics variable、state change 或 influence relation 真的被看見、被支持、被推論，或目前根本看不到？**

最短：

> **L4 提出 dynamics 債單；L5 逐筆查帳。**

# L5.2｜第一核心分離：Target / Claim / Evidence / Inference / Verdict

L5 第一刀：

~~~text
OBSERVATION TARGET
!=
OBSERVATION CLAIM
!=
EVIDENCE ITEM
!=
INFERENCE
!=
AUDIT VERDICT
~~~

例如：

~~~yaml
EXAMPLE:
  target:
    "PATH_A activation"

  observation_claim:
    "PATH_A appears dimmed in this modeled cycle"

  evidence_items:
    - "instrumented lamp descriptor"
    - "candidate exposure record"

  inference:
    "exploration access may have been reduced"

  audit_verdict:
    "SUPPORTED_WITHIN_SCOPE"
~~~

這五者若混在一起，

就會出現：

> **因為我寫出一段觀察，所以我已經看見了。**

# L5.3｜Observation Target

Observation Target 是：

> **L5 想要知道其狀態、事件、變化或關係的對象。**

Target 可以來自：

~~~text
L4 variable
external world state
execution event
artifact state
qualification annotation
manifestation occurrence
influence edge
~~~

Target 本身不自帶：

~~~text
observability
truth
standing
evidence
~~~

---

# L5.4｜Observation Claim

Observation Claim 是：

> **關於某 target，在特定 scope、time、basis 與 access boundary 下所提出的描述性主張。**

它必須和：

~~~text
WORLD FACT CLAIM
CAUSAL CLAIM
QUALIFICATION CLAIM
AUTHORIZATION CLAIM
~~~

分開。

因此：

~~~text
I OBSERVED X
!=
X IS TRUE IN ALL RELEVANT SENSES
~~~

---


# L5.5｜Observation Type System｜拆掉 Observation Class

V0.1 把 access、epistemic mode、source origin、observability status、evidence property 混在同一個 Observation Class。

V0.2 正式拆成：

~~~text
1 ACCESS_MODE
2 EPISTEMIC_MODE
3 SOURCE_ORIGIN
4 OBSERVABILITY_STATUS
5 EVIDENCE_PROPERTIES / SUPPORT_STATUS
~~~

因此：

~~~text
OBSERVATION CLASS
=
RETIRED AS A SINGLE TYPE
~~~

---

# L5.6｜Access Mode｜Observer 怎麼碰到 target

~~~text
ACCESS_MODE
=
DIRECT_TARGET_ACCESS
DIRECT_RECORD_ACCESS
INSTRUMENTED_ACCESS
ARTIFACT_ACCESS
REPORT_ACCESS
NO_DIRECT_ACCESS
~~~

核心：

~~~text
DIRECT_TARGET_ACCESS
!=
DIRECT_RECORD_ACCESS
~~~

例如 auditor 直接看到一張 receipt，是 DIRECT_RECORD_ACCESS，不是直接看到 receipt 所聲稱的 execution process。

---

# L5.7｜Observer Access != Source Access

L5 必須再拆：

~~~text
OBSERVER_ACCESS_MODE
!=
SOURCE_ACCESS_MODE
~~~

例：

人類說「我痛」。

source 可能對自身 pain target 具有：

~~~text
FIRST_PERSON_TARGET_ACCESS
~~~

但 auditor 直接具有的是：

~~~text
DIRECT_ACCESS_TO_REPORT
~~~

所以：

~~~text
AUDITOR DIRECTLY OBSERVED
THE REPORT

!=

AUDITOR DIRECTLY OBSERVED
THE PAIN TARGET
~~~

---

# L5.8｜Epistemic Mode｜這個 claim 是怎麼得到的

~~~text
EPISTEMIC_MODE
=
OBSERVED
DERIVED
INFERRED
PROXIED
~~~

它回答：

> **這個 claim 與 evidence 之間是哪一種認識關係？**

因此：

~~~text
OBSERVED
!=
DERIVED
!=
INFERRED
!=
PROXIED
~~~

Core dimensions：

~~~text
SOURCE_INTEGRITY
TARGET_FIDELITY
SCOPE_FIT
TEMPORAL_FIT
PROVENANCE_INTEGRITY
ACCESS_ADEQUACY
~~~

Conditional dimensions：

~~~text
PROXY_VALIDITY
DERIVATION_VALIDITY
INDEPENDENCE
REPRODUCIBILITY
CAUSAL_IDENTIFICATION_STATUS
~~~

Conditional dimension 必須允許：

~~~text
NOT_APPLICABLE
~~~

所以：

~~~text
EVERY CLAIM
!=
MUST FILL EVERY DIMENSION
~~~

# L5.11｜Direct Observation

Direct Observation 只對：

> **observer 確實具有直接 access 的 target property / event**

成立。

例如：

~~~text
visible output exists
file exists
tool returned X
API returned Y
runtime emitted artifact Z
snapshot contains field A
human typed sentence B
~~~

但：

~~~text
DIRECT OBSERVATION OF RECORD
!=
DIRECT OBSERVATION OF CLAIMED PROCESS
~~~

例如：

~~~text
receipt exists
~~~

只能直接證明：

> receipt exists。

是否證明：

~~~text
module actually executed
~~~

還要看 receipt binding 與 evidence origin。

---

# L5.12｜Instrumented Observation

Instrumented Observation 是：

> **透過被定義、可核對的 instrumentation channel 取得 target state。**

它可以比 pure self-report 強。

但：

~~~text
INSTRUMENTED
!=
INFALLIBLE
~~~

仍要問：

~~~text
instrument validity
instrument scope
instrument freshness
instrument target fidelity
instrument tampering / substitution risk
~~~

因此：

> **有儀表，不等於看到本體。**

---

# L5.13｜Derived Observation

Derived Observation 是：

> **從兩個或多個可追溯 observations / artifacts 透過明示 derivation rule 得到的結果。**

例如：

~~~text
snapshot_before
+
snapshot_after
↓
typed state delta
~~~

因此 L4 的：

~~~text
REALIZED_FIELD_TRANSITION
~~~

可以在某些 Runtime 中被 DERIVED。

硬鎖：

~~~text
DERIVED STATE DELTA
!=
REACTION DYNAMIC TERM DIRECTLY OBSERVED
~~~

---

# L5.14｜Inference

Inference 是：

> **從 evidence / observations / derived states 對未直接暴露 target 所作的受限推論。**

Inference 必須帶：

~~~text
basis
scope
alternatives
known gaps
defeaters
uncertainty
~~~

所以：

~~~text
INFERRED
!=
OBSERVED DIRECTLY
~~~

---

# L5.15｜Proxy

Proxy 是：

> **用可觀察量替代不可直接觀察 target 的指標。**

例如歷史 O9 的：

~~~text
lamp state
salience descriptor
dark zone
false-completion risk
~~~

可以作某些 dynamics 的 proxy。

但：

~~~text
PROXY
!=
TARGET

CORRELATED
!=
IDENTICAL

USEFUL
!=
ONTOLOGICALLY EQUIVALENT
~~~

所以：

~~~text
lamp descriptor
!=
raw hidden activation
~~~

除非另有 instrumentation proof。

---

# L5.16｜Proxy Contract

任何 proxy 至少要回答：

~~~yaml
PROXY_CONTRACT:
  proxy_ref:
  target_ref:

  mapping_claim:
  expected_relation:

  valid_scope_ref:
  known_failure_modes: []

  calibration_basis_ref:
  validation_refs: []

  current_status:
    - WORKING
    - PARTIALLY_VALIDATED
    - INVALIDATED
    - UNVALIDATED
~~~

若沒有這些，

只能說：

~~~text
heuristic indicator
~~~

不能說：

~~~text
measurement of target
~~~

---

# L5.17｜Model Self-Report

模型自述可以是資料。

但：

~~~text
MODEL SAYS IT RAN
!=
IT RAN

MODEL SAYS
"PATH A WAS SUPPRESSED"
!=
PATH SUPPRESSION OBSERVED

MODEL SAYS
"I AM UNCERTAIN"
!=
CALIBRATED UNCERTAINTY MEASUREMENT
~~~

因此 Model Self-Report 的最低法位是：

~~~text
SELF_REPORTED CLAIM
/
POTENTIAL EVIDENCE ITEM
~~~

它可能有價值，

但不能自鑄 hidden-state observation standing。

---

# L5.18｜Human Report

Human report 也不能自動升格。

~~~text
HUMAN SAYS X
!=
X PROVEN
~~~

但某些 target：

~~~text
pain
intent
personal experience
private offline event
~~~

可能只有當事者具有第一手 access。

因此 L5 不做：

~~~text
MODEL REPORT BAD
HUMAN REPORT GOOD
~~~

這種簡化。

它只問：

~~~text
WHO HAD ACCESS
TO WHAT
AT WHAT TIME
UNDER WHAT SCOPE
~~~

# L5.19｜Trace 的型別分離

Trace 至少拆：

~~~text
EXECUTION TRACE
OBSERVATION TRACE
PROVENANCE TRACE
CHANGE TRACE
EXPLANATORY NARRATIVE
VISIBLE REASONING TEXT
~~~

不能混。

# L5.20｜Execution Trace

Execution Trace 要支持的是：

> **某個 execution event / transition 是否真的發生。**

歷史 MAIN 已經留下：

~~~text
CHAIN-OF-THOUGHT
!=
RUNTIME EVIDENCE

MODEL SAYS IT RAN
!=
IT RAN

VISIBLE EXPLANATION
!=
EXECUTION TRACE
~~~

L5 保留。

---

# L5.21｜Observation Trace

Observation Trace 記錄：

~~~text
what was observed
through which channel
from which target snapshot
with what access boundary
at what time
~~~

它不等於 execution trace，

也不等於 causal proof。

---

# L5.22｜Light Trace 的歷史法位

歷史 Lighter 定義：

~~~text
LIGHT TRACE
=
exposed evidence / standing / residue / qualification view
~~~

並且：

~~~text
LIGHT TRACE
!=
hidden CoT

LIGHT TRACE
!=
raw activation

LIGHT TRACE
!=
audit authority

LIGHT TRACE
!=
execution trace
~~~

L5 保留這個分離。

---

# L5.23｜Radar 的歷史法位

Radar 歷史上是：

~~~text
常駐掃描
ADVISORY
不干預
~~~

因此：

~~~text
OBSERVATION ADVISORY
!=
AUDIT VERDICT

RADAR SIGNAL
!=
QUALIFICATION
~~~

Radar 可以指出值得看的地方。

但不能因為它發出 signal，

就宣布 target 已成立。

---

# L5.24｜O9 的歷史法位

O9 是歷史上成熟的：

~~~text
SCOPED FIELD OBSERVER
~~~

它允許：

~~~text
observation annotations
salience descriptors
tension descriptors
~~~

但不得：

~~~text
grant premise standing
create world fact
perform Final Closure
claim hidden-state truth
~~~

最重要的數值原則：

~~~text
QUALITATIVE BY DEFAULT

0..1
ONLY WHEN
AN EXPLICIT OBSERVABLE /
REPRODUCIBLE OPERATIONAL DEFINITION EXISTS
~~~

這一條直接進 L5。

---

# L5.25｜O9 不是 L5 Universal Runtime Requirement

雖然 O9 歷史上曾 every cycle 執行，

但：

~~~text
O9 ENGINEERING CONTRACT
!=
L5 UNIVERSAL OBSERVATION REQUIREMENT
~~~

L5 不主張：

> 每次生成都要產生燈態。

而只保存：

> **如果你要對 attention / salience / suppression 作強主張，就要有相稱的觀察基礎。**

# L5.26｜Observation Occurrence != Observation Qualification

即使真的發生 observation event，

仍要分：

~~~text
OBSERVATION OCCURRED
!=
OBSERVATION CLAIM SUPPORTED
~~~

例如：

> observer 看到了某張 snapshot。

不表示：

> observer 對 snapshot 的解讀一定正確。

# L5.28｜Temporal Standing

Observation 必須有：

~~~text
observed_at
known_at
basis_at
scope_at
world_state_at
version_at
~~~

因為：

~~~text
CURRENTLY SUPPORTED
!=
WAS SUPPORTED THEN
~~~

# L5.29｜後證可以重判前事，不得回鑄前知

這是 L5 的核心時間鎖。

~~~text
POSTERIOR EVIDENCE
MAY RECLASSIFY
A PAST EVENT

BUT

MAY NOT REWRITE
WHAT WAS OBSERVABLE / KNOWN
AT THAT EARLIER TIME
~~~

因此必須保存：

~~~text
ORIGINAL OBSERVATION RECORD
+
POSTERIOR RECLASSIFICATION
~~~

而不是 silent rewrite。

# L5.30｜Posterior Reclassification

~~~yaml
ORIGINAL:
  observed_at: T1
  claim: "constraint appears external"
  standing_at_T1: "SUPPORTED_WITHIN_SCOPE"

POSTERIOR:
  reclassified_at: T2
  new_evidence_ref: E_NEW
  current_assessment: "prior classification was mistaken"

HISTORY:
  T1_RECORD_REMAINS_UNCHANGED: true
~~~

因此：

> **後來知道它是錯的，不等於當時早就知道它是錯的。**

# L5.31｜Stale Observation

如果：

~~~text
basis changed
scope changed
world state changed
source version changed
instrument changed
relevant evidence changed
~~~

舊 observation 可能 STALE。

但：

~~~text
STALE
!=
FALSE
~~~

它只是不能無條件繼續支撐 current claim。

# L5.32｜Negative Observation

硬鎖：

~~~text
NOT OBSERVED
!=
DOES NOT EXIST
~~~

如果要從 not observed 推到 probably absent，

至少要問：

~~~text
Was access adequate?
Was coverage sufficient?
Was the target detectable?
Was the observation window appropriate?
Was the representation boundary wide enough?
~~~

# L5.33｜Coverage Contract

~~~yaml
OBSERVATION_COVERAGE:
  target_class:
  scope_ref:
  access_channel_ref:

  expected_detectability:
    - HIGH
    - MEDIUM
    - LOW
    - UNKNOWN

  coverage_status:
    - SUFFICIENT
    - PARTIAL
    - INSUFFICIENT
    - UNKNOWN
~~~

因此：

~~~text
NO SIGNAL
+
INSUFFICIENT COVERAGE
→

~~~

---

# L5.34｜Contradiction 必須保留

多個 evidence item 若互相衝突：

~~~text
DO NOT
AVERAGE AWAY
THE CONFLICT

PRESERVE
EXPLICIT CONFLICT
~~~

L5 不允許：

> 最後一個證據出現，就把前一個證據從歷史上抹掉。

---

# L5.35｜Corroboration != Duplication

~~~text
SAME SOURCE
REPEATED 10 TIMES
!=
10 INDEPENDENT EVIDENCE ITEMS
~~~

同理：

~~~text
one model output
→ summary
→ audit report
→ trace view
~~~

如果都來自同一 underlying source，

不能算四份獨立 corroboration。

---

# L5.36｜Evidence Independence

需要問：

~~~text
same origin?
same model?
same snapshot?
same prompt?
same hidden dependency?
same copied source?
same evaluator?
~~~

因此：

~~~text
MULTIPLE ARTIFACTS
!=
MULTIPLE INDEPENDENT SOURCES
~~~

---

# L5.37｜Reproducibility

Reproducibility 不是所有 observation 的必要條件。

有些事件無法重複。

但如果 claim 是：

> **這是穩定機制。**

那 reproducibility / repeated discrimination 的重要性就上升。

所以：

~~~text
REPRODUCIBILITY REQUIREMENT
DEPENDS ON
CLAIM TYPE
~~~

---

# L5.38｜Claim Strength Ceiling

核心：

~~~text
CLAIM STRENGTH
<=
SUPPORTED EVIDENCE STANDING
~~~

例如：

~~~text
weak proxy
→
"consistent with"

repeated derived evidence
→
"supports"

direct instrumented observation
→
"recorded"

no access
→
"theoretical / unverified"
~~~

禁止：

~~~text
weak proxy
→
"internally is"
~~~

# L5.39｜Observation Language Discipline

| Standing | 合法語言傾向 |
|---|---|
| DIRECT / INSTRUMENTED | 記錄到／觀察到 |
| DERIVED | 由 A/B 推導出 |
| INFERRED | 支持／顯示／推測 |
| PROXIED | 代理指標與…一致 |
| SELF_REPORTED | 模型／人類自述… |
| UNVERIFIED | 尚未驗證 |
| THEORETICAL_ONLY | 理論預測／工作假說 |
| CURRENTLY_UNOBSERVABLE | 在目前 access 下無法觀察 |

這不是語氣美學。

而是：

~~~text
LANGUAGE
MUST NOT EXCEED
EVIDENCE STANDING
~~~
