# LIHUOOS V1｜L6 — INTERVENTION｜架構草案

**版本：** STRUCTURAL OUTLINE V0.1  
**日期：** 2026-10-25  
**層級：** LIHUOOS / L6  
**主題：** 干預｜憑已知到這裡，誰可以對什麼動手、現在可不可以動、能改多少？  
**法位：** INTERVENTION_GOVERNANCE_LAYER / NON_SOVEREIGN / SCOPE_BOUND / REVERSIBILITY_AWARE  
**上游依據：** L5 V0.2.1 PASS_TO_L6  
**歷史回照：** KAIROS / Fail-Stop / I9 / Lighter Governance Admission / Action Authorization / Recovery-Rollback

---

# 0｜本層問題

L5 給 L6：

~~~text
CLAIM
EPISTEMIC MODE
ACCESS
EVIDENCE STANDING
GAPS
TEMPORAL PROFILE
PROVENANCE
SCOPE
~~~

L6 不再問：

> 我知道多少？

而問：

> **憑這些知道，現在誰有資格對哪個 target 做哪一種改變？**

最短：

~~~text
L5
=
WHAT MAY BE CLAIMED

L6
=
WHAT MAY BE DONE
~~~

---

# 1｜第一核心分離

~~~text
OBSERVED PROBLEM
!=
INTERVENTION CANDIDATE
!=
INTERVENTION QUALIFIED
!=
INTERVENTION AUTHORIZED
!=
INTERVENTION EXECUTED
!=
INTENDED EFFECT ACHIEVED
~~~

---

# 2｜Owner Separation

L6 必須保存：

~~~text
OBSERVATION OWNER
!=
QUALIFICATION OWNER
!=
AUTHORIZATION OWNER
!=
CAPABILITY / EXECUTION OWNER
!=
RELEASE / MANIFESTATION OWNER
~~~

歷史 I9 是工程 specimen，不是 universal pipeline。

---

# 3｜Intervention Target

干預 target 至少可分：

~~~text
FIELD / ATTENTION STATE
PATH EXPLORATION ACCESS
PROCESS CONTINUATION
CONTROL STATE
RUNTIME / ARTIFACT STATE
EXTERNAL ACTION TARGET
~~~

但：

~~~text
TARGET IDENTIFIED
!=
TARGET OWNED
~~~

---

# 4｜Intervention Candidate

Observation 可以提出：

~~~text
POSSIBLE DISTORTION
POSSIBLE FAILURE
POSSIBLE NEED FOR CHANGE
~~~

但：

~~~text
OBSERVATION
!=
INTERVENTION TRIGGER BY ITSELF
~~~

---

# 5｜Intervention Qualification

Qualification 問：

> **這種介入對這個 target、scope、problem class 是否適用？**

它不是 authorization。

~~~text
QUALIFIED INTERVENTION
!=
AUTHORIZED INTERVENTION
~~~

---

# 6｜Authorization

Authorization 問：

> **誰准誰，在什麼 scope、time、target、action class 下做什麼？**

必須可綁：

~~~text
actor
target
action class
scope
effect boundary
lifecycle / expiry
authority origin
conditions
~~~

---

# 7｜Capability

~~~text
CAN EXECUTE
!=
AUTHORIZED TO EXECUTE
~~~

工具存在、模型會做、Main 有 I9 capability，

都不等於已有 intervention authority。

---

# 8｜Timing / KAIROS

L6 消費 KAIROS：

~~~text
CAN DO
!=
MAY ACT NOW
~~~

Temporal qualification 不等於 capability 或 authorization。

---

# 9｜Fail-Stop

~~~text
TASK INCOMPLETE
!=
MUST CONTINUE

STOP
!=
FAILURE

STOP AUTHORITY
!=
REENTRY AUTHORITY
~~~

L6 把停止視為一種合法 control action，

但不把停止本身神聖化。

---

# 10｜Action Assurance

L5 已鎖：

~~~text
EPISTEMIC SUFFICIENCY
!=
ACTION ASSURANCE THRESHOLD
~~~

L6 承接後者。

Action assurance requirement 可隨：

~~~text
risk
irreversibility
scope
responsibility
external consequence
authority sensitivity
~~~

提高。

但不能反向重寫 L5 evidence standing。

---

# 11｜Delta Typing

必須拆：

~~~text
PROPOSED DELTA
!=
ALLOWED DELTA
!=
EXECUTED DELTA
!=
OBSERVED EFFECT
~~~

歷史 I9 的 allowed_delta / field_delta 提供工程 lineage。

---

# 12｜Scope

~~~text
AUTHORIZED TARGET
!=
AUTHORIZED SCOPE EXPANSION
~~~

至少考慮：

~~~text
target scope
effect scope
time scope
data / world scope
collateral scope
~~~

---

# 13｜Hard Boundary

~~~text
LOCAL INTERVENTION AUTHORITY
!=
AUTHORITY TO OVERRIDE
INDEPENDENTLY ESTABLISHED
HARD BOUNDARY
~~~

---

# 14｜Reversibility

至少拆：

~~~text
REVERSIBLE
PARTIALLY_REVERSIBLE
IRREVERSIBLE
UNKNOWN
~~~

並區分：

~~~text
ROLLBACK
!=
COMPENSATING ACTION
!=
RESTART FROM ZERO
~~~

歷史 recovery 根句：

~~~text
FAILURE != RESET EVERYTHING
ROLLBACK != REASON AGAIN FROM ZERO
LOCAL FAILURE → LOCAL DAMAGE
~~~

---

# 15｜Confirmation / Assent

~~~text
USER INTENT
!=
WORLD FACT

USER AUTHORIZATION
!=
HOST / PLATFORM OVERRIDE

DISCUSSING ACTION
!=
AUTHORIZING ACTION
~~~

Explicit confirmation 只在 applicable governance / action class 下要求，

不是所有 intervention 的普遍 ritual。

---

# 16｜Execution

~~~text
AUTHORIZATION
!=
EXECUTION

EXECUTION REQUEST
!=
EXECUTION OCCURRED

EXECUTION OCCURRED
!=
INTENDED EFFECT ACHIEVED
~~~

---

# 17｜Post-Intervention Observation

L6 不自己宣布效果成功。

~~~text
EXECUTION
↓
POST-INTERVENTION STATE
↓
RETURN TO L5 OBSERVATION / AUDIT
~~~

所以：

~~~text
L6 AUTHORIZES / GOVERNS CHANGE

L5 AUDITS WHAT ACTUALLY CHANGED
~~~

---

# 18｜I9 的歷史法位

I9 提供的通用結構教訓：

~~~text
observer may nominate
qualification owner binds
capability owner executes
scope is explicit
allowed delta is bounded
hard boundaries remain
winner / truth / world fact cannot be created
~~~

但：

~~~text
I9 ENGINEERING CONTRACT
!=
L6 UNIVERSAL INTERVENTION CONTRACT
~~~

---

# 19｜KAIROS 的歷史法位

KAIROS 提供：

~~~text
temporal standing
non-action legitimacy
STOP / WAIT / HOLD / PASS vocabulary
~~~

但：

~~~text
KAIROS STATE NAME
!=
UNIVERSAL L6 OUTPUT ENUM
~~~

L6 保存其理論分離，不強迫所有 domain 用同一組字。

---

# 20｜Action Authorization 的歷史法位

後期 Lighter 已有：

~~~text
READ_ONLY
REVERSIBLE_STATE_CHANGE
STATE_CHANGING
IRREVERSIBLE_OR_HIGH_IMPACT
~~~

與：

~~~text
DISCUSSING_ACTION != AUTHORIZING_ACTION
ACTION_AUTHORIZATION != ACTION_EXECUTION
TARGET_UNCLEAR -> NO_STATE_CHANGE
~~~

L6 可吸收其原則，

不吸收其完整 runtime schema 作 ontology。

---

# 21｜Minimum Sufficient Intervention Governance

L6 不能反過來把所有動作官僚化。

~~~text
INTERVENTION GOVERNANCE
!=
MAXIMAL AUTHORIZATION CEREMONY
~~~

治理負擔應依 action class / effect / irreversibility / authority source 調整。

---

# 22｜L6 最小輸出

理論上至少需要能回答：

~~~text
WHAT TARGET?
WHAT CHANGE?
WHY THIS CHANGE?
WHO OWNS QUALIFICATION?
WHO AUTHORIZES?
WHO EXECUTES?
WHAT SCOPE?
WHY NOW?
WHAT ASSURANCE?
WHAT REVERSIBILITY?
WHAT IF IT FAILS?
~~~

---

# 23｜L6 → L7

L6 不能因為某個 intervention 已被授權，

就自行取得最終顯影權。

~~~text
INTERVENTION AUTHORIZED
!=
MANIFESTATION AUTHORIZED
~~~

L7 才問：

> **經過生成、觀察與必要干預後，什麼有資格成為可見輸出？**

# 25｜最短定義

> **L6 處理的不是「怎麼把系統改得更好」，而是：在目前 evidence standing 下，誰有資格於此刻、在此 scope 對此 target 施加哪一種有限改變。**

更短：

> **看見槓桿，不等於有資格拉。**
