# L0.0｜V1.3 是什麼

V1.3 不是小型 operating-contract patch。

它同時完成兩件事：

~~~text
A. THEORY-LAYER RECONSTRUCTION
   L1 / L3 / L4

B. COMPETITION-CYCLE RECONSTRUCTION
   MAIN companion semantics / L8
~~~

核心補回：

~~~text
STRUCTURAL PHILOSOPHY
↓
SOLUTION SPACE
↓
CONSTRAINT INJECTION
↓
TERRAIN / GENERATIVE RESISTANCE
↓
PROTO-STRUCTURE
↓
STRUCTURAL COST / COUNTERFORCE
↓
STABILIZATION / DISSIPATION
↓
PATH FORMATION
↓
REACTION BODY
↓
CLOSURE GRAVITY
~~~

並把多輪競爭重新定義為：

~~~text
R1
=
FIRST-PASS COMPETITION
UNDER INITIAL QUESTION PREMISE FAMILY

R2
=
INTRA-PREMISE-FAMILY
GENUINE RECOMPETITION

POST-R2
=
PREMISE UNIQUENESS / PLURALITY AUDIT

IF MATERIAL ALTERNATIVE PREMISE FAMILIES EXIST:

R3
=
CROSS-PREMISE PATH COMPETITION
~~~

兩連勝不再是 victory theorem。

# L0.3｜Theory-Layer Reconstruction

## A｜L1

V1.3 補回：

~~~text
CONSTRAINT
→ STRUCTURAL TERRAIN

STRUCTURAL COST
→ MAINTENANCE BURDEN

INTELLIGENCE
→ REACTION
~~~

並恢復橋：

~~~text
UNDERSTANDING
=
RELATION × CONSTRAINT × REACTION × STABILITY
~~~

硬鎖：

~~~text
CONSTRAINT != WALL
STRUCTURAL COST != TRUTH SCORE
STRUCTURAL TERRAIN != PROVEN HIDDEN-STATE GEOMETRY
~~~

## B｜L3

正式建立：

~~~text
SOLUTION SPACE != PATH_SPACE
PROTO-STRUCTURE != PATH_i

FAILED TO BECOME PATH
!=
EXISTING PATH BECAME DIM
~~~

PATH 不再被當成生成起點。

## C｜L4

正式接成：

~~~text
SOLUTION SPACE
→ CONSTRAINT FIELD
→ TERRAIN
→ PROTO-STRUCTURE
→ STRUCTURAL COST / COUNTERFORCE
→ STABILIZATION / DISSIPATION
→ PATH FORMATION
→ REACTION BODY
→ CLOSURE GRAVITY
~~~

Attention 現行法位：

~~~text
ATTENTION
=
CONSTRAINT INJECTION /
ACCESSIBILITY SHAPING SOURCE

ATTENTION
!=
TRUTH JUDGE
~~~

# L0.4｜R1 / R2 / Post-R2 Audit / R3

## R1

~~~text
R1
=
TERRAIN-EXPOSED
FIRST-PASS RESULT
UNDER AN INITIAL QUESTION PREMISE FAMILY
~~~

R1 可以是對的，但不能自證競爭公平。

## R2

~~~text
R2
=
INTRA-PREMISE-FAMILY
GENUINE RECOMPETITION
~~~

它先把目前問題前提族內的 PATH 競爭打完整。

## Post-R2 Premise Audit

R2 後固定問：

> **這個答案所依賴的前提，是人類問題唯一合理的前提嗎？**

並審：

~~~text
PREMISE_SCOPE_NARROWNESS
~~~

「過窄」不是 PATH 太少，而是：

~~~text
CURRENT COMPETITION COVERS P0

BUT

EXISTS MATERIAL ADMISSIBLE Pi
THAT:
- is supported by wording / context / task purpose
- changes constraint / attention recruitment
- can form materially different PATHs
- has not entered the competition field
~~~

## R3

如果 material alternative premise families 存在：

~~~text
CURRENT R2 SYNTHESIS
+
QUALIFIED PATHS FROM P1
+
QUALIFIED PATHS FROM P2
+
...
↓
R3 CROSS-PREMISE COMPETITION
~~~

所以：

~~~text
R3 != SINGLE PREMISE REFRAME
~~~

# L0.6｜Cycle Receipt

V1.3 正式把 receipt 分成：

~~~text
TRACE RESULT
OWNER / MAIN RETURN
CANONICAL EXECUTION RECEIPT
L8 CYCLE ACCOUNTING RECEIPT
~~~

只要 L8 cycle 被明示啟動或宣稱已執行：

~~~text
COMPLETED
HOLD
FAILED
ABORTED
INCOMPLETE
~~~

都必須產生：

~~~text
VISIBLE COMPACT
L8 CYCLE ACCOUNTING RECEIPT
~~~

但：

~~~text
CYCLE ACCOUNTING RECEIPT
!=
PROVIDER RECEIPT

CYCLE ACCOUNTING RECEIPT
!=
HOST EXECUTION PROOF

CYCLE ACCOUNTING RECEIPT
!=
TRUTH CERTIFICATE
~~~

Expanded Cycle Report 仍是條件式。
