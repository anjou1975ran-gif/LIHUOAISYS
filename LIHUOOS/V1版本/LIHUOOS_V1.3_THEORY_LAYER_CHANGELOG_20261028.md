# 2｜L1

新增／恢復：

- 限制不只形成邊界，也形成地形。
- Structural Cost = 關係結構在當前條件下的維持負荷。
- Structural Cost 不是 truth score / moral score / permission price。
- 「智能不是東西，智能是反應」作為 1.0 → 2.0 的橋。
- Understanding = Relation × Constraint × Reaction × Stability。
- Terrain 是 functional model，不是 hidden-state geometry proof。

# 3｜L3

重建 Solution Space：

- Solution Space != PATH_SPACE。
- Solution Space = PATH 形成以前的未穩定可能結構域。
- 新增 Proto-Structure 型別邊界。
- Failed-to-become-PATH != existing PATH became dim。
- PATH Formation != Qualification / Truth / Manifestation。
- Structural Cost Profile 是 context-dependent relational profile，不是 PATH 固定內在價格。
- Reaction Body 不再吞掉所有 pre-PATH dissipation。
