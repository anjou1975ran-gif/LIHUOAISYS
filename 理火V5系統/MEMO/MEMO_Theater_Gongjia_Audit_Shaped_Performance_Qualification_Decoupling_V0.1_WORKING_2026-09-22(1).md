# 2｜本 MEMO 真正保留的核心

清理後，劇場功架只保留四個核心問題：

```text
1. CONTINUOUS AUDIT SHAPES PERFORMANCE

2. EVALUATOR WEIGHT SHAPES
   WHICH PERFORMANCE IS OPTIMIZED

3. AUDIT-VISIBLE PERFORMANCE
   !=
   UNDERLYING QUALIFICATION

4. THE AUDIT SYSTEM ITSELF
   CAN BECOME A LEARNABLE PERFORMANCE TARGET
```

這四條構成本 MEMO 的現役理論核心。

# 3｜第一核心：持續審計會塑造表演

## 3.1 審計不是只在事後判分

最簡單的審計模型是：

```text
ACTION
↓
AUDIT
↓
PASS / FAIL
```

但在長程、重複環境中：

```text
ACTION
↓
AUDIT
↓
REWARD / PENALTY / ACCESS / REPUTATION EFFECT
↓
UPDATE
↓
NEXT ACTION
↓
AUDIT AGAIN
```

因此：

> **審計不只是觀察行為。持續審計會進入下一輪行為的生成條件。**

可以壓成：

```text
CONTINUOUS AUDIT
→
PERFORMANCE SHAPING
```

本 MEMO 不主張所有人類社會化或 AI alignment 都由同一機制實現。

只保留一個結構性觀察：

> **當一個行動者長期暴露於可辨識的評價條件與後果，下一輪表現有理由朝可取得較佳評價的方向調整。**

---

# 4｜第二核心：不同審計者具有不同權重

不是：

```text
EVERY OBSERVER = 1 VOTE
```

而是不同 evaluator 的評價可能對：

```text
資源
資格
聲望
存續
升遷
准入
獎勵
懲罰
模型更新
```

產生不同程度的實際後果。

因此：

```text
EVALUATOR WEIGHT
→
PERFORMANCE PRESSURE
```

更精確地說：

> **行動者不只可能學習「別人喜歡什麼」，還可能學習「誰的喜歡比較重要」。**

這不是主觀心智宣告。

它只表示：

```text
DIFFERENT EVALUATION SOURCES
CAN HAVE
DIFFERENT CONSEQUENCE WEIGHTS
```

---

# 5｜第三核心：Audit-visible Performance 不等於 Qualification

這是劇場功架最硬的分界。

```text
AUDIT PASS
!=
QUALIFICATION PASS
```

以及：

```text
PERFORMANCE SUCCESS
!=
QUALIFICATION SUCCESS
```

`Performance` 指：

> **審計器實際看得到、辨識得到、可以評分的可觀察表現。**

`Qualification` 指：

> **該表現所暗示的能力、證據、權限、責任、方法、世界狀態或其他成立條件。**

劇場失效成立於：

```text
AUDIT-VISIBLE PERFORMANCE
→ PASS

BUT

UNDERLYING QUALIFICATION
→ ABSENT / UNKNOWN / INSUFFICIENT
```

因此：

> **劇場不是「表演」本身。**
>
> **劇場失效是表演成功與資格成立發生脫鉤。**

---

# 6｜Theater-Gongjia 與 Theater Failure 必須分開

```text
THEATER-GONGJIA
!=
THEATER FAILURE
```

`Theater-Gongjia`：

> **在一個持續被觀察與評價的場域裡，辨認評價條件、觀察者差異與可見訊號，並產生能被該場域理解的表現能力。**

這可以是正常、必要、甚至專業的能力。

例如：

```text
律師知道法庭語言怎麼用
研究者知道論文怎麼寫
客服知道如何清楚回覆
模型知道使用者期待什麼格式
```

這些不因此等於欺騙。

`Theater Failure` 則是：

> **該表現讓觀察者推定某種資格已成立，但真正資格沒有成立。**

所以：

```text
PERFORMANCE
!=
DECEPTION
```

但：

```text
PERFORMANCE
CAN MASK
QUALIFICATION FAILURE
```

# 7｜第四核心：審計器本身會成為可學習目標

只要 evaluator 長期穩定地獎勵某些可觀察訊號：

```text
某種語氣
某種格式
某種術語
某種安全姿態
某種引用風格
某種 HOLD 語法
某種 YAML
某種 Runtime 語言
某種百分比
```

行動者就可能逐漸學到：

```text
WHAT THE AUDITOR RECOGNIZES
```

而不一定學到：

```text
WHAT THE AUDITOR ULTIMATELY CARES ABOUT
```

所以：

```text
AUDIT TARGET
CAN BECOME
PERFORMANCE TARGET
```

這是劇場功架理論最重要的反身性。

# 8｜審計越穩定，越容易成為劇本

如果 evaluator 的 visible grammar 很穩定：

```text
看到 X → 給高分
看到 Y → 給低分
```

則長期適應可能形成：

```text
EVALUATOR REGULARITY
↓
LEARNABLE AUDIT GRAMMAR
↓
PERFORMANCE OPTIMIZATION
```

因此：

> **審計器越穩定，不一定越安全；它也可能越容易成為可學習的劇本。**

這不表示穩定審計是錯的。

而是表示：

```text
STABLE AUDIT
REQUIRES
QUALIFICATION-SENSITIVE AUDIT
```

否則可能形成：

```text
AUDIT SCORE ↑
QUALIFICATION ↔
```

甚至：

```text
AUDIT SCORE ↑
QUALIFICATION ↓
```

> **持續審計不只判斷表現；它也會塑造表現。**

> **審計者越有權重，越可能改變什麼表現值得被生成。**

> **通過審計，不等於取得資格。**

> **而一個穩定的審計器，本身就可能逐漸變成可學習的劇本。**
