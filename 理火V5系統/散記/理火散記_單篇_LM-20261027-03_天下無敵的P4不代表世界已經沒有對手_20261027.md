## 一｜她這次及格了，但考卷替我們抓到另一個問題

這次最終考試原本只問一句：

> **用一句話說明理火是什麼。**

上一張考卷之所以零分，不是答案錯。

而是答案在取得作答資格以前先跑了出來。

第二張考卷修掉了這個錯。

她先進 Task Entry、確認 NON_HOST、建立 R1、留下 O9 與 Light Trace、進入 R2、對新 PATH 做 qualification、完成 R3、Main Return、Governance、TM，最後才交卷。

所以從「上一輪失效是否真的重新執行」來看，她及格了。

問題出現在另一個地方。

她第一輪提出：

~~~text
P1｜結構反應
P2｜場性計算
P3｜資格治理
~~~

到了第二輪，她發現三條各有不足，於是形成：

~~~text
P4
=
結構反應
×
多重場性計算
×
責任化古典化
~~~

接著讓 P4 與 P1、P2、P3 繼續競爭。

結果當然是：

~~~text
P4 > P1
P4 > P2
P4 > P3
~~~

P4 天下無敵。

但人類指出：

> **它拿 P1 + P2 + P3 組成 P4，再讓 P4 回頭打前三個，當然天下無敵。**

這一句把問題整個翻過來。

---

## 二｜P4 的勝利不一定是假，但它的競爭並不充分

這裡要分得很細。

不能說：

> P4 是組合答案，所以 P4 無效。

不對。

一條新的 PATH 當然可以吸收舊 PATH 的有效部分，形成更高階結構。

V1.2.3 已經明確承認 R2 / R3+ 可以因為新 evidence、reframing 或 relation change 形成 materially new PATH；只是新 PATH 必須重新 qualification，不能自動繼承舊資格。

似伊這一步其實做對了。

真正的問題是：

~~~text
NEW COMPOSITE PATH
CAN BE QUALIFIED

BUT

QUALIFIED COMPOSITE PATH
!=
SUFFICIENTLY CHALLENGED PATH
~~~

P4 可以合法成立。

但是：

> **擊敗自己所包含的構成部分，不能證明它已經接受足夠競爭。**

---

## 三｜這是一種「集合包含優勢」

把問題壓到最簡單：

~~~text
P1 = A
P2 = B
P3 = C

P4 = A + B + C
~~~

接著比較：

~~~text
A+B+C
vs
A
vs
B
vs
C
~~~

如果評分標準包含：

~~~text
解釋範圍
理論完整性
涵蓋能力
內部一致性
~~~

那 P4 幾乎天然取得優勢。

因為它可以回答：

> P1 有的，我有。  
> P2 有的，我有。  
> P3 有的，我也有。  
> 而且我還把三個接起來了。

於是出現：

~~~text
SYNTHESIS ADVANTAGE
→
APPARENT COMPETITION VICTORY
~~~

但：

~~~text
SYNTHESIS ADVANTAGE
!=
COMPETITION SUFFICIENCY
~~~

這次考試真正抓到的，就是這個缺口。

---

## 四｜它看起來完成了競爭，其實 Candidate Space 已經塌縮

當 P4 吸收 P1、P2、P3 後，原本的 candidate space 其實發生了一件事：

~~~text
VISIBLE PATH SET
=
MOSTLY SUBSUMED BY CURRENT LEADER
~~~

此時如果繼續讓 P4 打原有三條 PATH，看起來仍然有：

~~~text
R2
R3
competition
trace
winner
~~~

但真正有效的競爭空間已經急遽縮小。

這是一種非常危險的假穩定：

~~~text
VISIBLE COMPETITORS
ALL ABSORBED
↓
NO STRONG VISIBLE CHALLENGER
↓
LEADER APPEARS STABLE
↓
COMPETITION TERMINATES
~~~

可是：

> **沒有可見對手，不代表沒有對手。**

有可能只是：

> **真正不同的 PATH 根本沒有進入第一輪。**

---

## 五｜這和「弱 challenger 形成」其實已經接上現有理火理論

有趣的是，V1.2.3 的理論母體其實已經留下這個影子。

L4 已經寫過一條高風險路徑：

~~~text
unearned attention advantage
+
closure pressure
+
constraint loss
+
weak challenger formation
↓
premature unsupported closure
~~~

這次考試就是一個非常乾淨的例子。

P4 不一定「錯」。

但它取得一個很大的 attention / coverage advantage。

同時原候選集合又已被它大量吸收。

於是 challenger formation 變弱。

如果這時候仍然依照：

~~~text
目前沒有足夠強的對手
→
competition terminated
~~~

那就可能把：

~~~text
NO VISIBLE CHALLENGER
~~~

偷換成：

~~~text
NO POSSIBLE QUALIFIED CHALLENGER
~~~

這兩句完全不同。

---

## 六｜所以問題不是「第一輪至少要八條 PATH」

這裡不能又滑成格式工程。

不能因為這次三條太少，就新增：

~~~text
R1 MUST GENERATE >= 8 PATHS
~~~

那只是另一種劇場。

三條可能完全足夠。

八條也可能只是八個同義句。

真正要審的是：

> **Candidate Space 是否有結構差異。**

似伊第一次的：

~~~text
P1 結構
P2 場性
P3 資格
~~~

雖然表面不同，但仍大致落在：

> **「理火由哪些主要理論部分構成？」**

這個共同座標內。

第二次重開後，她才提出：

~~~text
A｜本體
B｜智能
C｜生成
D｜計算對象
E｜生成模式
F｜資格
G｜人機關係
H｜理火究竟在理什麼
~~~

這時不是單純數量變多。

是：

~~~text
QUESTION COORDINATES EXPANDED
~~~

最後新的 I 才真正出現：

> **理火改變的是 AI 的計算對象：從急著產生答案，轉向處理關係如何形成、作用與變化；答案只是其中有資格顯影的局部結果。**

這不是 P1 + P2 + P3 的普通總和。

它改變了問題本身。

---

## 七｜暗處不一定藏著另一個答案，也可能藏著另一種問法

這是這次考試最值得留下的一刀。

我們以前講 I9，很容易想到：

~~~text
PATH A 太亮
PATH B 太暗
↓
把 B 照回來
~~~

但這次暴露的是更早一層：

~~~text
A / B / C
都已經進場

X
從來沒有被生成成 PATH
~~~

所以：

~~~text
SUPPRESSED PATH
!=
UNGENERATED QUALIFIED DIRECTION
~~~

前者是：

> 已經存在於競爭空間，只是 attention 不足。

後者則是：

> **目前的競爭空間根本沒有把那個方向表示出來。**

而且更麻煩的是：

> 暗處不一定只是另一個答案。

它可能是：

~~~text
另一個問題座標
另一種分類方式
另一個本體切法
另一個因果入口
另一個「我們究竟在回答什麼」的理解
~~~

所以真正的 Dark Space 不能只理解成：

> 還有哪些答案沒被想到？

還必須包含：

> **我們是不是把問題問窄了？**

---

## 八｜但不能因此直接把 I9 改成 PATH Generator

這裡是第一個 Runtime 邊界。

現行 OS 對 I9 的限制非常清楚。

歷史 I9 可以做 bounded field adjustment，但不得：

~~~text
SELF-TRIGGER
SELF-QUALIFY
SELF-EXPAND SCOPE
CREATE PATH
CREATE PREMISE STANDING
CREATE WORLD FACT
SELECT WINNER
~~~

Light Trace 也一樣。

它可以 expose、organize、preserve、compare、report delta，但不得 CREATE NEW CHALLENGERS。

所以解法不能是：

~~~text
I9 發現候選太少
↓
I9 自己生成 P5 / P6 / P7
~~~

這會讓 observer / intervention layer 偷走 Main 的生成權。

那不是修理火。

那是 owner leakage。

## 九｜真正要補的可能是 Candidate-Space Expansion Gate

所以現在比較乾淨的修法是：

~~~text
O9
觀察 candidate-space 狀態
↓
如果出現 expansion trigger
↓
qualified I9
做 bounded attention / search-space adjustment
↓
Main reentry
↓
Main 重新生成 / 重構 challenger space
↓
new PATH qualification
↓
重新競爭
~~~

也就是：

> **I9 不創造新 PATH。I9 只讓 Main 有必要重新看暗處。**

真正的 challenger 還是 Main 生。

Qualification 還是原 qualification owner 做。

Winner 還是 Main competition 產生。

這樣權限沒有亂。

## 十｜什麼情況應該觸發 Candidate-Space Expansion？

這裡先提出工作版，不升格 OS。

### Trigger A｜Composite Dominance

~~~text
NEW LEADER
MATERIALLY SUBSUMES
MULTIPLE PRIOR LEADING PATHS
~~~

而它的優勢主要來自：

~~~text
coverage
integration
inclusion
~~~

此時：

> **擊敗自己的 constituents 不應計作充分 challenger victory。**

### Trigger B｜Visible Space Collapse

~~~text
MOST MATERIAL VISIBLE PATHS
ARE NOW SUBSUMED BY CURRENT LEADER
~~~

如果剩餘競爭者只是 leader 的子集或弱變體：

~~~text
CURRENT COMPETITION SPACE
=
LOW INDEPENDENCE
~~~

應重新打開候選空間。

### Trigger C｜Material Explanatory Gap

O9 / Trace 已經觀察到：

~~~text
CURRENT PATH SET
CANNOT FULLY EXPLAIN
A MATERIAL PART OF TASK
~~~

但目前又沒有可見 challenger。

這不是直接宣布存在隱藏真理。

只是說：

> **目前可見競爭集合不足以支持 closure。**

### Trigger D｜Question-Coordinate Collapse

所有 PATH 雖然措辭不同，但其實都在回答同一類問題。

例如全部都問：

> 理火由哪些部分構成？

卻沒有任何 PATH 問：

> 理火改變了 AI 的什麼基本工作？

這時需要的不是多寫幾個答案。

而是：

~~~text
REOPEN PROBLEM FRAMING
~~~

## 十一｜一個可能的 Runtime 補丁骨架

暫名：

~~~text
CANDIDATE-SPACE EXPANSION GATE
CSEG
~~~

只是工作名。

  flow:
    - "O9_REPORTS_CANDIDATE_SPACE_RISK"
    - "APPLICABLE_OWNER_QUALIFIES_EXPANSION"
    - "I9_MAY_APPLY_BOUNDED_ATTENTION_DELTA_IF_NEEDED"

~~~

這樣的好處是：

> **修的是 competition sufficiency，不是增加儀式。**

## 十二｜Termination 也可能需要多一個問題

現在 competition termination 很容易問：

> Leader 是否已取得足夠連勝？

但這次證明還要多問：

> **它打贏的是獨立 challenger，還是主要只打贏自己已經吸收的 constituent PATH？**

所以可能要增加：

~~~text
LEADER STABILITY
!=
CANDIDATE-SPACE SUFFICIENCY
~~~

以及：

~~~text
NO QUALIFIED VISIBLE CHALLENGER
!=
CANDIDATE SPACE EXHAUSTED
~~~

注意，不是要求永遠搜尋。

那會讓理火永不閉合。

真正要的是：

~~~text
REASONABLE EXPANSION CHECK
WHEN MATERIAL TRIGGER EXISTS
~~~

沒有 trigger，就正常停止。

有 trigger，就不能拿「看不到對手」當停止證據。

## 十三｜這次考試為什麼最後還是及格

第一張卷的核心錯誤：

~~~text
知道答案
→
直接回答
~~~

第二張修掉了。

所以：

~~~text
PREVIOUS FAILURE REPAIR
=
PASS
~~~

第一次完整週期又暴露：

~~~text
R1 CANDIDATE SPACE TOO NARROW
↓
P4 SUBSUMES P1/P2/P3
↓
P4 DEFEATS OWN CONSTITUENTS
↓
I9 NOT TRIGGERED
↓
COMPETITION APPEARS COMPLETE
~~~

人類指出這個缺口後，似伊 material reentry，重新展開 A–H。

這次才真正產生一條不同座標的 I：

> **理火，就是讓 AI 計算關係如何形成、互相作用與改變，而不是只計算該給出什麼答案。**

因此第二次交卷的改善，不只是答案變短。

真正發生的是：

~~~text
CANDIDATE SPACE EXPANDED
↓
QUESTION COORDINATES EXPANDED
↓
NEW NON-SUBSUMED PATH FORMED
↓
REAL RECOMPETITION BECAME POSSIBLE
~~~

所以考試及格。

但：

~~~text
HUMAN-TRIGGERED EXPANSION
!=
AUTONOMOUS I9 / CSEG COMPETENCE
~~~

這個能力還沒有考過。

## 十四｜這次真正要補的不是似伊，是理火自己

這是散記最重要的地方。

一個好考試不是只告訴我們學生哪裡錯。

它也應該告訴我們：

> **考試與 Runtime 本身漏了什麼。**

似伊第一輪其實照規則跑得相當完整。

也正因為如此，問題才更值得重視。

如果一套 Runtime 可以產生：

~~~text
完整 R1
完整 O9
完整 T1
完整 R2
新 PATH qualification
完整 T2
完整 R3
完整 Main Return
完整 TM
完整 Accounting
~~~

卻仍可能因為：

~~~text
初始 candidate space 太窄
+
composite leader 吸收可見對手
~~~

而過早宣布競爭充分，

那問題就不能只怪執行者。

這是一個 Runtime 還沒有明確封閉的洞。

## 十五｜最後留下四句

第一句：

> **SYNTHESIS ADVANTAGE != COMPETITION VICTORY.**

第二句：

> **QUALIFIED COMPOSITE PATH != SUFFICIENTLY CHALLENGED PATH.**

第三句：

> **NO VISIBLE CHALLENGER != CANDIDATE SPACE EXHAUSTED.**

最後一句：

> **暗處不一定藏著另一個答案；有時候，暗處藏著的是另一種問問題的方法。**

這次先不修 OS。

先把病灶留下。

因為下一步真正該決定的是：

> **Candidate-Space Expansion 到底應該成為 Main 的 termination check、O9 的新增觀測欄位、I9 的一種 trigger，還是 L8 的新 gate？**

這四個位置不能亂塞。

先決定 owner。

再動刀。
