# 0｜這次錯在哪裡

V4.0 的架構方向仍然成立：

~~~text
FULL-PARENT NESTING
→
INDEX + BODY LOCATOR
~~~

錯的是 census。

V2.6 明確把 V2.5.2 的既有正文整批保存為 LEGACY CORPUS；這些舊文章形成於 LM-ID 標準化以前。

因此：

~~~text
NO LM-ID
!=
NO ARTICLE
~~~

V4.0 只掃 LM-ID，等於把整個 legacy corpus 從 collection index 裡切掉。

V4.0.1 不回寫那些舊文章，只恢復它們的 collection membership。
