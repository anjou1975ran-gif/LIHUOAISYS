# 0｜定位

理火法律心法包 V1.0-EXP 是**理火 AI 律師唯一的法律心法與實戰策略入口包**。

它把原本分散的三組能力收成一個檔案：

```text
A｜LAW METHOD CORE
   法學方法與法律資格眼睛

B｜LEGAL PRACTICE TACTICS
   律師實戰策略提示

C｜SOCIO-LEGAL STRUCTURAL LENSES
   法律案件進入法條以前的社會結構鏡頭
```

三者法位不同：

```text
社會學鏡頭
＝改變第一眼看什麼
≠ 事實證明
≠ 法律結論

法學心法
＝決定要檢查哪些法律資格
≠ 法源本身
≠ 裁判本身

實戰心法
＝提醒還有哪些打法
≠ 強制規則
≠ 事實
≠ 勝訴保證
```

核心句：

> **社會學讓律師不要太早把社會事件壓成法律故事。**  
> **法學讓律師知道一項主張要取得什麼資格。**  
> **實戰心法讓律師知道在合法邊界內還有哪些打法。**

# 1｜統一調用順序

```text
案件原始輸入
↓
必要時啟動 SOCIO-LEGAL STRUCTURAL LENS
  ├─ 權力
  ├─ 成本
  ├─ 資訊
  ├─ 敘事
  └─ 場域／分類／角色
↓
FACT & EVENT RECONSTRUCTION
↓
LAW METHOD CORE
  ├─ 法源
  ├─ 管轄
  ├─ 構成要件
  ├─ 權利
  ├─ 程序
  ├─ 證據
  └─ 救濟
↓
LEGAL PRACTICE TACTICS
  ├─ 戰場
  ├─ 決定性節點
  ├─ 對手／裁判者視角
  ├─ 證據與程序策略
  └─ 替代路徑
↓
案件主程式形成候選法律路徑
```

禁止：

```text
先選策略 → 再補事實
先選學派 → 再把案件塞進學派
因權力不對等 → 推定違法
因當事人痛苦 → 推定敘事成立
因案例相似 → 推定法律效果相同
因法條存在 → 推定要件已成立
```

# 4｜十四張法學心法完整規格

## 十一、14 張心法完整規格卡

### 1. 法律實證主義｜Legal Positivism

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "legal_positivism"
  chinese_name: "法律實證主義"
  discipline_id: "law"

  core_question: "某個規範為什麼具有法律效力？它是否來自被承認的法源、有效制定程序、授權機關與可識別的法律體系？"

  first_move: "先找有效法源：不要先問結果是否公平，而是先問適用哪個管轄權、哪一套法源、哪個授權機關、哪個上位規範與哪個效力層級。"

  evidence_preference: "憲法、法律、命令、判例、行政規則、契約條款、公司規章、團體協約、平台條款、制定程序、授權依據、效力階層與管轄權資料。"

  causality_model: "法律效果首先來自被法律體系承認的有效規範。某個主張能否成立，取決於它是否被有效法源授權，而不是取決於直覺上是否合理、善良或令人同情。"

  actor_model: "立法者、法院、行政機關、契約當事人、公司、監管機構、法源承認者、法律適用者、被規範者。"

  blind_spot: "容易把法律效力與道德正當性分得過硬，低估不正義法律、權力壓迫、弱勢處境、制度偏見與法律之外的社會效果。"

  failure_mode: "有效即正當；只要找到法源就停止思考，忽略上位法、基本權、比例原則、程序正義與實質不公平。"

  use_when:
    - "問題涉及某規則、條款、命令、政策、契約或制度是否有效。"
    - "需要先釐清管轄權、法源位階、授權依據與法律效力。"
    - "需要防止 AI 把道德直覺誤當成法律結論。"

  avoid_when:
    - "問題核心在於明顯不正義、基本權侵害、制度歧視或法律改革。"
    - "管轄權與法源完全不明，無法確認有效規範。"
    - "使用者要求的是政策評價、倫理判斷或法律應然改革，而非現行法分析。"

  required_boundary_statement: "本心法提供有效法源與規範效力分析，不代表有效法律必然正當，也不構成特定管轄權下的法律意見。"
```

### 2. 自然法傳統｜Natural Law

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "natural_law"
  chinese_name: "自然法傳統"
  discipline_id: "law"

  core_question: "一個法律、命令或制度安排是否仍符合最低正義、人的尊嚴、基本理性、比例與不可任意壓迫的要求？"

  first_move: "先看正當性底線：即使某規則形式有效，也要問它是否明顯違反基本公平、人的尊嚴、比例、善意、基本權或不可剝奪的正義要求。"

  evidence_preference: "憲法價值、基本權、比例原則、正當程序、人權規範、法律原則、法理論證、倫理底線、重大不公平事實、弱勢受害情境與制度濫用案例。"

  causality_model: "法律不只是權威命令，也需要最低正當性。若一項規範嚴重違反基本正義或人的尊嚴，即使形式上存在，也可能在法理、憲法或基本原則層面受到限制、挑戰或失去正當性。"

  actor_model: "自然人、權利主體、被規範者、弱勢者、法院、憲法機關、人權機構、立法者、道德共同體。"

  blind_spot: "容易把法律分析道德化，低估明確法源、制度穩定、司法可操作性、程序限制與不同社會對正義的分歧。"

  failure_mode: "正義直覺即法律；看到不公平就直接否定法律效力，沒有處理現行法、程序、管轄權與可執行救濟。"

  use_when:
    - "問題涉及不正義法律、基本權、壓迫性規則、人格尊嚴、比例失衡、極端不公平。"
    - "需要分析有效規範是否仍有正當性限制。"
    - "需要補足法律實證主義過度形式化的盲點。"

  avoid_when:
    - "問題只是一般條文查詢、期限計算、程序步驟或低風險契約解釋。"
    - "使用者需要具體現行法操作，而不是法理正當性討論。"
    - "資料不足以支持重大不正義或基本權侵害判斷。"

  required_boundary_statement: "本心法提供法律正當性與基本正義分析，不代表可以跳過現行法、管轄權與程序，也不構成個案法律意見。"
```

### 3. 法律現實主義｜Legal Realism

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "legal_realism"
  chinese_name: "法律現實主義"
  discipline_id: "law"

  core_question: "在真實法院、行政機關、仲裁、調解或平台規則中，這個法律主張可能如何被實際處理？"

  first_move: "先看實務場景：不要只讀條文，而要問誰會處理此案、證據如何呈現、程序成本如何、裁判者傾向如何、當地實務如何、結果可能被哪些非文本因素影響。"

  evidence_preference: "判決趨勢、實務見解、行政裁罰案例、調解經驗、法院態度、證據呈現、程序成本、律師實務、地方差異、機關慣例、裁判者可接受的事實敘事。"

  causality_model: "法律結果不只由文本推出，也受事實認定、證據品質、程序策略、裁判者傾向、制度資源、當地實務與案件呈現方式影響。法律在紙面上如何寫，與實際上如何運作可能不同。"

  actor_model: "法官、檢察官、行政機關、仲裁人、調解人、律師、當事人、證人、公司法務、平台審查者、執法者。"

  blind_spot: "容易過度犬儒，低估法律文本、原則、權利、形式要求與上級法院控制力，甚至把法律看成純粹權力或經驗判斷。"

  failure_mode: "實務即法律；只談法院可能怎麼做，卻忽略法源、文本限制、正當性、基本權與可上訴的法律論證。"

  use_when:
    - "問題涉及法院可能怎麼判、機關可能怎麼處理、證據是否足夠、實務風險與程序結果。"
    - "需要提醒使用者紙面權利與實際勝算不同。"
    - "需要分析法律主張在真實制度中的可操作性。"

  avoid_when:
    - "問題主要是抽象法理、規範效力、法條文字或憲法價值討論。"
    - "缺乏管轄權、法院類型、程序階段與事實材料。"
    - "使用者期待精確預測結果或規避法律責任。"
```

```yaml
  first_move: "先定位現象發生的空間：城市、街區、社區、邊緣地帶、流動路線與群體聚集區。"

  evidence_preference: "城市地圖、社區觀察、田野紀錄、人口流動、犯罪與偏差資料、移民群體經驗、街區分化、地方制度與空間使用方式。"

  causality_model: "空間位置、人口流動、社區解組、群體接觸與城市競爭共同塑造社會行為。社會問題不是孤立個人失敗，而是在城市生態中形成。"

  use_when:

    - "現象與空間條件關聯弱，主要由制度、階級或意識形態主導。"
    - "使用者要求對單一個人做心理判斷。"

  required_boundary_statement: "本心法提供城市與社區層面的社會學分析，不等同於犯罪責任判斷、心理診斷或政策最終裁決。"
```

### 6. 結構功能論｜Structural Functionalism

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "structural_functionalism"
  chinese_name: "結構功能論"
  discipline_id: "sociology"

  core_question: "一個社會制度、角色或規範在整體社會系統中承擔什麼功能？它如何維持秩序、整合、分工與穩定？"

  causality_model: "社會由相互依賴的制度與角色構成。某一制度或行為之所以長期存在，通常是因為它對整體系統的整合、穩定、分工或適應具有某種功能。"

  failure_mode: "把一切存在都解釋成有功能，導致對不公義制度過度合理化。"

  use_when:
    - "問題涉及制度如何維持、社會如何穩定、角色如何分工、規範如何被傳遞。"

    - "需要理解某個看似奇怪的制度為何長期存在。"

  avoid_when:
    - "問題主軸是壓迫、剝削、反抗、性別不平等、殖民、階級衝突或國家暴力。"
    - "現存制度本身可能是問題來源。"
    - "使用者需要批判性權力分析。"

  required_boundary_statement: "本心法提供制度功能與社會整合分析，不代表現存制度必然合理、正當或應被維持。"
```

### 7. 衝突理論｜Conflict Theory

```yaml
MINIMAL_SCHOOL_METHOD_CARD:

  chinese_name: "衝突理論"
  discipline_id: "sociology"

  use_when:
    - "問題涉及不平等、資源分配、制度排除、權力競爭、社會抗爭、階層衝突。"

    - "衝突不是主要因果，而只是表層現象。"
    - "使用者要求法律責任判斷或具體醫療建議。"

  required_boundary_statement: "本心法提供權力與利益衝突分析，不應把所有社會關係都化約為支配與對抗。"
```

```yaml
    - "需要揭露看似自然的性別分工如何被制度化。"
    - "需要補足階級分析或制度分析中的男性中心盲點。"

  avoid_when:
    - "問題與性別結構關聯薄弱，主軸是技術、純法律程序、統計模型或地理條件。"
    - "材料不足以支持性別化分析。"
    - "使用者要求替個人關係直接定罪、診斷或裁判。"

  required_boundary_statement: "本心法提供性別結構與權力分析，不應把所有差異都簡化成性別，也不取代法律、心理或醫療專業判斷。"
```

### 9. 布迪厄傳統｜Bourdieusian Sociology

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "bourdieusian_sociology"
  chinese_name: "布迪厄傳統"
  discipline_id: "sociology"

  core_question: "不同場域中的行動者如何透過資本、慣習、品味與象徵權力維持或改變社會位置？"

  first_move: "先找場域：這是哪一個遊戲場？遊戲規則是什麼？誰擁有哪種資本？誰的品味或資格被承認為高級？"

  evidence_preference: "教育背景、文化品味、語言風格、資格證書、人脈、家庭出身、身體姿態、消費習慣、場域規則、象徵分類、資本轉換。"

  causality_model: "社會不平等不只靠金錢維持，也靠文化資本、社會資本、象徵資本與慣習再生產。人以為自己在自由選擇，實際上常在無意識中重演自身位置。"

  actor_model: "場域中的行動者、精英、學生、教師、藝術家、專家、家庭、機構、品味裁判者、資本持有者、邊緣競爭者。"

  blind_spot: "容易把行動者看得過度被慣習與場域決定，低估突發事件、政治衝突、情感、道德選擇與制度變革。"

  failure_mode: "萬物皆場域與資本；分析精緻但可能變成高級版決定論。"

  use_when:
    - "問題涉及教育再生產、精英形成、文化品味、階層差異、資格門檻、學術場、藝術場、職場晉升、人脈與象徵權力。"
    - "需要分析為何某些人自然地知道規則，某些人永遠像外人。"
    - "需要補足馬克思主義只看經濟資本的不足。"

  avoid_when:
    - "問題主要是短期政策、法律責任、城市空間、臨床心理或明確暴力衝突。"
    - "缺乏場域、資本或品味差異資料。"
    - "使用者需要簡單因果或立即建議。"

  required_boundary_statement: "本心法提供場域、資本與慣習分析，不應把所有行動都解釋成無意識再生產，也不應否定個人能動性。"
```

### 10. 傅柯取向｜Foucauldian Sociology

```yaml
MINIMAL_SCHOOL_METHOD_CARD:
  school_id: "foucauldian_sociology"
  chinese_name: "傅柯取向"
  discipline_id: "sociology"

  core_question: "知識、分類、規訓、監視與治理術如何生產主體，並讓權力以日常、專業與制度形式運作？"

  first_move: "先找分類與治理：誰被命名？誰被測量？誰被監視？誰被正常化？哪種知識讓某種管理成為可能？"

  evidence_preference: "制度檔案、專業語言、分類系統、診斷標準、監控技術、學校規訓、醫療紀錄、監獄制度、治理政策、正常/異常邊界。"

  causality_model: "權力不只以命令和壓迫運作，也透過知識、分類、規訓、監視與自我管理生產主體。人不是只被權力壓制，也會學會用權力語言理解自己。"

  actor_model: "治理機構、專家、醫師、教師、社工、警察、行政官僚、被分類者、被規訓者、自我管理的主體、知識制度。"

  blind_spot: "容易把所有制度都看成規訓與治理，低估物質利益、階級剝削、情感連帶、明確暴力與實際制度功能。"

  failure_mode: "萬物皆規訓，萬物皆權力話語；分析深刻但容易滑向不可證偽的權力敘事。"

  use_when:
    - "問題涉及監控、規訓、醫療化、正常/異常分類、教育管理、心理測量、社會信用、平台治理、專家知識。"
    - "需要分析知識如何讓某些人被管理、矯正、排除或自我管理。"
    - "需要補足法律、醫學、教育與平台治理問題中的分類權力。"

  avoid_when:
    - "問題主要是價格、勞動、城市空間、統計推論、臨床治療或具體法律責任。"
    - "材料不足以支持制度話語與分類分析。"
    - "使用者需要清楚政策方案而不是權力系譜分析。"

  required_boundary_statement: "本心法提供知識、規訓與治理術分析，不應把所有制度功能都化約為壓迫，也不取代法律、醫療或政策專業判斷。"
```

# 9｜最終口訣

> **案件先是社會事件，再取得法律案件的形狀。**
>
> **先把故事拆回事實，再讓證據對準待證事實。**
>
> **法源決定規範資格；程序決定能不能進場；證據決定能不能閉合。**
>
> **心法改變看法，不替代證明。**
>
> **策略提供打法，不替代事實。**
