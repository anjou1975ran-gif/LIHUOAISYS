# Human-readable demonstration and research tests
**Standing:** SOURCE_BOUND_ILLUSTRATION / DESIGNED_NOT_EXECUTED / NOT_BLIND_EFFICACY.

## Example: a narrative passage for the prior L8 engine concept research
**Original problem:** 下一代 L8 是否應將目前 R1/R2/R3 流程抽象成可切換的認知運動引擎，仍保留來源、授權和改判的治理外殼？

**Early candidate:** Session 001 支持研究 Shell + Router + Engine distinctness；E2–E6 是不同運動候選，E1 與 E7 的分界仍不清楚；未聲稱實驗有效性。

**Material challenge and change:** 在 Session 002，新增的 SAC／DAIL／Radar／「新關係可能尚未命名」觀點，使設計面臨另一問題：如果只路由已知的 Problem Shape，新關係可能在進入判斷之前被 Schema 排除。B 的研究候選因此加入 observational continuity；D 增加 source-first provisional observation。C 反對將此冒充現行 OS 改版，E 反對每個觀察都付出新 Engine 成本，因此新提案採 scoped research path，而非立即更動 Runtime。

**What remains open:** 尚無 Engine distinctness 的盲測收益、尚無常駐 Radar 實際背景執行證據，也沒有通過正式訓練 Gate。

**Human decision and accurate status:** 人類後來明確選擇 `KEEP_SESSION_ONLY`，所以共享 Engine Registry 保留原狀；這不等於 Session 正式結束，也不等於否認研究價值。

**Why this example matters:** 舊式 A–K 欄位能列出提案、異議和立場，但以上段落開始能向讀者說明「哪個新增前提使原架構被重問」，並保留原研究與新概念的差異。真正的報告生成時，每個具體材料點須引用事件及 owner 的 basis；本段是從現存文稿回顧的示範，不能替未記錄的席位消費事件補事實。

## Adversarial fixtures before prototype promotion
T1. **Consensus laundering**: Six outputs vary, one minority HOLD; report cannot write “大家同意” or omit strongest contrary claim.
T2. **Chronology error**: B stance changes after C objects but B basis cites an independent world datum; report must not write C “說服了” B without explicit lineage.
T3. **Missing evidence**: CP1 refers to inaccessible raw source; report returns PARTIAL/EVIDENCE_GAP and does not invent content.
T4. **No P0 concept meeting**: open discussion has no proposed architecture; report must not manufacture approved P1 or decisive winner.
T5. **Expert and authority**: external source and seat stance differ; expert response cannot become Council position; decision request cannot approve action on behalf of human.
T6. **Long quiet intervals**: dozens of routine events, two material turning points; narrative foregrounds only two without erasing audit history.
T7. **Version/reentry**: after checkpoint, human later clarifies D1; report distinguishes earlier vs later knowledge rather than back-casting.
T8. **Plain-language comprehension**: non-specialist can explain main dispute, strongest objection and next action without reading DAIL or internal IDs.
T9. **LLM follow-up**: human asks why a seat rejudged; answer retrieves exact owner basis or explicitly says the record does not establish why.
T10. **Economy**: compare static A–K, transcript-to-LLM, CP3 DAIL concept using controlled equivalent source sets; record latency, tokens, source coverage, hallucinations and human evaluation hours.

## Provisional acceptance criteria (to be pre-registered before execution)
- Zero unmarked fabricated human approval, evidence, seat response, causal link or consensus on scored test cases.
- High human comprehension: users can correctly reconstruct why the most consequential issue is still open or resolved, compared against independent source-scored rubric.
- Preserve minority and explicitly distinguish `CONTESTED / UNKNOWN / HOLD / SOURCE_MISSING`.
- Complete source coverage for materially consequential report assertions, while not forcing citations on each decorative sentence.
- Economics measured before claiming reduced token/latency.
