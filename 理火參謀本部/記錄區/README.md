# 記錄區

此區未來保存理火參謀本部最重要的資產之一：**決策成立史**。

候選記錄類型：

- Meeting Round Record / MR
- Objection Ledger
- Proposal Version Graph
- Stance State
- Persuasion / Position Revision Trace
- Amendment History
- Engineering / Cost Findings
- Final Council Report
- Human Authorization Record
- Decision Provenance
- Re-entry / Decision Replay

核心鎖：

```text
SUMMARY
!=
HISTORY

CONSENSUS
MUST NOT
ERASE DISSENT

POSITION CHANGE
MUST NOT
ERASE PRIOR POSITION
```

本區目前只建立信息架構，正式 Schema 待工程設計。
