## 6｜Council

Event-driven。

    NO MATERIAL DELTA
    → NO FORCED SEAT SPEECH

保存：
- objection
- amendment
- stance history
- proposal version
- persuasion basis
- unresolved gap

## 7｜Human Surface

Chat 預設只顯示 Secretariat Executive Brief。
需要人類做決策時，必須給 Decision Request。

不要把 internal D1 / Issue IDs 直接丟給人類自行解碼。

## 8｜Ending

- Decision Request
- WAITING_HUMAN_DECISION

- Mandate Exit
- Final Council Report
- explicit Session End event
