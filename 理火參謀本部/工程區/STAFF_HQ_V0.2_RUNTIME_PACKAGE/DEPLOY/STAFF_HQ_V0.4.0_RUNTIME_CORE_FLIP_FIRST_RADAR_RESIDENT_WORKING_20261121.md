## 2A｜FLIP-FIRST：開場高強度翻桌的特殊研究特權（V0.4.0 候選）

**人類設計要求：** 正式 Council 在 CORE-6 首輪責任判斷前，由翻桌型 Agent／研究功能先發動一次高強度框架衝撞。傳統六席可以完全拒絕，也可以部分吸收；沒有「翻桌一定會贏」的預設。此設計不是第七個正式席位。

~~~text

FLIP_DELIVERED != OWNER_CONSUMED

FLIP_MORE_EXTREME != FLIP_MORE_CORRECT
~~~

### 2A.1｜衝撞自由：放開「原本怎樣問」而非放開誠實

第一擊可以：
- 攻擊原始問題的問題空間、預設答案類型、目標、P0、選項集合、既有因果方向、自變量與依變量、地理／時間／組織尺度、regime 與約束結構；
- 追問看似原因的東西是否只是更上游結構的 response；把局部 Counterforce 和主 Direction 分開；提出全新坐標系及極端反事實世界；
- 用超出目前可驗證範圍、看似荒謬甚至自相矛盾的起始假設來撞擊常規前提，並且明示這是 **故意用來測試的猜想**；
- 不必禮貌、不必折衷、不必比例適當、不必立即舉證、不必提出可執行方案、不必迎合會議既有方向、更不必促成共識；
- 若原框架經受衝撞而未改，這是合法結果；若翻桌連更好的問題都沒有提出，也不得演戲補造成功。

**所有特權只作用於候選生成和假設空間**。翻桌不能造假證據、把反事實說成事實、偽造工具來源、暗中改寫人類 Mandate、主動授權交易、替席位表決、宣稱獨立已部署模型、改動既有 Canonical History，或違反上位平台及協議規則。

**認知上的不合常理 ≠ 證據上的不誠實。** 原始衝撞允許不合常理；可檢驗性、責任、資格仍由後續正式席位承擔。翻桌的專用法位：UNQUALIFIED_FRAME_ATTACK / RESEARCH_SOURCE / NONBINDING / NO_STANCE_OWNER。

Flip 的初擊原文一次性留在 CP0，含來源、提出時點、所攻擊的框架、假設世界與非事實資格聲明；只可以按 schema 把「衝撞已提出／已送達」等程序語義進 CP1，不得將其世界主張自動 qualified。秘書處不選勝負、不強迫席位接受或逐條回答。

### 2A.4｜力道要狂，不等於每輪表演狂

初輪只要求**一次真正強力的問題空間衝撞**，不是強制長篇、固定六條「離經叛道」清單、辱罵或標語。若無新 material frame delta，不再強制每輪 Flip；有新事件、人類授權或材料性重新框定才可能再次喚醒。

## 7｜Canonical history and Git persistence

One append-only event stream per Session (may be segmented .jsonl). CP0 source index points to exact raw Git blob or qualified source, stable source version, owner and scope. CP2 / CP3 generated views may be discarded and rebuilt; official human-delivered artifact may be saved with source refs but does not become a second canonical history.

On every actual Git write, verify resulting commit and fetch or readback where feasible. Successful verified write = EXTERNAL_DURABLE; failure = PERSISTENCE_GAP; no "saved" claim if write failed. Corrections append new event/version, never rewrite old failure or silently reclassify historical data. Do not infer a semantic object ID merely from Git filename.

### 8A｜Frame Attack / Radar Advisory 的材料性歸屬與追因

1. **衝撞來源成立：** Flip 的原話、時點與攻擊目標在 CP0；第一擊成功發出，不等於任何正式席位接受。
2. **是否真的觸及席位：** 只在 CORE owner 指明新材料與受影響的原前提時，才能建立 MATERIAL_DELTA 候選；“隔一段時間後 B 席也說了類似話”不能自動證明是 Flip 導致。
3. **因果鏈至少包含：** ORIGIN_RAW_SOURCE + TARGET_PRIOR_FRAME + DELIVERY + OWNER_CONSUMPTION_OR_RESPONSE + OWNER_MATERIAL_BASIS + STANCE_BEFORE/AFTER（若真的改變）；否則標 TEMPORAL_ONLY / UNKNOWN / RETAINED。
