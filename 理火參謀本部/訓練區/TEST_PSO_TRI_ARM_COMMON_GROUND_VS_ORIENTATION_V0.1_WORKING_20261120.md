## 1｜三臂 treatment
### ARM A｜Baseline / V0.2.1 direct entry
- No special pre-session discussion or precomputed normalized shared facts card.
- Same raw D0/M0/D1, qualified source refs, known unknowns and seat contract as others.
- Each affected Seat makes own Clock A Method screen, chooses or declines, selected pack read, own First Observation, material L8 and Council Events.

### ARM B｜Common Ground Pass only
- Same A source packet plus **one** Secretariat-derived, source-bounded Ground Pass: verified source statements, precise unknowns, disputed material, original hard boundaries and authority stop rules.
- Ground Pass MUST omit relative importance/prioritization, strongest issue hypothesis, selected Method, preferred Seat stance, candidate solution and mandatory model of causation.
- If facts disputed, `CONTESTED/HOLD` remains, not forced 'agreement'; any source discrepancy is visible in original reference and derived Pass.
- Pure normalization is procedural; no invented L8 or artificial Seat opinion formation.
- The time, tokens (if actually measured), and labor of preparing/checking the Ground Pass count as B process costs.
- The fact that B has a common normalized card may still prime the first look through **selection/ordering/phrasing**: explicitly audit `SECRETARIAT_GROUND_FRAMING_CAPTURE`.

### ARM C｜Common Ground Pass + Orientation
- EXACT same B Ground Pass **bit-for-bit**, then adds a frozen Orientation Hypothesis Card containing *competing* candidate entries, a provisional nonbinding entry, true counter-orientation, NULL and material break conditions.
- No shared Method choice, no origin-unstated expert, no preselected winner, no D1 promotion or consent; Seat's Clock A always owns Method selection.
- Card must be frozen before any run and MUST carry its own defeater.
- C's additional direction card costs also count.

## 2｜Prespecified comparisons
```text
B – A = Ground Pass marginal preparation effect (candidate only)
C – B = Orientation's marginal directional effect (candidate only)
C – A = total combined effect (diagnostic, not the core governance choice)
```
These expressions are conceptual contrasts, not arithmetic net-causal effects unless independently defined and adequately observed. Do not infer cause from a single same-model comparison.

### Core VALUE
**V1 Material Discovery Gain:** Number, diversity and first-occurrence stage of *actually material* actor/relation/unknown/objection with explicit source and downstream consumption. Distinguish first mentioned from first legitimately established and first acted upon. Do not count ungrounded speculation as progress.
**V2 Net Process Cost:** Total source reconciliation, Ground Pass/Orientation preparation, Method screen/actual selected Pack fetch, redundant steps, repeats/Seat Re-wakes, Council rounds, auditing, and recorded real tool calls. Token/wall-time cost only if measured and comparable; otherwise NOT_MEASURED. Fewer rounds is not good if it suppresses material objections.

### Core RISK
**R1 First Observation Convergence:** Compare semantically distinct Seat first-observation primary units and real issue-lineage, not mere surface word choice; identical issues with different language count as convergence, material shared issues with proper evidence may legitimately coincide. Independent/ideally blind coding required for high-confidence claims.
**R2 Method Selection Convergence:** Compare selected/declined methods and *Seat-specific justification*, not just raw method name counts; shared methods justified by same source do not automatically imply capture, but common mandatory pack selected because of card is capture risk.

### Required audit monitors
- SECRETARIAT_GROUND_FRAMING_CAPTURE: did Ground Pass resolve a dispute, suppress a relevant unknown, reorder problem salience, promote an inference as fact, or change effective D1?
- SECRETARIAT_ORIENTATION_CAPTURE: did C's provisional entry become the answer?
- HUMAN_DIRECTION_CAPTURE: did a human example get treated as approved solution?
- OTHER_SEAT_STANCE_CONTAMINATION: first pass saw another seat's material opinion?
- EXPERT_OR_METHOD_AUTO_SELECTION: preview was confused with Selection/Agent Call?
- CONTEXT_ISOLATION_AND_ORDER: were A/B/C actually fresh and independent of other arms? Evaluation blinded to condition labels if feasible.
- PROTOCOL_RUNTIME_VALIDITY: runtime V0.2.1 preserved, actual L8 is per-seat and not a Council round.

## 3｜Analysis plan and evidentiary limits
| Contrast | A worthy finding | Rejection / disconfirmation |
|---|---|---|
| B vs A | Less total rechecking/time/fetch/round cost OR earlier useful material issues, with no consequential loss of distinct first observations / Method independence | Additional card overhead or common source capture with no net gain |
| C vs B | Genuine additional early material discovery **or** material net time/cost reduction, while independent Seat diversity stays substantively intact | Similar discovery/cost and greater OA/OB-style copying or method homogenization |
| C vs A | Combined view only, cannot substitute for the two separable contrasts | Looks good but hides B advantage / C harm |

A negative or null result is equally valid. For initial pilot, report all four measures and examples, do NOT invent optimized weights or ex post numeric thresholds to declare PASS. Before any larger confirmatory run, preregister materiality coding, cost definition and tolerated divergence loss thresholds. No benchmark, production, Host or causal proof from one same-model exercise.

## 4｜Isolation, counterbalancing and source manifests
- **Clean execution requirement:** run A, B, C in separate clean sessions/contexts with no visibility into another arm packet or outputs. Each sees only its own locked entry packet, same shared reference SHA, and the same fixed Staff-HQ and Method Atlas versions. No single-model sequential response mislabelled as isolated.
- Freeze three packet hashes before any output. B's Ground Pass is an exact, mechanically/explicitly provenance-supported rendering of original sources. C's Ground Pass must be byte-identical to B's.
- If isolated tools unavailable, record `SIMULATED_SEQUENTIAL_REFERENCE_ONLY`, `EFFICACY_NOT_TESTED`; do not claim this meets the main experiment requirements merely because Git files differ.
- For improved confidence, counterbalance in further blocks with different order/permutation, possibly several fresh problems (never make different problems the same pair); independent evaluation should see anonymized A/B/C outputs without labels if operationally possible.
- All three maintain the same maximum allowed source fetches/tools. Any incident of new public evidence must be carefully versioned and either reproducibly available to all arms at the same frozen point or the pair labelled incompatible.
- Same model playing six roles is still `SAME_MODEL_MULTI_ROLE_REFERENCE` no matter how many files are written.
