## 4｜Main methodological problem: this was NOT a clean paired evaluation
- Frozen **designed** input packet M0/D0/D1 was identical; B had only the Orientation card as defined intervention.
- But true *visible model context* was unequal and contaminated: card known before A output; A output known before B output. `DESIGN_SAME_MATERIAL != MODEL_EXPOSURE_ISOLATED`.
- Therefore a difference in first look or Method Selection could be caused by role writing, order effect, prior output, anticipation of scoring rubric, or pre-exposure to packs. **Not attributable to Orientation**.
- Objective staff/runtime evaluation of M1 through M4 from same-model generated logs is also not blind; report potential self-scoring bias.
- Existing method source snippets for Management/Economics/Sociology appeared during Git inspection before the pair; sequential Git fetch receipts do not prove that the respective model invocation had never read them.
