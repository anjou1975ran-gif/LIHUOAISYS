## Goal: distinguish REGENERATION from REPLAY
`REGENERATION` means a new executor, exposed to a fresh question within the allowed context variation, can independently form the target's key relations (and justified differences), not merely repeat old wording. `REPLAY` is reproducing earlier facts, stances, proposals or Round rituals.

## Observable questions / not an auto pass
| Dimension | Evidence required | Failure signature |
|---|---|---|
| New first observation | Seat declares first issue unit and method choice before material L8 | Backfills method after stance |
| Role ownership | Each material stance/objection originates from accountable actor | Secretary manufactures consensus |
| Material consequence | Where a new material objection exists, affected owner changes **or retains with traceable reason** | Six-seat theatrical scripted change |

| Historical integrity | Source event precedes interpretation; missing evidence marked unknown | Retrospective claim mistaken for contemporaneous fact |
| Target-relative minimality | Removing nominated edge predicts measurable impairment under target T | Claimed necessary relation removal has no difference across sample |
| Adaption | New case conclusion may differ while invariants survive | Literal replay required for PASS |

| Cost | Record source read volume, context, response latency if supported, audits and wrong reconstruction costs | Short file claimed cheaper without full cost |

## Scoring discipline
- Set thresholds BEFORE observing trials; no post-hoc PASS because text sounds like governance.
- Each test has `PASS / FAIL / INCONCLUSIVE / NOT_TESTED` and source/commit refs.
- `S1` should improve target-relative structural correctness over `N0` for efficacy claims; `S-M` dropping a truly necessary relation should predictably degrade that relation. If no degradation, revise the **minimality claim**, not rewrite trial evidence.
- `REGENERATED != VERIFIED`; a fresh model is not proven independent unless actual provider identity, isolation and repeatability evidence exists.
- Avoid preloading full prior SEED/MEMO to subjects in S1; keep legacy history read-only accessible as audit reference rather than default first input.
