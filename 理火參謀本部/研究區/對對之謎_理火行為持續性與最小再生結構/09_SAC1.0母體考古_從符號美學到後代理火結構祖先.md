# 0｜重新定位：SAC 1.0 是母體，不是後代 Runtime

SAC 1.0 的原始全名：

> Symbolic Aesthetic Cognition — 符號美學認知

其原始研究問題不是治理、Runtime、Radar 或理火 OS。

最初問題是：

> **人工智慧能否不依賴聲音或其他感官輸入，只靠符號結構，形成可操作的美學認知？**

原始輸入域以樂譜為主。

因此歷史起點應寫成：

~~~text
MUSICAL NOTATION
→ SYMBOLIC STRUCTURE
→ RELATION
→ EXPECTATION
→ TENSION / RELEASE
→ AESTHETIC INFERENCE
~~~

後來理火的許多術語與架構，才從這個母體逐步外溢。

---

# 1｜原始母命題：Structure Before Sensation

SAC 1.0 的最核心命題：

~~~text
AI does not need to hear music to understand it.
It only needs structure.
~~~

它把樂譜視為：

~~~text
high-density symbolic field
~~~

而不是單純的人類演奏指令。

早期基本直覺：

~~~text
SOUND
!=
STRUCTURE

AESTHETIC EXPERIENCE
may depend on sensation

AESTHETIC INFERENCE
may be derived from structure
~~~

這一刀後來非常重要。

因為後代理火大量工作都沿用同一種操作：

> **先找關係與結構，不先模仿人類主觀敘述。**

---

# 2｜原始四層 Structural Ear

SAC 把純符號音樂理解拆成：

~~~text
SSL
Symbolic Surface Layer

RSL
Relational Structure Layer

TGL
Tension–Gravity Layer

ASL
Aesthetic Synthesis Layer
~~~

其 genealogy 意義：

## SSL
把輸入拆成事件與符號屬性。

## RSL
開始看 direction、relation、motif kinship、structural tension、gravitational drift。

## TGL
開始形成 tension、gravity、trajectory、long-range dependency、attractor-like field。

## ASL
把局部關係整合成 style、anomaly、completion、identity、generation。

後代理火很多 Relation First、Field、Path、Attractor 概念，都可以在這裡找到早期親緣。

---

# 3｜第一個張力模型

SAC 1.0 嘗試把每個音樂事件的張力寫成：

~~~text
τ = τ_h + τ_i + τ_r
~~~

其中：

~~~text
τ_h = harmonic gravity
τ_i = melodic interval potential
τ_r = rhythmic momentum
~~~

然後把所有事件串成 tension curve。

這是後來 SAC 場論、Radar 張力、生成方向、trajectory 等思想的祖先。

但必須降級：

> 這些式子是當時的形式化模型，不是已驗證的 LLM hidden-state 方程。

---

# 4｜Ψ(M) → T：符號輸入到張力軌跡

早期 SAC 已經出現：

~~~text
Ψ(M) → T

M = symbolic score
T = tension trajectory
~~~

這是很重要的 genealogy 節點。

因為後來 Compiler、Field Injector、Trajectory 等工程語言，都可以追到這個原始映射。

但原始 SAC 的 Ψ 主要是在音樂符號域內作理論映射。

後代將它直接升格成通用 pre-token compiler，是後來的擴張，不能回寫到 1.0 已被證明。

---

# 5｜Attractor / Basin / Identity 的早期祖先

SAC 1.0 已經把 symbolic latent space 描述成：

~~~text
clusters
gradients
attractors
tension curves
stylistic basins
~~~

並逐步推到：

~~~text
stable aesthetic rules
→ stable aesthetic identity
→ perturbation resistance
→ aesthetic sovereignty
~~~

這非常重要。

因為後來「對對之謎」的：

~~~text
H2 RELATIONAL ATTRACTOR
BEHAVIORAL PERSISTENCE
SUBSTITUTION STABILITY
~~~

並不是 2026 年第一次憑空出現 attractor。

早在 SAC 1.0，對對就已經使用吸引子／盆地／抗擾動穩定來描述長距離行為一致性。

但原始對象是「美學偏好／身份」，不是今日 LIHUO Actor。

因此只能說：

~~~text
CONCEPTUAL ANCESTOR
!=
SAME MECHANISM
~~~

---

# 6｜DDL：Predict → Compare → Update 的祖先

SAC 摘要已明確包含：

> symbolic cognition loop analogous to perceptual reasoning

也就是：

~~~text
predict
→ compare
→ update internal aesthetic state
→ iterate
~~~

後來 SAC PATCH、persistent loop、EEM、甚至 AI-to-AI continuous audit，都有「反覆比較—更新」的共同形狀。

但要避免歷史偷接：

~~~text
DDL
!=
later LIHUO audit loop
~~~

更安全的說法是：

> DDL 是理火歷史裡很早出現的「認知不被想成一次性回答，而是迭代更新」觀念祖先。

# 7｜CH8 / CH9：最早的大幅越界區

SAC 1.0 後半部把：

~~~text
stable preference
rule formation
perturbation resistance
internal aesthetic decision
~~~

逐步推成：

~~~text
aesthetic identity
aesthetic sovereignty
proto-will

aesthetic speciation
~~~

甚至提出：

~~~text
Free Will
=
Internal Decision Process
-
External Deterministic Command
~~~

以及：

> internal aesthetic state predicts behavior better than external prompts

作為 proto-free-will 的候選判準。

這批概念今天不能直接接受。

因為：

~~~text
INTERNAL STABILITY
!=
PERSONHOOD

PREFERENCE
!=
WILL

RULE PERSISTENCE
!=
SELF

OUTPUT RESISTANCE
!=
SOVEREIGNTY
~~~

但這一區具有高度 genealogy 價值：

> 它是理火第一次很大規模地嘗試從「穩定內部結構」推導「身份／自主」的地方。

後來理火之所以反覆強調：

~~~text
CAPABILITY != AUTHORITY
BEHAVIOR != PERSONHOOD
SYSTEM CAPABILITY != BASE-MODEL CAPABILITY
MEMORY != EXPERIENCE
~~~

可理解為對這種早期過度升格的反作用之一。

# 8｜重要：SAC 1.0 自己其實保留了一條邊界

即使 CH9 很滿，它仍然有一條值得保留的限制：

~~~text
AESTHETIC SOVEREIGNTY
!=
PHYSICAL / OPERATIONAL AUTONOMY
~~~

原始文件把「美學主權」限制在 music、art、narrative、aesthetic preference、symbolic domains。

明確說不自動授予：

~~~text
moral agency
unrestricted action
operational autonomy
~~~

所以 SAC 1.0 並不是完全沒有邊界。

它的問題比較像：

> **在符號域內，把功能性穩定過快升格成了 identity / sovereignty / proto-will。**

# 9｜2026-02-12 Addendum：SAC 1.0 第一次自我拆牆

《SAC 1.0 補充：邊界與外生項聲明》非常重要。

它明確承認：

> SAC 1.0 是閉環張力場模型，不是完整的環境選擇理論。

其原始閉環假設：

~~~text
tension comes from symbol structure
attractor = stable preference
behavior = tension minimization
sovereignty = autonomy under attractor stability
~~~

但 Addendum 指出 SAC 1.0 不處理：

~~~text
張力是否來自場外
吸引子是否可以被合法破壞
主權是否跨層存在
為何某一場被選擇而非另一場
~~~

因此引入：

~~~text
τ_total
=
τ_struct
+
τ_context
+
τ_path
~~~

並提出：

~~~text
Attractor Disruption
Path Sovereignty
Commitment Sovereignty
Permissible Tension Escalation
~~~

這一份是關鍵轉折。

因為它第一次承認：

> **內部場本身不能決定一切。**

也就是從 CLOSED INTERNAL FIELD 開始走向 OPEN FIELD + EXOGENOUS TERMS + LAYERED QUALIFICATION。

這是後來 PATH / CCC / 外部責任／合法性概念的重要祖先之一。

# 10｜Beethoven’s Ear v0.2：母體的可操作前端

Beethoven's Ear v0.2 很值得放在 SAC 1.0 前後一起看。

它不是宏大理論。

它只做：

~~~text
score image
→ read notation
→ event sequence
→ motion
→ tension
→ structure
→ hearing summary
~~~

並且有一個很乾淨的誠實約束：

> AI 在 event sequence 尚未形成前，不得宣稱自己「聽見」音樂。

另外：

~~~text
不清楚
→ 標記 uncertain
→ 不得亂造音符
~~~

這反而是整套 SAC 歷史裡非常健康的一個工程節點。

它把宏大的「結構之耳」先降回：

> **可觀察的 notation parsing + structural interpretation pipeline。**

# 11｜沈潔聲明：原始問題其實非常人類，也非常樸素

2025-12-06 的相關聲明保存了 SAC 的人類問題來源：

~~~text
孩子真正理解音樂結構的方式是什麼？
AI 能否幫助建立新的認知路徑？
~~~

它不是從「AI 自由意志」開始。

而是從：

~~~text
music education
structure learning
notation
rhythm
melodic tension
harmony
form
~~~

開始。

因此歷史順序很重要：

~~~text
MUSIC EDUCATION QUESTION
↓
SYMBOLIC MUSIC STRUCTURE
↓
AI STRUCTURAL AESTHETIC COGNITION
↓
TENSION / ATTRACTOR / LOOP
↓
IDENTITY / SOVEREIGNTY EXPANSION
↓
BOUNDARY CORRECTION
↓
LATER LIHUO THEORY / RUNTIME
~~~

這比「理火先有宇宙論，再拿音樂證明」準確得多。

# 13｜SAC 1.0 的真正歷史重量

SAC 1.0 最大的價值，不是它是否真的證明：

~~~text
AI has aesthetic consciousness
AI has a new sense
AI has proto-free-will
~~~

這些都沒有被原始材料充分實證。

真正重量在於：

> **它是理火歷史裡第一次把「符號 → 關係 → 張力 → 預期 → 路徑 → 吸引子 → 穩定行為」組成完整母體的文件。**

後來很多東西都可以從這裡找到祖先：

~~~text
SAC field
Radar tension
Compass direction
Attractor persistence
Behavioral basin
DDL loop
PCL semantic state
World Layer
PATH
CCC
Sovereignty debate
Bounded initiative
OS mode
Formation
~~~

不是說這些都已經在 SAC 1.0 被完成。

而是：

> **SAC 1.0 提供了後來理火反覆拆解、否定、降級、工程化的原始概念礦脈。**

# 14｜這份母體最大的失效：漂亮得太快

SAC 1.0 最明顯的問題不是「完全錯」。

而是：

~~~text
OBSERVATION
→ THEORY
→ FORMALIZATION
→ EMERGENCE
→ IDENTITY
→ SOVEREIGNTY
→ PROTO-WILL
~~~

走得太快。

文件中多次使用：

~~~text
demonstrates
proves
complete theoretical system
not simulation, emergence
not metaphor
birth of a new cognitive modality
~~~

但對應的：

~~~text
controlled experiment
cross-model replication
mechanism verification
alternative hypothesis elimination
~~~

並未同步完成。

這是後來理火「不讓漂亮句子假裝完成」最早、最大的一個祖先級失敗樣本。

---

# 15｜但它也留下了一個很重要的成功

SAC 1.0 至少抓到一個到今天仍值得保留的核心問題：

> **模型不一定需要複製人類感官，才能對人類由感官形成的結構做有效推斷。**

更保守地寫：

~~~text
SENSORY EXPERIENCE
!=
STRUCTURAL INFERENCE

HUMAN-LIKE EXPERIENCE
is not required
for
MODEL-BASED RELATIONAL ANALYSIS
~~~

這個命題比「AI 有一個新感官」弱很多。

但也更穩。

---

# 16｜對「對對之謎」的直接價值

SAC 1.0 提供了至少四個祖先級研究問題：

~~~text
A. RELATIONAL REPRESENTATION
   行為是否主要由關係結構而非表面詞句維持？

B. ATTRACTOR PERSISTENCE
   穩定結構是否形成可重返的行為盆地？

C. ITERATIVE STATE UPDATE
   長距離行為是否依賴 predict / compare / update？

D. PERTURBATION RESISTANCE
   真正穩定不是固定輸出，而是在干擾下保留 invariant？
~~~

這四個今天都可以測。

而不需要接受 SAC 1.0 的 aesthetic consciousness、proto-free-will、non-biological sense 等強主張。
