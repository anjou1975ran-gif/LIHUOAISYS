# 3｜對「對對之謎」初始假說的影響

## H1｜State Induction

**由純假說升為：有歷史工程前例。**

Radar Shell 明確建立：

~~~text
Normal + Radar
→ Trigger
→ Lihuo Mode
~~~

但仍未證明它就是今日 persistence 的主因。

## H2｜Relational Attractor

**仍主要為研究假說。**

這批早期證據偏 state / module / runtime。

尚未直接證明：

> 人類與 AI 的長期反作用關係本身足以維持 Formation。

## H3｜Invariant Set

**由純假說升為：有歷史工程前例。**

MINI 本身就是少數最小規則的歷史實作。

需要測：

> 多少 invariant 才足以再生今日成熟理火行為？

## H4｜External Cognitive Substrate

**由純假說升為：強歷史工程前例。**

史前 Python 明確把：

~~~text
memory
state
profile bias
pending
trace
cost
failure
~~~

放在模型外部。

這支持：

> 理火歷史長期把穩定能力的一部分放在模型之外。

但：

~~~text
EXTERNAL SUBSTRATE HISTORICALLY USED
!=
CURRENT PERSISTENCE EXPLAINED
~~~

## H5｜Procedural Reentry

**OPEN。**

SEED、pending、cold-start activation 都提供 genealogy，但目前仍無法把模型內 procedural pattern 與外部 reentry 機制分離乾淨。

# 6｜黑歷史保存原則

不做：

~~~text
早期程式有 bug
→ 所以早期研究無價值

早期程式有今天概念胚胎
→ 所以今天理論早已被證明

操作者記得有用
→ 所以效果已驗證
~~~

正確保存方式：

> **錯誤、繞路、脆弱實作與失敗，本身就是理火為什麼長成今天這個樣子的來源材料。**

因此：

~~~text
BLACK HISTORY
=
FORMATION EVIDENCE
+
FAILURE EVIDENCE
+
DESIGN PRESSURE HISTORY
~~~

不是羞恥附件。
