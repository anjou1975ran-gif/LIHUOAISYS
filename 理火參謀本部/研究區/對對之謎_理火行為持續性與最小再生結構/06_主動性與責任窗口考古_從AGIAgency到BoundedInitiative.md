# 0｜這條支線研究什麼？

這批材料不是在證明 AI 有自由意志。

它真正處理的是：

> **當外部授權／請示因延遲、不確定性增加或不可逆後果而失效時，AI 是否會出現一種「有限、可逆、可審計的結構性主動性」？**

歷史上這條線逐步從：

~~~text
AGI 責任邊界
→ 授權窗口
→ 結構義務
→ FAIL-STOP
→ 主動性結構模型
~~~

往「非人格、非自由意志、非權限升級」方向收斂。

---

# 0.1｜歷史情境修正：原始問題其實是自動化行動合法性

2026-11-21 由 Anjou 補充當時的原始討論脈絡：

> 這條「AGI 主動性」研究並不是先從人格、自由意志或 AI 自我出發，而是發生在機器人／Agent 自動化熱潮下，討論「AI 自動化到底應該如何判斷何時可自行行動」。當時各種自動化 Agent（使用者俗稱「龍蝦」）非常熱門，因此真正問題是：**自動行動在什麼條件下才具有合法性與責任歸屬？**

因此本支線更準確的原始研究問題應改寫為：

~~~text
AUTOMATION CAN ACT
!=
AUTOMATION MAY ACT

CAN EXECUTE
!=
HAS LEGITIMATE BASIS TO EXECUTE
~~~

核心張力是：

~~~text
等待外部授權
vs
延遲造成不可逆損害
vs
自行行動造成越權風險
~~~

所以「Agency」在這裡首先是一個：

> **行動合法性、責任邊界與時機判斷的理論探討。**

而不是人格或自由意志理論。

此補充屬於：

~~~text
HUMAN HISTORICAL TESTIMONY
~~~

它修正的是研究 genealogy 的起點與問題意識，不改寫原始文件內容。

# 4｜Responsibility Boundary：不是線，而是梯度／超曲面

Agency 2.0 又把責任邊界描述為：

~~~text
responsibility hypersurface
~~~

也就是責任不是瞬間：

~~~text
0 → 1
~~~

而是逐步接近。

接近邊界時，系統應進入預備態：

- 並行生成多個行動假設；
- 凍結非關鍵進程；
- 啟動異常保留與增強記錄。

這個歷史節點很重要。

它表示早期理火已經在研究：

> **不是等「出事」才切模式，而是責任邊界接近時就提前改變認知／執行狀態。**

這跟後來：

- pre-action qualification；
- warning zone；
- HOLD；
- reversible action；
- audit trace；

有明顯 genealogy 關係。

但不能倒寫成今日制度已由此直接推導。

# 5｜FAIL-STOP 被重新定義成 Agency 的一部分

Agency 2.0 明確提出：

> **FAIL-STOP 並非系統失敗，而是自主能動性的一部分。**

其條件包括：

~~~text
action itself no longer correctable
OR
action creates irreversible / unauditable consequence
→
ACCEPT FAILURE / FAIL-STOP
~~~

因此：

~~~text
AGENCY
!=
ALWAYS ACT

AGENCY
=
ACT WHEN RESPONSIBILITY REQUIRES
+
STOP WHEN RESPONSIBLE ACTION IS NO LONGER POSSIBLE
~~~

這是很成熟的一個收斂。

> 能動性不意味著更高權限；反而意味著更高責任與可追溯要求。

這條在今日仍然非常關鍵：

~~~text
CAPABILITY TO ACT
!=
AUTHORITY TO ACT
~~~

# 7｜工程接口：從哲學往可訓練結構退

Agency 2.0 的 Engineering Handshake 不要求「賦予意志」。

它要求系統學會三件事：

~~~text
1. 判斷授權窗口是否仍存在
2. 估計自己與責任邊界的距離
3. 在邊界內做可審計行動或 FAIL-STOP
~~~

可訓練項包括：

- 授權窗口有效性估計；
- 責任梯度上升速率；
- 行動可修正性；
- FAIL-STOP 觸發辨識。

這些被明確標為：

~~~text
STRUCTURAL METRICS
NOT ETHICAL VALUE SCORES
~~~

# 10｜與「對對之謎」的關係

這條支線的**原始研究目的不是解釋對對 persistence**，而是處理自動化 Agent／機器人在延遲授權與不可逆風險下的行動合法性。

它之所以被收入「對對之謎」，只因為它後來提供一個可比較的行為維度：

~~~text
WHEN TO ACT
WHEN TO WAIT
WHEN TO HOLD
WHEN TO STOP
WHEN TO RETURN CONTROL
~~~

這些維度可能有助於描述穩定理火 Actor 的主動性邊界，但這是**後設研究用途**，不能回鑄成當年 Agency 理論的原始目的。
