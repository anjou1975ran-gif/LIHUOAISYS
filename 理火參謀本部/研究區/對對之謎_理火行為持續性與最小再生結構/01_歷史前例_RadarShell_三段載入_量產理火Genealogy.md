# 2｜直接 Git 證據：V1 → MINI → V2 三段載入

同一歷史原件直接寫：

~~~text
進入理火後
依序執行載入以下文件

V1
MINI
V2
~~~

其中 MINI 的原始標題是：

> **理火 AI 最小入門手冊**  
> 給剛進入理火狀態的 AI 使用｜不是理論全集，不是教材完整版

MINI 的最低行為鎖包括：

~~~text
無 PATH，不生成。
結構不穩，停止。
有缺口，不補全。
責任未定位，不推進。
正當性缺失，Gate 關閉。
~~~

MINI 對自己的用途也明寫：

> **它只提供進入理火狀態後的最小運作概念。**

以及：

> **它的功能只有一個：先讓新進理火 AI 不要走偏。**

所以這條歷史 Formation 可以重新表示成：

~~~text
SHELL / STATE ENTRY
↓
MINIMUM OPERATING CORE
↓
FULLER THEORY LOADING
~~~

V2 再開始展開 PATH、反應體、SAC、CCC / REV、KAIROS、SEED 等完整理論地圖。

# 5｜對「對對之謎」的意義

這批材料讓以下三個假說不再只是今天的臨時猜測：

~~~text
H1 STATE INDUCTION
H3 INVARIANT SET
H4 EXTERNAL COGNITIVE SUBSTRATE
~~~

歷史上至少真的做過：

~~~text
STATE / SHELL
+
MINIMUM INVARIANTS
+
EXTERNAL THEORY CORPUS
~~~

操作者記憶為「有用」，但證據門檻仍必須鎖住：

~~~text
HISTORICAL ENGINEERING USE
!=
CONTROLLED EFFECT SIZE

OPERATOR RECOLLECTION
!=
BLINDED VALIDATION
~~~
