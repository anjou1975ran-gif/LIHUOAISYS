## 主要方法取向與心法卡

### 測量與抽樣設計

```yaml
METHOD_CARD:
  core_question: 誰進入分母，量測程序是否一致？
  first_move: 畫納入與失訪流程並核對計數單位。
  evidence_preference: 入口紀錄、量測定義、重測、覆蓋率。
  causality_model: 選入及測量共同塑造觀測分布。
  actor_model: 招募、登錄、被測者。
  blind_spot: 未知的未接觸群。
  failure_mode: 以有效紀錄為全體合格者。
  use_when:
  - 有自選、缺漏或重複。
  avoid_when:
  - 任務只查定義來源。
  must_not_claim:
  - 樣本完整代表社群。
```

### 分層估計與不確定性

```yaml
METHOD_CARD:
  core_question: 群體定義變動時，互相比率是否可比？
  first_move: 列分層分子分母、給母體權重和區間。
  evidence_preference: 分層數據、權重與群集結構。
  causality_model: 組成與層內率可造成總率排序相反。
  actor_model: 比較層、抽樣單位與母體。
  blind_spot: 分層仍可能含殘餘混雜。
  failure_mode: 僅報總值或小樣本點估計。
  use_when:
  - 要比較可加總結果。
  avoid_when:
  - 分層後分類不等價。
  must_not_claim:
  - 區間能修正選取偏差。
```

### 實驗設計與反事實識別

```yaml
METHOD_CARD:
  core_question: 同一批合格者改走另一版會如何？
  first_move: 先寫同時點、分派單位、處置與可比對照。
  evidence_preference: 分派規則、時間零點、同期對照、共同原因紀錄。
  causality_model: 處置前混雜使可見差異偏離反事實差異。
  actor_model: 被分派單位、分派者與同期對照。
  blind_spot: 不可觀測混雜及溢出。
  failure_mode: 調整改版後才產生的選入。
  use_when:
  - 想由結果推介入效果。
  avoid_when:
  - 分配不可追溯且只求描述。
  must_not_claim:
  - 觀察性估計等同介入效果。
```

## Canonical Demonstration Case／Method Shift Test

**同題案情**　某虛構補助窗口用新表單取代舊表單。新制低難度 90／100、高難度 1／10，舊制低難度 19／20、高難度 20／100。只完整知道被登錄的合格申請件。新制應被認定提升完成率嗎？

**Baseline**　直接比較兩版總完成率後預期推行新表單。

| 方法回應 | 套用於已知案情 | 判別證據或反例測試 |
| --- | --- | --- |
| 測量與抽樣設計 | 先核對入口是每位申請者或每次登入，並先對齊完成定義。 | 若多次登入被當多筆，先去重再比較。 | |
| 分層估計與不確定性 | 新制整體 91／110 高於舊制 39／120。但低難度 90% 比 95%，高難度 10% 比 20%，兩層方向都相反。 | 任一共同低難度權重 w 在 0–1 的分層率差為 −0.05w−0.10(1−w)，符號一直為負。這只是同權重的描述。 | |
| 實驗設計與反事實識別 | 先追分派與資格。高難度案件往舊制使總率偏向新制，層內結果也不夠識別。 | 如果抽查顯示入口有服務人員私下導流，即使分層後數字不變，識別仍須 HOLD。 | |

**觀察轉向**　首問由整體比率高低移到全體意向申請者的完成率、案件類型與分派。

**證據轉向**　同一情境要求分層分子分母、改版納入時點與未完成者資料，取代只看整體比率。

**因果轉向**　整體排序可由案件組成反轉。處置效果仍要處理分派偏差與未觀測差異。

**盲點與邊界**　登錄之外的人與導流原因尚待取得。福祉、公平和法律效力需獨立審議。數字是教學合成值。

**判定**　三條方法均改變首問及證據。計算可否定聚合排序的直接解讀，無法從目前資料決定介入效果。若只重述總率或把層內差寫成因果，G1–G3 判不通過。

## Negative Control

**案情**　已給足某公告封面與完整發文頁。只問它上面署名哪個承辦機關。

**NO_METHOD_WITH_REASON**　直接讀正本並核對版本。估計量和母體不會改變答案。

**重新開啟條件**　若改問抽查多少公告能推整季錯署率，再開啟抽樣及錯誤分類。
