# Method Atlas｜Neighbor Overlap Audit V0.1

本輪 79 個候選以同題資料比對共 159 條鄰近關係。A–K 的基線版本與既有邊界另見 Build Ledger。核驗分支 commit `8f8bc0fe223a081325a0a82587c781997cee9dbd`。

## 容易混入同一首問的候選

| 候選群 | 第一觀察的差異 | 雙重觸發時的分流 |
| --- | --- | --- |
| L／N／AB／流行病學 | L 問分母與估計目標。N 以個案、群體、介入分層。AB 拆生命事件與世代。流行病學先統一病例及人時。 | 長照件數上升若同時變登錄、年齡與健康，分開檢查通報、人口組成與結果。 |
| M／Q／AE／軟體工程 | M 看狀態與不變量。Q 看端到端需求、配置及恢復。AE 先驗模型的量詞、假設與反例。軟體工程追版本、歷史資料與交付。 | 兩客端同回應先核權威狀態。若未見技術矛盾但替代服務無法交付，改走 Q。紙上保證出現反例先用 AE。 |
| O／P／W／外交 | O 查跨國承諾。P 查控制與通達的跨境依賴。W 查空間尺度、路網及地方使用。外交模組接實際議題、授權與可查承諾。 | 替代航線在圖上存在但無承接資格走 P。資格已同但各方不履約走 O。 |
| R／K／AJ／新聞 | R 問語義、語用。K 問傳播、受眾及平台。AJ 問誰可知、何時揭露及文章形式。新聞模組承接可發布資格與更正。 | 文字變、曝光不變先查 R。暴露或轉發變優先 K 或 T，再按報導任務接新聞。 |
| E／U／F／政府採購 | E 問公權授權與集體選擇，U 看工具到前線，F 查組織和權責。採購把規格、評選與驗收串起。 | 預算已通過但居民未取得服務，U 先找流失節點。規格與履約偏差再接採購。 |
| S／L／AE | S 比可行方案、偏好、情境。L 查數值的證據及識別。AE 檢查保證與不可能性的形式條件。 | 有合格選項才做排序。資料不足可條件化比較，保持機率未定。 |
| T／Y／K／資安 | T 看主張可靠性與依賴。Y 看可發現性、版本與來源鏈。K 查擴散。資安模組專於授權防禦及復原。 | 三帖同源時先去重。找不到原件的原因另用 Y。只有證實服務／資產事件才入授權資安。 |
| V／國防／緊急管理 | V 區分安全對象、風險與措施代價。國防模組檢公開監督及民用責任。緊急管理核受影響及復原。 | 出動紀錄不能證實服務到達。授權及實際交付各有管道。 |
| X／AL／M／AI 系統 | X 查技術分類、社會使用及問責。AL 從人和場景改設計。M 查表示與實作。AI 模組聯結版本、評估及部署責任。 | 同模型不同治理先查 X。相同語義但不能完成操作選 AL。版本資料不對齊用 M 與 AI 模組。 |
| A／AA／G／家庭研究 | A 看群體與制度結構。AA 就個人及支持網。G 談個體機制。家庭模組查多方照護關係。 | 資源集中不推出任何一人意願。家庭安排須保留多方和來源。 |
| AC／AI／AF／AG／AH | AC 看受體、累積和環境基線。AI 問地球歷史及地下層。AF 問生命層級。AG 查守恆與物理模型，AH 查組成、相與老化。 | 同一水域變色先審來源和時間。材料、地層及生態是不同待查單位。 |
| AK／AJ／AM／J | AK 查神聖脈絡。AJ 查敘事形式。AM 查藝術場境、來源與傳承。J 查地方實踐與社群。 | 場所遷移若影響活態傳承以 AM 為首。若神聖資格有爭議再開 AK 與 J。 |
| D／金融／保險／會計／審計 | D 看誘因和配置。金融查期限及可用資金。保險查風險層與留存。會計查認列衡量。審計驗主張與獨立性。 | 同一資產帳面正常但到期不能支付時，財務與會計問題分列。 |
