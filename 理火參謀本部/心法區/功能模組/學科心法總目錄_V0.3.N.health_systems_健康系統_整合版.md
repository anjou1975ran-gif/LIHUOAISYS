## Canonical Demonstration Case／Method Shift Test

**案例**　合成社區增診次但等待未下降，夜班及交通需求不可見。

**Baseline**　以資源增加判覆蓋增。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 容量與等待 | 查夜班人未覆蓋 | 若同時段再查費用 | |
| 可近與公平 | 核同源可比資料 | 若差異小仍查未使用 | |
| 品質和回饋 | 分等待與照護品質 | 若資料弱只描述 | |

**觀察轉向**　由基線轉向拆資源、服務、等待、費用和品質

**證據轉向**　服務能力、排隊、費用、結果和群體差

**因果轉向**　投入不必然轉成有效覆蓋，轉介、費用和距離居間

**盲點及邊界**　只分析證據需求。

**自審結果**　容量、可及及品質各需資料。

## Negative Control

**案件**　病人詢問個別影像診斷。

**NO_METHOD_WITH_REASON**　由有權臨床者。

**重新啟用**　若政策問多院可近性，才啟。
