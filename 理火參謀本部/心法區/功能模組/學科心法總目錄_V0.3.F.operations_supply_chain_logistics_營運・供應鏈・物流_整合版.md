## Professional Support

實際載運、危險物、安全及合約處理由物流和對應權責專業承接。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　虛構書展中央倉庫充足卻兩次補不到分館。已知補貨每週一批，週末需求高。

**Baseline**　再買更多庫存。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 事件鏈 | 查倉出貨前是否已分配 | 若早已出貨改查運送 | |
| 容量與批次 | 放週流量對照 | 若平日也缺，查轉運 | |
| 回饋與復原 | 查分館是否提前通知 | 若通知被收但沒排入解出接口 | |

**觀察轉向**　由庫存是否高轉到何處擁堵

**證據轉向**　看訂單、出入與可用容量

**因果轉向**　上游批次政策可放大下游等待

**盲點及邊界**　現場調度由權責者依安全資料。

**自審結果**　流量、佇列和反饋使建議從加庫存轉核交接。

## Negative Control

**案件**　只讀貨單上已知承運商名。

**NO_METHOD_WITH_REASON**　直接摘錄。

**重新啟用**　若要追貨還未到，查同號交接。
