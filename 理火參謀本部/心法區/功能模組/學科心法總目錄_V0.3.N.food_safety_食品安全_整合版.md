## Professional Support

食品衛生、實際產品放行、召回、就醫及稽核由有資格與授權的食品安全、衛生或醫療責任者。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成餐會供應商通報有兩批標示資料相同，但一批交接記錄缺失。用相同標籤判兩批同狀態是否可靠？

**Baseline**　按印字相同視兩批證明一致。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 批次來源 | 找兩批交接的時間 | 若不可分維持未知 | |
| 控制和查證 | 比兩批相應材料 | 若補件無獨立證據，交責任方 | |
| 責任接續 | 要求確認收件及日期 | 若未核責任不關事件 | |

**觀察轉向**　由基線轉向分品項、批次、流程、控制及查證

**證據轉向**　合規流程、批次收件及驗證與退件紀錄

**因果轉向**　缺批次或未核控制會令表面一致掩去問題

**盲點及邊界**　只分析資料，交授權食安角色。

**自審結果**　三回應分來源、控制和異常責任。

## Negative Control

**案件**　只讀包裝已核版的商家名稱。

**NO_METHOD_WITH_REASON**　依標籤，不作衛生結果。

**重新啟用**　若同名不同責任者，在食品安全案中核鏈。
