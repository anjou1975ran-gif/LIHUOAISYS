## Professional Support

正式報表、準則適用和稅務申報交具資格會計師與責任人。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成供應商本期收入升而現金不變，有跨期交付與重估。是否業務現金增加？

**Baseline**　見收入升就推現金增加。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 辨識與期間 | 先列上期與本期交付 | 若交付不變，查估計 | |
| 衡量與呈現 | 列出重估和非現金項 | 若重估不變，核分類 | |
| 勾稽與責任 | 查跨期應收調整 | 若勾稽缺初始紀錄即 HOLD | |

**觀察轉向**　從好壞轉向事件與入帳期間

**證據轉向**　查交易及分錄橋接

**因果轉向**　時點或估計造成差，不等價於現金增益

**盲點及邊界**　數字如未核版無法作正式報表。

**自審結果**　三回應分辨事件、計量與勾稽，收入無法直接推出現金。

## Negative Control

**案件**　只問董事會由誰召集。

**NO_METHOD_WITH_REASON**　用管轄法及章程，財務表述無增量。

**重新啟用**　若召集案關乎未交付報表，再進本模組。
