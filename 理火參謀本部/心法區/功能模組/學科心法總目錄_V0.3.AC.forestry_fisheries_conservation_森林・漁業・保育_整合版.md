## Canonical Demonstration Case／Method Shift Test

**案例**　虛構濕地議會接到漁獲報表下降、觀測點減少又改季節的資料。附近林帶監測只覆近路。

**Baseline**　認定資源均等下降。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 觀測努力 | 核點位及季節 | 若努力相近，查棲地 | |
| 管理單位 | 區分河口、林帶 | 若觀測範圍重疊需防重算 | |
| 回顧和責任 | 重做可比趨勢並留不確定 | 若沒有基線不作措施判定 | |

**觀察轉向**　由基線轉向拆觀測、努力量、棲地與受影響者

**證據轉向**　可重複監測、取用及用途、棲地和社群資料

**因果轉向**　取用強度和觀測變動可使表面資源指標偏離

**盲點及邊界**　限治理監測與社群同意。

**自審結果**　觀測努力、空間與週期互相驗證。
