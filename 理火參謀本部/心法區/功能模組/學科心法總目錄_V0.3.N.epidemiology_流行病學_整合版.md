## Canonical Demonstration Case／Method Shift Test

**案例**　合成步行活動一年中回報輕微扭傷增加，同時活動場次翻倍且新增手機回報。

**Baseline**　件數增加就判變危險。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 病例及口徑 | 分郵件、手機同一事件 | 若新件多為新增類別，重算 | |
| 人、地、時 | 檢每人時的方向 | 若無時數保留比較 | |
| 比較與用途 | 比較同地同類歷年 | 若無對照先描述 | |

**觀察轉向**　由基線轉向先比較定義、時間、地點和人群

**證據轉向**　持同定義的病例、風險時間和觀察量

**因果轉向**　病例定義和就醫變動產生表觀群聚

**盲點及邊界**　只是匿名群體審讀，不判健康處置。

**自審結果**　人時、口徑及同期改變各須查。

## Negative Control

**案件**　單一參加者需要正式臨床診斷。

**NO_METHOD_WITH_REASON**　由臨床責任者處理。

**重新啟用**　若要分析匿名群體事件，再回此。
