## Professional Support

照護處遇、臨床、危機及保密均交具責任者。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成住民轉到社區照護，書面轉介完成但首週沒有支援。

**Baseline**　把發送視為到位。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 需求與偏好 | 確認是否有接駁及其它支持 | 若已備妥查排程 | |
| 交接 | 索取同日時戳和承辦標記 | 若收到全部，再查容量 | |
| 續用與改正 | 核首週是否有人到 | 若有人到但選擇不續，復核目標 | |

**觀察轉向**　由基線轉向分照護需求、交接、可提供時間與回饋

**證據轉向**　受權需求、交接收件、服務實際時間

**因果轉向**　跨專業責任不清可製造照護空窗

**盲點及邊界**　只查協調，個案服務由責任者。

**自審結果**　需求確認、紀錄和可用容量三方把關。

## Negative Control

**重新啟用**　若實際無法進入服務，再查責任。
