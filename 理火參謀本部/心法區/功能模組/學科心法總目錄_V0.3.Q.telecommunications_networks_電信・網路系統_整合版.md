## Canonical Demonstration Case／Method Shift Test

**案例**　合成交通到站看板白天正常，晚尖峰延遲，經營者報核心平均不變。

**Baseline**　依平均速度判沒有問題。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 服務分段 | 查尖峰末段 | 若末段正常找轉接 | |
| 負荷和品質 | 比相同數端點 | 若共同延遲但使用少，查服務端 | |
| 互通與恢復 | 核看板與真實班次 | 若差仍在，保留事件 | |

**觀察轉向**　由基線轉向分端點、接續、承載、呼叫體驗及範圍

**證據轉向**　經授權端點品質、各段時窗與告警

**因果轉向**　一段平均效能佳仍可因同時使用及分段依賴劣化

**盲點及邊界**　只分析已授權運行材料。

**自審結果**　接入、互連、端點三處各需驗證。
