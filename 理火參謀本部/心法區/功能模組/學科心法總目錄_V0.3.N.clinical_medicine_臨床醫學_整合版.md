## Professional Support

具體健康和急迫性、診療、照護安全由合格臨床人員承接。 這裡交付待查問題、材料需求和責任接口。現場或個案判斷另依權責與有效規範。

## Canonical Demonstration Case／Method Shift Test

**案例**　合成門診品質演練。當事人在兩個時點描述不同，轉送文件只擷取第一段。要如何避免把摘要當結論？

**Baseline**　由最早一句定狀態。

| 方法 | 回應 | 反證 |
| --- | --- | --- |
| 病程與脈絡 | 留兩時點和來源 | 若原來都是轉述則無新事實 | |
| 待查與替代 | 列應移交補缺 | 若資料不支持保持未判 | |
| 知情與追蹤 | 給責任人兩段原記錄 | 若採新摘要需鎖版本 | |

**觀察轉向**　由基線轉向先區分自述、所見、時序和待核

**證據轉向**　由專業取得的病史、觀察、檢查及追蹤

**因果轉向**　多個原因可能產生同一表現，照護時序及資料可更新

**盲點及邊界**　沒有臨床行動指示。

**自審結果**　分病程、證據及後續責任，保留可反查條件。

## Negative Control

**案件**　資料只比較兩館跌倒率的分母。

**NO_METHOD_WITH_REASON**　以流行病學或統計查群體，臨床個案無增量。

**重新啟用**　若有個人照護時程才用。
