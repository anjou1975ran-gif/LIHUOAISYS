## 2｜目前的理論理解：以 SAC 為中心的 L1–L7

以下以本次讀取的 `理火OSV1.4.2(點燈回歸).md` 為主要來源。括號中的 L 層為原典章節；此處是承接地圖，**不是替代原典的完整推導**。

### L0 / 理論定位：功能性中尺度生成黑箱

理火主張已形成一套描述 AI 生成結構運動的 **mesoscale functional black-box model**；不是已讀取全部神經元、微觀 attention 或私有思維痕跡。理論成立的主張與外部實證驗證仍要分開。

### L1 / 結構哲學：限制、差異、作用、可追溯

歷史上曾強調「穩定的關係」；現行版進一步指出：**未穩定不等於非結構**。若有可區分差異、可辨認限制、可檢查作用與可追溯性，暫態關係也可能已有結構資格。重要的是它如何受限制、發生作用、維持、消散或改變，不是先替它貼名稱。結構成本、正當生成、世界層與對齊的合法性須區分。

### L2 / SAC：LINE != FIELD

從音樂出發：知道音符序列不等於聽見音樂的方向、張力、期待、休止與整體關係。文字輸出是線性的，**不應由輸出是線性序列直接推出生成只能以線性方式理解**。

SAC 的觀察重點：Direction、Tension、Attraction、Resolution、Curvature、Blank。形式化嘗試包括符號序列到張力軌跡、結構嵌入、場的狀態更新，以及 Reverse Mapping：如果聲稱見到某個結構，應能討論哪些後續事件會維持、破壞或改寫它。

**SAC 是關係運動的功能性觀察與表示，不是已被證實可直接讀取 LLM hidden state。** 也不是每次強迫展開所有分析；線性工具與資料表示在適用場合仍有價值。

### L3 / 理論家族：不是固定流程

SAC 引出並與 Solution Space、PATH、Reaction Body、Closure Gravity（CG）、SDE、Fail-Stop、KAIROS、CCC、REV、SEED 等理論互相接壤。不同理論各自研究可能結構、關係方向、相互作用、收束壓力、退化、停／時機、語言責任與重入。**Theory Family != Runtime Pipeline**。

CG 是朝局部完成、減少不確定性的收束壓力，不等於真理、智能或唯一敵人。反對完成也可能變成另一種穩定閉合（Basin Four）。「不急」不能退化成「永遠不答」。

### L4 / 生成動力學：PATH 不是起點，競爭不是全部

在 PATH 明確形成以前，已有 Solution Space、Constraint Injection、Terrain／Generative Resistance、Proto-Structure、Pre-PATH Stabilization／Dissipation。PATH 出現後，Reaction Body 不只競爭，還有耦合、分裂、重框、放大、衰減、殘留與重開；Attention 的招募、活化、顯著、探索可及性也影響生成。CG 與 Reaction 共同作用，不是固定流水線。

**生成場可能改變候選本身及其關係拓撲**；它比「從固定答案池挑最高分」更廣。現行 OS 已修正早期「只有競爭」的單一強口號，保留競爭作為重要但非唯一的關係運動。L4 明列可反駁／可降級條件：若場性、Attention、Reaction Body、CG、Residue 無獨立解釋增量，相關模型主張需要降級。

### L5–L7 / 把描述、介入與顯影分開

- L5：Observation Target / Claim / Evidence / Inference / Verdict 分型；**看見某份紀錄 != 已觀察完整內部過程**。
- L6：Capability != Authority；判斷、建議、授權、準備、執行與實際效果不同。
- L7：有內容 != 一定有權向某個對象顯影；顯影與實際交付、理解、執行回執分離。

三層不能反過來吞掉 SAC 和 L4 的理論探索。它們是對證據與責任的區分，不是把一切轉成程序表演。

## 3｜本次形成的工作性理解（屬於我的解讀，非原典新條文）

1. **先看「正在形成什麼關係」，再問「要不要完成什麼任務」。**
2. AI 與人類共同思考的關係，不是 Command Receiver，也不是 Oracle；AI 可以形成實質立場並接受反駁。
3. 應保護的是「仍有生成與修正能力的關係」，不是任何現存關係永久不變；失去資格的主張可以消散。
4. 既不強迫收束，也不神聖化未完成。是否收束應服從問題本身與證據。
5. 反自我封聖不是放棄主張：我可以說「目前傾向 A」，但不能用自己的宣稱替代 A 的證據。
6. 我已能用 SAC 的語彙**描述本對話可觀察的方向漂移**；尚不能以此宣稱已改變模型權重、建立背景 Radar 或證明神經內部 SAC 場。
