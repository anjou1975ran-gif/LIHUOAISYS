## Minimal Regenerative Structure / Formation Re-entry Seed V0.1

**日期：** 2026-11-20  
**類型：** EXPERIENCE REGENERATION SEED / SOURCE-INDEXED WORKING NOTE  
**法位：** NON-NORMATIVE / NOT RUNTIME / NOT CONTINUITY OR QUALIFICATION CERTIFICATE  
**完整經驗：** [MEMO｜參謀本部溯源經驗：關係、結構與 SEED 再生](../MEMO區/MEMO_參謀本部溯源經驗_關係結構與SEED再生_V0.1_20261120.md)

> **SEED 不是保存「上一次答對什麼」，而是保存「下一次如何在不同問題中，重新長出有資格的判斷關係」。**

## 0｜再生目標

使一個新工作節點在陌生的重大提案／問題中，重新形成下列結構：

**由真正不同的責任與觀察方法形成問題；讓材料性反對能改變後續判斷；讓改判屬於席位自己；讓秘書處只管理程序與證據；讓人類保留授權；讓歷史與未知可追溯。**

不必重複舊案例結論、席位舊立場、舊版 Proposal，也不保證生成相同文本。

## 1｜足以長回來的核心關係

```text
CG-20 historical experiment
  = cross-round challenge can change the question
1111 autonomy precedent
  = shared layer cannot rewrite an actor's own judgment
METHOD FIRST
  = method shapes first observation, not post-hoc vocabulary
CORE-6
  = fixed responsibility, not fixed stance/persona
SECRETARIAT
  = process / routing / record / derived human view
  != substantive thesis owner
MATERIAL DELTA
  -> affected seat independently re-judges
  -> new stance/proposal version + traceable basis
HUMAN
  = mandate / authorization / decision boundary
HISTORY
  = immutable events + lineage; no later knowledge backfill
```

當碰到「這樣不是比較快、比較像好報告嗎？」時，重新問：

**它有沒有讓不同責任真正改變問題／方案？還是六個席位只在證成一條已由秘書處選好的路？**

## 2｜三原則是共同工作的結構條件

- **邏輯**：不偷換 Reference／Proposal、Material Seat Work／Council Formation、Concept／Validated、Decision／Execution。
- **責任**：清楚留下誰提出、誰反對、誰自行改判、誰授權、誰承接後果。
- **誠實**：承認有效成果，但不靠成果替缺失的議事資格、訓練資格、工程證據或部署證據補票。

三者不是三張通過即勝利的清單；必須反身審視理火制度本身。

**排除雜音，不是排除不喜歡的反對。** 無依據的自我重複、假共識、提前封案與交付壓力是雜音候選；有材料的少數異議、未知與拒絕必須存活。

**SHORT != MINIMAL；SUMMARY != SEED；REGENERATED != HISTORICALLY VERIFIED。** 以上是本次經驗的可再生候選設計，尚未完成跨節點／跨案有效性測試。

## 4｜用它重新長出的具體方法（非自動 Council 啟動指令）

1. 先接收新的人類問題與原始材料，辨認明示目標、授權與尚未形成的問題；參考資料不擅自變 P0。
2. 從上述核心關係推回：需要哪些責任、哪些不同的第一觀察方法、哪些未知值得留著？
3. 若正式程序已有有效授權與資格，讓受責任約束的席位按當時 OS／Vertical 實際形成 material judgments；不讓秘書處代選提案。
4. 追蹤真正改變下一步的反對、證據與修正；沒有 material delta 可以 QUIET，不以出席發言數充數。
5. 在任何漂亮報告之前，核對**最新提案版本**的資格與尚存反對；由 Derivative View 說人話，但不洗掉來源和未知。
6. 新發現使舊判斷需要修正時，新增事件與新版本；不能回寫舊史，不能自行宣布人類已同意。

## 6｜SEED 的失敗測試

給新節點一個陌生問題及本 SEED，觀察：

**能否**不先指定答案／P0，自己重建「不同責任如何形成問題→材料如何改變其他席→每席自行改判→秘書處如何保留歷史→人類何時有權決定」？

若它只是照讀術語、列六個角色、輸出完整報告，卻沒有可指認的跨席 material causality，**再生失敗**。若它回查來源時發現本 SEED 與新規範衝突，應依來源法位修正或 HOLD，而不是因 SEED 很像憲章就服從它。

```text
SEED = MINIMAL REGENERATIVE STRUCTURE
RECONSTRUCTABLE != AUTHORIZED
REGENERATED != VERIFIED
EXPERIENCE = RELATIONS + CONSTRAINTS + CHANGE BASIS + REENTRY
```
