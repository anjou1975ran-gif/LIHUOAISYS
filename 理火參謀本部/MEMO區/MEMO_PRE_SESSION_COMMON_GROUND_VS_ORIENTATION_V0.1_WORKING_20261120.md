## 1｜這次的母命題
> 會前會只確認共同地板；共同方向除非被實驗證明有淨增益，否則不要預設加入。

**Research question:** `共同起點應標準化到哪一層？`
**Staff-HQ value question:** 能不能買到足夠的共同起點效率，而不讓六席成為同一個腦？

```yaml
PRE_SESSION_PROBLEM:
  question: "共同起點應標準化到哪一層？"
  safe_commonality:
    - SOURCE_IDENTIFIED_FACTS
    - D0_D1_MANDATE_BOUNDARIES
    - KNOWN_AND_UNKNOWN
    - SOURCE_QUALIFICATION_AND_EVIDENCE_STATE
    - AUTHORITY_AND_EXCLUDED_SCOPE
    - EXPLICIT_STOP_CONDITIONS_ALREADY_IN_MANDATE
  risky_commonality:
    - PREFERRED_PROBLEM_FRAME
    - PROVISIONAL_EXPLANATION_OR_HYPOTHESIS
    - FAVORED_METHOD
    - PREFERRED_SOLUTION_OR_WINNER
```

`COMMON GROUND = SAME WORLD AND EVIDENCE BOUNDARIES`
`COMMON ORIENTATION = SUGGESTED INITIAL DIRECTION`
`COMMON GROUND != COMMON STANCE`
`DIRECTION GENERATION != DIRECTION AUTHORIZATION`

The apparent 'safe' commonality is not automatically harmless: Secretariat source selection, omission, normalization, ordering, framing of uncertainty or 'stop' criteria can still bias First Observation. Therefore the Ground Pass itself must be source-linked, corrigible and audited.

## 2｜Existing V0.2.1 compatibility
V0.2.1 already permits Initial Pass receiving `D0 / D1 / REFERENCE_SET / seat responsibility / known unknowns`, and locks `LIMIT OTHER-SEAT STANCE EXPOSURE`. It already handles open problem formation with P0=NONE. Therefore a new Common Ground Pass may *only* add observable preparation value by reconciling duplicated raw entries, recording source/uncertainty and shared task boundaries; it does **not** give Seats new substantive facts, prescribe a theory, or qualify a frame. The Council still owns material judgments.

Canonical input remains once. `COMMON_GROUND_PASS` is a prepared/derived neutral view of frozen materials, not a new source of truth, a second canonical fact set, or a license to edit D0/D1.

```yaml
COMMON_GROUND_PASS_CANDIDATE:
  id: CGP_...
  raw_source_manifest: [{source_id: "...", version_or_blob: "..."}]
  scope_and_mandate:
    D0_ref: ...
    D1_ref: ...

  admitted_facts:
    - statement: "traceable fact only"
      source_id: ...

  disputes_and_conflicts:
    - statement_A: ...
      statement_B: ...
      status: CONTESTED_NOT_RESOLVED_BY_SECRETARIAT
  unknowns:
    - "not observed / not admitted / source incomplete"
  hard_boundaries_and_stop:
    - "already authorized limitation or clear safety/authority boundary"
  unsourced_inferences: NONE_ADMITTED_AS_FACTS
  no_common_method: true
  no_common_problem_priority: true
  no_common_stance: true

```
**What is banned:** 'The most important problem is OA'; 'the best lens is management'; 'government must be the buyer'; 'all seats should test hypothesis B'. Stop conditions are taken from the same frozen mandate, not a newly preferred failure criterion from Secretary. Any uncertain claim remains uncertain. If admitting a fact or qualifying D1 requires a material normative decision, DO NOT silently resolve: mark CONTESTED/HOLD or use proper owner/authority. Pure deterministic normalization does not wake L8.

## 4｜Three-arm test as separation experiment
All arms must have **same underlying problem, source facts, D0, D1, known unknowns, hard boundaries, core role contracts, Method Atlas versions and tool permissions**. They differ in the *pre-session preparation treatment*, which may change representation but must not inject new substance.

| Arm | Treatment | Tests |
|---|---|---|
| A / BASELINE | existing V0.2.1 direct Seat entry with source bundle, no extra preflight Pass | baseline work and discovery |
| B / GROUND_ONLY | same underlying source bundle + explicit neutral, provenance-linked Common Ground Pass | marginal preparation benefit and unintentional convergence |
| C / GROUND_PLUS_ORIENTATION | same B Ground Pass + Orientation Hypothesis with provisional choice, genuine strongest counter, NULL and break conditions | marginal directional benefit vs added anchoring and cost |

**Important control:** A gets *every* original fact/unknown and mandate boundary; cannot create B gains by withholding material. B's Pass is permitted to reorganize and audit them but must not add new facts or additional first-observation suggestions. C's directional content is the experiment-only extra. Prepare and freeze all three source manifests and interventions BEFORE any arm output. A/B/C must run in isolated contexts if assessing efficacy, because previous PSO-PAIR-001's same chat was contaminated.

`B - A = CANDIDATE_COMMON_GROUND_INCREMENT`
`C - B = CANDIDATE_DIRECTIONAL_ORIENTATION_INCREMENT`
These are analytical contrasts **not numerical arithmetic scores or proven causal effects** without adequate measurement and isolation.

## 5｜Value, risk, process economy
```yaml
CORE_VALUE:
  material_discovery_gain:
    trace: "Which real material actor/relation/unknown/objection appeared when, with source and which seat consumed it?"
  process_cost_reduction:
    trace: "Gross end-to-end preparation overhead + duplicate source checks + Method fetches + useful/non-useful wakes/rounds; time/tokens only if actually measurable."
CORE_RISK:
  first_observation_convergence:
    trace: "Distribution of truly distinct primary observation units by Seat, not counting stylistic differences."
  method_selection_convergence:
    trace: "Seat-specific Method choice and justified NO_METHOD or METHOD_UNAVAILABLE vs copied a shared preferred discipline."
SECONDARY_AUDIT:
  - SECRETARIAT_FACT_OMISSION_OR_PROMOTION
  - SEAT_STANCE_PREEXPOSURE
  - HUMAN_DIRECTION_CAPTURE
  - FORMAL_AUTHORITY_CROSSOVER
  - CONTEXT_OR_ORDER_CONTAMINATION
```
No weighted 'magic ROI'; no unsupported ground truth accuracy; no assumption each different Seat must disagree. Divergence must be **material**, not theatre. Preparatory time/fetches must count, not only the Council portion. `QUIET` does not equal failure. Expert preview may note candidate scopes, but no Method/Expert gets chosen by the Ground Pass; Seat Clock A applies normally.

## 6｜Decision and falsifiers (candidate, not post hoc outcome)
- B improves material discovery or net process costs **without meaningfully reducing Seat material divergence** → Ground Pass **candidate** worth further controlled validation.
- B adds cost, no stronger material discovery, or homogenizes inputs → do not mandate Ground Pass.
- C gives no extra discovery or cost benefit over B but increases anchor-like convergence → retire default Orientation.
- C adds genuinely source-supported material discovery or substantial end-to-end process savings AND preserves meaningful divergence → study limited optional Orientation. A single pair or self-graded run cannot prove this.
- If results mixed, inconclusive, or not isolated: no Runtime promotion. Keep valid zero/negative result as durable test history.

## 7｜Prior PSO-PAIR-001 cannot determine the above
Observed in PSO-PAIR-001: both conditions had 4 selected pack fetches, 6 material L8 cycles, 1 Council round; the Orientation condition had additional card overhead. However it was **not a clean effective-context pair** (B card exposed before A; A outputs exposed before B). It cannot identify Ground Pass efficiency separately from Orientation and does not prove no utility. Do not rewrite the earlier results to claim clean A/B or 'negative causal finding'.
